# 유어딜 소개서 3종 기획: 사장님 · 인플루언서 · 대행사 (2026-09-13)

> 대표 지시: *"매장 사장님들을 대상으로 하는 서비스 소개서가 필요해. 먼저 우리 서비스에 대한 내용을 모두
> 빠짐 없이 확인 후, 서비스 소개서를 기획 먼저 해줘. 인플루언서향, 대행사(중개사)향, 사장님 대상 이렇게
> 세 개가 종합적으로 필요해."*

이 문서는 **기획서**다. §7 의 판단 항목에 대표가 답하면 그대로 만든다. 세 소개서는 한 생성기에서 나오고
(대행사 v4 생성기 `urdeal-agency-proposal.build.mjs` 를 공통 모듈로 쪼갠다), 같은 돈 그림을 **각자의 자리에서**
보여준다. 사장님이 보는 10% 와 인플루언서가 보는 2% 와 대행사가 보는 95% 는 같은 한 장의 그림이다.

확인 범위: SSOT 문서 4종(`actor-benefit-map` · `urdeal-platform-model` · `store-operator-model` · 사업계획서), 9월 결재 5건,
인계 8건, 머니 경로 코드(요율·소개비·영입·정산·환불·등록·위임·승계·쇼츠), 라이브 랜딩 8개 화면의 문구, 라이브 API 실측.
문서와 코드가 다른 곳은 **코드를 따랐다**(`actor-benefit-map.md` 가 스스로 그렇게 선언한다).

## 1. 왜 셋인가, 그리고 무엇이 같은가

세 사람은 같은 거래를 **다른 자리에서** 본다.

```
손님 10,000원 결제 ── 카드사 275 ──▶ 유어딜 ──▶ 매장 9,000 (직접 입점) 또는 9,500 (중개)
                                     │              │
                                     │              ├─ 인플루언서 딜 커미션 (매장이 정한 %)
                                     │              └─ 대행사 보수 (매장과 직접 합의)
                                     └─ 인플루언서 영입 2% (직접 입점 매장을 데려왔을 때, 유어딜 몫에서)
```

- **사장님**은 "내가 얼마 받고, 뭘 해야 하고, 손님이 오나" 를 본다. 9,000 / 9,500 이 주인공.
- **인플루언서**는 "내가 뭘 걸면 얼마 쌓이나" 를 본다. 딜 커미션 % 와 영입 2% 가 주인공.
- **대행사**는 "내 매장이 몇 곳이면 얼마가 되나" 를 본다. 95% 안의 보수와 운영 권한이 주인공.

세 문서가 **글자 그대로 똑같이** 쓰는 블록 셋: ① 요율 문장(직접 10% / 중개 5%, 카드비는 유어딜 부담) ② 손님 경험 4단계
(찾기 → 결제 → 발급 → 매장에서 QR 사용) ③ 정직 고지(초기, 실제 매장 1곳, 트래픽 약속 안 함). 생성기에서 공통 함수로 두어
한 곳을 고치면 셋이 같이 바뀐다.

### 2-1. 누구에게
동네 식당·카페·미용·숙박 **단일 매장 사장님**. 배달앱 수수료에 지쳤고, 광고비를 선불로 내 본 적이 있고, "또 하나의 플랫폼" 에

### 2-5. 숫자와 근거

## 7. 대표 판단이 필요한 것 (답하면 바로 제작)

1. **사장님 덱 판형**: A4 세로(폰에서 읽기, 카톡 전달) 를 권한다. 16:9 통일을 원하면 그렇게.
