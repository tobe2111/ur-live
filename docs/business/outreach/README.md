## 2. 이메일 발송 규칙 — `outreach-cold.ts` 의 값을 그대로 쓴다

레포의 `send-cold` 경로는 `RESEND_API_KEY` 가 비어 있어 라이브에서 쓸 수 없다(2026-11-09 실측). 그래서 **대표 지메일(urteam.corp@gmail.com, Gmail MCP)** 로 보내되, 그 경로가 코드로 강제하던 것을 **세션이 똑같이 지킨다**:

1. **제목에 `(광고)`** · 본문 끝에 **수신거부 안내 줄 + 전송자 정보 줄**(`outreach-send.ts` 의 `OPT_OUT_LINE` · `SENDER_INFO_LINE` 과 같은 문구).
2. **야간 금지** — KST 21:00~08:00 발송 안 함(`isNightKST`). 예약 작업은 10시.
3. **하루 상한 20통**(코드 상한 200 보다 훨씬 보수적 — 매장이 채워지기 전이라 대표가 "일단"이라 했다).
4. **대상**: `status='new'` · `contacted_at IS NULL` · 이메일 보유 · `opted_out=0` · `is_brand=0` · `email_status` 가 bounced/complained 아님 · `consented_at IS NULL` · `outreach-queue.ts` 의 노이즈 이름 제외 · **개인 메일 도메인**(gmail/naver/daum/kakao/hanmail) 우선. 유튜브는 구독자 5천~30만 · 최근 평균 조회 3천 이상.
5. **보낸 직후** `POST /api/admin/ads/influencer-pool/mark-contacted {ids, channel:'email'}` 로 기록한다 — 안 하면 다음 날 같은 사람에게 또 간다.
6. **재발송 금지 30일**(`COLD_COOLDOWN_DAYS`). 기록이 있으면 mark-contacted 가 거른다.
7. **수신거부 답장**("수신거부"·"그만"·"보내지 마세요")이 오면 `PATCH /influencer-pool/:id {opted_out:1}` 로 즉시 제외. 반송(mailer-daemon)은 `email_status='bounced'`.
8. **반송·신고가 최근 발송의 8% 를 넘으면 멈춘다**(`COLD_BOUNCE_MAX_PCT`). 지메일 발신 평판은 되돌리기 어렵다.

⚠️ 정보통신망법 §50 의 사전동의 미비 리스크는 남는다(2026-07-28 `outreach-cold.ts` 헤더에 고지 기록). 공개된 **비즈니스 문의용 주소**에만, 소량·개인화로 보낸다.

### Resend 키 설정 (대표 10분 — 세션·지메일 의존을 없애는 길)
1. resend.com 가입 → Domains 에 `urdeal.kr` 추가 → 안내하는 DNS 레코드(SPF·DKIM) 를 Cloudflare DNS 에 추가 → Verified.
2. API Keys 에서 키 생성(Sending access).
3. Cloudflare → Workers & Pages → `ur-live` → Settings → Variables and Secrets → `RESEND_API_KEY`(secret) + `RESEND_FROM`(예 `유어딜 <hello@urdeal.kr>`) 추가 → 재배포.
4. 그 뒤 세션에 "Resend 켰어" 라고 알리면, 발송 작업을 레포 경로(`POST /api/admin/ads/influencer-pool/send-cold`)로 바꾼다 — 반송·수신거부가 DB 에 자동 기록되고 이 세션이 없어도 돈다.

## 6. 더 튼튼하게 만들려면 (대표 선택)
지메일 경로는 세션에 묶여 있다. 레포에는 이미 **같은 규칙이 코드로 박힌 발송 경로**가 있다 — `POST /api/admin/ads/influencer-pool/send-cold`(`outreach-cold.ts`: (광고) 표기·수신거부·야간 금지·1일 200·30일 쿨다운·반송 회로차단·접촉 기록 자동). 막힌 건 하나, Cloudflare 의 `RESEND_API_KEY` 가 비어 있다(세션은 플랫폼 쓰기를 하지 않는다 — CLAUDE.md ☁️ 절). 대표가 Resend 키를 넣으면(발신 도메인 `urdeal.kr` 인증 포함) 예약 작업을 그 엔드포인트 호출로 바꿔 **세션·지메일 의존을 없앨 수 있다**. 그때는 새 세션형 예약 작업으로도 된다(어드민 API 만 쓰므로).
