## A-5. 핵심 차별점 (Why 유어딜)
1. **링크샵 = 진짜 내 쇼핑몰** — `/u/{handle}` 하나로 브랜드가 남는다. 배달·예약앱처럼 "플랫폼 안 리스트"가 아니라 **내 주소·내 상품·내 고객**.
2. **능력이 레이어로 쌓임 (역할 stack)** — 유저→사업자 유저로 신분 교체 없이 기능만 추가. 한 계정에서 판매·추천·영입 수익이 **동시에** 붙는다.
3. **추천 경제 내장** — 모든 상품이 잠재 어필리에이트 상품. 인플루언서·일반 유저가 "+"로 담아 추천 → **소비자가 곧 마케팅 채널**(광고비를 커미션으로 전환).
4. **판매되는 만큼만 — 가입비·월 고정비 0** — 리스크 없는 입점. 안 팔리면 비용 0.
5. **팔수록 수수료 인하 (등급제)** — 월 매출이 오르면 등급 진급 → **수수료율 하락**. 성장할수록 유리.
6. **무료 CRM·알림톡 크레딧** — 고객관리·알림톡 인프라를 무료 제공(가입 시 크레딧).
7. **매장 QR/PIN 사용처리** — 온라인 할인 판매 → 매장에서 바로 사용. 매장원장·정산검문으로 정합.
8. **자동·투명 정산** — 플랫폼 수수료·원천징수·환불 커미션 역전까지 자동. 세금계산서 연동.
9. **하이퍼로컬 노출** — 동네딜 지도·행정동 태깅으로 내 주변 고객에게 노출.
10. **카톡·검색 유입 (SEO/OG)** — 링크샵·상품 공유 시 서버측 OG 카드 + 네이버/구글 SEO. 6개 언어.

# Part C — 입점·협업 제안서 (Merchant & Agency)

## 🏪 C-1. 매장 입점 제안 — "리스크 없이 내 쇼핑몰을 여세요"

### 왜 유어딜에 입점하나 (핵심 5)
1. **판매되는 만큼만 5% · 가입비/월정액 0** — 안 팔리면 비용 0. 부담 없이 시작.
2. **내 쇼핑몰(링크샵)** — `/u/{handle}` 내 주소·내 브랜드. 카톡 공유하면 내 매장 카드가 뜬다(OG). 인스타·블로그 프로필 링크로 딱.
3. **인플루언서·유저 추천 유입** — 내 상품이 누군가의 링크샵에 추천으로 걸리면 자동 유입. **내가 광고 안 해도 팔린다**.
4. **매장 QR/PIN 사용처리** — 온라인 할인 판매 → 손님이 매장에서 QR/PIN 제시. POS 없이 스마트폰으로.
5. **무료 CRM + 알림톡 크레딧** — 재구매 유도·단골 관리 인프라 무료(가입 크레딧).

| 💸 낮은 수수료 | 3P 5% / 유어딜 직판 0%. **팔수록 등급 진급 → 수수료 인하**. |

## 🤝 C-2. 에이전시 협업 제안 — "매장을 모아 성장시키고, 지속 수익을 받으세요"

1. **지속 수익(리커링)** — 영입한 매장의 **매 결제마다** 커미션(기본 1%, 최대 24개월). 한 번 영입하면 반복 수익.
2. **운영 자동화 도구 一式** — 아래 도구가 대시보드에 내장. 엑셀 대신 시스템으로 다수 매장 관리.
3. **매장 매칭 제안** — 시스템이 성장 가능 매장을 추천(`agency-match-suggestions`) → 영입 효율↑.
4. **투명 정산·자동 인보이스** — 관리 매장 매출 rollup + 월간 리포트/인보이스 자동 생성.

### 에이전시가 얻는 것
- **리커링 커미션**(영입 매장 GMV %·24개월) + **성장 기여 보너스**(월간).
- **관리 규모 = 수익**: 매장을 많이·잘 성장시킬수록 rollup 매출↑.
- **등급/티어 평가**로 우수 에이전시 우대(`agency-tier-eval`).

### 협업 시작
카카오 로그인 → 에이전시 승인 → 매장 영입/매칭 → 운영·성장 → 자동 정산. 제휴 문의: **jiwon@ur-team.com**.

## C-3. 자주 묻는 질문 (이의처리)
- **정말 수수료 5%뿐? 숨은 비용은?** → 판매 3P 5%가 기본, 가입비·월정액 없음. 결제 PG 수수료는 통상 결제사 기준. 요율은 계약·등급·어드민 설정에 따름.
- **재고를 넣어야 하나?** → 이용권/할인권은 무재고 발행 가능. 실물 상품만 재고 관리.
- **정산은 언제?** → 판매 성숙(hold) 후 자동 지급. 이용권은 매장 사용/발송 확인 게이트.
- **기존 배달·예약앱과 뭐가 다른가?** → 링크샵으로 **내 브랜드·내 고객**이 남고, 추천 유입 + 낮은 수수료 + 팔수록 인하.
- **세금계산서/원천징수는?** → 세금계산서 연동, 커미션 지급 시 원천징수 자동 처리.
