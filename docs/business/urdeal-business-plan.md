# Part A — 회사소개서 (Company Profile)

## A-1. 한 줄 소개
> **유어딜은 "누구나 자기 쇼핑몰(링크샵)을 갖고, 추천만으로도 수익을 내는" 소셜 커머스 플랫폼입니다.**
> 소비자는 이용권·교환권·동네딜을 할인가에 발견·구매하고, 사업자는 링크샵을 자기 매장으로, 인플루언서는 추천으로, 에이전시는 매장 성장으로 수익을 만듭니다.

## A-2. 회사 개요
| 항목 | 내용 |
|---|---|
| 운영사 | 리스터코퍼레이션 |
| 서비스 브랜드 | 유어딜 (소비자) · 유통스타트 (B2B 도매) · 유어애즈 (마케팅) |
| 도메인 | `live.ur-team.com` (유어딜) · `utongstart.com` (유통스타트) |
| 설립 / 대표 / 소재지 | [[채워넣기: 법인 설립일 · 대표자 · 주소 · 사업자등록번호]] |

| 연락처 | [[채워넣기: 이메일 · 전화 · 채용/제휴 창구]] |

## A-3. 미션 · 비전
- **미션**: 온라인 판매의 진입장벽을 0으로 — 카카오 로그인 5분이면 누구나 자기 쇼핑몰과 판매·정산을 시작한다.
- **비전**: 소상공인·창작자·소비자가 **하나의 링크샵 경제**로 연결되어, 추천·판매·소비가 서로의 수익이 되는 로컬 커머스 네트워크.

## A-4. 서비스 3축
1. **🎟️ 유어딜 공구 (소비자)** — 이용권(식사·미용·숙박·액티비티)·기프티콘 교환권·내 주변 동네딜·공동구매·쇼핑. 딜포인트/간편결제(토스).
2. **🏭 유통스타트 (B2B 도매몰)** — 제조사→판매사 도매 거래(도매가·예치금·정산). 무재고 위탁·OEM·사입.
3. **📣 유어애즈 (마케팅)** — 매장/셀러 대상 광고·자동입찰·부정클릭 방지·통합 실적·AI 마케터.

## A-5. 핵심 차별점 (요약)
- **링크샵 단일화**: 누구나 `/u/{handle}` 하나로 자기 쇼핑몰. 유저→사업자 유저로 **능력이 레이어로 쌓임**(신분 교체 없음).
- **추천 경제 내장**: 어느 상품/공구든 "+"로 내 링크샵에 담아 추천 → 구매 시 커미션. 인플루언서·일반 유저 모두 수익화.
- **하이퍼로컬 동네딜**: 지도 기반 내 주변 딜 + 매장 QR/PIN 사용처리.
- **다중 서비스 시너지**: 소비 유어딜 ↔ 공급 유통스타트 ↔ 확산 유어애즈가 한 계정/한 코드베이스에서 연결.
- **투명·자동 정산**: 플랫폼 수수료·원천징수·커미션 역전(환불)까지 자동. 신뢰(사업자 인증·전자상거래법 표시).

# Part B — 사업계획서 (Business Plan)

## B-1. 시장 · 문제 (Problem)
- **소상공인/매장**: 자사몰 구축·운영은 비싸고 어렵다. 배달·예약 앱은 수수료가 높고 "내 브랜드"가 안 남는다.
- **창작자/인플루언서**: 팔로워는 있는데 수익화 수단(커머스 연동·정산)이 파편화돼 있다.
- **소비자**: 진짜 할인·내 주변 딜을 한 곳에서 발견·신뢰하기 어렵다.
- **시장 규모**: [[채워넣기: 국내 로컬커머스/기프티콘/공동구매/소셜커머스 TAM·SAM·SOM 근거자료]]

## B-2. 솔루션 (Solution)
- **링크샵 = 5분 쇼핑몰**: 카카오 로그인 → (사업자면) 인증·승인 → 상품/이용권 등록 → `/u/{handle}` 공유. 결제·정산·QR 사용처리 내장.
- **역할 stack 경제**: 판매(−수수료) + 추천(어필리에이트) + 영입(매장 유치 커미션)이 **동시에 적립**. 한 사람이 여러 수익축.
- **발견→전환 루프**: 링크샵/블로그/공구 상세의 SSR·OG로 카톡·검색 유입 → 추천 어트리뷰션 → 구매 → 정산.

## B-3. 타겟 고객 (5부류)
| 부류 | 핵심 Job | 유어딜이 주는 가치 |
|---|---|---|
| 일반 유저 | 딜 발견·구매·가벼운 추천 | 할인·딜적립·친구추천 수익 |
| 인플루언서 | 팔로워 수익화 | 추천 커미션 + 매장 영입 커미션 |
| 매장 업주 | 본인 상품 판매 | 내 쇼핑몰(링크샵)·낮은 수수료·현금정산·QR |
| 에이전시 | 매장 관리·성장 | 관리 매장 GMV 커미션·시한부 배분 |
| 유어딜 운영 | 거래 최대화 | 다면 마켓 take rate |

## B-4. 비즈니스 모델 · 수익 구조 (요율=현재 기본값·어드민 조정)
| 수익원 | 방식 | 기본값 |
|---|---|---|
| **판매 수수료** | 3P(남의 상품·이용권/쇼핑) 매출의 % / 1P(유어딜 직판) 0% | **3P 5%** |
| **후원 수수료** | 후원(도네이션) 금액의 % | **15%** |
| **딜포인트 충전** | 1원=1딜(수수료 0) — PG 변동비 흡수용 고액 패키지 유도 마진 | 구조 마진 |
| **광고(유어애즈)** | 매장/셀러 광고비·자동입찰 | [[채워넣기: 광고 단가/모델]] |
| **도매(유통스타트)** | 도매 거래 정산·예치금 | [[채워넣기: 도매 take]] |
| (성장 비용) | 어필리에이트 **2%**·매장영입 인플루언서 **1.5%**/에이전시 **1%(24개월)** — CAC 성격 | 조정 가능 |

> **원천징수**: 커미션 지급 시 사업소득 3.3% / 기타소득 8.8%. **최소 후원** 500딜.

## B-5. 성장 전략 (Growth Loops)
1. **추천 루프**: "+"핀 → 링크샵 → 공유 → 어트리뷰션 → 구매 → 커미션 → 더 많은 추천.
2. **영입 루프**: 인플루언서·에이전시가 매장 영입 → 매장 매출마다 지속 커미션 → 공급 확장.
3. **초대 루프**: 초대 링크 → 피초대자 첫 구매 시 양쪽 보상.
4. **수요신호 루프**: 소비자 커뮤니티 공구 제안 → 확정 → 없던 상품을 시장이 끌어옴.
5. **SEO/공유 루프**: 서버측 OG·JSON-LD로 카톡·네이버·구글 유입 → 재유통.

## B-6. 경쟁 우위 · 해자 (Moat)
- **단일 링크샵 정체성** + **역할 stack**: 경쟁사는 판매자/창작자/소비자 앱이 분리. 유어딜은 한 계정에 능력이 쌓여 **전환·리텐션·LTV** 유리.
- **공급×수요×확산 3서비스 시너지**: 유통스타트(공급)–유어딜(수요)–유어애즈(확산)의 데이터/트래픽 루프.
- **정합성 엔진**: claim-before-credit·멱등·환불 역전 대칭 등 **머니 정합 자동 방어선 42종** — 스케일 시 신뢰/CS 비용 우위.
- **하이퍼로컬 데이터**: 동네딜 지도·행정동 태깅.

## B-7. 유닛 이코노믹스 (구조 — 수치는 채워넣기)
- 거래 1건 기여이익 = 판매수수료(3P 5%) + 광고/도매 take − PG 변동비(~2.5%) − 커미션(어필리에이트/영입) − 운영변동비.

# Part C — 입점제안서 (Merchant · Partner Proposal)

## C-1. 왜 유어딜인가 (한 장 요약)
> **"내 쇼핑몰을 5분 만에, 낮은 수수료로, 추천까지 붙여서."**
> 카카오 로그인 → 사업자 인증 → 상품/이용권 등록 → `유어딜.com/u/내주소` 공유. 결제·정산·매장 QR 사용처리·마케팅까지 한 번에.

## C-2. 입점 혜택
| 혜택 | 내용 |
|---|---|
| 🏪 **내 쇼핑몰(링크샵)** | `/u/{handle}` 단일 주소가 내 매장. 본인 상품이 주인공, 카톡 공유 최적화(OG 카드). |
| 💸 **낮은 수수료** | 판매 수수료 기본 **5%**(유어딜 직판은 0%). 배달·예약앱 대비 경쟁력 [[채워넣기: 비교표]]. |
| 💳 **간편결제·정산** | 토스 간편결제 + 자동 정산(성숙 후 현금 지급). 세금계산서 연동. |
| 🎟️ **이용권/QR 사용처리** | 온라인 할인 판매 → 매장에서 QR/PIN으로 사용. 매장원장·정산검문. |
| 📣 **마케팅(유어애즈)** | 광고·자동입찰·부정클릭 방지로 노출 확대. |
| 🤝 **에이전시·영입 지원** | 에이전시가 입점·운영·성장 지원(선택). 인플루언서 추천으로 자연 유입. |
| 🏭 **도매 소싱(유통스타트)** | 무재고 위탁·도매가 사입으로 상품 확장. |
| 🌐 **다국어·SEO** | 6개 언어 UI + 서버측 SEO로 검색/소셜 유입. |

## C-3. 입점 대상
- **오프라인 매장**(식당·카페·미용·숙박·액티비티): 이용권·동네딜.
- **온라인 셀러**: 자사 상품 쇼핑.
- **인플루언서/창작자**: 추천·영입 수익 + (원하면) 자기 상품.
- **에이전시**: 다수 매장 관리·성장 파트너.
- **제조사(유통스타트)**: B2B 도매 공급.

## C-4. 입점 절차 (온보딩)
1. **가입/로그인**: 카카오 5분.
2. **사업자 인증**: 셀러 대시보드(`/seller/business-info`)에서 사업자등록번호·대표자·주소·통신판매업신고번호 입력 + 국세청 진위확인.
3. **승인**: 관리자 검토(1–2 영업일, 국세청 일치 시 자동). 앱 알림·알림톡 안내.
4. **상품/이용권 등록**: `/seller/products/new`·`/seller/meal-voucher/new` (이미지·옵션·위치·목표 설정).
5. **공유·판매·정산**: 링크샵 공유 → 판매 → 자동 정산.

## C-5. 정산·수수료 안내 (기본값·어드민 조정)
- 판매 수수료 **3P 5%** / 1P 0%. 정산 성숙 후 현금 지급, 이용권은 매장 사용/발송 확인 게이트.
- 커미션 수령(인플루언서/에이전시) 시 원천징수(3.3%/8.8%). 세부 요율은 계약/어드민 설정에 따름.

## C-6. 지원 · 문의
- 운영 가이드(`/seller/guide`), 관리자 CS, 알림톡 안내. 제휴/입점 문의: [[채워넣기: 창구]].
