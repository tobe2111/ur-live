## A-5. 핵심 차별점 (Why 유어딜)
1. **유어샵 = 진짜 내 쇼핑몰** — `/u/{handle}` 하나로 브랜드가 남는다. 배달·예약앱처럼 "플랫폼 안 리스트"가 아니라 **내 주소·내 상품·내 고객**.
2. **능력이 레이어로 쌓임 (역할 stack)** — 유저→사업자 유저로 신분 교체 없이 기능만 추가. 한 계정에서 판매·추천·영입 수익이 **동시에** 붙는다.
3. **소개 경제** — 인플루언서·유저가 "+"로 담아 소개하면 **소비자가 곧 마케팅 채널**. 소개비는 **매장이 제안한 딜**에만 붙어(제안서의 % · 매장 부담) 매장이 비용을 통제한다 — 플랫폼이 일괄 뿌리는 어필리에이트는 2026-08-22 종료.
4. **판매되는 만큼만 — 가입비·월 고정비 0** — 리스크 없는 입점. 안 팔리면 비용 0.
5. **팔수록 수수료 인하 (등급제)** — 월 매출이 오르면 등급 진급 → **수수료율 하락**. 성장할수록 유리.
6. **무료 CRM·알림톡 크레딧** — 고객관리·알림톡 인프라를 무료 제공(가입 시 크레딧).
7. **매장 QR/PIN 사용처리** — 온라인 할인 판매 → 매장에서 바로 사용. 매장원장·정산검문으로 정합.
8. **자동·투명 정산** — 플랫폼 수수료·원천징수·환불 커미션 역전까지 자동. 세금계산서 연동.
9. **하이퍼로컬 노출** — 동네딜 지도·행정동 태깅으로 내 주변 고객에게 노출.
10. **카톡·검색 유입 (SEO/OG)** — 유어샵·상품 공유 시 서버측 OG 카드 + 네이버/구글 SEO. 6개 언어.

# Part C — 입점·협업 제안서 (Merchant & Agency)

## 🏪 C-1. 매장 입점 제안 — "리스크 없이 내 쇼핑몰을 여세요"

### 왜 유어딜에 입점하나 (핵심 5)
1. **판매되는 만큼만 5% · 가입비/월정액 0** — 안 팔리면 비용 0. 부담 없이 시작.
2. **내 쇼핑몰(유어샵)** — `/u/{handle}` 내 주소·내 브랜드. 카톡 공유하면 내 매장 카드가 뜬다(OG). 인스타·블로그 프로필 링크로 딱.
3. **인플루언서·유저 추천 유입** — 내 상품이 누군가의 유어샵에 추천으로 걸리면 자동 유입. **내가 광고 안 해도 팔린다**.
4. **매장 QR/PIN 사용처리** — 온라인 할인 판매 → 손님이 매장에서 QR/PIN 제시. POS 없이 스마트폰으로.
5. **무료 CRM + 알림톡 크레딧** — 재구매 유도·단골 관리 인프라 무료(가입 크레딧).

| 🧾 무재고 이용권 | 재고 없이 할인권만 발행 가능(식당·미용 등). |

### 입점 절차 (5분 시작)
1. 카카오 로그인 → 2. 사업자 인증(`/seller/business-info`, 국세청 진위확인) → 3. 승인(1–2 영업일, 일치 시 자동) → 4. 상품/이용권 등록 → 5. 유어샵 공유·판매·정산.

## 🤝 C-2. 중개사(대행) 협업 제안 — "매장을 모아 운영하고, 매장에게서 받으세요"

> 🌇 **2026-09-04 전면 개정.** 이 자리에 오래 *"영입 매장 GMV 1%·24개월 리커링 + 에이전시 전용 대시보드
> (매칭 제안·인센티브·캠페인·쿠폰·PK배틀·멤버·캘린더)"* 라고 적혀 있었습니다. **그 대시보드는 존재하지
> 않았고(관계 0건), 2026-09-04 에 코드에서 삭제됐습니다.** 아래가 실제 모델입니다.

### 구조 — 유어딜은 중개사에게 지급하지 않습니다
| | 유어딜이 떼는 것 | 매장이 갖는 것 |
|---|---|---|
| 매장이 **직접 입점** | 10% | 90% |
| **중개사가 데려와 운영** | **5%** | **95%** |

- 낮은 요율(5%)은 **매장에게 여유를 드리는 것**입니다. 유어딜이 중개사에게 주는 돈이 아닙니다.
- **중개사 보수는 그 95% 안에서 매장과 직접** 정합니다 — 금액·방식·기간 모두 두 분의 계약입니다.
- 그래서 유어딜 정산서에 중개사 지급은 **한 줄도 나오지 않습니다.** 유어딜이 중간에서 떼지 않습니다.

### 중개사가 쓰는 도구 (별도 대시보드가 없습니다 — 셀러 대시보드 그대로)
| 도구 | 경로 |
|---|---|
| 🏪 여러 매장 운영·전환 | `/seller/stores` — 운영을 맡은 매장 사이를 오갑니다 |
| 👥 운영 권한 | `/seller/operators` — 매장 사장님이 운영자를 추가/회수합니다(언제든, 조건 없이) |
| 🎤 인플루언서 섭외 | `/seller/influencers` · `/seller/influencer-deals` — 소개 딜을 제안·수락 |
| 💸 소개비 지출 내역 | `/seller/promo-spend` — 매장 사장님도 **항상** 직접 볼 수 있습니다(투명성) |
| 🎟️ 이용권 등록·정산 | 셀러 대시보드의 상품·주문·정산 화면 전부 |

### 중개사가 얻는 것
- **매장 몫이 5%p 더 큽니다** — 그 여유가 중개 비용의 재원이 됩니다.
- **운영 도구가 이미 있습니다** — 매장마다 따로 계정을 파지 않고 한 로그인으로 오갑니다.
- **관계는 권한 한 줄** — 사장님이 직접 이어받을 때 계정 양도가 아니라 권한 변경입니다.

### 협업 시작
카카오 로그인(셀러) → 매장 등록/운영 권한 부여 → 이용권 운영·인플루언서 섭외 → 매장과 정산.
제휴 문의: **jiwon@ur-team.com**.

⚠️ 운영자 권한의 **세부 범위**(정산계좌·사업자정보 열람 여부)는 설계 확정 중입니다 —
`docs/design/store-operator-model.md` §7.7.

## C-3. 자주 묻는 질문 (이의처리)
- **정말 수수료뿐? 숨은 비용은?** → 매장 직접 등록 10% / 중개사 경유 5%(2026-08-20 대표 확정), 가입비·월정액 없음. 결제 PG 수수료는 통상 결제사 기준. 요율은 계약·등급·어드민 설정에 따름.
- **재고를 넣어야 하나?** → 이용권/할인권은 무재고 발행 가능. 실물 상품만 재고 관리.
- **정산은 언제?** → 판매 성숙(hold) 후 자동 지급. 이용권은 매장 사용/발송 확인 게이트.
- **기존 배달·예약앱과 뭐가 다른가?** → 유어샵으로 **내 브랜드·내 고객**이 남고, 추천 유입 + 낮은 수수료 + 팔수록 인하.
- **세금계산서/원천징수는?** → 세금계산서 연동, 커미션 지급 시 원천징수 자동 처리.
