# 카카오 로그인에서 번호·알림 동의까지 받기 — 콘솔 설정 순서

> 2026-11-04 대표 *"카카오 로그인 시 알림 설정이랑 받을 수 없나? 최대한 받으면 좋겠는데"* → *"응 해줘. 다"*
> 코드는 전부 **꺼진 채로** 들어가 있다. 아래 순서대로 콘솔을 마친 **뒤에** 스위치를 켠다.
> ⚠️ 콘솔 설정 전에 스위치를 켜면 카카오가 로그인 자체를 거부한다(KOE205) — 모든 손님 로그인이 막힌다.

지금(라이브 실측): 동의 화면 = 이메일 · 닉네임 · 프로필 사진뿐. 번호·알림 동의·채널 추가 없음.

## 0. 공통 — 비즈 앱 전환 (한 번만)
1. developers.kakao.com → 내 애플리케이션 → 유어딜 앱
2. 앱 설정 → 비즈니스 → **사업자 정보 등록**(사업자등록증) → 비즈 앱 전환

## ① 휴대폰 번호 (효과 가장 큼 — 번호 입력 창이 안 뜨게 된다)
1. 제품 설정 → 카카오 로그인 → **동의항목** → "카카오계정(전화번호)" → 설정
2. 동의 단계: **필수 동의** 권장(선택이면 거절한 손님은 번호 창이 대신 받는다) · 목적: "예약 확인·이용 안내 발송"
3. **검수 신청** — 며칠 걸린다. 승인 메일 확인
4. 승인 뒤 Cloudflare Pages(ur-live) 환경변수 `KAKAO_PHONE_SCOPE_ENABLED = true` → 재배포
   - 효과: 로그인 때 번호가 들어온다. 기존 회원도 다음 로그인 때 비어 있던 번호가 채워진다(있던 번호는 안 덮는다).
   - 대가: 로그인 때 카카오를 한 번 더 부른다(약 0.2~0.3초).

## ② 카카오톡 채널 추가 (할인·이벤트 소식 채널)
1. 카카오톡 채널 관리자센터 → 유어딜 채널 → **비즈니스 채널 전환**
2. 개발자 사이트 → 앱 설정 → 비즈니스 → **카카오톡 채널 연결** → 유어딜 채널 · 대표 채널 지정
3. 동의항목 → "카카오톡 채널 추가 상태 및 내역" → **선택 동의**
4. 환경변수 `KAKAO_CHANNEL_ADD_ENABLED = true` → 재배포
   - 효과: 동의 화면에 "유어딜 채널 추가" 체크가 뜬다. 체크하면 가입과 동시에 채널 친구.

## ③ 마케팅 정보 수신 동의(선택) 약관
1. 카카오싱크 사용 신청(비즈 앱 필요)
2. 카카오 로그인 → 카카오싱크 → **약관 관리** → 약관 추가
   - 서비스 이용약관(필수) · 개인정보 수집·이용(필수) · **마케팅 정보 수신(선택)**
   - 각 약관의 **태그**를 적어 둔다(예: `service_v1`, `privacy_v1`, `marketing_v1`)
3. 환경변수
   - `KAKAO_SERVICE_TERMS = service_v1,privacy_v1,marketing_v1` (동의 화면에 띄울 태그, 쉼표)
   - `KAKAO_MARKETING_TERM_TAG = marketing_v1` (그중 마케팅 약관 태그)
4. 재배포
   - 효과: 손님이 체크하면 우리 동의 기록(`terms_agreements` marketing)에 남는다. 체크 안 하면 아무것도 안 남긴다(번호 창의 선택 동의와 겹치지 않게).

## 켠 뒤 확인
- 새 카카오 계정으로 가입 1건 → 동의 화면에 항목이 뜨는지 · 번호가 들어왔는지(번호 창이 안 떠야 정상)
- 문제가 생기면 해당 환경변수를 지우고 재배포하면 오늘 상태로 돌아간다.
