# 유어쇼츠 구매 바에 흰 카드가 없었다 — 스케일 밖 불투명도 (2026-09-16)

`[E2]` 검증됨(tsc 0 · 관련 유닛 115 pass · pre-push 게이트 96개 · 주입 5건 되돌려-검증 빨간불).
라이브 판정(E4)은 배포 후 `/videos` 에서 눈으로.

## 대표 신고

> *"유어쇼츠 왜이래? 밑에 이용권 카드? 섹션도 지금 엉망이고 왜이런거야"* (스크린샷 동봉)

스크린샷에서 상품명·가격이 영상 위에 **맨살로** 떠 있고 유튜브 Shorts 워터마크와 겹쳐 있었다.
`구매` 버튼만 파란 알약으로 혼자 떠 있어서 대표가 *"이용권 카드?"* 라고 물음표를 붙였다 —
**그게 카드로 안 읽혔다는 뜻이고, 실제로 카드가 없었다.**

## 원인 — `bg-white/97` 은 클래스가 **생성되지 않는다**

Tailwind 불투명도 스케일은 `0 5 10 … 95 100` 이고 **97 이 없다.** 스케일 밖 값은 임의값
대괄호(`bg-white/[.97]`)로 써야 생성된다. 그냥 `/97` 이면 그 클래스는 CSS 에 존재하지 않는다.

브라우저 실측(로컬 렌더 + 라이브 데이터):

```
getComputedStyle(bar).backgroundColor === 'rgba(0, 0, 0, 0)'   ← 배경이 아예 없다
```

빌드도 타입체크도 `videos-buy-bar.test.ts` 15건도 **전부 초록**이었다. 그 이유가 이 건에서
제일 값지다 — **기존 검사는 전부 글자와 배치만 봤다.** "그 글자가 읽히는 바닥이 있는가" 는
아무도 안 봤다. `#1385`(첫 판)부터라 **이 바는 한 번도 배경을 가진 적이 없다.**

## 영구 가드 — `scripts/check-tailwind-opacity-scale.mjs`

이 레포가 반복해 당한 **"실패가 아니라 조용한 부재"** 의 또 한 판이라 클래스로 막았다.

- 스케일을 **하드코딩하지 않는다** — `tailwindcss/defaultTheme` + config 의 `theme.extend.opacity`
  에서 읽는다(스케일을 넓히면 가드가 자동으로 따라간다).
- 대괄호 임의값(`bg-white/[.97]`)·CSS 변수는 정상이라 통과.
- **측정 대상 400건 미만이면 통과가 아니라 실패** + 매 실행 합성 대조(양성·음성).
  현재 925개 수식어 / 2,106파일 검사.
- 등록: `verify.yml`(strict) · `audit-gate`(112번째 불변식) · `docs/AUDIT_INVARIANTS.md`.
- 주입 매니페스트 `scripts/mutations/opacity-scale.mjs` 5건 — **전부 빨간불 확인**.

⚠️ **못 잡는 것**: 런타임 조립(`` `bg-white/${n}` ``) · 스케일 안이지만 의도보다 흐린 값 ·
불투명도 아닌 다른 스케일 밖 값(`p-7.5`). 예외 `opacity-scale-ok`.

## 대표 판단이 필요한 것 (내가 임의로 안 바꿨다)

- **구매 바가 유튜브 Shorts 워터마크를 덮는다.** 바가 투명한 동안엔 워터마크가 비쳐 보였는데,
  이제 카드가 생기면서 가린다. `VideosPage.tsx` 주석이 *"유튜브가 남기는 제목 띠·🔗·Shorts 로고를
  가리는 것은 embed 약관 위반"* 이라며 **우리 X 버튼을 비켜 준 전례**가 있다(2026-09-13).
  다만 구매 바는 대표가 "안 B" 로 확정한 이 화면의 본체라 **레이아웃을 임의로 안 옮겼다.**
  옮긴다면 바를 워터마크 위로 올리는 것뿐인데 영상을 더 가린다.
- 유어쇼츠 7편 중 **이용권이 붙은 건 1편**이다. 나머지 6편은 구매 바가 아예 안 뜬다(설계대로).
