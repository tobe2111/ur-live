# 수집 키워드 순환 — 몫을 "슬롯"에서 "한 바퀴 시간"으로 (2026-08-05)

## 경보와 진단

경보: *"한 바퀴 3.8일인데 가장 밀린 키워드가 3.9바퀴째 순번을 못 받음(라운드로빈이 깨진 상태)"*

**먼저 배제한 것 — 라운드로빈은 안 깨졌다.**
- 커서는 `prefixDone`(**처리된 연속 접두**)만큼만 전진한다. 처리 못 한 픽은 다음 회차가 정확히 이어받는다.
  (2026-08-03 에 leapfrog 를 고친 그 코드가 지금도 유효하다.)
- 같은 날 머지한 **저수율 솎아내기(#1060)도 원인이 아니다** — 밀린 키워드는 `nb_measured=0` 이라
  `isLowRotationYield` 의 증거 하한(40)에 못 미쳐 애초에 솎아내기 대상이 아니다.
- 밀린 게 아니라 **`last_run_at IS NULL` — 한 번도 안 돈** 키워드였다(59개).

**진짜 원인: 몫이 풀 크기를 안 본다.** 회차 16픽이 이렇게 갈렸다.

| 축 | 풀 | 슬롯 | 키워드당 | 한 바퀴(계획 기준) |
|---|---|---|---|---|
| 집중(마케팅대행사) | 19 | 4 | **0.211** | 5회차 |
| 우선(맛집·숙소·뷰티·네일…) | 315 | 9 | 0.029 | 35회차 |
| 일반(골프·여행…) | 65 | 3 | 0.046 | 22회차 |

**집중 축 키워드가 우선 축보다 7배 자주 돌았다.** 라이브가 정확히 그 모양:
마케팅대행사 19개 중 **18개가 24h 내 실행** ↔ 숙소 19개 중 **12개 미실행·24h 0개** · 골프 6개 **전부 미실행** ·
외식창업 18개 중 6개 미실행. 여기에 **계획 16 vs 처리 6**(예산 51/56)이 곱해져 실제 한 바퀴는 약 2.7배.

⚠️ **이 구조는 스스로 나빠진다** — 맛집에 키워드를 더 넣으면 아무도 규칙을 안 바꿨는데 숙소가 굶는다.
고정 비율은 풀이 커질수록 작은 축을 **상대적으로 빠르게** 만든다.

## 처방 — `AXIS_ROTATION_MULTIPLIER`

몫 ∝ (그 축 가용 키워드 수) × (배수 3:2:1). 그러면 **한 바퀴 시간 ∝ 1/배수** 가 되어 풀 크기와 무관해진다.
대표가 정한 축 우선순위는 **표현만 바뀌고 그대로 보존**된다("집중 25% 슬롯" → "집중이 3배 자주 돈다").

- 바닥 1슬롯: 순수 비례면 6슬롯 회차에서 집중(19)이 0.45 → **매 회차 0**. 정책이 아니라 반올림이
  전략 축을 끄는 걸 막는다.
- 죽은 상수 `FOCUS_SHARE` 제거 — 아무것도 지배하지 않는 채 남으면 다음 세션이 정책으로 오독한다.

## 다음 세션의 첫 액션

배포 24시간 뒤 **한 번도 안 돈 키워드가 줄었는지**로 판정한다.

```sql
SELECT category, COUNT(*) n, SUM(CASE WHEN last_run_at IS NULL THEN 1 ELSE 0 END) never,
       SUM(CASE WHEN last_run_at >= datetime('now','-1 day') THEN 1 ELSE 0 END) d1
  FROM ad_discovery_keywords WHERE active=1 GROUP BY category ORDER BY n DESC
```
**판정선**: `숙소`·`골프`·`외식창업` 의 `d1` 이 0 을 벗어나면 성공. 기준선(오늘) — 숙소 never 12/19·d1 0 ·
골프 6/6·d1 0 · 외식창업 6/18·d1 0 · 마케팅대행사 never 0·d1 18.
⚠️ 마케팅대행사 `d1` 이 18 → 6~8 로 **내려가는 건 정상**이다(7배 → 3배). 그게 이 변경의 대가다.

## 안 한 것 (보고만)

- **계획 16 → 예산 6 정렬**: 안 했다. 과계획 자체는 안전하다(커서가 처리분만 전진). 문제는 *보고*가
  거짓이 되는 것(경보의 "한 바퀴 3.8일"도 16 기준이라 실제와 다르다). 고칠 자리는 계획이 아니라 계측이다.
- `ADS_COLLECT_KEYWORD_CAP` env 로 회차 픽 수가 16 으로 올라가 있다 — 되돌릴지는 대표 판단(세션은 env 미변경).
