## 2) "AI 같다"의 정체 — 라이브 `/group-buy/2888` 실측

`scripts/visual-preview.mjs` 에 실제 2888 데이터(`/api/group-buy/products/2888`)를 넣어 렌더해 봤다.
문제는 모양보다 **내용**이었다:

| # | 무엇 | 근거 |
|---|---|---|
| ① | 같은 할인을 한 화면에 **세 번** | `34%` · `25,000원` 취소선 · 하단 바 `8,500원 할인 중` |
| ② | "딜 안내" 3줄이 **하드코딩** | `['즉시 교환권 발급','전 지점 사용', …]` — 상품과 무관하게 항상 같다 |
| ③ | 그중 **"전 지점 사용"은 거짓** | 2888(홍대돈까스)은 **전주 단일 매장**. 손님이 다른 지점서 못 쓰면 분쟁 |
| ④ | 그 셋을 아래 `UsageGuide`(이용 안내)가 **이미** 말함 | 같은 표가 한 페이지에 두 번 |
| ⑤ | 섹션 사이 8px 회색 띠 4개 | 표면 규칙은 "표면 두 톤"인데 띠가 세 번째 톤 |
| ⑥ | 할인율만 `--gbd-danger`(#F23E4D) | 2026-09-07 대표 확정 SSOT 는 `--sale`. 목록 10곳은 이미 `--sale` → **같은 상품이 목록·상세에서 다른 빨강** |

지갑(`/my-vouchers`)은 가진 이용권을 **전부 펼친 티켓**으로 그렸다 — 8장이면 훑는 데만 네 번 스크롤.

## 4) 이번에 틀렸던 판단 (다음 세션이 같은 오판을 안 하도록)

1. 🩸 **"한 화면에 카드 3종류"라고 대표에게 보고했는데 정확하지 않았다.**
   `KtAlphaVoucherCard`·`WalletArchive` 는 `my-vouchers/` 폴더에 있지만 실제로는
   **`/my-gifticons`(교환권 지갑)** 가 렌더한다. `/my-vouchers` 는 이미 전부 `TicketCard` 였다.
   두 페이지는 2026-08-31 에 분리됐다 — **폴더 위치로 렌더 위치를 단정하지 말 것.**
   (`VoucherTicket` 은 `v.source === 'kt_alpha'` 일 때만 옛 카드로 위임한다.)
2. 🩸 **"빨강이 세 개"도 절반만 맞았다.** 지갑의 `#DC2626` 은 `--sale` 과 **같은 값**을
   하드코딩한 것이었다(값이 아니라 토큰화가 문제). 진짜로 값이 갈린 건 `#16A34A` vs `--tone-ok`(#0F7B45)
   와 상세의 `--gbd-danger`(#F23E4D) 다.
3. 🩸 **`--gbd-danger` 를 `--sale` 로 보내려다 멈췄다** — `src/index.css:1168` 에 *"일부러 안 보낸다,
   이쪽은 빨간 **면** 위 흰 글자라 대비 기준이 다르다"* 는 경고가 있다. **토큰은 그대로 두고
   할인율 렌더 한 곳만** `--sale` 로 옮겼다.
4. 🩸 **내 테스트 앵커가 공유 문구를 잡았다.** `formatNumber(unitPrice)` 는 카카오 공유 텍스트에
   **먼저** 나온다 — 가격 블록을 앵커하지 않으면 엉뚱한 줄을 검사한다(헬퍼가 경고한 함정).
5. 🩸 **되돌려-검증이 헛도는 가드 하나를 잡았다.** "접힌 줄을 누르면 QR 이 열린다" 가 **호출부만**
   보고 있어, `WalletRow` 안에서 `onClick={() => {}}` 으로 바꿔도 초록이었다 → 부품 배선을 추가로 고정.
6. 🩸 **주석 안의 hex 가 가드를 빨갛게 만들었다.** `stripComments` 는 **한 줄에서 닫히는** 블록주석만
   지운다 — 여러 줄 주석에 `#DC2626` 을 적으면 hex 스캐너가 잡는다. **주석에 hex 를 적지 말 것.**
7. 🩸 **내 편집이 기존 주입 2건을 낡게 만들었다**(`>딜 안내</div>` 앵커 소멸, description margin 변경).
   CLAUDE.md 교훈 그대로 — *"가드가 붙은 코드를 고쳤으면 그 파일의 기존 주입까지 돌려 볼 것."*
