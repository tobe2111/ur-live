# 인계 — 배너 미디어 업로드 + 마감임박 줄 제거 (2026-08-04)

대표 지시: **"남은 일 2번 빼고 하자, 4번은 아예 필요없어"**
(2번 = 모바일 홈 → 안 함 / 3번 = 히어로에 진짜 이미지·영상 → 함 / 4번 = 마감임박 줄 → **제거**)

## 3번 — 배너에 파일을 직접 올릴 수 있게

**왜 필요했나**: 배너 폼이 **URL 입력칸만** 있었다. 즉 대표가 어딘가에 파일을 올려 URL 을 구해
와야 히어로를 채울 수 있었고 — 그건 사실상 "못 쓴다"는 뜻이다. 히어로를 만들어 놓고
채울 방법을 안 준 셈이었다.

- `BannerMediaUpload` (신규) — 이미지/영상 공용. URL 직접 입력도 그대로 가능.
- **영상은 어드민 전용 엔드포인트** `POST /api/upload/banner-video` (`requireAdmin`).
  ⚠️ 공용 `/upload/image` 에 영상 MIME 을 열면 **모든 셀러가 영상을 올릴 수 있게 된다**
  (rate-limit 100/10분 · 10MB) — 그래서 갈랐다. 공용 `ALLOWED_MIME` 에 video 유입 금지를 테스트로 고정.
- 매직바이트 검증(`ftyp` / EBML) — 확장자만 믿지 않는다.
- 상한 10MB(안내는 5MB 이하 권장 — 홈 최상단이라 클수록 첫 화면이 느려진다).
- 화면에 **"올린 뒤 저장 버튼을 눌러야 반영됩니다"** 명시 — 안 적으면 올리고 나가서 "왜 안 됐지"가 된다.

## 4번 — '오늘 마감 임박' 줄 제거

시드에서 제외했다. 규칙(`deadline`) 자체는 살아 있어 어드민에서 언제든 다시 만들 수 있다.
⚠️ **라이브 DB 의 시드 행(id 3)은 별도로 지워야 한다** — 시드 버전이 이미 1 로 저장돼 있어
코드만 고쳐도 기존 행은 안 사라진다. 어드민 `/admin/home-sections` 에서 삭제하면 된다.

## 다음 세션의 첫 액션

1. 위 ⚠️ — 라이브에서 '오늘 마감 임박' 섹션 삭제(어드민 화면에서 클릭 한 번)
2. 배포 후 `/admin/banners` → 히어로 자리 선택 → **영상 파일 올리기** → 저장 → 홈 확인
   (모바일 사파리에서 재생되는지도 — `muted`·`playsInline` 은 넣었지만 실기기가 유일한 판정)
