# 2026-10-08 — 지갑 머리글의 장수 제거 (대표 "굳이 없어도 될 것 같아")

## 무엇을 했나

지갑(`/my-vouchers`) 머리글이 `88,900 원 · 3장` 이라고 적고, **40px 아래** 탭 배지가
`사용 가능 3` 으로 **같은 `unusedItems.length`** 를 또 말하고 있었다.
대표가 렌더를 보고 *"굳이 없어도 될 것 같아"* → *"진행해줘"*.

- `MyVouchersPage.tsx` — `countText` prop 한 줄 제거(머리글은 **금액만**)
- `my-vouchers/WalletHeader.tsx` — 쓰는 데가 없어진 `countText` prop 제거
- `wallet-and-slop.test.ts` — 단언을 **지우지 않고 재조준**
- `scripts/mutations/wallet-count-once.mjs` — 주입 2건 신설

## 불변식이 어디로 옮겨갔나

| | 전 | 후 |
|---|---|---|
| 장수를 말하는 곳 | 머리글 **+** 탭 배지 (2곳) | 탭 배지 **한 곳** |
| 가드가 지키는 것 | "머리글에 장수가 있어야 한다" | "머리글엔 없고, 탭 배지엔 있어야 한다" |

**두 방향을 다 막는다** — 머리글에 되살아나도(중복), 탭 배지가 사라져도(0곳) 빨간불.
0곳을 막는 쪽이 특히 중요하다: 머리글에서 뺀 뒤로 탭 배지가 **유일한** 자리다.

## 이번에 값을 치르고 배운 것

🩸 **거리로 앵커를 잡으면 주석만 써도 깨진다.** 기존 단언
`/<WalletHeader[\s\S]{0,600}eyebrow=/` 가, 내가 그 사이에 설명 주석을 넣자 **실제로 빨간불**이
났다. 결함이 아니라 **주석이 길어진 것**이 원인이다. ⇒ 거리 앵커는 쓰지 말고, 쓸 수밖에 없으면
`stripComments(…)` 한 코드만 보게 할 것(이 파일은 그렇게 고쳤다).

⚠️ 이 테스트는 원래 **원문**(`R(...)`)을 읽는다. 내가 추가한 단언들만 주석 제거본을 본다 —
`not.toMatch(/countText=/)` 같은 "없어야 한다" 단언은 주석에 그 낱말이 남아 있기만 해도
조용히 실패하기 때문이다.
