## 무엇이 바뀌었나

### ① 히어로 (`HomeHeroDefault` / `HomeHeroBanner` / `PcHomePage` / `PcHomeLocationBar`)
- 검색 폼 **제거**(헤더 2행 개편으로 46px 대형 검색바가 생겨 중복). 위치·지도 칩을 히어로 안으로 흡수.
- `PcHomePage` 의 **위치바 흰 패널(145px) 삭제** · `PcHomeMapButton.tsx` **파일 삭제**(참조 0).
- `PcHomeLocationBar` 에 `tone="hero"` — 잉크 색면 위 반투명 흰 칩. **드롭다운 패널은 흰색 유지**(지역 목록 가독성).
- 🔴 **히어로는 이제 `HOME_SHOWCASE_ENABLED` 게이트 밖**이다. 칩이 여기 말고는 없어서, 플래그를 끄면
  지역 선택·현 위치·지도 진입이 홈에서 통째로 사라진다. 플래그는 ①섹션·③배너만 지배한다.
- `HomeHeroBanner` 는 이제 **레이아웃을 갈아 끼우지 않는다** — 콘텐츠 소스(사진/카피/영상)만 고르고
  렌더는 `HomeHeroDefault` 한 벌. 이전엔 배너를 올리는 순간 위치 칩이 사라지는 구조였다.

### ② 이용권 상세 (`GroupBuyDetailPage` / `DetailTitleHeader`(신규) / `DealPurchaseBox` / `DetailGallery` / `pricing.ts`(신규))
- PC: 제목 헤더(매장명 · h1 · ★평점 · 주소 · 전화)를 갤러리 **위**로. 모바일 블록은 `lg:hidden`.
- PC 대형 사진 1장짜리 `1/1` → **`16/9`**(정사각은 800px 를 먹었다). 모바일 스와이프는 1:1 그대로.
- 구매 패널에 **가격 헤드라인**(-N% pill → 판매가 → 정가 취소선). PC 본문 가격 블록은 `lg:hidden`.
- 🐛 **실제 결함 수리**: 같은 상품이 **홈 카드엔 `-26%`, 상세엔 할인 표시 없음**이었다
  (실측 id 2846, 32,000→23,800). 카드는 `max(선언 할인율, 정가 대비 계산값)`, 상세는
  `current_discount_pct`(티어 파생, 이 상품은 0)만 봤다. → `derivePricing()` SSOT 신설.
  **결제가(`unitPrice`)는 서버 할인율로만 계산** — 표시 폴백을 섞으면 이중 할인이 된다(테스트가 고정).
  배지·SEO·카톡 공유 `discountRate` 도 같은 값으로 통일.

### ③ /map (`RestaurantMapPage` / `MapTopBar`)
- `MapTopBar` 에 `variant`: `overlay`(모바일, `lg:hidden`) / `panel`(PC 좌측 400px 리스트 헤더).
- **마크업은 한 벌** — props 도 `topBarProps` 하나로 spread. 두 벌이면 칩 하나 추가할 때 갈린다.
- 패널에서는 칩이 **줄바꿈**(400px 에서 가로 스크롤이면 '기타'가 잘려 안 보이고, 잘린 줄 모른다).
