대표: *"유어딜 마이페이지에서 앱 정보 부분에 지금 디자인? 너무 별로야. 그냥 줄글로 보여주면 되는데
굳이 여기도 이렇게 보여줄 필요는 없는 것 같아. 시안 보여줘봐."* → 시안 3안 제시 → **"안 2"** 확정.

## 무엇이 어긋나 있었나

종전엔 `[섹션 라벨 "앱 정보" + 흰 카드 + 구분선 3줄]` 이었다. **문제는 카드 자체가 아니라 바로 위와의
낙차다** — 그 위는 이미 11px 잔글씨(`고객센터 / 공지사항 / 이용약관`, `평일 10:00~18:00 응대`)인데
거기서 갑자기 카드가 섰다.

그리고 그 세 줄 중 **행동이 있는 줄은 하나**(최신 버전 확인)이고, 그 행동은 **새 버전이 있을 때만**
의미가 있다. ⇒ 95% 의 시간 동안 빈 무게였다.

**이건 취향 문제가 아니라 이미 정해 둔 규칙이다**(CLAUDE.md 🎫 표면 규칙):
- ⑥ **"섹션 라벨 0"** 이 `앱 정보` 라벨을 금지한다.
- ③ **"숫자가 주인공"** — 이 자리엔 주인공이 될 숫자가 없다.
- 이 파일의 2026-09-02 주석도 대표 지시를 *"버전 표기는 찾을 수 있으면 되는 정보"* 로 적어 뒀는데,
  카드는 찾을 수 있게 하는 것을 넘어 **보라고** 말하고 있었다.

## 안 2 (확정)

```
평소                              새 버전 있음
유어딜 v1.4.2 (3f01ed7)           유어딜 v1.4.2 (3f01ed7)
최신 버전이에요                     새 버전이 나왔어요        ← 브랜드 블루
                                 [    지금 업데이트    ]    ← 전체 폭 파란 버튼
```

상태 줄은 **이미 하고 있는 조회**(마운트 시 `/api/version`)의 결과를 그대로 말하는 것이라
**새 요청이 0** 이다. 파란 버튼은 새 버전이 있을 때만 선다 — 그때가 이 영역이 존재하는 유일한 순간이다.

**빠져 있던 상태 하나를 챙겼다**: 서버 조회가 실패했거나 로컬 빌드 기록이 아직 없을 때는 `최신` 이라고
말하면 거짓말이라, 그때만 `최신 버전인지 확인` 버튼이 뜬다.
