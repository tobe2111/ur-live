# 2026-09-15 — 시안 갤러리 `/design/variants` 신설

> 대표: *"각 페이지마다 이렇게 지금 UI들이 공통적으로 잡혀있는데 어떻게 다른 디자인 시안들로 더 받을 수
> 있을까?"* → 세 갈래(① CSS 변형 ② 시안 라우트 ③ 피그마)를 제시하고 ②를 권함 → *"시안 라우트 만들어줘."*
> 어느 서비스인가: **내부 도구**(소비자·셀러·어드민 어느 표면에도 노출 0). 도매·공구 서비스·유어애즈 무접촉.

## 무엇이 달라졌나 (사용자 관점)

`urdeal.kr/design/variants` 에서 **한 화면의 구조가 다른 안들을 같은 데이터로 나란히** 보고 고를 수 있습니다.
장사가 되는 상태와 비어 있는 상태를 스위치로 바꿔 가며 볼 수 있습니다.

## 왜 이 모양인가

기존에 시안을 주고받는 길은 둘이었고 둘 다 *레이아웃*을 못 다뤘다:
- **글로 설명 + 알파벳 선택** — 색·여백엔 통하지만 "이 페이지 자체가 별로야" 에는 못 쓴다.
- **`visual-preview --css`** — 실제 컴포넌트를 렌더하지만 **CSS 만** 바꾼다. 구조가 다른 안은 못 만든다.

🔑 **데이터 스위치(`?data=empty`)가 이 도구의 핵심이다.** 대표가 실제로 불편해한 화면
(`/seller/analytics`)은 **숫자가 0일 때** 무너진다 — 0 이 다섯 개인데 그 앞뒤로 컨트롤이 12개다.
데이터가 있을 때만 보면 그 문제가 안 보이고, 그래서 시안도 헛돈다.

## 구조

```
src/pages/design-variants/
  registry.ts               SET_LOADERS(본문 lazy) + SET_INDEX(이름 미러) · 타입
  DesignVariantsPage.tsx    껍데기 — 화면/데이터/폭/나란히 picker, URL 에 상태 저장
  sets/seller-analytics.tsx 첫 세트(안 A 지금 · 안 B 숫자가 주인공 · 안 C 빈 화면을 먼저)
```

- 라우트 `/design/variants` — `App.tsx` **lazy**, `fullScreenPrefixes` + `HIDE_SIDEBAR_PREFIXES` 에 `/design`
- `robots.txt` `Disallow: /design/` + 페이지 자체 `noindex`(2026-07-29 에 라이브 robots 가 Cloudflare
  Managed 로 통째 대체된 적이 있어 두 겹으로 막는다)

## 🩸 이번에 틀렸던 판단

1. **액자에 갇혔다.** `fullScreenPrefixes` 에만 넣고 끝낸 줄 알았는데, 그건 **네비만** 숨긴다.
   430px 액자·거터 레일은 `MobileAppLayout` 의 `HIDE_SIDEBAR_PREFIXES` 가 따로 관장한다 —
   첫 렌더에서 갤러리가 폰 액자 안에 갇혀 "나란히"가 세로로 쌓였다. **렌더해 보지 않았으면 몰랐다.**
2. **내 가드가 내 주석을 링크로 신고했다.** "어디에서도 링크하지 않는다" 를 raw 파일 문자열로 검사해서,
   `MobileAppLayout` 에 내가 쓴 *설명 주석*이 위반으로 잡혔다 → 주석을 걷어내고 본다(주석은 링크가 아니다).

## 🩸 CI 가 잡은 넷째 — 몰 슬러그와 라우트가 같은 뿌리를 쓴다

`mall-branding.test.ts` 가 빨간불: **`design` 이 `RESERVED_SLUGS` 에 없다.**

공구 서비스(운영자 몰)는 `urdeal.kr/{몰슬러그}` 를 **루트 1세그먼트**로 서빙한다. 누군가 `design`
이라는 슬러그로 몰을 열면 **내 `/design/variants` 가 그 몰에 먹히거나 몰이 죽는다.** 새 최상위
라우트를 만들 때마다 예약어를 함께 늘려야 하고, 그 테스트가 그걸 강제한다. ⇒ `'design'` 추가.

⚠️ **pre-push 게이트가 이걸 못 막는다** — 게이트는 `scripts/check-*` 만 돌리고 **vitest 는 안 돈다**
(#1450 핸드오프가 이미 지적한 구조적 구멍: `local-ci-parity` 가 verify.yml 에서 스크립트 스텝만
긁어서 `npm test` 스텝이 모델 밖이다). ⇒ **최상위 라우트를 추가했으면 푸시 전에 vitest 를 돌릴 것.**
