# 🧪 "staging 실결제" 게이트가 실재하지 않는다 (2026-09-19)

`[E2]` **실측됨.** 코드 변경 없음 — 문서·결재 항목만.

## 1. 무엇을 발견했나

대표가 *"계속 진행"* 이라 해서 #1149 마무리 뒤 건강검진을 돌리다 나왔다.

**2026-09-17 에 내가 대표께 드린 "남은 것 셋" 중 하나가 수행 불가능한 일이었다.**
*"staging 실결제 1회"* 라고 적었는데 그 환경이 없다.

```
docs/STAGING_CHECKLIST.md   항목 23개 (S1~S12 · P1~P14)
   ⬜ 미검증                 20
   🔴 staging 없이 라이브 ON   1   ← S7 채널 요율(2026-08-29 대표 지시)
   🟡 부분                     2
   ✅ 통과                     0   ← 2026-07-05 신설 이후 2.5개월간 0건
CLAUDE.md audit log 의 "staging 실결제 필수/권장"   13건 — 전부 미수행
```

레포가 스스로 모순된 말을 한다:
- `scripts/deploy-staging.sh:32` → `--project-name=ur-live-staging` (있다는 전제)
- `.github/workflows/prod-smoke.yml:4` 주석 → *"staging 이 없어…"*
- `docs/design/operator-mall-release-checklist.md` X1 → **없음 확정(실측) · 수행 불가**

⚠️ **나는 직접 확인하지 못했다.** 이 세션에 CF API 토큰이 없고(`X6`: 현 토큰은 verify 자체 실패),
`*.pages.dev` 는 이 환경 프록시가 막는다(내 curl 은 `000` — "없음" 과 "차단됨" 을 구분 못 한다).
위 "없음 확정" 은 **다른 세션의 실측 인용**이다. 다음 세션이 이걸 내 실측으로 오독하지 말 것.

## 2. 그런데 게이트가 막으려던 것의 상당 부분은 이미 잠겨 있다

내가 대표께 눈으로 확인해 달라고 한 바로 그 불변식들:
```
src/tests/unit/mall-origin-banner.test.tsx     실제 렌더 6건 (흔적 없음 → 조회조차 안 함 ·
                                               조회 실패/404/빈 이름 → 이름 추측 안 함)
scripts/mutations/mall-payment-flow.mjs        주입 7건 — 2026-09-19 전부 빨간불 확인
```
⇒ 화면 로직은 기계가 막는다. staging 실결제가 **추가로** 주는 증거는 *"진짜 토스 결제가
끝까지 가서 그 화면에 닿는가"* 하나다. 작지 않지만 게이트 전부를 막을 근거는 아니다.

## 3. 결재로 올렸다

`docs/decisions/2026-09-19-staging-gate-unperformable.md` — 선택지 셋(환경 구축 / 대표 통제

## 4. 다음 세션의 첫 액션

1. 위 결재에 대표 답이 있으면 그대로 집행. 2번이면 `STAGING_CHECKLIST` 운영 룰부터 고친다.
2. 답이 없으면 **건드리지 말 것** — 이건 머니 경로 검증 방식이라 C 등급이다.
3. ⚠️ `ur-live-staging` 존재 여부를 **CF API 로 직접 확인할 수 있는 세션이라면 먼저 확인**하고
   그 결과를 결재 파일 근거에 덧붙일 것(내가 못 한 것이 그것이다).

## 5. 이번에 내가 틀린 것

**관측 범위를 좁게 잡고 대표에게 할 일을 넘겼다.** "이건 대표 몫" 이라고 분류하기 전에
*그 일이 가능한지* 를 확인했어야 했다. 같은 세션에서 cron 하트비트도 처음엔 `d1-backup` 이
47일 멎었다고 볼 뻔했는데, 실제로는 `d1-backup-chunked` 로 **이름이 바뀌어 1분 전에 돌고
있었다**(API 가 `verdict: superseded` 로 이미 표시하고 있었다). 두 번 다 **원본 신호를
한 겹 더 파니 결론이 뒤집혔다.**
