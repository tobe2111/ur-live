# 2026-10-12 — 로그인 전 탭 화면(이용권·유어샵·마이)

## 다음 세션의 첫 액션
배포 뒤 **로그아웃 상태**(시크릿 창)로 `https://urdeal.kr/my-vouchers` · `/u/me` · `/user/profile` 을 연다.
- 로그인 화면이 아니라 게스트 화면이 떠야 한다(첫 줄: "동네 가게, 미리 사면 더 싸요" / "좋아하는 가게 이용권," / "반가워요!").
- 이용권 탭 아래 인기 이용권 4개, 유어샵 탭 예시 진열 3줄이 **실제 사진과 함께** 뜨는지.
- 카카오로 시작하기 → 로그인 → **같은 탭**으로 돌아와 진짜 화면이 뜨는지(폰은 카톡 간편로그인).

## 완료분
- `ProtectedRoute` 의 `guest` 속성(잠금 파일 — 대표 승인 "일단 이렇게 구현") · `App.tsx` 세 라우트 배선
- `src/pages/guest/*` 게스트 화면 셋 + 카카오 버튼 + 혜택 목록 + 인기 이용권 훅(홈 피드 캐시 공유)
- `kakao-talk-login.ts` 복귀 주소별 준비(첫 표를 계속 돌려주던 결함)
- 마이 사장님 줄의 "팔린 만큼만 수수료" 는 대표 지시로 뺐다
- 시안 보관: `docs/design/guest-tabs-2026-10-12.md`

## 이번에 틀릴 뻔한 것
- 프리뷰에서 인기 이용권·예시 진열이 **비어 보였다** — 결함이 아니라 하네스가 `--deals` 없이는 상품을 안 준다. `--trace-api` 로 요청이 실제로 나가는 것을 먼저 확인했다.
- 시안 단계에서 "팔리면 소개비" 를 혜택으로 넣었다가 뺐다 — 담기 커미션은 꺼져 있다. 혜택 문구는 `docs/FEATURE_STATUS.md` 부터 볼 것.

## 남은 결정
- 없음(대표 확정 범위 안). 비로그인 상태에서 `UMeRedirectPage` 가 401 을 받으면 여전히 로그인으로 보낸다(로컬 user_id 는 있는데 세션이 죽은 경우) — 드물어서 그대로 뒀다.
