- **로그인 상태 화면 실측은 이 환경에서 불가** — localStorage 로 로그인 표시만 심으면 서버가 `/login?returnUrl=` 로 돌려보낸다(진짜 카카오 세션 필요). 비로그인으로 잰 것: `/my-stays`·`/my-appointments` 직접진입 ← → `/user/profile`, `/faq` → `/`. 보호 화면 → 로그인 화면 → 뒤로 → 홈 → 앱 밖(고리 없음, ProtectedRoute 가 replace).
- **카카오 로그인 뒤 뒤로** (코드 추적 — 서버 `/sync/callback` 이 returnUrl 로 302): 이력이 `[상세, /login, 상세']` 로 남아 폰 뒤로가 로그인 화면 → 다시 상세로 튕겨 '뒤로가 먹통' 이었다. 고친 것(LoginPage):
  ① 카카오로 갈 때 `location.replace` — 로그인 화면을 이력에 안 남긴다 ② 로그인 끝난 뒤 POP 으로 다시 온 로그인 화면은 앞으로가 아니라 한 칸 더 뒤로 ③ bfcache 로 되살아난 로그인 화면은 '카카오로 이동 중' 가림막을 걷는다.
  ⚠️ 남는 것: 카카오 계정 로그인 폼을 거친 경우 그 카카오 화면 한 칸은 이력에 남는다(카카오 쪽 화면이라 우리가 못 지운다). 상세가 한 번 더 보이는 것(`[상세, 상세']`)도 남는다 — 문서를 바꿔 돌아오는 구조라 이전 칸을 지울 방법이 없다.
