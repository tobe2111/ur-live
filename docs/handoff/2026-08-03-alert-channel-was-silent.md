# 유어애즈 경보가 무음이었는데, **무음이라는 사실도 무음**이었다

> 2026-08-03 세션. 오늘 고친 것들과 **같은 클래스**다 — 코드는 있는데 안 돎.
> 다만 이번엔 코드가 아니라 **env 한 칸**이 비어 있었고, 그걸 볼 방법이 없었다.

## 1) 다음 세션의 첫 액션

배포 후 서비스바인딩으로 한 번 찔러 보면 끝난다:

```
POST /api/admin/ads/alert-test    → { success, status } — Discord 는 204 가 정상
```

⚠️ `/__ads/*` 는 **서비스바인딩 전용이라 밖에서 못 친다.** 위 어드민 경로로 부를 것.
   (#1029 배포 직후 실측에서 이걸 놓쳤다 — 확인 라우트를 만들어 놓고 부를 길을 안 냈다.)

`status` 가 2xx 가 아니면 웹훅 URL/채널 문제다. **`ok:true` 만 보고 넘기지 말 것** —
이 라우트는 상태를 그대로 돌려주도록 만들었고, 그게 존재 이유다.

## 2) 무엇이 고장나 있었나 (실측)

```
ur-live (유어딜 메인, Pages)  DISCORD_WEBHOOK_URL = 설정됨(plain_text)
ur-ads  (유어애즈 워커)        DISCORD_WEBHOOK_URL = 미설정          ← 무음
```

유어애즈 경보 세 종이 전부 조용했다 — 구글시트 동기화 실패 · 인플루언서 수집 침묵/회복 ·
팔로업 리마인더. 경보 코드가 전부 `if (env.DISCORD_WEBHOOK_URL && …)` 라 값이 없으면
**흔적 없이 건너뛴다.** 그래서 시트 미러가 이틀 멈추는 동안 알림이 0건이었다.

같은 시점 메인의 머니 경보(정산·원장·환불)는 정상이었다. **두 워커의 env 가 갈렸는데
밖에서 확인할 방법이 없었다** — 헬스체크가 게이트·튜닝은 보여 주면서 정작
"알림이 갈 곳이 있는가"는 안 보여 줬다.

⚠️ 기록은 정상이었다(`cron_failures` 7일 350건). 즉 **pull 은 되고 push 가 안 됐다.**
그 차이가 "이틀 몰랐다"와 "즉시 안다"를 가른다 — "기록도 안 된다"로 오해해 과잉대응하지 말 것.

## 3) 수리

* `/__ads/health` 에 `alerts` 블록 — 미설정이면 `🔴 무음`, **무엇을 잃는지 목록**,
  채널 없이도 남는 곳(`cron_failures`, pull)을 구분 표기.
* `POST /__ads/alert-test` 신설 — "설정됨"과 "도착함"을 가른다. URL 오타·삭제된 채널은
  조용히 실패하는데 물을 방법이 없었다.
  ⚠️ **결과를 삼키지 않는다**(Discord HTTP 상태 그대로). ⚠️ 응답에 URL 을 **싣지 않는다**
  (웹훅 URL 자체가 자격증명 — 아는 사람은 누구나 그 채널에 글을 쓴다).

검증: tsc 0 · 신규 유닛 7 · audit-gate 87 GREEN · 주입 153 전부 빨강(신규 3 —
alerts 제거 / 상태 삼킴 / URL 노출).

## 4) 이번에 틀렸던 판단

세션 내내 *"이제 문제가 생기면 보인다"* 고 보고했는데 **경로를 확인하지 않고 말했다.**
대표가 *"디스코드로 오는 건가?"* 라고 물어서야 재 봤고, 답은 **아니오** 였다.
관측을 고쳤다고 말하려면 **그 관측이 어디로 도착하는지**까지 확인했어야 했다.

## 5) 대표가 한 것 / 남은 것

* ✅ 대표가 **유어애즈 전용 웹훅**을 `ur-ads` 에 `secret_text` 로 설정(2026-08-03).
  머니 경보와 채널이 분리돼 섞이지 않는다.
* ⏳ **실발사 확인** — 어드민 위임(`POST /api/admin/ads/alert-test`)이 배포된 뒤 한 번 찔러
  `status: 204` 확인 + 채널 도착을 눈으로 확인할 것.
  ⚠️ **`success:true` 만 보고 넘기지 말 것** — 위임·ur-ads 양쪽 다 Discord 상태를 그대로
  흘리도록 만들었고(주입 2건으로 고정), 그게 이 경로의 존재 이유다.
* 남은 판단: Workers 유료 전환(부모 CPU 10초 천장) · 브랜치 보호(필수 상태체크).
