**다른 세션에서 main 에 먼저 들어갔다**(결재 `2026-10-06-npm-audit-three-new-advisories.md`).
main 의 audit 게이트를 실측하니 이미 초록이라, 중복분을 전부 환원하고 **shell-quote 하나만** 남겼다.

그리고 그게 남은 이유가 이 PR 의 요점이다 — **면제가 피할 수 있는 것이었다**(취약 범위 `<=1.8.4`,
npm 최신 `1.12.0`, 같은 major). 허용목록 3 → 2.
