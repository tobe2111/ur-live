# 로그아웃 상태 화면 UI 재검토 (2026-11-18)

서비스: 유어딜(소비자). 머니 경로 접촉 없음.

## 한 일
라이브 urdeal.kr 를 로그아웃 상태로 폰(390, 라이트·다크)·PC(1440)에서 찍어 봤다 —
홈 · 지도 · 교환권 · 이용권 상세(/pass) · 숙소 · 숙소 상세 · 매장(/s) · 지역 · 블로그 · 로그인 · 검색 · 소개(/about) · 마이 · 내 이용권 · 장바구니 · 약관.

## 고친 것
1. **PC 에서 로그인 전 세 탭(내 이용권·유어샵·마이)의 카카오 로그인 버튼이 사라져 있었다.**
   `GUEST_CLS.dock` 의 `app-frame-bar` 가 `body.pc-fullbleed .app-frame-bar{display:none}`(PC 에서 하단 탭 숨김)에 같이 걸림.
   실측 1440px 세 화면 모두 display none. → app-frame-bar 제거, PC 는 화면 맨 아래 720 폭. 본문도 PC 720 가운데(전엔 1440 왼쪽에 붙어 줄이 화면 끝까지).
2. **/about 모바일: 첫 화면에 '내 주변 딜 보러가기' 버튼이 두 개**(히어로 + 고정 바)이고 고정 바가 '매장 입점 안내' 버튼을 덮었다.
   → 히어로 버튼 줄이 화면에서 벗어난 뒤에만 고정 바를 올린다.
가드: `src/tests/unit/guest-dock-pc-2026-11-18.test.ts` (되돌려-검증: app-frame-bar 재주입 시 빨강 확인).

## 안 고친 것 (대표 판단 또는 별도 작업)
- 영어 브라우저로 들어오면 하단 탭이 `Vouchers` 두 개(교환권·이용권 둘 다 같은 번역) · 장바구니에 '쇼핑 계속하기' 만 한국어로 남음.
- 이용권/숙소 상세 아래 바: 가격 `26,000원` 옆 버튼이 `응모하기 (무료)` — 추첨 응모 설계로 보이나 "돈 내는지 공짜인지" 헷갈릴 수 있음.
- 지도: 가격 핀끼리 겹침(59% 핀이 169,000 핀을 덮음).
- 약관 제2조 5항이 아직 "유상으로 충전" — 충전은 2026-07-18 종료(법무 문구라 손대지 않음).
- 교환권 브랜드 로고가 빈 동그라미 — 이 환경이 bizimg.giftishow.com 에 접속 못 해서(연결 리셋) **판정 못 함**.

## 이번에 틀렸던 판단
- 첫 촬영을 Playwright 기본 영어 로케일로 해서 화면이 영어로 나왔다 — 한국 손님 기준은 `locale:'ko-KR'` 로 찍어야 한다.

## 이어받는 세션의 첫 액션
배포 뒤 `node scripts/measure-live-vitals.mjs /about /user/profile /my-vouchers` + 1440px 에서 세 탭 카카오 버튼이 보이는지 확인.

## 2차 (대표 "모두 고치고")
- 영어 하단 탭: 교환권 `Gift Cards` / 이용권 `Passes`(종전 둘 다 `Vouchers`). 장바구니 '쇼핑 계속하기' 번역 연결(ko 문구도 화면과 통일).
- 추첨 상품 하단 바(이용권·숙소): 가격 위에 "당첨되면 이 가격에" — 버튼 '응모하기 (무료)' 와 가격이 한 줄에 있어 헷갈리던 것.
- 지도: 클러스터 칸을 도(°) 고정값 → **화면 픽셀(88×40, 핀 크기)** 로. 실측 종전 칸은 22~35px 로 94px 핀보다 4배 좁았다(`shared/map-marker` `mapCellSizeDeg`). ⚠️ 중간 줌에서 묶음 버블이 종전보다 많아진다 — 의도.
- 교환권 브랜드 칩: 로고가 원본까지 실패하면 이름 두 글자(빈 흰 칸 방지). 로고 자체는 의도적 원본 직결(2026-10-31) — 이 환경은 giftishow 접속 불가라 실패율 판정 못 함.
- 약관 충전 문구: 결재함 `docs/decisions/2026-11-18-terms-deal-topup-wording.md`(파일 머리 "대표 확인 후에만").
