# 2026-10-01 — 인스타 댓글 → 자동 DM (유어딜 공식 계정)

대표: *"'댓글에 ooo 라고 적어주세요, 그럼 바로 링크 DM 보내드려요' 자동화 — 직접 개발해줄래? 우리 유어딜에서 쓰게끔"*

**서비스**: 유어딜 자체 홍보(마케팅). 셀러·유어애즈 광고주용이 아니다. 머니 경로 접촉 없음.

## 무엇을 만들었나

| 자리 | 내용 |
|---|---|
| 웹훅 | `GET/POST /api/instagram/webhook` — 메타가 호출. POST 는 `X-Hub-Signature-256`(앱 시크릿 HMAC) 검증 실패 시 401 |
| 처리 | `features/instagram-autodm/api/autodm-service.ts` — 우리 계정 이벤트만 · 우리 계정이 단 댓글 제외(공개 답글 루프 방지) · 규칙 매칭 · 일일 상한 · `comment_id` UNIQUE 선점 → Private Reply DM → (선택) 공개 답글 |
| 저장 | 테이블 3개(`ig_autodm_account` 1행 · `ig_autodm_rules` · `ig_autodm_sends`), ensure+WeakSet. 토큰·앱 시크릿 at-rest 암호화(`DATA_ENCRYPTION_KEY`) |
| 어드민 | `/admin/instagram-autodm` (메뉴 '콘텐츠 → 인스타 자동 DM'): 웹훅 URL·확인 토큰 복사, 토큰·시크릿 입력(연결 시 `subscribed_apps?subscribed_fields=comments` 자동 호출), 켜기/끄기, 일일 상한, 규칙 CRUD(게시물 썸네일에서 고르기), "이 댓글이면 어떤 DM?" 미리보기(실발송 X), 발송 기록 |
| 토큰 | 장기 토큰(60일)을 7일마다 자동 연장 — 웹훅 처리·어드민 상태 조회 때. cron 없음 |
| 요청 제한 | 웹훅 경로만 전역 IP 레이트리밋 제외(메타 IP 몇 개에서 몰려 옴). 서명 검증이 대신 지킨다 |

🔒 **게이트**: 어드민 '켜기' — 기본 OFF. 켜려면 계정 연결 + 앱 시크릿 둘 다 필요(서버가 거절).

## ➡️ 다음 액션(대표) — 켜기 전 필요한 것
1. Meta for Developers 에서 앱(비즈니스 유형) → **Instagram** 제품 → "Instagram 로그인으로 API 설정"
2. 유어딜 인스타 계정(프로페셔널 계정)을 추가하고 **액세스 토큰 생성** → 어드민에 붙여 넣기
3. 앱 설정의 **Instagram 앱 시크릿** → 어드민에 붙여 넣기
4. 웹훅 구성: 어드민 화면의 콜백 URL·확인 토큰 → 메타 화면에 붙여 넣기 → `comments` 구독
5. 권한 `instagram_business_basic` · `instagram_business_manage_comments` · `instagram_business_manage_messages`
   — **우리 계정만 쓰면 앱을 '개발' 모드로 두고 심사 없이** 쓸 수 있다(앱 역할에 그 인스타 계정을 테스터로).
   ⚠️ 개발 모드에서 웹훅은 앱 역할이 있는 사용자 댓글에만 올 수 있다 — **일반인 댓글까지 받으려면 '라이브' 전환 +
   권한 고급 액세스(앱 심사)** 가 필요할 수 있다. 실계정 연결 후 일반 계정 댓글로 1회 확인할 것.
6. 규칙 1개 만들고 → 미리보기로 확인 → 켜기 → 다른 계정으로 댓글 → DM 도착 확인(E4)

## 틀렸던 판단
- 없음(신규). 처음엔 토큰 갱신을 cron 으로 하려 했으나 이 레포 cron 이 트리거 한도·슬롯 체계로 복잡해
  **요청 경로에서 7일 간격 지연 갱신**으로 바꿨다. 웹훅이 한 달 넘게 안 오고 어드민도 안 열면 만료될 수 있다 —
  그 경우 어드민 '지금 연장' 또는 토큰 재입력.

## 남은 것
- 팔로우 확인 2단계(버튼 → 답장 → 링크) — 지금은 첫 DM 에 바로 링크. 원하면 Instagram 버튼 템플릿으로 확장.
- 메타 앱 심사(라이브) 여부는 대표 판단.
