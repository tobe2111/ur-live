## 지도 — 고친 것 (`useFeedWindow.ts`, `RestaurantMapPage.tsx`)
지도는 필터(지역·반경·가격·즐겨찾기)를 켜면 전체를 받는다(loadAll). 구멍이 둘이었다:
1. 전체를 받는 **도중** 0건이면 유달이 "이용권이 없어요" + "0곳" 이 먼저 떴다 → `stillHunting` 동안은 로딩 모양 + 개수 '…'.
2. 1페이지가 오기 **전에** 필터를 켜면 loadAll 이 page 0 이라 no-op 이고 다시 안 불렸다 → 1페이지 도착(`isLoading` false) 뒤 다시 부른다.
네트워크 실패면 `loadingMore` 가 풀려 종전 빈 화면으로 떨어진다(영원히 로딩에 갇히지 않게 — 의도).
