# 2026-08-04 — 지역 집계에 데모 딜 포함 (대표 결정)

## 배경 — 배포 직후 라이브 판정에서 드러난 것

`/region/*`(PR #1037, `c272e6d`) 머지 후 실측:

| 판정 | 결과 |
|---|---|
| ① 서버 메타 | ✅ `<title>서울 중구 이용권·동네딜 할인 - 유어딜</title>` + 자기 canonical. Yeti 대응 정상 |
| ② sitemap `/region` | **1개**(허브만). 기대 40개 |
| ③ `/api/regions` | 서울 1건(광진구 1) · `indexable: false` |

원인은 버그가 아니었다: **활성 딜 329건 중 328건이 데모 시드**(`slug` 가 `demo-`)이고
실제 상품은 1건(id=25, 서울 광진구)뿐이다. 데모를 제외하도록 만든 집계가 설계대로 동작한 것.

> ⚠️ **08-03 세션이 "31개 시군구가 색인 가치 있다"고 보고한 수치는 전부 데모였다.**
> 45개 시군구 분포도 데모 시드였다. 라이브 목록 API 를 셀 때 `slug` 를 안 봤다.
> **다음에 재고를 셀 때는 `demo-` 슬러그를 먼저 갈라낼 것.**

## 결정

대표: **"포함시키자"** — 세션이 반대 의견(검색 유입자가 못 쓰는 데모 상품 페이지에 착지 ·
색인은 배포로 되돌아오지 않음)을 냈고, 대표가 포함으로 확정했다.

근거 쪽도 분명하다: 데모는 **소비자 홈 피드에 이미 노출된다**(후순위 정렬). 지역만 빼면
홈은 가득한데 지역은 비는 불일치가 생긴다.

## 구현

- `REGION_COUNT_INCLUDE_DEMO`(`shared/feature-flags.ts`, 기본 `true`)
- `computeRegionStats` 의 데모 제외 절이 이 플래그 뒤로
- **캐시 키에 플래그 반영** — `region_stats:v2:{incl-demo|real-only}`.
  안 하면 플래그를 되돌려도 최대 10분간 옛 집계가 나가고, 그 사이 "고쳤는데 왜 그대로냐"를 디버깅한다.
- `RegionLinkGrid`: 링크할 지역이 **어디에도** 없으면 섹션 전체 미노출
  (대표가 배너에 정한 "올리지 않으면 아예 안 보이게" 원칙과 동일. 배포 직후 홈 하단이
  제목 + "아직 딜이 모이지 않았어요" 만 띄우는 상태였다.)

⚠️ **되돌림의 비대칭**: 플래그를 끄면 집계는 즉시 바뀌지만 **이미 색인된 URL 은 즉시 사라지지
않는다**(재크롤링 대기). 이 값은 자유로운 스위치가 아니라 **한 방향으로 비용이 붙는 결정**이다.

## 검증

- vitest **4896 pass**(신규 3: 플래그 뒤 배선 · 기본값 · 캐시 키 반영)
- 되돌려-검증: 데모 무조건 제외로 되돌림 + 캐시 키에서 플래그 제거 → 정확히 그 2개만 빨강. 복원 확인.
- tsc 0 · build 0 · critical-chunks 17개 = 기준 동일

## 다음 세션의 첫 액션

배포 후 라이브 재판정(브라우저 UA 필수):

```bash
UA='Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/126.0.0.0 Safari/537.36'
curl -sS -A "$UA" https://urdeal.kr/api/regions | head -c 400        # 시/도 11개 안팎 · indexable true 다수
curl -sS -A "$UA" https://urdeal.kr/sitemap.xml | grep -c '/region'  # 기대 40개 안팎(1이면 미반영)
curl -sS -A "$UA" 'https://urdeal.kr/region/%EC%84%9C%EC%9A%B8/%EC%A4%91%EA%B5%AC' | grep -oE '<title>[^<]*'
```

`/api/regions` 는 **10분 캐시**라 배포 직후 바로 안 바뀔 수 있다 — 키가 v1→v2 로 바뀌어
첫 요청에 새로 계산되지만, 엣지 캐시(600s)가 남아 있으면 그만큼 기다릴 것.

## 남은 결정 (대표 확답 대기)

- **①홈 카테고리 섹션형**(여기어때식 섹션+더보기) — 홈 정체성 변경.
  `homepage_sections` 테이블 + CRUD API 9개가 이미 있고 프론트 소비 0.
- **③④배너** — `banners` 테이블·공개/어드민 API·`AdminBannersPage` 이미 있고 소비자 소비 0.
  필요한 건 배선 + `video_url`·`banner_type`(hero/inline)·`position` 컬럼.
  🔑 대표 확정 규칙: **배너 0건이면 컴포넌트가 `null`** — 빈 자리 없이 레이아웃이 위로 붙는다.
- **실제 재고**가 이 기능의 진짜 병목이다. 실제 매장 1곳뿐 — 지역 SEO 의 효과는 재고가 붙는 만큼 나온다.
