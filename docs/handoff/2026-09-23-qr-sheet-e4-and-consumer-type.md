# 2026-09-23 — 이용권 QR 시트 E4 판정 + 소비자 화면 글꼴 정리

> 대표: *"이용권 페이지에 잘려서 안보임."* → *"배포되면 판정까지 해줘."*
> 이어서 *"아니 영어나 숫자 폰트 좀 어떻게 수정 안될까? 너무 AI스러운데"*

## ✅ 완료 ①: QR 시트 넘침 — **E4 라이브 판정 통과** (PR #1533, 머지 `833ef70cd`)

대표 스크린샷에서 **QR 과 상품명이 화면 위로 잘려** 있었다. 원인은 스타일이 아니라 **구조**다 —
바텀시트에 ⓐ 높이 상한이 없고 ⓑ 본문 스크롤이 없었다. `items-end` 라 **아래가 고정**이므로
내용이 길어지면 **위가 뷰포트 밖으로** 나가고, 스크롤이 없어 되돌릴 수 없다.

**수정**: 패널에 `flex flex-col max-h-[92dvh] sm:max-h-[88dvh]` + 본문에
`flex-1 min-h-0 overflow-y-auto overscroll-contain` + `env(safe-area-inset-bottom)`.
닫기 버튼(`absolute top-3 right-3`)과 그래버는 **스크롤 영역 밖**에 둔다(스크롤해도 닫기가 남는다).

**E4 판정 방법이 이번의 수확이다.** 이 컨테이너 브라우저는 프록시 CA 를 안 믿어
`https://urdeal.kr` 을 `ERR_CERT_AUTHORITY_INVALID` 로 거절한다. TLS 검증을 끄지 않고
**`context.route('**/*')` + `curl` 서브프로세스로 실제 바이트를 받아 `route.fulfill()`** 했다
⇒ 브라우저 TLS 를 0 으로 두고 **배포된 진짜 번들**을 렌더한다.

그 위에서 **대조군을 런타임으로 만들었다** — 같은 배포 번들에서 수정분(상한+스크롤)만 제거:

| 390×640 | 제목 `top` | 스크롤 |
|---|---|---|
| 대조(수정 제거) | **−344px**(화면 밖) | 없음 |
| 현재 라이브 | **+28px** | 있음 |

대표 스크린샷과 대조군이 정확히 일치했다. 내용이 짧을 때도 확인 — `flex-1`(flex-basis 0)이
QR 을 찌그러뜨리지 않는다.

가드: `voucher-qr-sheet-overflow-2026-09-21.test.ts` 8건 + 주입 4건 **되돌려-검증 전부 빨간불**.

## ✅ 완료 ②: 소비자 화면 터미널 고정폭 제거 (이 브랜치)

**진단**: 본문은 Pretendard 인데 **이용권 코드·실시간 시계·잔액·전화번호·우편번호**에만
`font-mono` 가 붙어 있었다. Tailwind 의 `font-mono` 는 우리가 고른 글꼴이 아니라
`ui-monospace, SFMono-Regular, Menlo, …` **터미널 폴백**이다 — 그 자리만 개발자 콘솔처럼 보인다.
대표가 "AI스럽다"고 한 것이 정확히 이 자리다.

**그냥 지우면 안 된다 — 시계가 떨린다.** 라이브 페이지에서 실제 Pretendard 15종을 띄워 쟀다:

| | 기본 | `tabular-nums` |
|---|---|---|
| `08:11:11` | 66.47px | 81.06px |
| `07:36:15` | 74.56px | 81.06px |

기본 숫자는 **비례폭**이라 초가 바뀔 때마다 폭이 최대 8px 출렁인다. `tabular-nums`
(`font-variant-numeric`)는 **글꼴은 Pretendard 그대로 두고 숫자 폭만** 맞춘다.
⇒ `font-mono` → `tabular-nums`, **23파일 42곳**(소비자 표면만).

**고정폭이 맞는 자리는 남겼다** — `MarkdownView` · `GuideViewer`(마크다운/코드 블록) ·
`SellerPinPrompt`(대시보드 위젯). 대시보드(어드민·셀러·도매)는 손대지 않았다.

💡 **판독성 논거도 이미 없다**: `generateVoucherCode()` 의 알파벳이
`ABCDEFGHJKLMNPQRSTUVWXYZ23456789` 로 **I/O/0/1 을 이미 뺐다** — 고정폭으로 얻을 구분이 없다.

가드: `consumer-font-mono-2026-09-23.test.ts` 8건 + 주입 5건 **되돌려-검증 전부 빨간불**.

## 🩸 이번에 틀렸던 판단

1. **제외 규칙을 파일 이름으로 짰다.** `pages/payment-success/SellerConversionNudge.tsx` 는
   이름에 `Seller` 가 있지만 **결제 완료 화면**(소비자)이다. 이름 규칙이 그 파일을 통째로
   범위 밖으로 빼서 `font-mono` 가 남은 채 **초록불**이 떴다 → 판정을 **디렉터리**로 옮겼고
   (`pages/` 바로 아래만 이름으로, 중첩은 디렉터리로), 주입 5번이 그 교정을 잠근다.
2. **첫 폭 측정이 거짓 음성이었다.** 독립 페이지로 재려니 프록시 때문에 Pretendard CDN 이
   안 떠서(`로드 ❌`) **폴백 글꼴**을 재고 "차이 없음"을 보고할 뻔했다. 라이브 페이지 안에서
   다시 재서야 위 표가 나왔다 — **무엇을 재고 있는지 먼저 확인할 것.**
3. **시험 앵커가 엉뚱한 줄을 잡았다.** `{voucher.code}` 로 찾으니 QR URL 템플릿
   (`/v/${voucher.code}`)이 먼저 걸렸다 → `>{voucher.code}</code>` 로 재앵커.
4. **`pkill -f "qr/mirror"` 로 내 셸을 죽였다**(exit 144) — 패턴이 내 명령줄 자신에 매치.
   CLAUDE.md 가 경고한 바로 그 함정이다.
