## 다음 세션의 첫 액션

배포 판정은 **압축돼도 남는 문자열**로 본다:

```bash
UA='Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/126 Safari/537.36'
for c in $(curl -sS -A "$UA" https://urdeal.kr/vouchers | grep -o '/assets/VouchersPage-[A-Za-z0-9._-]*\.js' | sort -u); do
  curl -sS -A "$UA" "https://urdeal.kr$c" -o /tmp/v.js
  echo "$(basename $c) 브랜드로찾기=$(grep -c '브랜드로 찾기' /tmp/v.js) 한줄바=$(grep -c '현금처럼 써요' /tmp/v.js)"
done
```
**기대: 둘 다 1.** 배포 전 기준선은 둘 다 0 이므로 **머지 전에 재 두고** 비교할 것.
⚠️ 이 세션에서 판정을 세 번 헛짚었다 — `cfFallback`(배포 전후 동일) · `from"./app-utils"`(원래도 import) ·
엔트리 해시(남의 배포에도 바뀜, 머지 1분 뒤 뜬 배포를 내 것으로 오인). **배포 전 상태에서 실제로 거짓이 되는 조건**만 쓸 것.

## 🩸 이 세션에서 틀렸던 판단 (누적)

1. **시안을 화면 절반 빼놓고 냈다** — 하네스가 `/api/vouchers/categories` 에 빈 배열을 줘 카테고리 칩·브랜드
   스트립이 안 그려진 화면으로 "상품 3개→5개" 라고 보고. 대표가 *"카테고리 및 브랜드 선택하는건 어딨어?"* 로 발각.
   ⇒ **시안은 반드시 `--deals` 로 렌더.**
2. **같은 자리를 하루에 두 번 뒤집었다** — 카드 할인율을 사진 위로 옮겼다가 되돌림. 진단은 맞았는데
   "자리를 옮겨 피한다" 를 골랐다. 쿠팡식 2줄이 원인을 없앤다.
3. **판정 조건이 배포 전후를 구분 못 했다**(3회). 위 ⚠️ 참조.
4. **`git checkout -- src/` 로 커밋 안 한 작업을 통째로 날렸다.** 되돌려-검증 복원은 **그 파일만 `cp`**.
