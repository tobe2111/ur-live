# 같은 PR — 에이전시 로그인(`/agency/login`) 꾸미기

대표: *"에이전시 소개서 다운로드도 받을 수 있게 하고 페이지를 좀 꾸며야 하지 않을까?"*

## 한 것
- 신규 `AgencyIntro.tsx` — 제목 · 할 수 있는 것 넷(여러 매장 · 직원 · 우리 이용권 성과 · 가입비 0원) · 시작 3단계.
  **지금 실제로 되는 것만** 적었다(초대 링크/대신 등록 · 직원 배정 · 이용권 단위 성과).
- `AgencyAuthShell` 에 `aside` — PC 는 [소개 | 로그인] 두 칸, 폰은 로그인 칸 아래 소개. 가입·재설정 등 다른 화면은 종전 그대로.
- 굵기 semibold → medium(로그인 화면).
- 가드 `agency-login-intro-2026-10-26.test.ts` + 주입 2건.

## ⛔ 소개서 다운로드는 일부러 안 달았다
`docs/business/proposals/urdeal-agency-proposal.pdf`(대행사 제휴 제안서, 30장)가 **지금 모델과 돈 흐름이 다르다**:
덱은 "귀사 몫 %는 귀사가 정하고 **유어딜이 직접 송금**", "셀러 계정을 만드십시오 · 셀러 대시보드" 라고 말하는데,
지금은 에이전시 이메일 계정이고, 몫은 **사장님이 정하고 매장이 직접 보낸다**(`agency-share.ts` 1단계 — 유어딜 송금 없음).
공개 화면에서 내려받게 하면 없는 지급을 약속하는 문서가 나간다. 덱을 고친 뒤(마이 통합 후가 효율적) 같은 자리에 버튼을 단다.
