(`worker-deploy.yml:68-72`). ⇒ **`wrangler.toml` 의 crons 는 한 번도 푸시된 적 없다.**

### 🔴 단계 분할의 착수 조건 — 이게 계획보다 앞선다

**스케줄 PUT 은 전체 교체다.** 현재 등록분(`*/5` 9개 + `0 18` 15개, 둘 다 실행 증거 있음)을
포함하지 않은 목록을 푸시하면 **그 순간 사라진다.** 분할 배포가 소등이 된다.

⇒ **대표의 X9(Trigger Events 목록 원문) 없이는 어떤 단계도 안전하게 실행할 수 없다.**
특히 `0 18` 이 정확히 어떤 문자열로 적혀 있는지 — 디스패처는 **문자열 완전일치**로 분기하고
unmatched 분기가 없어 조용히 무동작한다.
