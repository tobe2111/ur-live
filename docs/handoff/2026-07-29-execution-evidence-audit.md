### ② 🔴 같은 이름의 두 런타임 — **이게 이번 세션 최대 발견**

대표: *"worker 에서는 없는데 pages 에 다 넣어놨어."*

| | Pages `ur-live` | Workers `ur-live` |
|---|---|---|
| 역할 | HTTP 요청 전부 | **cron 전부** |
| 시크릿 | 전부 있음 | **0개** |
| 바인딩 | KV 3종·R2·DB·DO·ADS | **DB·DO 뿐**(wrangler.toml 이 KV/R2 를 전부 주석 처리) |

**`env-readiness` 는 HTTP 엔드포인트라 Pages 를 잰다.** 그 `✅` 가 **cron 이 쓸 수 있다는 뜻이 아니다.**
내가 §2.2 표를 실을 때 이 구분을 안 했다 — **판정 범위를 잘못 잡았다.**
이 감사가 스스로 낸 교훈("같은 함수를 쓴다 ≠ 같은 게이트 뒤다")이 **런타임 층에서 반복**됐다.

**죽어 있던 것**: SSR KV 전역 워밍(2026-07-12 기능, `cache-prewarm.ts:159` 가 `env.CACHE_KV` 요구 → 한 번도 안 돎) ·
알림톡 계열 · `daily-self-diagnostic`(Discord 없어 경보가 갈 곳 없음) · 교환권 카드 만료환불.
**정상**: DB 만 쓰는 정산 성숙·원장 정합(그래서 `ledger_mismatch` 는 기록됐다).

⚠️ **하트비트가 이걸 못 잡는다 — 전부 `ok=true`.** 예외 없이 조용히 아무것도 안 한다.
**하트비트는 "돌았다"를 증명하지 "했다"를 증명하지 않는다.**
