## 수정

- `/introduce` — 배지·스토어 URL·"앱 다운로드" **전부 삭제**. CTA 섹션은 원래 보조였던
  `웹에서 바로 시작하기` 를 **주 CTA** 로 올렸고(`바로 시작하기`), eyebrow 는 `설치 없이 바로 시작`.
- `PcHomeAppBand` — **배너는 남긴다.** 폰 목업은 실제 모바일 웹 화면이라 거짓이 아니고,
  PC→폰 손잡이는 여전히 필요하다 ⇒ 스토어 배지 자리를 **QR**(`urdeal.kr`)로 교체.
  문구 `지금 바로 다운로드하기` → `설치 없이 폰에서 바로 열려요`.
- `AppDownloadModal` — 배지 2개 삭제(QR + '지금 유어딜 열기' 는 실제 동작 그대로라 정직).
  제목 `유어딜 앱으로` → `폰에서 유어딜을`.
- `DesktopTopNav` 버튼 라벨 `앱` → `모바일` — `nav.app` 은 **locale 파일에 키가 없어**
  `defaultValue` 만 고치면 6개 언어에 전부 반영된다(locale 6개 무접촉).

### 🩸 이 판정에서 내가 세 번 틀렸다 — 전부 **하네스** 버그였고, 라이브는 멀쩡했다

셋 다 "라이브가 깨졌다" 로 보고할 뻔한 모양이라 적어 둔다.

1. **`/` 가 `networkidle` 로 60초 타임아웃.** 홈은 지도·배너·Sentry 때문에 **idle 이 안 온다.**
   ⇒ `domcontentloaded` + 명시적 대기 + 끝까지 스크롤(앱 띠가 화면 아래라 lazy 섹션까지 그려야 한다).
2. **캡션 요소를 못 찾음(`caption element not found`).** 선택자에 `children.length === 0` 을 걸었는데
   그 `<p>` 안에 `<br>` 가 있어 **언제나 탈락**했다. ⇒ "그 문구를 가진 가장 깊은 요소"로 교체.
3. **QR 이 없다고 나옴(`found: false`).** 조상을 훑으며 `path,rect > 3` 인 svg 를 찾았는데,
   **`QRCodeSVG` 는 전체 모듈을 path 1~2개로 그린다**(실측 `marks: 2`). 진짜 QR 이 내 필터에 걸러졌다.
   ⇒ 흰 상자(`div.bg-white`) 안의 svg 를 **직접** 재서 92×92 확인.

🧭 교훈: **"없다"는 측정은 "못 봤다"와 구분이 안 된다.** 부재를 보고하기 전에 *그 자리에 무엇이 있는지*를
먼저 찍어 볼 것 — 3번은 QR 컨테이너를 덤프해 `svg: 1` 을 보고서야 내 필터 탓임이 드러났다.
(이 세션은 같은 클래스를 이미 두 번 겪었다: 프록시 `CONNECT` 헤더를 본문으로 읽어 앵커가 전부 `null` 이던 건.)

⚠️ 하네스 로그의 `curl: (56) CONNECT tunnel failed` 와 `403`/`404` 는 **광고·추적·외부 이미지**
(beacon·vitals·부킹닷컴 사진 등)라 판정과 무관하다 — 그걸 실패로 읽지 말 것.
