# 없는 앱의 스토어 배지 제거 (2026-09-28)

대표 확정: **"아직 앱은 하나도 없어."**

## 무엇이 있었나 (실측)

세 화면이 각자 다른 방식으로 "앱이 있다"고 말하고 있었다.

| 화면 | 링크 | 실제 동작 |
|---|---|---|
| `IntroducePage` **4곳**(헤더·히어로·CTA·푸터) | `apps.apple.com/…/id6745051422` · `play.google.com/…?id=com.urdeal.app` | **스토어 '앱을 찾을 수 없음'** |
| `PcHomeAppBand`(PC 홈 하단) | `href="#"` + "지금 바로 다운로드하기" | **눌러도 아무 일 없음** |
| `AppDownloadModal`(PC 네비) | `urdeal.kr`(모바일 웹) | 동작은 함 — **말만 거짓** |

셋 다 **에러가 안 난다.** 그래서 아무도 신고하지 않았고, 2026-09-24 에 지어낸 실적 수치를
지우던 세션도 바로 옆의 이 배지들은 그냥 지나갔다.

## 수정

- `/introduce` — 배지·스토어 URL·"앱 다운로드" **전부 삭제**. CTA 섹션은 원래 보조였던
  `웹에서 바로 시작하기` 를 **주 CTA** 로 올렸고(`바로 시작하기`), eyebrow 는 `설치 없이 바로 시작`.
- `PcHomeAppBand` — **배너는 남긴다.** 폰 목업은 실제 모바일 웹 화면이라 거짓이 아니고,
  PC→폰 손잡이는 여전히 필요하다 ⇒ 스토어 배지 자리를 **QR**(`urdeal.kr`)로 교체.
  문구 `지금 바로 다운로드하기` → `설치 없이 폰에서 바로 열려요`.
- `AppDownloadModal` — 배지 2개 삭제(QR + '지금 유어딜 열기' 는 실제 동작 그대로라 정직).
  제목 `유어딜 앱으로` → `폰에서 유어딜을`.
- `DesktopTopNav` 버튼 라벨 `앱` → `모바일` — `nav.app` 은 **locale 파일에 키가 없어**
  `defaultValue` 만 고치면 6개 언어에 전부 반영된다(locale 6개 무접촉).

## 🩸 이번에 틀린 것 — 둘 다 자동 검사가 잡았다

1. **네 번째 자리를 못 봤다.** `AppBadges` 호출 3곳만 세고 지우려 했는데, 헤더에 **같은 죽은 URL 을
   쓰는 '앱 다운로드' 버튼**이 하나 더 있었다. 스크립트에 넣어 둔 `assert` 가 잡았다
   (파일을 쓰기 **전에** 단언한 덕에 망가진 파일이 안 남았다).
2. **구간 삭제가 남의 코드를 먹었다.** `AppleLogo`~`PhoneFeed` 사이를 통째로 잘랐는데 그 사이에
   **`StatusBar`** 가 있었다. `tsc` 가 `TS2552` 로 잡았다.
   ⇒ **"A 부터 B 까지 지운다" 는 그 사이에 뭐가 있는지 먼저 세고 할 것.**
