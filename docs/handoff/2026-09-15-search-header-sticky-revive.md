# 태블릿·화면고정 재조사 — 세 결함 중 **하나만 살아 있었다** (2026-09-15)

2026-08-14 에 태블릿 이중 헤더 조사로 세 가지를 고쳐 PR #1160 을 올렸는데 **머지 없이 닫혔다.**
대표 지시로 되살리려고 최신 `main`(그 사이 50커밋 진행) 기준으로 **다시 재 봤다.**
결론: **그대로 되살렸으면 라이브를 깨뜨릴 뻔했다.**

## 판정 — 셋 중 둘은 폐기, 하나만 유효

| 08-14 처방 | 2026-09-15 판정 | 근거 |
|---|---|---|
| ① `LEGACY_OWN_HEADER` 에 `/` 추가 | 🚫 **적용 금지 — 지금은 해롭다** | 아래 |
| ② `mapFullScreen` 에 `/` 추가 | 🚫 폐기(전제 소멸) | 아래 |
| ③ `/search` 헤더가 네비를 덮음 | ✅ **유효 — 수리함** | 실측 재현 |

### ① 은 그 사이 **다른 방식으로 해결됐고, 내 처방은 이제 버그가 된다**

08-14 의 전제는 *"홈은 `lg`(1024) 미만에서 `RestaurantMapPage`(자체 헤더)를 렌더한다"* 였다.
그런데 **2026-08-19 에 `HomeRoute` 경계가 `md`(768)로 내려갔고 본문도 `MobileHomePage` 로 바뀌었다.**
그래서 768~1023 홈은 이제 `PcHomePage`(자체 헤더 없음)다 — 여기서 네비를 `null` 로 만들면
**태블릿 헤더가 통째로 사라진다.**

실제로 그 일이 일어났다: 누군가 08-19 에 `/` 를 넣었고, **08-24 대표가 "태블릿 메인이 예전 디자인"
으로 신고**해서 도로 뺐다. 그 경위가 `DesktopTopNav` 주석과 `home-tablet-breakpoint.test.ts` 에 남아 있다.
⇒ **내 08-14 패치를 그대로 복원했으면 그 신고를 재현했을 것이다.**

실측으로도 확인 — 홈은 지금 정상이다:
```
/ @768 · 900 · 1023   네비h=114   로고 1개   페이지바 0      ← 이중 헤더 없음
```

### ② 도 같은 이유로 소멸

`/` 가 `<md` 에서 렌더하는 것이 `RestaurantMapPage`(100dvh 자체관리)가 아니라 `MobileHomePage`
(평범한 스크롤 페이지)로 바뀌었다. 하단 네비 여백 56px 은 이제 **정상적으로 필요한 값**이다.

### ③ 만 살아 있었다 — 그리고 **내 08-14 처방 자체가 이미 틀어져 있었다**

```
고침 전  /search @900 (스크롤 500)   네비 0~114 z=40   페이지바 0~65 z=50   🔴 덮음
고침 후  /search @900               네비 0~114        페이지바 0            ✅
모바일   /search @390               네비 없음          페이지바 top-0 고정   ← 불변
```

08-14 처방은 `md:top-[102px]`(그때 네비 높이)였다. **한 달 만에 네비가 102 → 114 로 자라
그 값이 조용히 틀어졌다.** 오프셋은 *다른 파일의 높이를 외우는 것*이라 반드시 드리프트한다.

**이번 처방: `md:static`** — md+ 에서 **고정을 풀기만 한다.** 그 구간엔 네비가 자체 검색창을
이미 띄우므로(`DesktopTopNav` 의 검색 form, `/map` 에서만 숨김) 이 바까지 고정할 이유가 없다.
형제 `/browse` 는 같은 헤더를 `md:hidden` 으로 아예 없앤다 — 이쪽은 자동완성을 살리려고
숨기지 않고 스크롤을 따라가게만 했다. **기능 손실 0 · 겹침 0 · 외울 숫자 0.**

## 이번에 배운 것 (이게 제일 값지다)

🧭 **"고쳐 뒀던 패치를 되살린다"는 것은 *다시 적용한다*가 아니라 *다시 판정한다*이다.**
한 달 사이 전제가 셋 중 둘에서 사라졌고, 남은 하나도 상수가 틀어져 있었다. 그대로 복원했으면
(a) 08-24 대표 신고를 재현하고 (b) 12px 어긋난 오프셋을 심었을 것이다.
⇒ 오래된 브랜치를 되살릴 때는 **패치를 보지 말고 현재 코드를 다시 재라.**

🧭 **다른 파일의 치수를 복사한 상수는 드리프트한다.** `md:top-[102px]` 가 한 달 만에 틀어졌다.
같은 질문에 답이 두 군데면(여기선 "네비가 몇 픽셀인가") 반드시 갈라진다 — 이 레포가 반복해 만난 형태다.
처방은 값을 맞추는 게 아니라 **값을 몰라도 되게 만드는 것**이다.
