# 등록된 동네딜 검색 (2026-09-16)

대표: *"등록된 동네딜 검색도 가능하게 해줘. 매장명이라던지. 급해."*

## 무엇이 없었나

`/admin/dongnedeal-import` 목록에는 필터가 여섯 개(지역·카테고리·형태·데모여부·상태·정렬)였는데
**검색이 없었다.** 라이브에 동네딜이 수백 건이라, 이름을 아는 한 곳을 찾으려면 필터로 좁혀 놓고
눈으로 훑는 수밖에 없었다.

## 붙인 것

| | |
|---|---|
| `dongnedeal-search.ts` (신규) | 글자 필터 **순수 빌더**. 지역(주소)과 검색(q)의 SQL·바인딩을 한 곳에서 만든다 |
| `admin-products.routes.ts` `/dongnedeal/list` | `?q=` opt-in. 위 빌더에 위임(지역 필터도 같이 옮겼다). **2368 → 2348줄**(동결값 2350 안) |
| `admin-dongnedeal/DealList.tsx` | 필터 바 맨 앞 검색창(300ms 디바운스 · 지우기 버튼 · 빈 결과 문구) |

**검색 규칙 두 가지**

1. **한 칸으로 매장명 · 상품명 · 주소를 한꺼번에** 본다. 칸을 셋으로 나누면 손에 쥔 단서가 셋 중
   무엇인지 모르는 사람은 못 찾는다(그리고 급할 때 고를 시간이 없다).
2. **공백은 AND** — `강남 파스타` 는 둘 다 든 것만. OR 로 하면 흔한 낱말 하나에 목록 전체가 걸려
   검색이 아니라 소음이 된다. 지역 필터와 같은 규칙이다.

숫자만 넣으면 **상품 id** 도 함께 본다(어드민이 로그·URL 에서 집어오는 값). `2888번` 은 글자로 본다.

⚠️ LIKE 라 `%`·`_` 는 와일드카드다(종전 지역 필터와 같은 성질). 값은 전부 바인딩이라 주입은 없고,
어드민 전용 화면이라 와일드카드는 해가 아니라 가끔 쓸모가 있다.

## 왜 파일을 쪼갰나

`admin-products.routes.ts` 가 파일크기 래칫에 **2350줄로 동결**돼 있어 그 안에서는 한 줄도 못 늘린다.
빌더로 빼면서 지역 필터도 같이 옮겨 **오히려 2줄 줄었고**, 덤으로 가드가 소스를 grep 하는 대신
**함수를 불러 나온 SQL 과 바인딩을 직접 잰다**(문자열이 아니라 동작).

## 검증

- 유닛 14건 pass — 물음표 수 = 바인딩 수를 **다섯 입력에 대해 실제로 센다**
- 주입 8건 되돌려-검증(`scripts/mutations/dongnedeal-search.mjs`)
- ⚠️ **판정은 어드민 화면에서**: `/admin/dongnedeal-import` → 매장명 한 낱말을 쳐서 그 딜이 나오는지,
  지우면 전체가 돌아오는지, 숫자(상품 id)로도 나오는지.
