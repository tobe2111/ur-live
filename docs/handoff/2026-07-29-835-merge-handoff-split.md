### 🔑 왜 충돌이 났나 — 실측으로 밝힌 것 (이게 이 세션의 핵심)

`.gitattributes` 의 `merge=union`(#836, 07-29 오전)이 이 문제를 이미 해결한 줄 알았는데 **아니었다.**

| 조건 | 결과 |
|---|---|
| 로컬 `git merge` (gitattributes 적용) | **clean** |
| GitHub 머지 API | **405 `mergeable_state: dirty`** |

**GitHub 서버측 머지는 `.gitattributes` 의 union 드라이버를 적용하지 않는다.** 그래서 정작
*머지 버튼이 막히는 지점*의 마찰은 그대로였다. 충돌 지점은 항상 **문서 3번째 줄 한 곳** —
두 세션이 각자 새 항목을 맨 위에 넣어서 생기는 자리 다툼이고, 내용 충돌이 아니다.

게다가 재병합·푸시하는 동안 **main 이 두 번 먼저 전진**해(#838, #842) 두 번 다시 병합했다.
동시 세션이 도는 한 이 경주는 계속 진다 → **다툴 줄 자체를 없애는 것**이 유일한 처방이었다.
