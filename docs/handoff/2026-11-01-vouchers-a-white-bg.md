## 3. 이번에 틀렸던 판단 (제일 값진 것)

1. **"마이에서 흰 카드가 녹는다"는 과장이었다.** 픽셀로 재니 로그인한 마이는 **이미 거의 평면**
   (순백 판이 화면의 **6.6%**). 실제로 녹는 건 로그인 전 안내 카드·지갑 요약뿐이다.
   → 대표에게 정정 보고했고 그 둘만 고쳤다.
2. **"교환권 사진이 전부 안 뜬다"(26장 중 21장)는 UI 결함이 아니라 측정 한계.**
   `bizimg.giftishow.com` 이 이 컨테이너에서 connection reset(우리 R2 는 200)이고,
   라이브 교환권 100건은 전부 giftishow 직링크다(2026-10-31 `RAW_ONLY_IMAGE_HOSTS`). 대표 폰에선 뜬다.
   **이걸 UI 결함으로 보고하지 말 것.**
3. 시안 캔버스의 첫 상품 y 라벨을 손으로 적었다가 실측과 어긋났다(432↔422). 렌더 후 **실측값으로
   덮어쓰게** 고쳤다 — 라벨이 거짓말하면 시안 비교가 통째로 무의미해진다.
4. `"이용권 페이지"` 라는 호칭과 **배너가 있는 화면이 달랐다**(배너는 `/vouchers`=교환권 탭에만).
   `AskUserQuestion` 으로 확정받고 시작했다 — 안 물었으면 엉뚱한 화면을 고쳤을 것이다.

## 6. 후속 — CI 가 "가드가 지키는 척만 한다"로 잡은 것 (같은 PR, 2026-11-01)

PR #2066 의 `Verify` 가 **가드 주입 검증**에서 빨간불이 났다(run `41286191380`):

```
🖼️ 앱이 배너 시드를 안 읽는다 — 서버 배너가 사라졌다 다시 나타난다:
   결함을 심었는데 vouchers-hero-banner-ssr-2026-10-18.test.tsx 가 **통과**
```

🔎 **원인은 픽스처가 아니라 그 결함이 더 이상 결함이 아니라는 것**이었다. 주입은
`useHomeBanners.ts` 의 `const full = readBannersSeed()` **호출**을 지우는데, A안으로 머리에 배너가
없어지면서 워커가 `__SSR_INITIAL_BANNERS__` 를 **아예 안 싣는다**(주입처 전수 0 — 실측).
그러면 그 리더는 **늘 `undefined`** 를 내므로 지워도 **행동이 안 변한다.**
그리고 시험은 리더 **정의**(`getElementById('__SSR_INITIAL_BANNERS__')`)를 앵커로 잡고 있어서
호출이 사라져도 통과했다 — **계산과 사용은 다른 자리다**(2026-08-02 `goneStatus` 교훈의 재현).

**처방 — 가드 재조준이 아니라 죽은 가지 제거:**

| 자리 | 조치 |
|---|---|
| `components/home/useHomeBanners.ts` | `readBannersSeed()` 정의·호출 **제거**(주입처 0 = 도달 불가) |
| `scripts/mutations/vouchers-hero-banner-ssr-2026-10-18.mjs` | 그 주입 **삭제** + 왜 다시 만들면 안 되는지 묘비 주석 |
| 같은 매니페스트 | **반대 방향** 주입 신설 — `🖼️ 홈이 섹션 시드로 첫 배너를 안 세운다` |
| 시험 ② | *"앱이 그 시드를 읽는다"* → *"BANNERS 는 주입처도 리더도 없다"* + *"홈 strip 경로는 남아 있다"* |
| 낡은 주석 2곳 | `worker/index.ts:760`(`교환권=BANNERS`) · `shared/home-strip-banners.ts` |

🔴 **새 단언 하나엔 주입이 없다(의도).** 리더를 되살려도 행동이 안 변하므로 **출력으로 판정할 수
없다** — 행동 가드가 아니라 **근거 정확성** 가드다(선례 `blog-dates-honest-2026-10-12`).
주입을 다시 만들려 하지 말 것. 되살아나는 방향은 기존 주입
`🖼️ 교환권이 다시 배너 보조 시드를 받는다` 가 잡는다.

🔴 **중복 잠금을 피했다.** 홈 strip 시드의 *쌍*(서버 마크업 ↔ `placeholderData`)은
`home-strip-banner-ssr-2026-10-14` 가 주인이다. 그쪽은 `placeholderData: seeded,` 를 앵커하고
여기선 **계산 쪽**(`stripBannersOf(raw)`)만 본다 — 전수 확인 결과 그 줄을 보는 시험은 여기뿐이다.

**검증**: tsc 0 · 관련 유닛 3파일 40건 pass · 낡은 앵커 0(4,995건) ·
주입 3건(`머리에 배너가 되살아난다` · `다시 배너 보조 시드를 받는다` · `홈이 섹션 시드로 안 세운다`)
**되돌려-검증 전부 빨간불 확인**.

⚠️ **교훈**: 기능을 걷을 때는 **그 기능을 지키던 주입도 함께 판정**할 것. 결함이 결함이 아니게
되면 그 주입은 가드를 *헛돌게* 만들고, CI 는 "가드가 거짓이다"로 읽어 빨간불을 낸다(옳은 동작).
