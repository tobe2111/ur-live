4. 🔴 **반대 방향** — 홈(`/`) 상단 배너가 **여전히 뜨는가**. 이 방향이 깨지면 조용히 사라진다
   (교환권만 빼고 홈 보조 시드 장치는 남겨 뒀다).

## 3. 이번에 틀렸던 판단 (제일 값진 것)

1. **"마이에서 흰 카드가 녹는다"는 과장이었다.** 픽셀로 재니 로그인한 마이는 **이미 거의 평면**
   (순백 판이 화면의 **6.6%**). 실제로 녹는 건 로그인 전 안내 카드·지갑 요약뿐이다.
   → 대표에게 정정 보고했고 그 둘만 고쳤다.
2. **"교환권 사진이 전부 안 뜬다"(26장 중 21장)는 UI 결함이 아니라 측정 한계.**
   `bizimg.giftishow.com` 이 이 컨테이너에서 connection reset(우리 R2 는 200)이고,
   라이브 교환권 100건은 전부 giftishow 직링크다(2026-10-31 `RAW_ONLY_IMAGE_HOSTS`). 대표 폰에선 뜬다.
   **이걸 UI 결함으로 보고하지 말 것.**
3. 시안 캔버스의 첫 상품 y 라벨을 손으로 적었다가 실측과 어긋났다(432↔422). 렌더 후 **실측값으로
   덮어쓰게** 고쳤다 — 라벨이 거짓말하면 시안 비교가 통째로 무의미해진다.
4. `"이용권 페이지"` 라는 호칭과 **배너가 있는 화면이 달랐다**(배너는 `/vouchers`=교환권 탭에만).
   `AskUserQuestion` 으로 확정받고 시작했다 — 안 물었으면 엉뚱한 화면을 고쳤을 것이다.

## 4. 알아 둘 것

- `scripts/visual-preview.mjs --route=/vouchers` 는 그 경로 **시드가 없어 목록 0건**으로 렌더된다.
  머리·바탕 판단엔 쓸 수 있지만 목록 판단엔 못 쓴다(그래서 시안을 캔버스로 그렸다).
- 레포 `node_modules` 를 설치하면 전역 chromium 과 playwright 버전이 어긋난다 → `executablePath` 명시.
- `npm run build` 는 `route-chunk-map.ts`(커밋 대상 **아님** → `git checkout`)와
  `critical-css.ts`(**커밋 대상** — `--bg` 가 바뀌면 같이 바뀐다)를 재생성한다.

## 5. 남은 결정 / 후속

- **처방 1 은 토큰 한 줄이라 248건에 한 번에 먹었다.** 후속으로 평면(처방 3)을 다시 검토한다면
  `--lift: none` 은 쓸 수 없다 — 떠 있는 면(모달·시트·드롭다운·토스트·캐러셀 화살표·지도 오버레이·
  차트 툴팁)이 흰 배경에서 통째로 사라진다. 카드만 골라 평면화해야 하고 그게 248건을 가르는 일이다.
- **`BannerHeroRail`(hero 변형)이 사용처 0.** 지우지 않았다 — 같은 파일을 홈 배너가 계속 쓰고
  (strip/inline/wide) 섞어 지우면 홈이 깨진다. 제거는 별건.
- 대표가 배너를 되돌리고 싶어지면: `VouchersPage` 의 `<VouchersTopRow>` → `<VouchersHero>`(복원 필요) +
  워커 보조 시드 한 줄. 그때 재조준한 가드 넷이 빨간불이 되므로 함께 판단할 것.
