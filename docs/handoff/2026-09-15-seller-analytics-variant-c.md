# 셀러 매출 분석 — 안 C 구현 (2026-09-15)

**대표 확정**: *"안 C로 가자."* 시안 갤러리 `/design/variants?set=seller-analytics` 에서 세 안을 나란히 보고 고른 것.

## 무엇을 바꿨나

바꾼 것은 스킨이 아니라 **순서**다. 실측한 문제는 "내용이 나오기 전에 질문이 셋(탭 6 → 기간 3)이고
그 답이 전부 0 으로 간다" 였다 — 컨트롤 12개, 정보 0개.

| | 종전 | 안 C |
|---|---|---|
| 첫 화면 | 헤더 + KPI 카드 4 + 탭 버튼 6 + 기간 칩 3 | (판매 0) 빈 화면 한 장 / (판매 있음) 기간 3 → 큰 숫자 하나 → 목록 줄 |
| 다른 화면 가는 길 | 버튼 여섯 줄 | 목록의 줄(자주 안 쓰는 셋은 `더 보기` 뒤) |
| 돌아오는 길 | 탭 버튼 | ← `매출 요약으로` |

**기능은 하나도 안 줄었다** — 탭 6개 전부 살아 있고 구조만 바뀌었다.

## 두 가지 "없음" 을 구분한다

섞으면 거짓말이 된다:
- **전 기간 0**(`detailedData.total_buyers === 0`) → 온보딩. "아직 판매가 없어요" + `이용권 등록하기`.
- **이 기간만 0** → "최근 N일에는 판매가 없어요" + `90일로 보기`. 기간 세그먼트는 **그대로 남는다**
  (감추면 다른 기간으로 갈 길이 없어진다 — 주입이 이걸 잡았다).

⚠️ `total_buyers` 를 쓴 이유: `/api/seller/analytics/detailed` 는 **날짜 필터가 없다**(전 기간 집계).
기간 합계로 판정하면 90일 전에 판 사람에게 "아직 판매가 없어요" 라고 말하게 된다.

## 🩸 이번에 틀린 것 — 렌더가 잡았고 테스트는 못 잡았다

i18n 키를 `seller.analytics.*` 로 나눠 넣었는데, **`seller.analytics` 는 이미 `"매출 분석"` 문자열이었다.**
중첩 객체로 덮어써서 셀러 탭 묶음 라벨(`seller-tab-groups.ts`)이 깨졌다 —
화면에 `key 'seller.analytics (ko)' returned an object instead of string` 이 그대로 떴다.

- **테스트 12건은 전부 통과했다.** 내 테스트는 내가 추가한 키만 봤지 *덮어썼는지*는 안 봤다.
- 잡은 것은 `scripts/visual-preview.mjs` 렌더 한 장이었다.
- 수리: 원래 문자열 복원 + 내 키는 `seller.analyticsView.*` 로 이동(6개 언어).

🧭 **교훈**: 로케일에 **중첩 객체를 새로 넣을 때는 같은 이름의 문자열이 이미 있는지 먼저 본다.**
i18next 는 조용히 안 죽고 화면에 영문 오류를 찍는다(빌드도 테스트도 초록).

## 프리뷰 하네스 보강

`scripts/visual-preview.mjs --analytics[=empty]` 추가 — 없으면 기본 폴백(`data: []`)이 떨어져
**"한 번도 판 적 없음"** 화면이 뜬다(그게 기본인 편이 낫다). `=empty` 는 "판 적은 있으나 이 기간엔 없음".
