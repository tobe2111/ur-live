# 어드민 플랫폼 설정이 폰에서 한 글자씩 세로로 쌓였다 (2026-09-28)

## 무엇이었나

대표가 `/admin/platform-settings` 를 **폰(카카오 인앱)으로** 열어 머니 스위치 ⑨ 를 켰는데,
라벨이 **한 글자 폭**으로 짜부라져 세로로 흘렀다. 스위치는 정상 저장됐다
(라이브 실측 `settlement_skip_ledgered = true`) — **화면만** 깨져 있었다.

## 실측 (실제 페이지 렌더 · 설정 행 65개)

| 뷰포트 | 깨진 행 | 최악 라벨 칸 | 가장 높은 행 |
|---|---|---|---|
| 360px **수정 전** | **29개** | **0px** | **3,739px** |
| 360px 수정 후 | 0개 | 262px | 259px |
| 430px 수정 후 | 0개 | 332px | 211px |
| 1280px 수정 전 / 후 | 0 / 0 | 77 / 76px | **151px / 151px** |

**PC 는 151px 로 완전히 동일 — 회귀 0.** 그래서 개발 중엔 절대 안 보였다.

## 원인 — 오타가 아니라 산수

행이 `flex items-center justify-between gap-4 px-5 py-4` 이고 입력이 `shrink-0` 이라,
폰 폭에서 고정분(패딩 40 + 간격 16 + 입력 288~363)을 빼면 라벨 몫이 **0~14px** 다.
`min-w-0` 이 붙어 있어 그만큼까지 실제로 줄어든다.

🔴 **가장 심한 것이 하필 머니 스위치였다** — 그 `<select>` 는 선택지 문구가 길어
(`ON — 원장에 이미 잡힌 주문은 자동정산 건너뜀`) 고유 폭이 297~363px 라 라벨 몫이 정확히 0 이 된다.

## 고친 것

`admin-platform-settings/SettingRow.tsx` 신설 — 좁으면 쌓고 `sm`(640px)부터 종전 한 줄로 돌아간다.
**입력 폭은 호출부가 정한다**(필드마다 다르다 — 숫자 28 · 경로 72 · 색 40). 배선 네 곳:
기본 설정 · 커미션 예산(머니 스위치) · 운영 정책 · 프로모 바 5줄. Cloudflare 자격 칸은
행 모양이 달라(설정됨 배지 + 교체 버튼) 같은 클래스를 직접 썼다.

가드 `admin-settings-row-2026-09-28.test.ts` 21건 + 주입 4건 **전부 빨간불 확인**.

## 🩸 이번에 틀렸던 것 (다음 세션이 같은 함정을 밟지 않게)

1. **미리 빌드된 CSS 로 수정안을 재려 했다.** 새로 만든 `sm:w-72` 는 그 CSS 에 없어서
   `w-full` 이 이겼고, **PC 입력이 917px 로 늘어난 것처럼** 보였다. 설계가 틀린 게 아니라
   프로브가 틀렸다. ⇒ 새 유틸리티 클래스를 쓰면 **반드시 다시 빌드하고 재라.**
2. **"라벨이 짧다" 를 결함으로 신고했다.** 첫 판정이 `labelW < 80` 이라 `초대 보상 딜`(76px,
   한 줄) 같은 멀쩡한 행을 잡았다. 진짜 신호는 **제목이 되감긴 것**(`titleH > 44`)이다.
3. **가드 하나가 헛돌았다.** 헬퍼의 소스 문자열을 정규식으로 봤는데 템플릿 리터럴의 백틱에 걸렸다
   ⇒ **함수를 호출해** 나오는 클래스를 본다.
4. **러너에 없는 옵션(`expectPass`)을 지어냈다.** "통과해도 되는 주입" 으로 적었는데 그런 건 없다
   ⇒ 주입이 통과하면 그건 가드가 안 지키는 것이다. 시험이 실제로 지키게 고쳤다(`as="label"`).

## 남은 것 (이번 범위 밖)

**어드민의 다른 화면들**은 여전히 같은 클래스를 쓴다. 이번 범위는 대표가 실제로 부딪힌
플랫폼 설정 한 장이다 — 신고되면 같은 방식으로(`SettingRow` 로) 옮기면 된다.
전수로 훑고 싶으면 `scripts/`(스크래치) 의 `settings-page-probe.mjs` 가 **실제 페이지를 렌더해**
라벨 폭·제목 되감김을 세므로 경로만 바꿔 돌리면 된다.
