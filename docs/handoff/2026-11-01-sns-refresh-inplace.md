# SNS 제자리 새로고침 (2026-11-01)

앞선 PR [#2071](https://github.com/tobe2111/ur-live/pull/2071)(연동 정보 카드)이 남긴 한 가지:
> ⟳ 를 누르면 **플랫폼 로그인으로 리다이렉트**된다(앱을 벗어난다). 참고 화면은 제자리 갱신이다.

## 1. 가능했던 이유

토큰이 **처음부터 암호화 저장돼 있었다** — `user_sns_links.access_token_enc` ·
`refresh_token_enc` · `token_expires_at`. 왕복이 필요 없었다.

## 2. 무엇을 했나

### ⓐ 프로필 조회를 `fetchProfile(p, token)` 로 **추출**

종전엔 `exchangeAndFetch`(코드 교환) 안에 인라인이었다. 갱신을 만들려면 **같은 필드 목록과 같은
해석**(숨긴 구독자 → null 등)을 두 번째로 적어야 했고, 두 벌이 되면 *연동했을 때와 다시 확인했을 때
숫자가 다른* 어긋남이 생기는데 **에러는 안 난다.**

🔑 새 필드(프로필 사진·게시물 수 …)를 넣는다면 **여기 한 곳**이다.

### ⓑ `refreshSnsLink(env, userId, platform)`

1. 행 읽기 → 토큰 복호
2. **만료가 5분 안이면 먼저 재발급** — 구글 access token 은 ~1시간, 틱톡은 ~24시간이라
   안 하면 **가장 흔한 경우에 늘 "다시 연동"** 이 뜬다(이 처방의 존재 이유).
   인스타는 장기 토큰(60일)이라 만료가 가까울 때만 `ig_refresh_token`.
3. `fetchProfile` → 실패하고 아직 재발급을 안 했으면 **한 번 더 재발급 후 재시도**
   (만료 예측이 빗나갈 수 있다 — 에러 문구로 판정하지 않는다)
4. 🔒 `external_id` 불일치 → **갱신하지 않는다**(플랫폼에서 다른 계정으로 로그인한 경우.
   덮으면 "한 SNS 계정은 한 유어딜 계정" UNIQUE 가 지키던 것이 조용히 무너진다)
5. UPDATE — 토큰은 `COALESCE(?, 기존)` 이라 **새로 받았을 때만** 덮는다

### ⓒ `POST /api/seeding/sns/:platform/refresh` (`requireAuth`)

🔴 **실패해도 연동을 지우지 않는다** — 일시 장애로 사람의 연동을 끊으면 다시 연동하는 동안
신청이 막힌다. 읽기 실패는 *모름*이지 *없음*이 아니다.

### ⓓ 화면

⟳ → `refresh(p)`. 도는 동안 아이콘 회전 + `확인 중`. `reconnect` 일 때만 플랫폼으로 보낸다
(그게 실제로 고치는 길이고 누른 사람의 의도와 같다).

## 3. 가드

`sns-refresh-inplace-2026-11-01.test.ts` 9건 — **가짜 D1 + 가짜 fetch 로 진짜 함수를 돌려** 판정한다
(발행된 SQL·bind·호출 순서를 본다). 주입 8건 **되돌려-검증 전부 빨간불**.

🩸 **첫 판의 단언 하나가 틀렸다**: *"`followers_count` 가 1번만 나온다"* 로 두 벌을 막으려 했는데,
같은 함수 안에서 두 번 나온다(필드 목록 + 꺼내 쓰기). **개수가 아니라 *어디서* 읽는가**가 불변식이라
`exchangeAndFetch` 본문을 잘라 "프로필 필드를 직접 다루지 않는다" 로 바꿨다.

## 4. 검증

- tsc 0 · `pre-push-gate` 가드 101개
- ⚠️ **실제 플랫폼 호출은 못 해 봤다** — 키가 아직 없고(인스타 `app_id` null · 유튜브·틱톡 env 없음)
  라이브 연동도 **0건**이다. 가짜 fetch 로 분기만 확인했다.

## 5. ⚠️ 다음 세션이 알아야 할 것

### 첫 연동에서 확인할 것 (키가 들어간 뒤)

1. ⟳ 를 눌렀을 때 **앱을 안 벗어나고** 숫자/시각이 갱신되는지
2. **유튜브 — 1시간 뒤에 다시** 눌러 보기. 재발급이 실제로 도는지가 여기서만 드러난다
   (가짜 fetch 는 구글이 `grant_type=refresh_token` 에 뭘 주는지 증명하지 못한다)
3. 틱톡은 심사 전까지 팔로워가 **안 온다** — `—` 가 뜨는 게 정상

### 대표 답 대기 — 어떤 정보를 더 보여줄까

재 봤고 시안까지 보냈으나 아직 확정 전:
- ① 이미 저장돼 있는데 안 쓰는 것: `profile_url`(계정 링크) · `account_type`(왜 못 읽었는지) · `token_expires_at`
- ② 권한 범위 안인데 안 받는 것: 프로필 사진 · 게시물 수 (유튜브는 **이미 응답에 들어와 있고 버린다** —
  `part=snippet,statistics` 로 `thumbnails`·`videoCount`·`viewCount` 를 받아 놓고 구독자만 쓴다)
- ③ 안 되는 것: 참여율·평균 조회수(인스타 `manage_insights` = **Meta 심사 별도**) ·
  팔로워 추이(지금은 덮어쓴다 — 스냅샷 테이블이 필요)

⚠️ 라이브 연동이 **0건**이라 지금 필드를 늘리면 첫 연동부터 채워진다(백필 불필요).

### 그대로인 것

유어샵 SNS(`users.*_url`, 손입력) ↔ 체험 SNS(`user_sns_links`, OAuth) **상호 참조 0건** ·
어드민에 체험용 콜백 주소 미표시 · 알림톡 7종 SENS 심사 · 신청권 staging 실결제 후 스위치.
