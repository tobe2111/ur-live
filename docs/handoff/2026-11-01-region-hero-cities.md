## 2차 (같은 날) — 대표 *"밝은 사진들로 해서 그라데이션도 넣고 … 지금은 어둡기만 하네"*
- 7장 전부 밝은 파스텔 낮 사진으로 재생성(Figma 노드 2:3~2:9) → 서울·부산·대구·제주 v3, 인천·세종·전주 v2.
- `dark` 강제·남색 막(REGION_HERO_SHADE) 제거 → `REGION_HERO_FADE_LIGHT`(아래로 흰색에 녹음 + 왼쪽 옅은 흰 막) / `REGION_HERO_FADE_DARK`(다크 테마만).
- index.css 의 안 고른 탭 흰 글자 규칙은 `.dark` 일 때만.

## 3차 — 대표 *"16개잖아 우리 1차 도시 필터링은. 그거 다 해야지"*
- 추가: 경기(수원 화성)·강원(경포+설악)·대전(엑스포다리·한빛탑) v1, 충남세종 칸 → 세종 사진. 좌표는 여러 상자(`boxes`) 지원.
- ⚠️ 남은 6곳: 충북·울산·경남·경북·광주·전남 — 사진은 Figma 노드 3:5(충북)·3:7(울산)·3:8(경남)·3:9(경북)·3:10(광주)·3:11(전남)에 이미 생성돼 있다(충남 3:6 도 있음).
  1080px 로 받는 도중 **Figma Starter 플랜 MCP 호출 한도**에 걸렸다. 한도가 풀리면 `get_screenshot(maxDimension 1080, base64)` 로 받아 webp 로 저장 + 표 한 줄씩.
  (figma.com 자산 URL 은 이 컨테이너 프록시가 막는다 — curl 불가.)

## 4차 — 스크롤 접힘(대표 확정 스크롤 시안 ①②③)
- 사진 머리는 더 이상 sticky 아님(`relative`). 머리 끝 점(`heroEndRef`)이 화면 위로 지나가면 `data-home-compact-bar` 고정 막대(로고 줄 + 카테고리 줄, `bg-surface shadow-lift`)가 뜬다. 같은 JSX(`logoRow`·`catRow`)를 두 곳에서 쓴다.
- 사진 없는 지역은 종전 sticky 머리 그대로.
- ⚠️ 실기기 확인 필요: 막대가 뜨는 순간 깜빡임, 상태바(노치) 영역 겹침.
