## 🔑 대표 규율 — "앞으로는 이런 개선은 다른 카테고리와 함께"

원인은 디자인이 아니라 **구조**였다. 같은 것을 두 벌로 가지면 반드시 한쪽만 고쳐진다.
⇒ 갤러리·제목 헤더를 **한 벌**로 만들고, 그것을 **CI 가드로 고정**했다
(`groupon-detail-map.test.ts` — 상세 각 종류가 `DetailGallery`/`DetailTitleHeader` 를 쓸 것 +
자체 스와이프 갤러리 부활 금지 + 제목 헤더가 표면 의존 색(`var(--gbd-*)`)을 쓰지 않을 것).

⚠️ **아직 남은 구멍**: 쇼핑 상세(`/products/:id`)와 교환권 상세(`/vouchers/:id`)는 단일 이미지
구조라 이 통일에서 빠져 있다. 갤러리로 올릴 때 가드의 `PAGES` 목록에 **함께 추가**할 것.

## 이번에 발견한 부수 결함 (지적 외)
- **리뷰 사진이 화면에 없었다** — 서버는 `images` 를 계속 주고 작성 폼은 5장까지 받는데 목록이
  한 장도 안 그렸다. 이제 최대 4장 썸네일.
- 그루폰에 있지만 **일부러 안 넣은 것**: 리뷰의 "N ratings · N reviews" 와 `👍 Helpful`.
  우리 API 에 없는 값/동작이라, 넣으면 화면만 그루폰이고 내용은 거짓이 된다(helpful_count 는
  **숙소 리뷰에만** 있다). 서버가 생기면 그때.

## 다음 세션의 첫 액션 — 배포 후 라이브 판정

배포 전 대조군을 미리 재 뒀다(수정 전 라이브 실측):
```
#2843 · #2813 → 각 죽은 타일 1개(회색 칸)     #2839 → 커버가 죽어 사진 0개
```
배포 후 같은 상품에서 **죽은 타일 0 / 사진 정상**이면 수리 완료.

그리고:
1. `urdeal.kr` 홈 PC — "지금 인기 이용권"의 **더보기**를 눌러 URL 에 `?sort=popular` 가 붙고
   그리드가 실제로 바뀌는지(이전엔 `/` 라 아무 일도 안 났다)
2. `urdeal.kr/stays/2790` PC — 제목·별점이 사진 위 + [좌 갤러리 | 우 예약 패널]
3. `urdeal.kr/cart` PC — 좌 목록 + 우 결제 요약 2단(액자 아님)
4. 카드 사진 화살표 — 눌렀을 때 **빈 칸 없이** 바로 다음 사진
