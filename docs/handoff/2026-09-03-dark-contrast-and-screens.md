## 2. 히어로 사진이 아래 매대와 어긋나 있었다

대표가 빨간 상자로 짚어 준 것: 사진 오른쪽 끝이 아래 매대와 안 맞는다.

원인은 `right-0` — 사진이 **뷰포트 오른쪽 끝**까지 가는데 바로 아래 매대는
`max-w-[1440px] + px-6/8` 안에 있다. 넓은 화면일수록 벌어진다(**1904px 에서 264px**).

수정: 색면은 전체 폭 그대로(그게 이 히어로의 바탕이다), **사진만** 같은 자로 당긴다.
`right-[calc(max(0px,(100vw-1440px)/2)+2rem)]`. 폭(46/54%)은 안 건드려 좁은 화면 균형은 그대로.
"사진 속 딜 보기" 링크도 같은 자로.

## 3. 히어로 영상 — **이미 됩니다** (코드 변경 없음)

대표 질문 *"히어로에 사진 대신에 영상도 넣을 수 있어?"* → 전 구간 배선 완료 상태였다:

```
banners.video_url (DB)
  → admin-banners.routes (validateImageUrl 검증)
  → AdminBannersPage <BannerMediaUpload kind="video">   ← 어드민 UI 입력칸 있음
  → HomeHeroBanner (prefers-reduced-motion 존중)
  → HomeHeroDefault <video autoPlay muted loop playsInline>
```

⚠️ 다음 세션이 "구현해야 한다" 고 오판하지 말 것. **어드민 배너에 영상 올리면 끝이다.**
`video_url` 이 있으면 사진 대신 영상이 나가고, 사용자가 모션 최소화를 켜 놨으면 자동으로 사진으로 떨어진다.

## 4. 위시리스트 PC

- 뒤로가기 원형 버튼 `lg:hidden` — PC 는 상단 네비가 있는데 이것 하나 때문에 **줄 하나가 통째로 흰 띠**(60px)
- 제목이 그리드 컨테이너 **밖**이라 왼쪽 끝이 어긋남(24px vs 44px) → 안으로.
  ⚠️ `LargeTitle` 은 자기 `px-4` 를 갖고 **마이·주문·지갑 세 페이지가 컨테이너 밖에서** 쓴다 →
  공유 부품은 안 고치고 이 페이지에서만 `[&>div]:px-0` 로 껐다.
- 빈 상태: 테두리 카드 + 그라디언트 버튼 → 흰 카드(들림) + 브랜드 블루 알약(표면 규칙 ①⑥ 위반이었다).
  PC 는 1900px 카드에 하트 하나라 텅 비어 보여 `lg:max-w-xl` 중앙 정렬.

## 5. 스크롤바 — 시안 4안 (대표 판단 대기)

지금 유어딜은 스크롤바를 **한 번도 정의한 적이 없다**(`no-scrollbar` 숨김 유틸만 있다).
지역 선택창의 두꺼운 회색 막대는 **OS 기본값**이고 윈도우/맥/안드로이드가 다르게 그린다.

시안: https://claude.ai/code/artifact/35a30905-0f4d-4984-bf67-4c6b886c57b7
(네 안 모두 **실제로 움직이는** 스크롤바 · 화이트/다크 나란히)

| 안 | 형태 | 판단 |
|---|---|---|
| 1 | 얇은 잉크 8px, hover 시 진해짐 | **추천** — 스크롤바는 가구지 강조 대상이 아니다 |
| 2 | 초슬림 4px | 예쁘지만 윈도우에서 **잡기 어렵다** |
| 3 | 트랙 있는 알약 12px | 목록이 아주 긴 화면(지역 선택)엔 이쪽이 낫다 |
| 4 | 브랜드 블루 | 표면 규칙 ②와 충돌 — 강조색 예산을 가구에 쓴다 |

⚠️ 모바일 영향 0(터치 기기는 스크롤바를 안 그린다). 파이어폭스는 `scrollbar-width: thin` 근사치만.
