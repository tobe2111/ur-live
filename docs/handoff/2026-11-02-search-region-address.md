# 2026-11-02 — 지역 검색(부산 등)에서 이용권이 안 나오던 문제

서비스: **유어딜(소비자) 검색** `/search` → `GET /api/search?q=` → `ProductRepository.searchByText`.
머니 경로 접촉 없음 · 잠금표 파일 무접촉.

## 대표 질문
*"부산 같이 지역을 검색 시에 이용권이 왜이렇게 안나오지? 검색 로직 지금 완벽한 거 맞아?"*

## 원인 (라이브 실측)
검색 대상 칸이 `상품명 · 매장명 · 설명 · 카테고리` 넷이었고 **매장 주소(`restaurant_address`)가 없었다.**
지역 검색은 상품명·설명에 지명이 *우연히* 적힌 이용권만 잡았다.

| 검색어 | 주소에 그 지명이 있는 활성 이용권 | 수리 전 검색 결과 | 수리 후(라이브 DB 에 새 SQL 실행) |
|---|---|---|---|
| 부산 | 7 | 1 | 7 |
| 해운대 | 3 | 0 | 3 |
| 서울 | 86 | 2 | 87 |
| 강남 | 8 | 1 | 8 |
| 제주 | 8 | 5 | 9 |

## 고친 것
1. `search-query.ts` `SEARCH_COLUMNS` 에 `restaurant_address` 추가 + 랭킹에 주소 단계(400, 매장명 500 과 카테고리 300 사이).
2. 시·도 표기 묶음(`REGION_GROUPS`) — `부산시`·`부산광역시` → `부산`, `경상북도` ↔ `경북`, `제주도` → `제주` 등.
3. 🩸 **시·도 이름은 주소 맨 앞에서만 맞춘다** — 첫 판(어디든 부분매칭)에서 `대구` 가 `부산 해운대구 …` 를 잡는 걸 시험이 잡았다.
4. 폴백 경로(`findAll`·`count`)에도 주소 칸 추가.

가드: `src/tests/unit/search-region-address-2026-11-02.test.ts`(진짜 SQLite, 12건). 되돌려-검증 2회
(주소 칸 제거 → 8건 빨강 · 맨앞 매칭 제거 → 2건 빨강).

## 다음 세션 첫 액션
배포 후 라이브 확인:
`curl -sS "https://urdeal.kr/api/search?q=%EB%B6%80%EC%82%B0&limit=50" -H "User-Agent: Mozilla/5.0 ..."`
→ 응답 중 `category` 가 `_voucher` 이고 `deal_only` 가 0 인 행이 **7개**면 E4 통과(수리 전 1개).

## 후속 (같은 날, 대표 *"아쉬운 점들 다 해결해줘"*)
1. **서버가 범위를 거른다** — 검색 화면이 `scope=voucher|exchange` 를 보내고 라우트가 `voucherOnly`/`dealOnly` 로
   바꿔 랭킹 검색·폴백 둘 다 SQL 에서 거른다. 라이브: `서울` 첫 장 이용권 **40 → 50/50**.
   `scope` 를 안 보내는 다른 호출부는 종전 그대로(전부). 화면의 클라이언트 필터는 안전망으로 남겼다.
2. **광주** — 시·도 이름은 주소의 *낱말 첫머리*(맨 앞 또는 공백 뒤)에서 맞춘다. 사람이 친 `광주` 는
   광주광역시 + 경기 광주시를 둘 다 잡고(라이브: 0 → 1, 경기 광주시 가게), `광주광역시` 로 치면 펼친 `광주` 는
   맨 앞에서만 맞춰 경기 광주시를 안 끌고 온다. `대구` 는 여전히 해운대구를 안 잡는다.
3. **pre-push 시험 1회 빨간불의 정체** — 다시 돌리니 736개 전부 통과(303초). 그때 같은 컨테이너에서 전체 단위시험을
   백그라운드로 동시에 돌리고 있었다 → 부하로 인한 시간 초과로 본다(어느 시험이었는지는 로그가 남지 않아 미확정).
   ⇒ **pre-push 와 전체 vitest 를 동시에 돌리지 말 것.**

## 남은 것
- 라이브 E4 판정: 배포 후 `GET /api/search?q=서울&scope=voucher&limit=50` 가 50개 전부 이용권이면 통과.

## 틀렸던 판단
- 처음엔 지명을 주소 어디서든 찾게 했는데 `대구`⊂`해운대구` 오매칭을 시험이 잡았다. 짧은 지명은 겹친다.
- 광주광역시로 쳐도 펼친 `광주` 가 공백 뒤 매칭으로 경기 광주시를 끌고 왔다 — 시험이 잡았다. 펼친 표기는 맨 앞에서만.
