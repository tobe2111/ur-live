## 🩸 하네스가 두 판 헛돌았다 — 다음 세션이 반드시 피할 것

`curl -D -` 로 헤더와 본문을 한 스트림에 받아 **첫 `\r\n\r\n` 로 잘랐더니** 측정이 통째로
거짓이 됐다. 이 컨테이너는 에이전트 프록시를 거치므로 덤프 맨 앞에

```
HTTP/1.1 200 Connection Established\r\n
\r\n                       ← 첫 구분자가 여기다
HTTP/2 200 \r\n
```

가 먼저 온다 ⇒ **진짜 헤더가 통째로 body 안으로** 들어가 페이지가 헤더 텍스트 덤프로 렌더됐다.
`innerText` 가 57,188자나 나와서 얼핏 "잘 열렸다"로 보였고, 앵커 4개가 전부 `null` 인 것이
유일한 이상 신호였다(그게 없었으면 조용히 통과했을 것이다).
⇒ **헤더는 `-D <파일>`, 본문은 stdout 으로 분리해 받고, 헤더 블록은 마지막 것만 쓴다.**

🧭 교훈: 측정이 틀렸는지 알려 준 건 "값이 이상하다"가 아니라 **"앵커가 하나도 안 잡힌다"**
였다. 측정에는 늘 *성공을 확인하는 앵커*를 같이 넣을 것.
