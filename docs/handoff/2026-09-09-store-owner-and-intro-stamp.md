## 🔴 ① 직접 등록한 사장님이 자기 매장의 소유자가 아니었다 (잠복 결함 — 돈을 못 받는다)

`/store/new` 는 설계상 `sellers.linked_user_id` 를 **비워 두고**(UNIQUE 1인1행)
`seller_operators` 로 접근을 준다 — **직접(direct)=`role:'owner'` · 중개(brokered)=`role:'operator'`**
(`seller-stores.routes.ts:12-14, 479`).

그런데 소유 판정이 **토큰을 건너며 무너졌다**:
```
canOperateStore    → { role:'owner', source:'grant' }        ← 역할은 맞게 나온다
토큰 발급          → if (source==='grant') operator_user_id  ← 역할을 안 싣는다
resolveStoreActor  → isOwner = operatorUserId === null       ← 그래서 false
```
⇒ 직접 등록한 **진짜 사장님이 운영자로 오판**되고 소유자 전용 게이트가 전부 닫힌다:
① **정산 계좌 변경 403 → 그 매장은 돈을 받을 방법이 없다** ② 자기 사업자정보 마스킹
③ 탈퇴 불가 ④ 자기 매장 정산 내역이 합류 이후로 잘림(#1404 가 넣은 범위 게이트).

**수리**: 토큰에 `store_role` 을 함께 싣고, `resolveStoreActor` 가 **역할로** 소유를 가른다.
`operator_user_id` 는 그대로 둔다 — 그건 소유 판정이 아니라 **시트 분리**용이다(빼면 운영자
진입 시 사장님이 튕긴다). 옛 토큰(30일)은 `store_role` 이 없으므로 **종전 규칙으로 폴백**.

⚠️ 라이브에 직접 등록 매장이 아직 0이라(유일한 매장 14 는 brokered) 오늘 터지진 않았다 —
**다음에 "직접(업주)"로 등록하는 첫 사장님이 바로 밟는다.** 그게 주 경로다(수수료 10%).

## 🕳️ ② 손바뀜 자물쇠가 **지금 만드는 모든 매장에서 무력**이었다

어제 건 자물쇠(#1404)는 `sellers.linked_user_id` 만 봤다. 그런데 위 설계대로 그 칸은 항상 비어 있다.

## 🧭 ④ 위치 없이 '가까운 순'이면 정렬이 통째로 사라졌다 (대표 신고 — 세션 중 추가)

대표: *"딜 50개 아래에 있는 쪽 이용권들은 거리순으로 정렬이 안되어있는데?"*

**서버는 멀쩡했다**(라이브 실측 `?near=37.2005,127.0980` → 0.1 · 0.2 · 0.3 · 0.5 · 0.8 · 1.0km).
클라가 `near` 를 안 보내고 있었다:
```
sort = sortBy==='distance' ? '' : sortBy      → 거리순이면 서버 sort 를 비운다
near = sortBy==='distance' ? userLoc : null   → 위치가 없으면 near 도 없다
클라 정렬: if (sortBy==='distance' && userLoc) → 위치가 없으면 건너뛴다
```
⇒ **셋이 겹쳐 아무 정렬도 안 된 목록이 "거리순" 라벨을 달고 나온다.** 에러도 빈 화면도 없다.

🕳️ 그리고 헤더의 동네 이름(`ur_near_dong_v1`)은 **localStorage 에 따로 남아** 위치가 없어도
계속 보인다 — 사용자는 위치가 잡힌 줄 안다. 이 구멍이 눈에 안 띈 이유다.

**수리** — `restaurant-map/effective-sort.ts` SSOT:
- **위치 없이 거리순은 존재할 수 없다** → 할인율 순으로 내려간다(정렬 부재 상태 금지)
- **서버 요청과 클라 재정렬이 같은 함수를 쓴다**(2026-09-03 에 둘이 갈려 "인기순"이 인기순이
  아니었던 그 클래스 재발 방지)
- 거리순을 고르면 **위치를 요청한다**(`chooseSort` → `requestNearMe`) — 막다른 상태를 애초에 안 만든다

⚠️ **거리순 1번이 항상 최단거리는 아니다** — "데모 이용권 항상 후순위"(2026-07-04 대표 지시)가
1차 정렬 키라 비데모가 먼저 온다(실측: 전주 151km 가 동탄 0.1km 앞). **의도된 규칙**이고
데모가 사라지면 함께 사라진다. 지금 바꾸지 않았다.

- **(b) 사장님이 실제로 요청할 때 짓는다** — 그때까지 어드민이 수동으로 승격(1건이라 가능).

**추천: (b)**. 이번에 자물쇠가 그 문을 보게 만들었으므로 **수동 승격도 이제 안전하다**(잔액이
