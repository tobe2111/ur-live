# 유료 전환 준비 마감 — 등기부가 못 보던 절반 (2026-08-03)

## 다음 세션의 첫 액션

유료 전환을 **실제로 하는 날**의 절차다. 그 전엔 할 일 없음.

```
1) 대시보드에서 Workers Paid 전환
2) ur-ads 워커 env 에 ADS_PLAN=paid 추가
3) 한 시간 뒤 판정:
```
```sql
SELECT key, value FROM platform_settings WHERE key IN ('ads_lanes_learned','ads_tick_history');
```
**기대**: `cap` 이 배운 자리(현재 4)에서 **+1씩** 오른다. **64 로 점프하면 안 된다** —
점프하면 `lane-aimd.ts` 의 "요금제는 천장만 바꾼다" 가 깨진 것이다(그 불변식은 테스트로 고정돼 있다).

⚠️ **급하면 `ADS_LANES_PER_TICK` 명시값**으로 즉시 올릴 수 있다(학습 우회, 무배포). 다만
그 값은 학습기를 **완전히** 이기므로, 켜 두면 자가 조정이 멈춘다는 걸 알고 쓸 것.

## 무엇을 고쳤나 — 등기부의 사각지대(R3)

`check-plan-knob-coverage.mjs` 는 **`ADS_*` env 노브만** 봤다. 그런데 이 파이프라인의 요금제 축
**절반은 env 가 아니라 파일 안 상수 쌍**이다:

| 상수 쌍 | 파일 |
|---|---|
| `RUN_DEADLINE_MS` / `_PAID` | `commerce-notify-collect.ts` · `store-kakao-collect.ts` |
| `ALARM_INTERVAL_MS_DEFAULT` / `_PAID` | `lane-alarm-policy.ts` |
| `RUNS_PER_HOUR_DEFAULT` / `_PAID` | 〃 |
| `SUBREQ_PLATFORM_CAP_DEFAULT` / `_PAID` | `collect-budget.ts` |
| `ENRICH_DEADLINE_MS_DEFAULT` / `_PAID` | 〃 |

**이것들은 등기부에도 안 뜨고 R2 에도 안 걸린다.** 08-03 전수 확인에서 다행히 전부 배선돼
있었지만, 그건 **강제가 아니라 성실함**이었다. `_PAID` 를 만들고 선택부를 안 붙이면
**유료로 바꿔도 그 축은 안 오른다**(에러 없음) — 하루에 세 번 만난 그 모양이 env 밖에서 재현된다.

**R3**: `_PAID` 상수는 **정의만으로 부족하고 실제로 선택돼야 한다**(`envPlanValue` 등 요금제 판정 경유).

⚠️ **R3 가 못 잡는 것**: `_PAID` 짝이 **아예 없는** CF-bound 상수. 이름만으로는 그게 CPU 에 묶인
건지 데이터 모양인지 알 수 없다 — 사람이 판단해야 한다(등기부의 `why` 와 같은 이유).

## 이번에 틀렸던 판단 (둘 다 주입 하네스가 잡았다)

### ① R3 를 `let bad` **앞**에 뒀다 — 위반 시 TDZ 로 죽는 코드
통과할 땐 멀쩡하고 **실패할 때만** `ReferenceError` 로 깨진다. 가장 나쁜 모양이다 —
가드가 "지키는 척"도 못 하고 그냥 죽는다. 순서 검사를 넣고서야 알았다.

### ② 테스트가 **이름**을 봐서 헛돌았다
`orphanPaid.size` 문자열만 확인했는데, 그 이름이 **에러 메시지 안에도** 있어서
`if (orphanPaid.size)` 를 `if (false)` 로 바꿔도 초록이었다.
⇒ **이름이 아니라 강제 경로**(`if (…) { bad = true`)를 겨누도록 교정.
🔑 같은 함정을 이 파일에서 **두 번째** 겪었다(첫 번째는 08-02 R1). 다음에도 또 온다 —
**"이 문자열이 다른 곳에도 있나"를 먼저 확인할 것.**

## 유료 전환 시 자동으로 오르는 축 (현재 상태)

| 축 | 무료 | 유료 | 방식 |
|---|---|---|---|
| 회차당 레인 수 | 학습값(현재 4) | 같은 자리에서 +1씩 → 최대 64 | **자가측정(AIMD)** |
| 서브리퀘스트 천장 | 60 | 900 | env 리졸버 |
| 보강 벽시계 | 7s | 20s | env 리졸버 |
| DO 알람 간격·상한 | 5분/12회 | 1분/60회 | 상수 쌍 |
| 레인별 예산 7종 | 각 기본값 | ×15(천장 클램프) | env 리졸버 |
| 수집 레인 마감선 2종 | 12s | 24s | 상수 쌍 |

🔴 **외부 쿼터 11개는 안 오른다** — YouTube 유닛·카카오/네이버 일 한도. 올리면 **유료 전환이 곧 장애**다
(그날 쿼터를 태우고 그 레인이 종일 죽는다). 등기부가 `external` 로 못박고 있다.
