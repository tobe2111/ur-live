## 🩸 틀렸던 판단 / 발견한 구멍

1. **일괄 이모지 제거는 빈 요소를 남긴다** — 닫기 버튼 5개(`✕`)·빈 상태 큰 글리프 5개·상태 글리프 span 4개. 셀러 PR 에서
   배운 그대로 `<x></x>` grep 으로 잡아 lucide `X`/텍스트로 채웠다. **일괄 제거 뒤 빈 요소 grep 은 필수 단계.**
2. `BusinessSegments.card(tone, emoji, title…)` 처럼 **이모지를 인자로 받는 함수**는 일괄 제거로 `''` 만 남는다 — 렌더에서
   `{emoji} {title}` 이 `" 페이백"` 이 되어 있었다. 인자 자체를 죽였다(`_emoji`).
3. `stripComments` 가 `StatusLines.tsx` 의 JSX 주석 두 곳(`{/* 👥 … */}`)을 못 걷어 테스트가 주석 이모지에 걸렸다.
   주석의 이모지를 지워 우회했다 — **SSOT 스트리퍼의 구멍은 별건**(그 파일 246줄 근처 문자열/정규식 리터럴이 원인으로 보임).
   `check-comment-stripper` 가 자체 스트리퍼를 막으므로 테스트 안에서 우회하지 말 것.
4. 주입 앵커 `rounded-[var(--dash-radius,16px)]` 가 파일에 3곳 — 러너가 **유일성**을 요구해 빨간불이 아니라 오류였다.
   앵커는 늘 앞뒤 클래스까지 붙여 유일하게.
5. 테스트의 `[^']*` 가 **줄을 넘어** 별표 `★`(U+2605)까지 잡았다 — 이모지 범위에서 ★☆ 를 빼고(`2600-2604`, `2607-27BF`)
   `[^'\n]*` 로 고정. ★ 는 글자다(평점·우선 표시).
