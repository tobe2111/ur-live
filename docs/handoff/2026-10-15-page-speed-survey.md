## 2. 로그아웃 마이·장바구니가 가장 느렸던 원인 — API 가 아니었다

- 트레이스(`pages/trace.mjs`): API 대기 0. 그 두 페이지가 워커 청크 맵(`ROUTES`)에 없어서 **페이지 청크가 앱 부팅(약 2.5초) 뒤에야 출발**했고
  20여 파일을 받느라 마지막(`app-components`)이 5.1~5.5초에 도착했다.
- 그 사이 `load` 가 이미 지나 **센트리(129KB)가 같은 회선을 나눠 썼다**(3.1초 출발 → 5.6초 도착).
  preload 는 `load` 를 붙들므로 맵에 올리면 센트리도 페이지 뒤로 밀린다(한 수정으로 둘이 풀린다).
