# 매장 영입 2% 폐지 — 화면이 하던 거짓 약속을 걷어냄 (2026-09-16)

**대표 확정**: *"인플루언서 2%는 뭐지? 그런거 없어."* · *"매장 데려온 사람 2%는 이제 아예 없는거야."*

## 이건 "기능 삭제"가 아니라 "거짓말 삭제"였다

적립은 **이미 죽어 있었다**:
- `creditInfluencerStoreIntroCommission` **호출부 0** (`order-commissions.ts` 가 "적립만 없앴다"고 기록)
- 라이브 `influencer_attributions` **0건** · `seller_influencer_deals` 0건 · `user_withdrawals` 0건

그런데 **화면 넷이 계속 2%를 약속하고 있었다**:

| 화면 | 문구 |
|---|---|
| 유어샵 수익 사다리 1단 | "내 초대 링크로 등록한 가게는 매출의 2%를 1년간 받습니다" |
| 정산 페이지 매장 초대 링크 | "그 매장 매출의 2%를 1년간 받습니다" |
| 정산 페이지 빈 상태 | "6개월간 +1% 추가 commission" (값조차 낡은 옛 규칙) |
| **인플루언서 약관 제3조** | "매출 2%를 가입 후 1년간 적립합니다" ← **법적 문서** |

같은 레포가 이 위험을 정확히 적어 뒀다 — *"화면은 'N% 받는다'인데 정산은 0 이 된다. 그건 버그가
아니라 **약속 위반**이고, 되돌리는 데 드는 비용(환급 + 신뢰)이 훨씬 크다"* (`influencer-deal.ts`).

## 🩸 이 괴리가 사람도 속였다

2026-09-15 에 세션이 대표에게 **"영입 2% 가 살아 있다"** 고 보고했다. 설정값(`influencer_store_intro_pct=2`)과
환불 역전 코드만 보고 단정한 것이고, **적립 호출부는 0**이었다. 대표가 *"그런거 없어"* 로 바로잡았다.

⇒ **화면·설정이 코드보다 뒤처지면 사람도 코드를 오독한다.** 죽은 기능은 조용히 두지 말고 명시적으로 죽여야 한다.

## 한 것

- 유어샵 수익 사다리: 1단(영입 2%) **삭제** → 사다리가 2단이 됨(딜 → 담아 팔기). 초대 링크·복사 버튼도 제거
- 정산 페이지: 매장 초대 링크 블록 삭제 · 빈 상태 문구에서 "6개월간 +1%" 제거
- **인플루언서 약관 제3조에서 영입 조항 삭제**
- 어드민 커미션 설정: 입력란을 지우지 않고 **"폐지됨" + disabled** 로. 지우면 다음 사람이 다시 만든다
- 제안서 요약 문구 정정

## 일부러 안 지운 것

| | 왜 |
|---|---|
| `introduced_by_influencer_id` | "누가 데려왔나"는 **사실**이고 중개사 계약이 그 위에 선다 |
| `reverseInfluencerStoreIntroOnRefund` | 적립 0건이라 no-op. 머니 경로를 건드려 얻을 게 없다 |
| `platform_settings` 값 | 지우면 저장 payload 가 흔들린다. 화면에서 **끈 채로** 보인다 |
