# 2026-08-27 — 매장에 보여 준 수수료가 실제 청구와 갈려 있었다 (+ 유어샵 카드 갤러리)

대표 *"저 요율들은 다 어드민 대시보드에서 정할 수 있는거지? 이거 말고는 이제 더 할 거 있어?"* →
내가 남은 일을 셋으로 나눠 보고 → *"일단 너가 할 것 다 해줘. 끝까지 다 해줘."*

세 갈래를 한 브랜치에서 처리했다. 서로 무관하지만 전부 **"화면이 조용히 거짓말한다"** 는 같은 종류다.

---

## ① 💸 직접 등록 10% 는 표시만 되고 청구되지 않는다 (실측)

매장이 등록에서 **직접(10%)** 을 고르면 이용권 등록 화면의 "판매 1건당 실수령" 카드가 **10% 를 떼고**
보여 줬다. 그런데 결제 분배는 그 값을 안 쓴다:

```
표시 경로  loadFeeRates → fee_platform_pct_3p_direct (10)
청구 경로  getSellerCommissionRate → sellers.commission_rate → GMV 티어 → commission_rate_default(5)
                                     ↑ 채널(direct/brokered)을 **아예 안 본다**
채널 요율을 원장에 적용하는 경로는 게이트 `fee_channel_rates_enabled` 뒤 → 라이브 **미설정(꺼짐)**
```

⇒ 직접 등록 매장은 **10% 를 뗀 실수령을 보고 5% 만 떼였다.** 매장 입장에선 더 받는 쪽이라
신고가 안 들어왔고, 그래서 몇 달을 아무도 몰랐다.

🩸 **두 파일이 각각 주석으로 *"loadFeeRates SSOT 라 표시·정산이 갈릴 수 없다"* 고 단언**하고 있었다.
같은 값을 읽는 건 사실이었지만 **그 값이 정산에 안 쓰였다.** 주석은 가드가 아니다.

**수리**: `src/worker/utils/effective-platform-fee.ts`(신규 SSOT) — 표시 요율을 **결제가 부르는 그 함수**
(`getSellerCommissionRate`)에서 뽑고, 게이트가 켜졌을 때만 채널 요율을 청구율로 쓴다. 응답에
`channel_rates_active` 를 실어 **꺼져 있음을 숨기지 않는다**. 화면(`NetProceedsCard`)은 서버가 준
`platform_fee_pct` 로만 계산한다(채널로 다시 분기하지 않는다).

**어드민 `/admin/policy`** 커미션 섹션에 경고 note 를 띄운다 — 설계값(10%)을 오늘의 청구액으로 읽지
않도록. (처음엔 표에 *행*으로 넣었다가 유령 키 가드에 걸렸다. 맞는 지적이라 note 로 옮겼다.)

### ⚠️ 대표 판단이 필요한 것 (내가 못 정한다)
셋 중 하나를 골라야 한다. **아무것도 안 고르면 화면과 청구가 계속 갈린 채로 남는다** — 지금은
"갈려 있다는 사실"만 화면에 밝혀 둔 상태다.
1. **10% 를 실제로 받는다** → `fee_channel_rates_enabled` ON. **머니 경로라 단독 세션 + staging 실결제.**
2. **5% 로 통일한다** → 등록 화면의 채널 선택에서 요율 문구를 걷어낸다.
3. **매장별로 받는다** → `sellers.commission_rate` 를 어드민에서 매장마다 지정(이미 그렇게 동작한다).

## ② 🎛️ 영입 2% · 1년을 어드민에서 바꿀 수 있게

`influencer_store_intro_pct`(2%) / `_months`(12)가 **읽기 전용**이었다 — 정책 대시보드에 값만 뜨고
바꿀 화면이 없었다. `/admin/commission-settings` 에 입력 두 칸 추가 + 서버 검증
(`platform-settings-validation.ts`)까지. 이제 대표가 직접 조정한다.

📌 함께 확인한 것(이미 되던 것): `max_influencer_commission_pct`(현재 **2**) ·
`influencer_payout_min`(현재 **100,000원**) 는 같은 화면에서 이미 조정 가능하다.
⚠️ 둘 다 지금 값이 **딜을 사실상 못 쓰게 막는 수준**이다 — 매장이 5% 를 주고 싶어도 2% 로 잘리고,
10만원을 못 넘긴 소개자는 정산을 못 받는다. 올릴지는 대표 판단.

## 🧹 곁다리 수리 — `stripComments` 가 파일 절반을 삼키고 있었다

가드들이 각자 들고 있던 `codeOnly`(주석 제거)가 **라인 주석 안의 `/*`** 를 블록 주석 시작으로 읽어
그 뒤 수천 자를 통째로 삼켰다. 실측: `(/api/wholesale/*)` 한 줄 때문에 **5,911자**가 사라졌고,
그 안의 코드 문자열 4개가 **부정 단언을 늘 통과시키고** 있었다.

😖 `src/tests/helpers/source-text.ts` 는 **이 지뢰를 이미 문서로 적어 두고** "아무도 안 밟는다"며
남겨 둔 상태였다. 그 지뢰를 내가 밟았다. 문자 스캐너(문자열·템플릿·정규식 리터럴 인식)로 교체하고
레포 전체 1,000+ 파일 스윕 테스트를 붙였다.
