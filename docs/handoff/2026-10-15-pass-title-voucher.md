# 2026-10-15 — 이용권 상세 제목 "공동구매" 수리 + 배달 안 되던 `twitter:site` 제거

대표 지시: **"Seo, geo 개선해줘"** → 제가 판단 3건을 올림 → ***"네 추천대로 할게. 3가지 모두 다."***

## 🎯 다음 세션의 첫 액션 — E4 판정 (배포 후 1분)

```bash
UA='Mozilla/5.0 (compatible; Googlebot/2.1; +http://www.google.com/bot.html)'
# ① 제목이 바뀌었나 (기대: "… 이용권 - 달빛한스푼 …", 종전 "… 공동구매 - …")
curl -sS -A "$UA" https://urdeal.kr/pass/2919 | grep -o '<title>[^<]*</title>'
# ② 활성 310건에 공동구매가 0건인가 (어드민 토큰 필요 — CLAUDE.md "어드민 진단 접근")
#    /api/products?limit=100&page=1..4 로 받아 name 으로 제목을 조립해 세는 것이 아니라,
#    실제 상세 몇 건을 UA 로 받아 확인할 것(제목 조립은 서버가 한다).
for id in 2919 2888 2915; do curl -sS -A "$UA" "https://urdeal.kr/pass/$id" | grep -o '<title>[^<]*</title>'; done
# ③ 🔴 반대 방향 — 몰은 여전히 공동구매여야 한다(진짜 공동구매다)
curl -sS -A "$UA" https://urdeal.kr/<몰슬러그> | grep -o '<meta name="description"[^>]*'
# ④ twitter:site 가 0건인가 (사람 UA 로 — 그 메타는 react-helmet 이 심던 것)
curl -sS https://urdeal.kr/pass/2919 | grep -c 'twitter:site'
```

**그리고 서버와 화면이 같은 제목인지** — 구글은 JS 를 렌더하므로 두 층을 다 본다. 브라우저로
`/pass/2919` 를 열어 탭 제목을 서버 응답의 `<title>` 과 대조할 것(지금은 같은 함수라 갈릴 수 없지만,
**그게 이 PR 의 요점**이므로 한 번은 눈으로 확인한다).

## 결함과 처방

| | 무엇 | 왜 안 보였나 |
|---|---|---|
| 내용 | 활성 이용권 **310건 제목이 `{상품명} 공동구매 - {가게}`** | 화면엔 안 뜬다(`<title>`·`og:title`) |
| 구조 | 제목을 **서버와 화면이 각자 조립** | 글자가 같아서 무해했다 — 한쪽만 고치는 날 갈린다 |

이 상품은 **모여서 사는 게 아니다**(2026-05-30 대표 확정 A2 즉시판매 단일가 — 인원이 가격을 안 움직인다).
2026-06-27 *"공구권 → 이용권"* 통일이 사용자-가시 156건을 치환했는데 **서버 메타가 그 치환에서 빠졌다.**

처방: `shared/seo/detail-title.ts` 에 `passDetailTitle(name, storeName)` 신설 → 서버(`detail-ssr-meta.ts`)와
화면(`GroupBuyDetailPage.tsx`)이 **같은 함수를 import**. 서버 description 폴백도 `{가게} 공동구매` → `{가게} 이용권`.

**🔴 `- 유어딜` 을 붙이지 않았다** — 제목 23~35자라 자르면 **가게 이름이 먼저 사라진다**(지역 검색의
가장 값진 토큰). 다른 표면의 `- 유어딜` 과 어긋나지만 의도다.

**🏪 공구 서비스(운영자 몰)는 무접촉** — `/{몰슬러그}` 픽업 공구는 진짜 공동구매라 `mall-ssr-meta.ts:218`
이 맞다. 시험이 **그 반대 방향도** 고정한다(일관성을 이유로 몰까지 바꾸는 쪽이 더 조용하고 더 나쁘다).

## ③ `twitter:site` — "잘못된 귀속" 이 아니라 "배달 안 되는 메타"

처음엔 *"`@urdeal_kr` 계정이 실재하는지 모른다"* 로 올렸는데, 재 보니 더 근본적이었다:

- **Twitterbot 은 JS 를 안 돌린다** → react-helmet 이 심는 메타를 못 본다.
- **봇 셸**(`worker/index.ts` `app.get('*')`)엔 `twitter:site` 가 **애초에 없다**(실측).

⇒ 어떤 스크래퍼에도 도착한 적이 없고, 없는 계정을 가리킬 위험만 남는다 → 제거.
`twitter:card`·`title`·`description`·`image`·`image:alt` 는 그대로. **되살리려면 봇 셸에** 넣어야 하고,
그 전에 계정 실재를 확인해야 한다(주석에 적어 뒀다).
