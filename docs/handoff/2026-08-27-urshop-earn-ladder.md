# 유어샵 수익 사다리 + 딜 우선 정렬 (2026-08-27)

대표 확정: *"유어샵을 여는 유저 누구나 인플루언서는 될 수 있는거지. 유어샵에 1번이 있으면 될거고,
매장을 영입해서 1년 내내 수익을 자동으로 받으라는 형태로"* · *"어차피 공개가 되어있잖아"* ·
*"직접 매장과 매칭이 되어진 이용권이 위에 노출, 그냥 유어딜에서 담아온거면 밑에 노출"*

## 무엇이 문제였나
소개자가 돈 버는 길이 **셋인데 세 화면에 흩어져** 있었다:
| | 어디 있었나 |
|---|---|
| ① 매장 영입 2%/1년 | `/influencer/settlement`(정산 페이지) 안쪽 — **돈 받을 때만 가는 화면** |
| ② 딜(소개비 %) | 안내 없음. 매장이 먼저 제안해야 함 |
| ③ 담아서 팔기 | 유어샵 — "최근 30일 적립 ₩0" 만 |

가장 돈이 되는 ①이 가장 안 가는 화면에 있었고, **자주 오는 유어샵엔 그 이야기가 한 줄도 없었다.**

## 한 것
1. **`EarnLadder`** (`src/pages/curator-page/EarnLadder.tsx`) — 유어샵 주인 화면에 3단.
   ⚠️ `pins.length` 로 **막지 않는다**. 빈 유어샵일수록 필요한데 그때 보이는 건 "적립 ₩0" 뿐이었다.
2. **핀 3섹션** — `내 계약 매장`(딜 있음) → `추천템` → `교환권·동네딜`.
   ⚠️ **`sort` 가 아니라 `filter`** 다. 주인이 드래그로 맞춘 `position` 을 덮으면 재정렬 기능이
   무의미해진다 — 덩어리만 가르고 각 덩어리 안은 원래 순서 그대로.
3. **서버**: 핀 SELECT 에 `p.seller_id` + 핀마다 `deal_pct` 동봉(왕복 1회).
   딜은 **유어샵 주인 기준**이라 익명 엣지 캐시(300s)에 실려도 정확하다.
4. **검색 모수 확장**: `is_open=1` → **핀을 담았거나 공개를 켠 사람**, 명시 옵트아웃(`is_open=0` 행) 제외.
   ⚠️ 핸들 기준이 아니다 — 핸들은 가입 시 자동 발급이라(실측 17명 중 9명) 그걸 쓰면 **가입자 전원 노출**이다.
   기준은 **행동**(`product_pins`, 실측 3명).

## 🔑 곁다리로 없앤 진짜 위험 — 딜 조건 복사본
`discovery.ts` 가 딜 WHERE 절을 **복사**해 두고 "SSOT 와 같아야 한다"는 주석을 달고 있었다.
복사본은 결국 갈리고, 갈리면 **화면은 "N% 받는다"인데 정산은 0** 이 된다.
→ SSOT 에 배치판 `findActiveDealPctsBySeller` 를 넣고 **양쪽(카탈로그·유어샵)이 그걸 부른다.**

## 🩸 이번에 틀린 것 — 다음 세션이 반복하지 말 것
1. **컨테이너 재시작이 로컬 클론을 옛 커밋으로 되돌리고 `node_modules` 를 지웠다.**
   그래서 내가 만든 파일들이 "존재하지 않는" 것처럼 보였고 tsc 가 `Cannot find module 'react'` 를 뱉었다.
   → 파일이 없다고 놀라기 전에 **`git log --oneline -1` 과 `ls node_modules`** 를 먼저 볼 것.
   (머지본은 원격에 안전했다. `git fetch && git checkout -B <br> origin/main` + `npm ci` 로 복구.)
2. **주입 검증에서 "적용 확인"을 잘못했다.** `grep -B1 "<EarnLadder"` 는 한 줄만 봐서 두 줄 위의
   게이트를 놓쳤고, **주입이 안 된 줄 알았는데 사실 적용됐다.** 빨간불의 원인을 오진할 뻔했다.
   → 다중행 구조는 `-B3` 이상이나 python 으로 확인할 것.
3. **내 옛 가드 둘이 옛 설계를 지키고 있었다**(낡은 지도):
   - `discover-deal-gate ②` 가 "조건을 정확히 베꼈나"를 검사 → **"안 베끼는가"(SSOT 위임)** 로 재조준
   - `influencer-picker ①` 이 `p.is_open = 1` 을 요구 → **활동 기준 + 옵트아웃** 으로 재조준
   - ⚠️ 같은 파일 `②` 는 **초록인데 헛돌고 있었다** — 앵커 `FROM influencer_profiles` 가 사라져
     `indexOf` 가 -1 → slice 가 파일 끝까지를 집어 무조건 통과. 재조준 + 앵커 실재 검사 추가.
