## 🩸 이번에 배운 것

### ① baseline 0 래칫은 **둘 다** 있어야 한다 — 합성 대조 없이는 죽어도 초록
버튼 래칫에서 겪은 것과 같은 구조라, 이미지 래칫도 baseline 을 0 으로 내리면서 **같은 자리에**
`FIXTURE_BAD`(일부러 무방비) / `FIXTURE_OK`(배선됨 + cfImage 밖 `<img>`)를 넣었다.
되돌려-검증 2종 전부 빨간불 확인(무방비 주입 · 매칭 무력화).

### ② 경계는 눈으로 봐야 한다 — 라이브에 그 경계가 없으면 하네스로 만든다
`SEARCH_MIN_PINS = 12` 는 라이브에 12개짜리 진열대가 **하나도 없어**(최다 4개) 실물 확인이 불가능했다.
그래서 미리보기 하네스에 `--pins=N` 을 넣고 11 / 12 를 각각 렌더해 **11=검색창 없음 · 12=나타남**을 확인했다.
"측정할 수 없으니 넘어간다" 가 아니라 **측정 가능한 자리를 만든다**.

### ③ 크로스-레일이라 먼저 보고했다
도매·어드민·몰을 건드리므로 CLAUDE.md 룰 4 대로 세 줄(어느 레일 / 머니 경로 없음 / 롤백)을 먼저 보고하고 진행.

## 🩸 추가 (같은 세션, 저녁) — **하네스가 빈 화면을 주면 시안이 거짓말을 한다**

교환권 탭(`/vouchers`) 시안을 내면서 "상단을 줄이면 첫 화면 상품이 3개→5개" 라고 보고했는데,
대표가 *"카테고리 및 브랜드 선택하는건 어딨어?"* 로 잡아 줬다. **화면의 절반이 빠져 있었다.**

원인: 미리보기 하네스가 `/api/vouchers/categories` 에 빈 배열을 줘서
**카테고리 칩 행(50px)과 브랜드 스트립(113px)이 통째로 안 그려졌다.** 그 화면으로 높이를 쟀다.

실제 교환권 탭에서 첫 상품 위에 쌓인 것:
```
검정 잔액 슬래브 ~250px · 고아 링크 ~40px · 카테고리 칩 ~60px
브랜드 스트립 ~175px · 섹션 헤더+정렬 ~60px   =  약 700px
```
잔액 패치가 건드리는 건 위 두 층(290px)뿐이라 실제 효과는 **상품 1.5개 정도**다(2개 아님).

⇒ 하네스에 `VOUCHER_SECTIONS` 시드를 넣었다(`--deals` 와 함께 동작).
**교훈: 하네스가 빈 배열을 주는 축은 시안에서 "없는 것" 이 아니라 "안 그려진 것" 이다.**
새 표면을 시안으로 낼 때는 그 화면이 부르는 API 를 먼저 세어 보고, 스텁이 없는 축이 있으면
시드부터 넣을 것. (2026-08-30 에 `--deals` 를 만든 이유와 같은 사고가 한 번 더 났다.)
