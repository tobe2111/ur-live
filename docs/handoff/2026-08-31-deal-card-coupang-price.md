## 다음 세션의 첫 액션

배포 판정은 **압축 번들에서 클래스 문자열**로 본다(Tailwind 클래스는 번들에 그대로 남는다):

```bash
UA='Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/126 Safari/537.36'
E=$(curl -sS -A "$UA" https://urdeal.kr/ | grep -o '/assets/index-[A-Za-z0-9_-]*\.js' | head -1)
C=$(curl -sS -A "$UA" "https://urdeal.kr$E" | grep -o 'app-components-[A-Za-z0-9_-]*\.js' | head -1)
# 배포 후: 사진 위 배지 클래스가 사라지고, 로즈 할인율 클래스가 생긴다
curl -sS -A "$UA" "https://urdeal.kr/assets/$C" | grep -c 'absolute bottom-2 left-2 px-1.5 py-0.5 rounded bg-brand'   # 배포 전 1 → 후 0
curl -sS -A "$UA" "https://urdeal.kr/assets/$C" | grep -c 'text-\[12.5px\] font-extrabold text-brand'                 # 배포 전 0 → 후 1
```
⚠️ **카드가 어느 청크에 있는지 먼저 확인할 것** — `GroupBuyFeedCard` 는 홈·유어샵 공용이라 공유 청크에 들어간다.
⚠️ 오늘 판정에서 두 번 헛짚었다: `cfFallback`(배포 전후 동일) · `from"./app-utils"`(원래도 import).
   **배포 전 상태에서 실제로 거짓이 되는 조건**인지 먼저 확인하고 쓸 것.

## 🩸 이번에 틀렸던 판단

### ① 같은 자리를 하루에 두 번 뒤집었다
오전에 "6자리 가격 줄 깨짐" 을 고치려고 배지를 사진 위로 올렸다. **문제 진단은 맞았지만 해법이 틀렸다** —
사진을 가리는 대가를 안 셌다. 쿠팡식 2줄은 사진을 안 건드리고 같은 문제를 구조적으로 없앤다.
⇒ **"자리를 옮겨 피한다" 보다 "구조를 바꿔 없앤다" 를 먼저 볼 것.**

### ② 시안을 화면의 절반을 빼놓고 냈다 (대표가 잡아 줬다)
교환권 탭 시안을 낼 때 미리보기 하네스가 `/api/vouchers/categories` 에 빈 배열을 줘서
**카테고리 칩(50px)과 브랜드 스트립(175px)이 통째로 안 그려진 화면**으로 재고 "상품 3개→5개" 라고 보고했다.
대표의 *"카테고리 및 브랜드 선택하는건 어딨어?"* 로 발각. 하네스에 시드를 넣고 다시 쟀다(#1281).
⇒ **시안은 반드시 `--deals` 로 렌더할 것.** 빈 화면으로 재면 틀린 숫자가 나온다.
