## 4. 🩸 이번에 내가 만든 사고 — 주입 잔재

매니페스트 구문을 **`node -e "import('./scripts/check-guard-mutations.mjs')"`** 로 확인했는데,
그게 **러너를 실제로 실행**시켰다(import 는 top-level 코드를 돌린다). 급히 SIGKILL 했더니 복원 단계
전에 죽어 **`ProductRepository.ts` 에 주입된 결함(`gateAffiliateRows(...)` 제거)이 파일에 남았다.**

그 상태로 돌린 전체 스위트가 **4건 실패**했고, 처음엔 체리픽 탓인 줄 알았다.

🔑 **찾은 방법(재사용할 것)**: 체리픽 4건이 건드리는 파일 목록(25개)을 만들고, **변경된 파일 중 그
범위 밖에 있는 것**을 찾았다. 정확히 둘이 나왔고 하나는 내가 만든 매니페스트, 나머지가 잔재였다.
`git diff` 를 눈으로 훑는 것보다 확실하다.

```bash
for c in <체리픽 SHA들>; do git show --name-only --format="" $c; done | sort -u > /tmp/cp-files.txt
git diff origin/main --name-only | while read f; do grep -qxF "$f" /tmp/cp-files.txt || echo "범위 밖: $f"; done
```

**교훈 둘**:
- **구문 확인은 `node --check`** — `import` 는 실행이다.
- **주입 러너를 강제 종료하면 파일이 오염된 채 남을 수 있다.** CLAUDE.md 가 *"타임아웃은 자식을 안
  죽인다"* 로 경고한 것의 **반대쪽 면**이다(그쪽은 안 죽어서 문제, 이쪽은 죽여서 문제). 죽인 뒤에는
  **범위 밖 변경 파일**을 반드시 확인할 것. `.claude/agents/dev.md` 는 복원됐길래 정리된 줄 알았는데
  아니었다 — **한 파일이 복원됐다고 전부 복원된 게 아니다.**
