**① 인계가 지목한 레인이 틀렸다.** 넘어온 인계는 *"나라장터 수집(`collect-nara-vendor`)이 유력"* 이라고

**③ 테스트 기대가 코드보다 먼저 틀렸다.** `애드업` 이 `애드\b` 규칙에 걸릴 거라 기대했는데 빨간불이 떴다.

창 휴리스틱이라, 내가 주석 13줄을 더하자 창이 밀려 **helper 의 `AbortSignal.timeout` 을 놓치고 진짜 루프를

포털 '미리보기' URL 과 대조해 `ADS_NARA_VENDOR_ENDPOINT`/`_OP` 로 무배포 교정.

### ⓑ 🩸 **`마케팅 대행` 항목을 내가 잘못 옮겨 적었다** (정정)

이 문서에 *"업종어만 있는 상호가 `evidence`/partner 로 남는 문제"* 라고 적어 뒀는데 **그런 문제는 없다.**
실측으로 그 가설을 검증하려다 발견했다 — 걸린 행들(`거산광고인쇄`·`강원광고`·`고릴라마케팅` …)은
전부 **실제 광고·간판 업체**이고 `evidence`/partner 가 **맞는 판정**이다.

원문은 `docs/handoff/2026-08-03-collection-routes-map.md` 이고 뜻이 다르다:
```
category='대행사'  1,989건 중 연락처 보유 111건(5.6%)
통신판매 원부 업태 필터로 짜내도 300건 안팎   ← 재분류로는 안 나온다
⇒ 대행사는 분류 문제가 아니라 **수집원 문제**다
```
⚠️ **인계를 요약할 때 원문을 다시 열지 않으면 이렇게 뜻이 바뀐다.** 이 세션이 문서를 근거로
오진하지 말라고 세 번이나 적어 놓고 **내가 그 문서를 오염시켰다.**
