# 인플루언서 국가 필터 (2026-11-14)

서비스: **유어애즈 · 인플루언서 DB**(`/admin/influencer-pool`, `ad_influencer_leads`). 머니 경로 없음.

## 대표 요청
*"인플루언서 DB 수집하는거 유튜브 같은 경우에는 외국인들도 있을텐데 국가별로 수집도 가능한가? 필터링을 할 수 있게 해줘"*

## 라이브 실측 (유튜브 24,672명)
```
KR 표기 17,427 · 해외 표기 1,514 · 미표기 5,731(23%)
미표기  → 한국어 5,367 · 외국어 364
해외 표기 → 한국어 557(예: 'US' 로 적은 보람튜브) · 외국어 957
해외 표기 상위: US 612 · IN 217 · JP 87 · GB 77 · CA 57 · AU 40
```
네이버 블로그·카페·티스토리는 전부 `KR`.

## 한 것
- 판정 SSOT `src/shared/ads/influencer-country.ts` — 채널이 밝힌 국가 + 이름·소개 한글 여부(SQLite `GLOB '*[가-힣]*'`).
  선택지: 한국(KR 표기 + 미표기 한국어) · 해외 거주 한국어 채널 · 외국 채널(한국어 아님) · 국가 코드 15개.
- 목록 API `?country=` · 엑셀 내보내기(본문·남은 수 둘 다) · 화면 필터(`PoolFilters`) · 엑셀 버튼에 전달. CSV 는 같은 목록 쿼리라 자동.
- 가드 `influencer-country-filter-2026-11-14.test.ts`(진짜 SQLite) + 주입 4건 빨간불 확인.

## 국가별 **수집**은 하지 않았다
유튜브 검색은 이미 `regionCode=KR&relevanceLanguage=ko` 로 돈다(`influencer-discovery.ts`). 해외 수집은 그 값만 바꾸면
기술적으로 되지만, 유튜브 일일 쿼터는 이미 한도에 붙어 있고(CLAUDE.md 천장 표), 유어딜은 국내 매장 서비스라 하지 않았다.
대표가 원하면 별도 결정.

## 이어받는 세션의 첫 액션 (대표가 이어서 하라고 했을 때만)
배포 후 `/admin/influencer-pool` 에서 유튜브 + '외국 채널(한국어 아님)' 이 약 1,300명, '한국' 이 약 22,800명 나오는지.

## 틀렸던 판단
- 처음엔 `country` 표기만으로 가르면 된다고 봤는데, 미표기 23% 중 94%가 한국 채널이라 그러면 한국 필터가 5천 명을 잃는다.

## 2. 외국 유튜버 수집 (2026-11-15)
대표 *"필요하긴 해."* → 질문 셋에 대한 답: 대상 **"나라별 일반 인플루언서"** · 배분 **"10번 (약 11%)"** · 언어 **"영어, 중국어, 기타 동남아 언어, 일본어"**.

- `src/features/marketing/api/influencer-yt-foreign.ts` — 6개 나라·언어(US/en · TW/zh-Hant · JP/ja · VN/vi · TH/th · ID/id) 키워드 회전, 회차당 최대 1번, 하루 기본 10번(env `ADS_YT_FOREIGN_SEARCH_BUDGET` 0~30, 0 = 끔).
- 쿼터: 하루 총 90번은 그대로. **오늘 안 쓴 외국 몫을 한국 상한에서 미리 뺀다**(안 빼면 한국이 오전에 90을 다 써 외국은 매일 0).
- `discoverYouTubeInfluencers` 에 `regionCode`·`relevanceLanguage` 옵션(기본 KR·ko — 한국 수집 불변).
- 진행값 `platform_settings.ads_yt_foreign_used` = `"<태평양 날짜>:<오늘 쓴 수>:<누적>"`.
- 가드 `influencer-yt-foreign-2026-11-15.test.ts` 13건 + 주입 4건 빨간불 확인.
- 중국어는 대만(번체)으로 묻는다 — 본토는 유튜브가 막혀 있다.

### 판정 (배포 후 며칠, 대표가 이어서 하라고 했을 때만)
- `SELECT value FROM platform_settings WHERE key='ads_yt_foreign_used'` (메인 D1) → 오늘 쓴 수가 10 근처로 차는가.
- 인플루언서 풀 → 유튜브 + '외국 채널' 수가 하루 수십 명씩 느는가 · 그중 이메일 보유 비율.

### 틀릴 수 있는 것
- 외국 채널은 소개란에 이메일을 덜 적는다 — 연락처 수율이 한국보다 낮을 수 있다. 낮으면 몫을 줄이는 판단은 대표.
