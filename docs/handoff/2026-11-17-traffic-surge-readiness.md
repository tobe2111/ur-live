## 이번에 고친 것 (PR 하나, 커밋 3개 · 원인별)

## 우선순위 낮음 (기록만)
- 검색 기록 `search_logs` 정리 cron 없음 — 실측 2주 984행이라 수개월 무관. `void` 로 쏴서 잘릴 수 있음(손실 무해).
- 목록 캐시 미스마다 리뷰 lazy seed 한 번 더 조회(`group-buy-public.routes.ts`·`products.routes.ts`).
- 모르는 한 칸 주소(봇 스캔)가 `/api/mall/:slug` 자기호출로 2배 호출, 404 는 캐시 안 됨.
- 메인 DB `UPDATE home_shorts … NOT EXISTS`(하루 2,000만 줄 읽음, cron 60회) — `store_creator_content` 색인 확인 대상.
- 서버 코드 타입 검사(`tsconfig.worker.json`) 오류 **348건**, CI 에서 `continue-on-error: true`(경고만). 대부분 프론트 파일이 DOM 타입 없이 끌려온 TS2304.
- 외부 부품 경고: 본체 보통 5 · `apps/ssr`(배포되는 SSR 워커) 높음 16 · `naver-ad-scraper` 높음 6 · `docs/business/proposals` 높음 2. 본체 심각·높음 0.
- 코드 곳곳이 아직 "무료 50 서브리퀘스트" 를 전제로 스스로 작업량을 줄인다(`cache-prewarm.ts` 등) — 유료 한도로 재산정하면 cron 처리량이 는다.
