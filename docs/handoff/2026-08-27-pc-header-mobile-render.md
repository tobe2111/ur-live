# 2026-08-27 — "로딩이 심각한 문제" 의 진짜 원인: PC 헤더가 폰에서도 렌더됐다

대표 폰 스크린샷(홈 섹션 자리에 스켈레톤) + *"여전히 이 상태야. 로딩이 심각한 문제."*

## 원인

`DesktopTopNav` 의 루트가 `hidden md:block`. **그 숨김이 CSS 뿐**이라, 폰에서도 React 가
트리 전체를 만들고(하위 컴포넌트·훅·이펙트 포함) 화면에서만 감췄다.

> 🔑 **`hidden` 은 페인트만 막지 렌더를 안 막는다. 비용은 그대로 낸다.**

라이브 실측(390px 모바일, CPU 프로파일):

| | |
|---|---|
| `DesktopTopNav` self time | **548ms — 홈에서 가장 비쌈** |
| DOM 노드 (수리 전 → 후) | **539 → 308 (231개, 43% 감소)** |

`isDesktop` (`min-width: 768px`) 이 **이미 계산돼 있었는데** 두 쿼리를 끄는 데만 쓰이고
렌더를 막는 데는 안 쓰이고 있었다.

## 수리

훅 호출 뒤 early-return 한 줄: `if (!isDesktop) return null`.

- 중단점이 CSS(`md` = 768px)와 **정확히 같다** — 어긋나면 사이 구간에서 헤더가 사라지거나 공짜로 렌더된다
- `isDesktop` 은 matchMedia `change` 리스너로 갱신 → 창을 키우면 그대로 나타난다
- `createRoot`(hydrate 아님)라 미스매치 없음
- `index.css` 의 `.desktop-topnav` 규칙은 프레임 모드(lg+) 전용이라 무관

브라우저 실측: 390/700 → DOM 부재, 900/1440 → 존재. 중단점 정확히 768px.

## 같은 클래스 후보 — **한 개만 고쳤다**

루트가 `hidden {bp}:` 인데 JS 게이트가 없는 컴포넌트 7개를 스캔했다:

| 파일 | 홈에 뜨나 | 조치 |
|---|---|---|
| `main/DesktopTopNav` | ✅ 뜬다 (측정 548ms) | **수리** |
| `DesktopLiveSidebar` | ❌ `showSidebar` 에 `!isFullBleedHome` 이 있어 홈에선 안 뜬다 | 보류 |
| `SideBanner` | ❌ `!isFullBleedPcPath` 게이트 + lazy | 보류 |
| `main/HomeTopHeader` | ❌ `MainHomePage`(참조 0 죽은 파일)에만 있다 | 보류 |
| `group-buy/DetailTitleHeader` | 상세 페이지 | **후속 후보** — 안 쟀다 |
| `user-profile/AccountSideNav` | 마이 페이지 | **후속 후보** — 안 쟀다 |
| `wholesale-catalog/cat-nav` | 도매(소비자 번들 제외) | 무관 |

⚠️ **일괄 규칙으로 만들지 않았다** — 마운트 조건이 제각각이라 "루트가 hidden 이면 게이트 필요"
같은 가드는 오탐투성이가 된다(후보 7개 중 홈에 실제로 뜨는 건 1개였다).
상세/마이 두 개는 **재고 나서** 고칠 것.

## 이번에 틀렸던 판단

### 1. PC UA 로만 확인하고 "시드 정상" 이라고 결론냈다

대표가 폰 스크린샷을 보내기 전, 나는 `__SSR_INITIAL_SECTIONS__` 를 **데스크톱 UA** 로만 확인하고
"시드는 멀쩡하다" 고 보고했다. 모바일 UA 로도 재보니 시드는 정말 멀쩡했지만, **그걸 확인한
방법이 대표가 쓰는 환경과 달랐다** — 운이 좋아 결론이 맞았을 뿐이다.
⇒ 대표가 모바일에서 신고하면 **모바일로 재라.**

### 2. 성능 기준선을 단일 샘플로 잡았다

`#1227` 개선폭을 재려다 실패했다. 기준선이 1회 측정이었는데 6회 재보니 2,847~3,958ms 로
40% 흔들렸고, TTFB(574→830)까지 달라져 환경 자체가 이동했다.
⇒ **성능 기준선은 반드시 여러 번 샘플링해서 중앙값으로.** CLAUDE.md 에 이미 같은 교훈이
있었는데(*"주기가 있는 계에서는 관측 창이 주기보다 길어야 한다"*) 그대로 반복했다.

### 3. 로컬 A/B 를 시도했다가 접었다

수리 전/후 빌드를 교차 측정하려 했으나 로컬 페이지가 렌더를 멈춰(원인 미규명) 실패했다.
나중에 다시 재보니 정상 렌더됐다 — **일시적이었다.** 로컬 A/B 자체는 유효한 방법이니
다음에 필요하면 다시 시도할 것(단, 로컬은 API 가 없어 데이터 의존 지표는 못 잰다).
