# 2026-08-31 — 운영 가이드를 읽을 수 있는 문서로

## 대표 지시
> "그걸 어디서 확인하지? **보기좋게 운영자료처럼** 확인 가능한가?"

## 무엇이 문제였나
`/admin/operations-guide` 는 **한 번에 하나만 열리는 아코디언**이었다. 섹션이 40개인데
**검색도 목차도 없어서**, 뭘 찾으려면 접힌 줄을 하나씩 눌러 열어 보는 수밖에 없었다.
내용을 아무리 정확하게 해도 **찾을 수 없으면 안 읽힌다.**

## 무엇을 했나 (`GuideViewer.tsx` — 어드민·셀러·에이전시·도매가 공유)
- **다중 열기** — `expanded: string|null` → `openKeys: Set<string>` + [모두 펼치기 / 접기]
- **검색** — 제목만이 아니라 **본문까지**. "영입 2%" 처럼 **값으로 찾는 것**이 실제 용례다
- **목차** — 섹션 4개 이상이면 칩 목록. 누르면 **열고 그 자리로 이동**(열지 않고 스크롤만 하면 접힌 채 도착한다)
- **앵커** — `id="guide-{key}"` 로 특정 절을 링크로 지목 가능

셀러·에이전시 대시보드가 같은 컴포넌트를 쓰므로 **그쪽도 같이 좋아진다.**

## 🩸 이번에 내가 만든 헛도는 주입
첫 주입을 "선언 줄에 변수 하나 덧붙이기"로 썼더니 **가드가 그대로 통과**했다 — 상태는 안 바뀌니까.
상태 타입 자체를 단일 open 으로 되돌리는 주입으로 고쳐 red 확인. **주입은 "무엇이 실제로 깨지는가"로 써야 한다.**
