## 2. 무슨 일이 있었나

PR #2013(내보낸 리드 도장 — 500행 묶음)이 머지·배포됐는데 **라이브에서 도장이 한 건도 안 찍혔다.**
업체 CSV 를 두 번 받으니 **바이트까지 거의 같은 파일**이 나왔고(상호 교집합 486/486), 파일 끝은
`이 묶음 0건에 "내보냄" 표시를 했습니다 · 남은 미다운로드 64303건` — 전체 이메일 보유 수와 **같았다**.

원인은 한 줄이었다. `stampExported` 가 청크당 **id 100개 + 도장 1 = 바인딩 101개**를 보냈다.
라이브 D1 에 직접 찔러 확증:

```
바인딩  99개 → OK      100개 → OK      101개 → ERR 7500 "too many SQL variables"
```

그리고 그 실패를 호출부가 `.catch(() => null)` 로 **삼켜** 에러도 로그도 없었다. 안내문의 "0건" 은
사실이었지만 **정상처럼 읽혔다** — 이 레포가 반복해 당한 *조용한 부재*다.

## 3. 왜 시험이 통과했나 (이게 제일 값지다)

`pool-export-batch-2026-10-25.test.ts` 는 **진짜 SQLite**(`node:sqlite`)로 돌며 "동작 판정" 을 한다.
그런데 **그쪽 바인딩 한도는 32,766** 이다 — 101개든 500개든 멀쩡히 통과한다.

> **진짜 DB 로 쟀는데도 D1 전용 제약이 보이지 않았다.** 게다가 시험의 픽스처는 id 가 1·2·3 뿐이라
> 청크 경계를 **한 번도 넘지 않았다**.

⇒ 처방은 시험을 더 쓰는 게 아니라 **D1 의 한도를 흉내 낸 가짜 DB** 로 같은 함수를 돌리는 것이다
(`src/tests/unit/d1-bind-limit-2026-10-26.test.ts`). 그 가짜 DB 가 헛돌지 않는다는 증거도 함께
단언한다(한도를 10 으로 낮추면 거부가 **보여야** 한다 — 없으면 ④가 101개 버그에도 초록이 된다).

## 4. 고친 것

| 파일 | 무엇 |
|---|---|
| `src/shared/db/d1-binds.ts` (신규) | `D1_MAX_BINDS = 100`(실측) + `chunkForBinds(items, extraBinds)` **SSOT** |
| `pool-export-batch.ts` | 청크를 SSOT 로(`extraBinds=1` → id 99개씩) · 실패를 `console.error` 로 **드러낸다** · 목록·취소의 침묵도 함께 |
| `pool-export-batch.ts` | `exportStampFailedNote()` — 도장이 통째로 실패하면 **파일에 적는다** |
| `influencer-pool-export.ts` | 같은 실패 안내(그 경로는 안내문을 손으로 적는다) |
| `seller-daily-report.ts` | 같은 클래스 — 100개 + 기간 2 = **102개**였다 |

🔑 **청크 크기를 손으로 적지 않는다.** `extraBinds` 만 넘기면 한도는 SSOT 가 센다 — 같은 문장에
바인딩이 하나 더 붙는 날(기간·도장 값) 조용히 넘치는 것이 이 사고의 모양이었다.

🔴 **`cancelExportBatch` 의 침묵이 더 위험했다** — 조용히 0 을 돌려주면 화면이
*"이미 취소된 묶음입니다"* 라는 **거짓말**을 하고, 되돌리기는 끊긴 다운로드의 **유일한 복구 경로**라
그 거짓이 영구 손실로 굳는다.

## 5. 이번에 틀렸던 판단

- 📏 **"100은 넉넉히 밑도는 값"** — PR #2013 의 주석이 그렇게 적어 뒀다. D1 한도가 **정확히 100**이라
  `SET ... = ?` 하나만 붙어도 넘친다. **"넉넉히" 를 재지 않고 적지 말 것.**
- 🧪 **"진짜 SQLite 로 돌리면 동작 판정이다"** — 맞지만 **D1 과 같은 제약이라는 뜻은 아니다.**
  한도·확장·PRAGMA 가 다르다. D1 전용 제약은 **흉내 낸 DB** 로만 잡힌다.
- 🩸 측정 중 **컬럼 이름을 짐작**해 두 번 틀렸다(`merged_into`·`active`) — `pragma_table_info` 로 먼저 볼 것.
