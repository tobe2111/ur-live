# 2026-09-21 — 사장님 통보(알림톡) 탐지·큐·게이트드 발송

`[E2]` 작성·검증됨(tsc 0 · 유닛 23건 · 주입 14건 되돌려-검증 전부 빨간불). **발송은 아직 0건이고, 그게 정상이다.**

## 대표가 시킨 것
> *"매장 사장님의 전화번호. 010으로 말이야. 되면 보내주는걸로."*

## 왜 이게 사기 방어인가
남의 가게 이름으로 올라간 이용권을 가장 먼저 알아볼 사람은 **그 가게 사장님**이다. 그런데
지금까지 사장님은 알 길이 없었다 — 유어딜에 올 일이 없으니까. 제보 창구(#1515)를 만들어도
**존재를 모르면 쓰이지 않는다.** 이 통보가 그 창구로 데려간다.

## 지금 상태: **줄은 서고, 아무것도 안 나간다**
승인 순간(두 경로 모두) 매장 전화가 **010 이면** `store_owner_notices` 에 한 줄 선다.
실제 발송은 **둘 다** 갖춰져야 돈다:
1. `ALIGO_TPL_STORE_NOTICE` — 카카오 알림톡 템플릿 코드. **외부 검수**를 거쳐야 하고
   **대표가 채널 관리자에서 등록**한다(세션이 못 한다).
2. `platform_settings.store_owner_notice_enabled = 'true'` — 발송은 등급 C.

어드민 `/admin/store-owner` 의 **"사장님 통보"** 패널이 줄과 *왜 막혀 있는지*를 보여 주고,
게이트가 열리면 `N곳에 보내기` 버튼이 활성화된다. **자동 발송은 없다 — 사람이 누른다.**

## 검수에 낼 문구 (코드의 `ownerNoticeMessage` 와 **같은 문안**)
```
[유어딜] {매장명} 매장이 유어딜에 등록되었습니다.

이 등록을 직접 하지 않으셨다면 아래에서 바로 알려 주세요.
https://urdeal.kr/store/find

문의: 유어딜 고객센터
```
> 문안을 바꾸면 **코드와 템플릿 둘 다** 고칠 것. 두 벌이 되면 반드시 갈린다.

## 설계에서 갈린 자리 셋 (다음 세션이 뒤집기 전에 읽을 것)
1. **010 만 줄을 선다.** 지역번호·대표번호·번호 없음은 알림톡이 아예 안 가므로
   **"매장 확인 통화" 큐**(#1517)가 맡는다. 두 레일이 같은 매장을 두 번 붙들지 않게 여기서 가른다.
   ⚠️ 010 이라고 진짜 사장님 번호라는 뜻은 아니다 — 사기꾼이 자기 번호를 적었다면 통보는
   그에게 간다. 그래도 손해는 없다(그는 이미 다 안다). 이 레일의 값은 *흔한 경우*에 있다.
2. **셀러 크레딧을 쓰지 않는다.** `sendSellerAlimtalk` 은 셀러 크레딧 1건을 깎는데, 그 모델은
   "셀러가 자기 손님에게 보낸다" 는 전제다. 이건 정반대다 — **유어딜이 (아직 유어딜을 모르는)
   사장님에게** 보낸다. 남의 잔액을 깎아 그 사람에게 통보하는 건 말이 안 되므로 발송기를 직접 부른다.
3. **실패는 재시도하지 않는다.** `failed` 로 남고 어드민이 본다. 자동 재시도는 수신거부한 번호에
   문자 폭탄이 된다.

## 🩸 이번에 내 시험 둘이 헛돌았다 (주입이 잡았다)
- **"두 번째 호출에선 아무 일 없다"** 로 선점(CAS)을 쟀는데, **선점을 통째로 지워도 초록**이었다 —
  순차 호출에선 앞 호출이 이미 상태를 바꿔 놓기 때문이다. 선점이 지키는 것은 *동시*다.
  ⇒ 드레인 둘을 `Promise.all` 로 겹쳐 돌려 "한 통만 갔는가" 를 재도록 교체.
- **게이트 순서**를 파일 전체의 `indexOf` 로 쟀는데, **조회 라우트가 그 이름을 먼저 언급**해서
  발송 라우트 조건을 `if (false)` 로 바꿔도 초록이었다. ⇒ 발송 라우트 **안쪽만** 보도록 교체.

## 다음 세션의 첫 액션
1. PR 초록 → 머지 → 배포. 배포만으로는 **아무 일도 일어나지 않는다**(의도).
2. **E4 판정(발송 없이)**: `/admin/store-owner` 에 "사장님 통보" 패널이 뜨고, 010 인 매장을
   하나 승인했을 때 줄이 한 줄 서는지. 버튼은 **비활성이어야 정상**이고 그 아래 사유 문구가 뜬다.
3. **발송을 켜려면**(대표): 카카오 템플릿 검수 → `ALIGO_TPL_STORE_NOTICE` 등록 →
   `platform_settings.store_owner_notice_enabled='true'` → 어드민에서 1건만 먼저 보내 실제 수신 확인.

## 📌 운영 게이트 등재
