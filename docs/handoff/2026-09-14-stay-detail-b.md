## ② 뿌리 — 토큰 세트가 둘이었다

`.gbd`(공구 상세)가 자기 hex 를 갖고 있었고 **다크가 갈라져** 있었다:
배경 `#070809`↔`#11141C` · 카드 `#141517`↔`#1D1F29`. 라이트는 우연히 거의 같아서
**아무도 눈치채지 못했다** — 다크에서만 공구 상세가 다른 앱처럼 보였다.

⇒ `.gbd` 가 값을 체계에서 받아 온다(`var(--bg)`·`var(--surface)`…). **마크업 무변경**(변수 155곳 그대로).
그리고 공유 부품 `components/ticket/FieldCard` 를 만들어 **숙소 '인원' 행 = 공구 '수량' 행**.

**시각 변화 범위(토큰별 실측 대조)** — 라이트는 사실상 무변화다:

| 토큰 | 라이트 | 다크 |
|---|---|---|
| ink / ink2 / sub / sub2 / accent / cta | **완전히 동일** | 보조 2종이 밝아짐(새 카드 위 대비 ↑) |
| bg / card | **완전히 동일** | `#070809→#11141C` · `#141517→#1D1F29` ← **보이는 변화** |
| line2 | **완전히 동일** | `#2A2D31→#2C2F35` (2 hex) |
| chip | 웜 `#F3EEEA` → 쿨 잉크 5% (명도 비슷) | 카드가 밝아진 만큼 한 단계 위로 |

⇒ 라이트에서 사람이 알아볼 변화는 **칩 색온도 하나**뿐이고, 다크에서 두 상세가 같은 표면이 된다.

🩸 **`--gbd-line` 과 `--gbd-accent-soft` 는 정의된 적이 없었다.** `FcfsApplyBlock` 의
`border: 1px solid var(--gbd-line)` 은 값이 없으면 선언이 통째로 무효 → 테두리가
`currentColor`(글자색)로 그려진다. 헤어라인 자리에 진한 선이 있었다.

체계에 없던 두 단계를 토큰으로 올렸다: `--ink2`(잉크↔보조 중간) · `--wash`(카드 안 옅은 면 —
마크업이 이미 `bg-gray-100 dark:bg-white/[0.06]` 로 손으로 쓰던 값).
⚠️ `--gbd-danger` 는 **일부러 안 옮겼다**(빨간 면 위 흰 글자라 대비 기준이 다르다 —
`discount-is-sale-red.test.ts`).

## ③ 주소 — 중복이 아니라 오표기였다

라이브 50건 전수: 주소가 자체 지역을 가진 것 **50/50**, 지역 없는 맨 주소 **0**,
그런데 **12건(24%)은 지역 항목과 주소가 서로 다르다**(`region=강원 속초시` ↔
`address=강원특별자치도 양양군`). 이어 붙이면 **있지도 않은 곳**이 찍힌다.
⇒ `shared/stay-address.ts` — 주소가 이긴다. 지역은 검색·필터용으로 존치.
상세 2곳 + 검색 카드 1곳이 같은 함수를 쓴다(카드와 상세가 다른 지역을 말하지 않게).
