# 알림톡 템플릿 등록 목록 (2026-10-11 — 등록용 정본)

> 대표 지시: *"템플릿 문구들도 빠짐없이 다 정리해서 만들어줘"*.
> **이 문서가 등록용 정본이다.** 옛 `docs/kakao-alimtalk-templates.md` 는 배경·이력용으로만 남긴다
> (그 문서의 본문은 옛 도메인 `live.ur-team.com` 과 영문 변수로 적혀 있어 지금 코드와 다르다).

## 먼저 알아둘 규칙 3개

1. **본문은 글자 하나까지 같아야 한다.** 아래 본문을 그대로 복사해서 등록한다(줄바꿈·기호·이모지 포함).
   바뀔 수 있는 자리는 `#{...}` 변수뿐이다. 코드는 그 자리에 실제 값을 넣어 보낸다.
2. **버튼 없이 등록한다.** 지금 코드는 버튼을 보내지 않는다. 버튼을 붙여 등록하면 "템플릿 불일치"로 거절된다.
   링크는 본문 안의 주소로 충분하다(카카오톡이 눌리는 링크로 보여 준다).
3. **승인되면 알리고가 붙인 코드를 알려 주세요.** 알리고는 템플릿을 등록하면 `UA_1234` 같은 **자기 코드**를
   붙인다. 그 코드를 어드민 설정 `alimtalk_approved_templates` 에 `우리이름=알리고코드` 로 적어야 알림톡이 나간다.
   예: `voucher_issued=UA_1234, voucher_used=UA_5678`. **적기 전까지는 아무것도 안 나간다**(문자도 안 나간다 — 2026-10-11 "카톡만").
   대표님이 코드를 알려 주시면 세션이 대신 적는다.

> 🔎 코드 쪽 정본: 손님·사장님 이용권 알림 `src/features/group-buy/api/helpers.ts`, 발송 규칙 `src/lib/text-notice.ts`.
> 본문을 고칠 일이 생기면 **코드와 이 문서를 같은 커밋에서** 고치고, 카카오에도 다시 심사를 넣어야 한다.
> 가드: `src/tests/unit/alimtalk-template-bodies-2026-10-11.test.ts`(본문에 조건부 줄 금지).

## 손님에게 가는 알림

### 1. `voucher_issued` — 이용권 발급 완료
```
[유어딜] #{이용권종류} 발급 완료

#{매장명} · #{상품명}
#{수량}장 발급되었습니다.

📱 매장에서 QR 코드 보여주세요:
https://urdeal.kr/my-vouchers

⏰ 유효기간: #{유효기간}

문의: 유어딜 고객센터
```
- `#{이용권종류}` 예: 이용권 · `#{유효기간}` 예: `2026. 12. 31.까지` 또는 `제한 없음`
- 교환권(기프티콘, 딜 결제)에는 보내지 않는다(기프티콘은 바코드로 쓴다 — 코드가 거른다).

### 4. `voucher_used` — 이용권 사용 완료
```
[유어딜] ✅ #{이용권종류} 사용 완료

#{매장명}
"#{상품명}"
사용 시각: #{사용시각}

후기 남기기:
https://urdeal.kr/my-vouchers

문의: 유어딜 고객센터
```
- `#{사용시각}` 예: `오후 07:30` (값이 없으면 `-`)

```
[유어딜] 환불 완료 — #{상품명}
#{금액}원이 환불 처리되었습니다.
(딜 결제건은 즉시 잔액 반영, 카드 결제건은 영업일 기준 3~5일 소요)

```

```
#{이용권명} 이용권이 #{남은일수}일 후 만료됩니다.

```
- `#{이용권명}` = 상품명(매장이 있으면 `상품명 · 매장명`) · `#{만료일}` 예: `2026-12-31`

## 알려진 한계 (다음에 고칠 것)

- `seller_bank_changed` 는 아직 매장 대표번호(`sellers.phone`)로 간다 — 유선이면 안 닿는다. 다른 사장님 알림처럼
  담당자 휴대폰(`resolveSellerNotifyTarget`)으로 옮겨야 한다.
