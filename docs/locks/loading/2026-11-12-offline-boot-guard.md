# 2026-11-12 [LOADING_ADDITIVE] 오프라인에서 부트 가드가 새로고침·복구 화면을 하지 않는다 (`index.html` 첫 인라인 스크립트)

- **증상(라이브 실측)**: 재방문 즉시 표시(shell-sw) 저장본이 오프라인에서 뜨는데, 부품 하나 실패를 부트 가드(`reloadOnce`)가 '새 배포' 로 읽고 `?__cb=` 로 새로고침 → 쿼리 주소는 SW 가 안 다뤄 **브라우저 오류 화면**(2초). `chunk-error.ts` 쪽 수정(#2339)만으로는 안 고쳐졌다 — 같은 일을 하는 장치가 `index.html` 에 따로 있다(배포 뒤 재측정으로 확인).
- **무엇**: `offlineWait()` — `navigator.onLine === false` 면 ① 청크 실패 새로고침 안 함(예산도 안 씀) ② 12초 복구 화면을 덮지 않음(완전복구 버튼이 저장본까지 지운다) ③ 30초 자동 재시도 안 함. `online` 이벤트에 한 번 새로고침.
- **실측(라이브 HTML 의 가드를 새 것으로 끼워, 같은 브라우저 오프라인)**: 종전 2초 뒤 빈 오류 화면 → 15초까지 저장된 홈 화면 유지(주소 `/` 그대로) → 연결 복구 뒤 새로고침으로 앱 정상.
- 🩸 측정 함정: 배포된 `index.html` 은 압축돼 함수 이름이 바뀐다 — 가드를 끼울 때 `reloadOnce` 로 찾으면 0건이다(`__ur_chunk_reload__` 로 찾을 것).
- **가드**: `offline-boot-guard-2026-11-12.test.ts`(가드 스크립트를 가짜 window 에서 **실제로 돌린다**) + 주입 3건. 옛 시험·주입 각 1건 재조준.
- **롤백**: `offlineWait()` 호출 세 줄 제거.
