## 3. 전체 설명 (구글 4000자 / 애플 설명란 공용)

**유어딜 — 동네에서 매일 쓰는 할인 이용권**

유어딜은 우리 동네 매장의 이용권을 할인가로 구매하고, 매장에서 QR 코드 한 번으로 바로 사용하는 로컬 커머스 앱입니다.

**🎟️ 동네 이용권**
- 식사·뷰티·숙소·액티비티 이용권을 온라인 할인가로 즉시 구매
- 구매한 이용권은 내 이용권함에 자동 보관
- 매장에서 QR/PIN 제시 → 끝. 사용된 이용권엔 사용 완료 도장이 찍혀 안심
- 오프라인(지하·약전파)에서도 QR 화면이 열립니다

**🎁 교환권**
- 커피·베이커리 등 인기 브랜드 교환권을 문자(MMS)로 즉시 수령
- 활동으로 모은 딜 포인트로 알뜰하게 교환

**💎 딜 포인트 — 활동으로 모으는 리워드**
- 친구 초대, 링크샵 추천 등 활동으로 딜이 쌓입니다 (1딜 = 1원 가치)
- 모은 딜은 이용권·교환권 결제에 현금처럼 사용

**🛍️ 링크샵 — 나만의 추천 쇼핑몰**
- 마음에 든 상품을 내 링크샵에 담아 공유
- 내 추천으로 판매되면 커미션 딜 적립
- 사업자라면 내 상품을 직접 판매하는 쇼핑몰로 확장

**🗺️ 동네딜 지도**
- 내 주변 참여 매장과 진행 중인 딜을 지도에서 한눈에

**안전한 결제**
- 모든 결제는 토스페이먼츠로 안전하게 처리됩니다

문의: urteam.corp@gmail.com

## 5. 스크린샷 계획 (촬영 가이드)

폰 세로 5~8장. 라이브 사이트를 폰(또는 데스크톱 개발자도구 430px)에서 캡처 후 문구 오버레이:

| # | 화면 | 캡션(오버레이) |
|---|---|---|
| 1 | 홈 (교환권 피드 + 딜 모으는 법) | "우리 동네 할인, 매일 유어딜" |
| 2 | 동네딜 지도 (`/restaurant-map`) | "내 주변 딜을 지도에서 한눈에" |
| 3 | 이용권 상세 (실매장 딜) | "할인가로 사고, 매장에서 바로 사용" |
| 4 | 내 이용권함 QR 화면 | "QR 한 번이면 끝" |
| 5 | QR 사용 완료(도장) 화면 | "사용 완료 도장으로 안심" |
| 6 | 링크샵 (`/u/{handle}`) | "추천하면 딜이 쌓이는 나만의 링크샵" |
| 7 | (선택) 교환권 카탈로그 | "인기 브랜드 교환권, 문자로 즉시" |

- 규격: 구글 폰 16:9~9:16 자유 / 애플 6.7"(1290×2796)·6.5"·5.5" 필요
- 아이콘 512×512(구글)·1024×1024(애플): `public/icon-512.png` 기반 (1024 업스케일 필요 시 세션에 요청)
- 구글 그래픽 이미지(1024×500): 검정 배경 + UR 로고 + "동네 이용권·교환권" 카피 — 요청 시 생성

## 7. Apple App Privacy (영양표 초안)

- **Contact Info**(이름·이메일·전화): 계정/앱 기능 — 사용자에 연결됨
- **Purchases**(구매 이력): 앱 기능 — 사용자에 연결됨
- **Location**(대략 위치): 앱 기능 — 선택적, 사용자에 연결 안 함(지도 표시용)
- **Identifiers**: 사용자 ID(계정) — 연결됨. 광고 추적 없음 → **ATT 팝업 불필요**
- Tracking(타사 추적): 없음
