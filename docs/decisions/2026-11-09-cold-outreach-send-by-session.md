# 세션이 제휴 제안(콜드 메일)을 직접 발송해도 되는가

기한: 2026-11-09

## 질문
세션이 대표 지메일(urteam.corp@gmail.com)로 유어애즈 DB 의 인플루언서(유튜버·네이버 블로거)에게 제휴 제안 메일을 하루 소량씩 직접 발송해도 되는가?

## 근거 (실측 2026-11-09)
- 라이브 `urdeal.kr` 공개 상품 200개 중 실제 매장 상품 2개(판매 0) · 오늘 매출 0 · 최근 실제 주문 10월 4건. 영업이 병목이다.
- 유어애즈 풀: 발송 가능(이메일 보유·거부 아님·카테고리 있음·미접촉) 유튜브 8,703 · 네이버 블로그 89,305 (`ad_influencer_leads`, DB `d4630482`).
- 레포의 콜드 발송 경로(`send-cold`)는 `RESEND_API_KEY` 미설정이라 라이브에서 400 — 지메일 MCP 가 유일하게 열린 발송 경로.
- 종전 규칙: CLAUDE.md *"발송 자체는 대표가 한다 — 세션이 콜드 발송을 자동화하지 않는다"*(2026-08-03) · *"발송 시점 = 한참 뒤"*(2026-08-05).

## 선택지
1. 세션 발송 허용(지메일, 하루 ≤20통, 법정 표기·야간 금지·30일 쿨다운·반송 회로차단을 세션이 지킴) — 장점 즉시 시작 / 단점 정보통신망법 §50 사전동의 미비 리스크 잔존(발송은 공개된 비즈니스 문의 주소에만)
2. 세션은 초안까지, 발송은 대표 — 장점 리스크 통제 / 단점 대표 시간 소모
3. RESEND 키를 대표가 Cloudflare 에 넣고 레포 경로(`send-cold`)로 발송 — 장점 반송·거부가 DB 에 자동 기록 / 단점 대표 설정 작업 필요
