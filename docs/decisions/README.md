# 결재함 — 대표가 판단할 것은 여기에만 (2026-09-07 신설)

운영 SSOT: `docs/design/ai-team-operating-model.md` §5. 이 폴더는 **결정 하나 = 파일 하나** 다.

## 규칙
- 파일명 `YYYY-MM-DD-<slug>.md`. 템플릿은 `_template.md` 를 복사한다.
- handoff·PR 코멘트·채팅에 "대표 판단 필요" 라고만 적고 끝내지 않는다. **여기에 항목을 만든다.**
- `상태` 는 `open` → `approved` | `rejected` | `expired`. 기한이 지나도 C 등급은 자동 실행되지 않는다(`expired` 는 다시 올린다는 뜻).
- `결정` 필드는 대표가 한 말을 **그대로** 옮긴다. 의역·요약 금지.
- `approved` 인데 `반영 커밋` 이 비어 있으면 미반영이다. ceo-office 루틴이 매일 다시 올린다.
- 공유 파일에 append 하지 않는다(파일 단위라 세션 간 충돌 0).

## 필수 필드
`상태` · `등급`(C) · `역할` · `질문`(한 문장) · `근거`(실측 수치·출처) · `선택지` · `기본안` · `기한` · `롤백` · `결정` · `반영 커밋`
