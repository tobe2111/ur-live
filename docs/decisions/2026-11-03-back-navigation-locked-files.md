## 선택지
1. **① 상세 ←** — `GroupBuyDetailPage.tsx:616` 의 `onBack={() => navigate(-1)}` 을 `useSafeBack('/')` 로. 한 줄. 잠긴 항목(SSR 시드·폴링·lazy)은 불변. 머니 접촉 없음.
2. **② 결제 뒤 뒤로** — 상세에서 결제창을 열 때 `navigate('/pay/widget…', { replace: true })` 는 쓰지 않는다(결제창에서 ← 하면 상세로 돌아와야 한다). 대신 완료 화면(`GroupBuyConfirmPaymentPage`, 잠금 밖)이 결제 완료를 `sessionStorage` 에 적고, 결제창(`TossWidgetPayPage`, **Toss 잠금**)이 다시 열렸을 때 그 표시가 있으면 결제 위젯을 띄우지 않고 상세로 replace. 결제 승인·금액 로직은 무접촉이지만 Toss 잠금 파일을 연다 → 결제 흐름 staging 확인 필요.
3. **③ 하단 탭** — 탭끼리 옮길 때는 replace, 홈에서 다른 탭으로 갈 때만 push(쿠팡·당근 앱 방식). 결과: 어느 탭에서든 폰 뒤로 한 번 → 홈, 한 번 더 → 앱 밖. `BottomNav.tsx`(로딩 잠금) 수정, 잠긴 항목(유어샵 경로 캐시·활성 표시)은 불변.
