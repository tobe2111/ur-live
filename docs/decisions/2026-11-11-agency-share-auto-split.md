# 에이전시 몫을 사장님 직접 송금이 아니라 유어딜이 자동으로 나눠 보내고, 소개비와 겹치면 큰 쪽 하나만 줄까?

상태: approved
등급: C
역할: finance
올린 날: 2026-11-11
기한: 2026-12-31

## 질문
에이전시 몫을 ① 에이전시가 미리 정한 % 로 ② 유어딜이 판매마다 자동으로 나눠 보내고 ③ 같은 사람이 에이전시 몫과 소개비를 둘 다 받게 되면 큰 쪽 하나만 줄까?

## 근거 (실측)
- 파트너 질문(2026-11-11): *"제가 영입한 가게를 뽀야 계정으로 직접 팔면, 에이전시 몫이랑 인플루언서 소개비를 둘 다 받는 거예요?"*
- 지금 에이전시 몫은 **사장님이 장부 밖에서 직접** 보낸다 — 유어딜 지급 스위치 `agency_share_payout_enabled` OFF(2026-11-01 핸드오프).
  그래서 유어딜은 소개비만 보고, 같은 사람이 둘 다 받는지 **알 방법이 없다**.
- 규칙 1(2026-10-11, `isOwnAgencyReferral`)은 "에이전시 직원 계정의 링크 = 에이전시 몫만" 인데 ⓐ 스위치 OFF 면 작동하지 않고
  ⓑ 다른 계정으로 팔면 못 잡는다. 소개비가 몫보다 크면 **다른 계정으로 팔 동기**가 생긴다.
- 11-01 실측: 에이전시 계정 0곳 · 에이전시 몫 지급 0건 — 지금 바꾸는 비용이 가장 낮다.
- 사업계획서: 매장 대금은 2026-12 부터 토스페이먼츠 지급대행(개정 전자금융거래법). 에이전시 몫도 같은 길로 가야 남의 돈을 대신 보내는 일이 법적으로 깔끔하다.

## 선택지
1. **자동 분배 + 겹치면 큰 쪽 하나** — 사장님·에이전시 할 일이 처음 한 번(몫 % 동의, 계좌 등록)뿐. 두 번 지급이 구조적으로 불가능. 머니 경로 접촉 있음(지급·원장).
2. 자동 분배 + 겹치면 에이전시 몫만(규칙 1 유지) — 단순하지만 소개비가 크면 계정 우회 동기.
3. 지금처럼 사장님 직접 송금 — 유어딜은 중복을 못 막는다.

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
안 1.

## 롤백
`agency_share_payout_enabled` OFF(종전 동작 = 사장님 직접 송금). 몫 % 자동 저장(①)은 저장만이라 돈 영향 0.

## 결정 (대표가 한 말 그대로)
> 그냥 모두가 번거롭지 않게 자동화하면 좋겠어. 어떻게 할까?

(제안: 처음 한 번 정하면 유어딜이 자동 분배 · 겹치면 큰 쪽 하나 · 자동 지급은 12월 토스 지급대행과 함께 켬)

> 이게 지금 가장 이상적이야?

> 응 그렇게 진행해줘.사장님이 에이전시에게 직접 주는거 말고 자동 분배

### 구현 단위 (범위 표시 — 의역 아님)
- ① **지금**: 에이전시가 *우리 몫 %* 를 한 번 정함 → 사장님이 초대 화면에서 보고 [맡기기] → 그 매장 몫으로 자동 저장. (돈 이동 0)
- ② **겹침 규칙**: 한 판매에 같은 사람(에이전시 직원 등록 · 같은 본인확인/정산 계좌)이 에이전시 몫과 소개비를 함께 받게 되면 **큰 쪽 하나**만.
- ③ **자동 분배·자동 지급**: 에이전시 정산 계좌 칸 → staging 실결제(S-AGENCYSHARE) → 12월 지급대행에 실어 매월 자동 지급 → 스위치 ON.
- 켜는 것(③의 ON)은 **대표**다. 실행기는 PR 까지만.
