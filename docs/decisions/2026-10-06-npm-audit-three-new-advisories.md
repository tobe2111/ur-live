   장점: 앱에 닿는 critical 을 진짜로 없애고 게이트도 열림 / 단점: capacitor·postcss 상향이라
   **모바일 앱 빌드와 CSS 빌드 회귀 확인**이 필요합니다(둘 다 메이저 아님) / 머니 접촉 **없음**
