## 질문
정기결제(카드 등록 후 자동결제) 계약을 아래 중 어디에 붙일까요? (번호로 답)

## 근거 (실측)
- 2026-11-24 대표가 토스 정기결제 계약 완료 알림을 공유. MID `bill_uhomesn95` — 지금 쓰는 일반결제 MID 와 **다른 상점**이라 시크릿 키도 따로다.
- 코드에 정기결제(빌링키) 경로가 **0개**다: `grep -rn "billingKey\|/v1/billing" src` 결과 없음.
- 대외 약속: 매장은 **가입비·월정액 0** (`docs/business/urdeal-business-plan.md:121,180`). 매장에게 월 요금을 받는 데 쓰면 이 약속과 충돌한다.
- 공구 서비스(운영자 몰)는 사업설계상 **초기 무료**(`docs/design/operator-mall-saas-gap.md:213,251`).
- AI 가 손님 카드로 혼자 자동결제하는 것은 하지 않기로 이미 정했다(`docs/decisions/2026-10-19-ai-agent-channel.md:39`).

## 선택지
1. **당장은 붙이지 않고 보관** — 장점: 약속과 충돌 없음, 개발 0 / 단점: 계약만 있고 매출 없음 / 머니 접촉 없음
2. **공구 서비스(운영자 몰) 월 구독** — 유료 전환 시점에 운영자 몰 요금을 자동결제로 받는다. 장점: 정기결제가 가장 자연스러운 자리 / 단점: "초기 무료" 전략을 언제 끝낼지 먼저 정해야 함 / 머니 접촉 있음(새 결제 레일)
3. **소비자 멤버십** — 손님이 월 N원 내고 할인·혜택을 받는다. 장점: 재방문 고정 / 단점: 혜택 재원을 누가 내는지(매장? 유어딜 수수료?) 설계 필요, 해지·환불 규칙 필요 / 머니 접촉 있음
4. **정기 이용권** — 예: 매달 커피 10잔권이 자동으로 다시 발급. 장점: 매장 매출 고정 / 단점: 매장 정산·미사용분 환불·유효기간이 매달 겹쳐 가장 복잡 / 머니 접촉 있음

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
1번(보관). 지금 유어딜에는 정기 요금을 받는 상품이 없고, 매장 월정액 0 약속이 있다. 2번은 공구 서비스 유료화를 정할 때 함께 결정하는 것이 맞다.
