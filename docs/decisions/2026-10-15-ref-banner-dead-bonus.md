# 공유 링크로 들어온 첫 방문자가 보는 `?ref=` 배너가 안 주는 보너스를 약속합니다 — 어떻게 할까요?

상태: open
등급: C
역할: dev

기한: 2026-10-22

## 질문
`/pass/:id` 의 `?ref=` 진입 배너(`참여 시 양쪽 0.5% 보너스 딜`)를 **삭제**할까요,
아니면 설정값을 읽어 **0 이면 안 그리는 방식**으로 바꿀까요? (선택지 1 / 2)

## 근거 (실측)

**무엇이 떠 있나** — `GroupBuyDetailPage.tsx:674~683`(잠금표 파일), `?ref=` 진입에서만 뜨는 잉크색 배너:
> 친구 추천 공구
> **참여 시 양쪽 0.5% 보너스 딜**

**누가 보나** — 이 페이지 공유 버튼이 만드는 주소가 `` /pass/:id?ref=<내 user_id> ``(`:207`)다.
즉 어제 #1853 으로 카드 문구를 고친 **그 링크로 들어온 사람이 가장 먼저 보는 블록**이다.

**보상은 0 이다** (어드민 `/api/admin/tools/settings`, 2026-10-15):

| 값 | 실측 | 언제 꺼졌나 |
|---|---|---|
| `user_referral_bonus_pct` | **`'0'`** | 2026-08-23 대표 "심플 모델" |
| `influencer_commission_pct` | **`'0'`** | 2026-08-22 대표 결정 |
| `invite_reward_enabled` | **행 부재 = 꺼짐** | 운영 게이트 표: *"켜지 않는다 — 종료한 축"* |

비율이 0 이라 **분기와 무관하게** 0 이다 — `calcSplit`·`group-buy.routes:478` 은 물론
인플 차단 분기(`calcSplitInfluencerBlocked`, *"회사가 보장"* 하는 그 경로)도 같은 값이다.
⇒ **배너를 읽는 사람(구매자)은 어떤 경로로도 0 원을 받는다.**

**문구가 틀린 지점이 둘** — ① 비율(0.5% 아니라 0) ② 수령자("양쪽" 중 소개한 쪽이 받는 길은
이 레일이 아니라 **매장이 제안한 딜 %**(`seller_influencer_deals`)이고, 그건 `ShareRewardBanner` 가 따로 말한다).

**어제 배포가 이 배너만 남긴 것을 숫자로 확인했다** — 상세 봉투의 `0.5% 보너스` 가 **2 → 1**.
사라진 하나가 공유 설명이고 **남은 하나가 이 배너**다(#1853 승인 범위가 메타 설명이라 일부러 안 건드렸다).

**선례 — 같은 원인에 처방이 두 갈래로 이미 내려져 있다**

| 날짜 | 자리 | 처방 |
|---|---|---|
| 2026-08-26 | `/influencer` 랜딩 | **전면 재작성** — *"지금 실제로 도는 것 하나만 말한다"* |
| 2026-10-06 | 지갑 '참여 완료' 공유 모달 | **삭제** — *"문구만 고치면 보상 없는 공유 권유만 남는다"* |
| 2026-10-06 | `/api/affiliate/top-groups` | **설정 읽기** — 0 이면 화면이 그 줄을 안 그린다 |

**같은 약속의 형제 하나 — 공구 이용약관 제5조**(`GroupBuyTermsPage.tsx:59`)
*"…사용자에게도 **0.5% 보너스** 즉시 적립"* + *"매장이 인플을 차단한 경우에도 회사가 보장"*.
배너는 마케팅 문구지만 이쪽은 **약관(회사의 약속)** 이다. 다만 도달은 어렵다
(라이브 `noindex, follow` · sitemap 0건 · UI 링크 0 — 주소를 직접 쳐야 한다).

**접촉 범위** — 🔒 **소개 귀속은 안 깨진다**: `?ref=` 저장은 **별도 effect**(`:155` `storeAffiliateRef`)가
하고, 배너 플래그(`isInfluencerLanding`)는 이 배너 **한 곳에서만** 쓰인다. 잠긴 항목 전부 byte-불변 예정.
**머니 경로 없음**(표시 문구와 렌더 조건뿐 — 적립 계산·원장 접촉 0). 상세: 인계 `2026-10-15-pass-title-voucher.md`.

## 선택지
1. **배너 삭제**(선례 2026-10-06 지갑) — 거짓 약속이 사라지고 첫 화면이 그만큼 올라온다 /
   보상이 재개되면 배너를 다시 만들어야 한다 / 머니 접촉 없음
2. **설정값을 읽어 조건부 노출**(선례 2026-10-06 어필리에이트) — 지금은 안 뜨고 대표가 보너스를 켜면
   **저절로** 다시 뜬다 · 문구가 사실과 갈릴 수 없다 / 상세 응답에 비율 필드 1개 추가(서버 1곳) / 머니 접촉 없음
3. **문구만 보상 없이 고치기**(`친구가 추천한 이용권`) — 가장 작은 변경 /
   보상 없는 배너가 첫 화면 자리를 계속 차지한다(지갑 선례가 기각한 길) / 머니 접촉 없음
4. **보너스를 되살리기**(`user_referral_bonus_pct` → 0.5) — 배너가 사실이 된다 /
   **2026-08-23 "심플 모델" 을 뒤집는다 · 머니 경로 → 단독 세션 + staging 실결제** / 머니 접촉 **있음**
