## 질문
매장을 데려와 대신 등록하고 운영하는 쪽(지금 화면 이름 "중개사")을 **"에이전시"** 로 통합하고, 에이전시 계정은 **이메일로만 가입·로그인**하게 하며, 로그인 화면은 **안 A** 로 갈까요?

## 근거 (실측)
- 옛 에이전시(`agencies` 테이블, `/agency/*`)는 2026-09-04 대표 결정으로 일몰됐고 `src/tests/unit/agency-sunset-final.test.ts` 가 되살림을 막는다. 그 일을 이어받은 것이 지금의 중개사다 — 같은 자리이고 이름만 갈려 있다.
- 지금 중개사는 **개인 소비자 계정 하나**다(`seller_operators` role=operator, `/store/new` 의 brokered 채널). 직원 여럿이 쓰거나 회사 이름으로 정산받을 구조가 없다.
- 매장 운영자 추가는 지금 **사장님만** 할 수 있다(`POST /api/seller/operators`). 에이전시가 직원을 붙이려면 매장마다 사장님에게 부탁해야 한다.
- 에이전시 몫 상한이 코드에 고정돼 있다: `broker-share.ts` `BROKER_SHARE_PCT_MAX=50` · `INFLUENCER_CAP_PCT_MAX=50` · `BROKER_TERMS_SUM_MAX=90`.
- 사장님 회수는 이미 있다: `POST /api/seller/operators/:userId/revoke` → 그 순간부터 몫 적립 중단(좌석 active 일 때만 적립). 기간 개념은 없다.
- 라이브(2026-10-11 어드민 조회, 읽기 전용): 중개 매장 4곳, `broker_share_enabled=true`, 지급된 에이전시 몫 0건, staging 실결제 기록 없음.
- 이메일·비밀번호 로그인 부품은 레포에 이미 있다(비밀번호 해시·로그인 시도 제한·대시보드 세션·Resend 메일·`password_reset_tokens`).
- 로그인 시안 6장: `docs/design/agency-login-2026-10-11.md` · 캔버스 https://claude.ai/artifact/27VApxxLQkDpiVxtZPt66d (맨 아래 줄 Login1~6).

## 선택지
1. **에이전시로 통합 + 이메일 전용 + 로그인 안 A** — 손님 로그인은 카카오 그대로, 맨 아래 "에이전시이신가요? · 에이전시 로그인" 한 줄로 별도 이메일 로그인 화면. 개인 돈(소개비)과 에이전시 몫이 처음부터 다른 계정에 쌓인다. 머니 접촉: 있음(에이전시 몫 귀속처·정산 분기).
2. 로그인 안 B — 위쪽 탭 [개인 | 에이전시]. 손님 모두가 매번 탭을 본다.
3. 로그인 안 C — 로그인 전에 "개인으로 / 에이전시로" 먼저 고르기. 손님에게 한 단계가 더 생긴다.
4. 지금처럼 개인 카카오 계정 하나로 두기 — 직원·회사 정산을 못 담는다.

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
안 1. 로그인하는 사람 대부분은 손님이라 첫 화면엔 입구 한 줄이면 충분하고, 에이전시는 매일 쓰는 소수라 별도 주소를 즐겨찾기한다.

### 정리 (위 말씀을 구현 단위로 옮긴 것 — 의역이 아니라 범위 표시)
- 명칭: 화면의 "중개사" → **"에이전시"**. 코드 식별자(`broker_*`)는 그대로. 옛 `/agency` 화면·`agencies` 테이블은 되살리지 않는다.
- 에이전시는 회사 단위 계정(사업자 / 개인 둘 다). 매장은 사람이 아니라 에이전시에 붙는다.
- 가입·로그인은 **이메일로만**. 카카오로는 에이전시를 만들 수 없다. 직원은 각자 이메일 초대로 합류(관리자 / 직원).
- 로그인 화면 = 안 A. 손님 화면에서 에이전시 이메일을 넣으면 에이전시 로그인으로 안내한다.
- 규칙 1: 에이전시가 자기 링크로 판 건은 에이전시 몫만(소개비 미적립).
- 규칙 2: 유어딜 고정 상한 제거. 사장님이 정한 범위 안은 에이전시가 혼자 수락, 넘으면 사장님 승인. 남는 하드 바닥 = 에이전시 몫 + 소개비 ≤ 매장 몫.
- 규칙 3: 기간 없음. 사장님이 언제든 끊는다(끊은 다음 판매부터 몫 중단, 붙은 몫 유지).
- 순서: ① 에이전시 계정·이메일 로그인·직원 초대·매장 귀속·기존 4곳 이관 → ② 규칙 1~3 → ③ 정산 분기(세금계산서 / 3.3%). 머니 경로는 단계마다 staging 실결제 확인 뒤 켠다.
