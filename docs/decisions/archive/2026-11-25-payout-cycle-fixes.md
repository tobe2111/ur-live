## 실행한 것

1. 에이전시 몫의 확정 조건을 소개비와 같은 규칙으로 맞췄다(`payout_requires_voucher_use` 설정 하나가 둘 다 다스린다). 잔액 표시 · 지급 신청 · 정산일 자동 신청이 같은 조건을 쓴다. 안 쓴 이용권의 몫은 대기로 남고, 환불되면 회수된다.
2. 월별 회계 자료의 원천징수 합계에 에이전시 지급분을 더했다.
3. 현금 지급은 받을 계좌가 있어야 처리된다(`PAYOUT_NO_ACCOUNT`). 방식은 현금·딜 중 하나를 꼭 보내야 한다.
4. 새로 생기는 잔액 행은 사업소득으로 만든다. 라이브의 기존 행은 수리 경로(`repair-schema`)가 고친다(계좌·사업자번호·지급 이력이 모두 없는 행만).
5. 훅을 조기 반환 위로 올렸다.
6. "+N%" 는 서버 설정값이 0 보다 클 때만 적는다. 세금 선택지는 사업소득 3.3%(기본) · 기타소득 8.8% 둘로 줄였다.
