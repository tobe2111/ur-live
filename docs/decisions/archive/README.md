# 결재함 보관소 — 반영이 끝났거나 반려된 결재

여기 있는 문서는 **지워진 것이 아니다.** 내용도 파일명도 그대로이고, 위 폴더에서 한 칸 내려왔을 뿐이다.

## 왜 옮기나

어드민 결재함(`/admin/decisions`)은 `import.meta.glob('docs/decisions/*.md', { eager: true })` 로
**결재 원문을 통째로 번들에 박는다.** 그래서 처리 끝난 결재가 쌓이면 그 무게를 *모든 방문자가* 아니라
어드민 청크가 지고, 저장소 번들 총량 예산을 계속 밀어 올린다 —
`scripts/check-bundle-size.mjs` 의 상향 이력이 **아홉 번 연속** 같은 원인을 적고 있고,
그 파일 자신이 *"이 값을 또 올리기 전에 처리 끝난 결재를 archive 로 옮겨라"* 고 요구해 왔다.

glob 이 `*.md`(비재귀)라 **이 폴더는 자동으로 빠진다.** 코드 변경 0.

## 무엇을 옮기고 무엇을 남기나 (2026-09-28 대표 승인)

| | 어디에 | 왜 |
|---|---|---|
| `상태: rejected` | **여기** | 구현할 것이 없다 |
| `상태: approved` + **반영 커밋에 해시** | **여기** | 어드민 화면에서 이미 `반영 끝` 으로 접힌다 |
| `상태: approved` + 반영 커밋 비었거나 "머지 대기" | **위 폴더 유지** | 어드민이 `승인 · 구현 중` 으로 **추적하고 있는 살아 있는 일**이다 |
| `상태: open` | **위 폴더 유지** | 대표 답을 기다리는 것 |

⚠️ **승인만 보고 옮기지 말 것.** 2026-09-28 에 "approved/rejected 20건" 으로 셌다가, 그중 13건이
`반영 커밋` 이 비어 있어 **구현 중인 일**임을 확인하고 7건으로 줄였다. 그 13건을 옮겼으면 대표가
"승인해 줬는데 어디 갔지" 를 겪었을 것이다. 판정은 `parse-decision.ts` 의 `fullyApplied` 가 SSOT 다.

## ⚠️ 끝난 결재만이 아니다 — **살아 있는 결재 안에 쌓이는 측정 로그**도 같은 무게다

2026-10-01 에 이 구조로 **번들 예산이 터졌다**(PR #1602 `Verify` 빨간불). 원인은 처리 끝난 결재가
아니라 **열려 있는 결재문 하나가 측정 1·2·3차를 다 싣고 24.0 KB 로 자란 것**이었다
(`AdminDecisionsPage` 청크 +8.1 KB). 그 파일은 archive 대상이 아니다 — `상태: open` 이고
대표 답을 기다린다.

⇒ **결재문은 대표가 5분에 읽는 자리다.** 측정 로그·재현 명령·실패한 시도의 상세는
`docs/design/<시안>.md` 나 `docs/handoff/<세션>.md` 로 내리고 결재문엔 **현재 상태 + 포인터**만 둔다
(그 둘은 glob 밖이라 번들에 안 들어간다). 같은 날 1·2차를 시안 문서로 내려 **24.0 → 14.8 KB** 로
줄였고 예산 상향 없이 초록이 됐다.

🩸 **상태 한 줄로 기계적으로 옮기지 말 것**: 같은 날 `상태: rejected` 인 28 KB 파일
(`2026-09-21-settlement-structure-payouts.md`)이 가장 큰 후보로 잡혔지만 **옮기지 않았다** —
그 문서는 질문 넷(Q1~Q4)을 한 `상태:` 줄 아래 담고 있고, 본문이 *"닫힌 것이 아니라 미룬 것이라
10월에 재상정할 것"* · *"남은 것은 대표가 누를 어드민 값 셋"* 이라고 적는다. 옮겼으면 대표가
10월에 재상정할 일을 결재함에서 잃는다. **판정은 `상태:` 가 아니라 본문이 말하는 남은 일이다.**

## 🕳️ "코드 변경 0" 결재는 SSOT 가 끝났다고 말해 주지 못한다 (2026-10-02)

`fullyApplied`(`parse-decision.ts:63`)는 `반영 커밋` 에 **16진수 해시 7~40자**를 요구한다. 그래서
*"안 만든다 / 지금 상태 유지"* 로 끝난 결재는 **영원히 `승인 · 구현 중`** 으로 남는다 — 구현할 것이
없는데 추적 목록에 앉아 있다. 2026-10-02 에 그런 셋(`ushop-star-rating` · `ushop-bottom-buy-bar`
· `store-scan-counter`)을 `반영 커밋` 에 *"코드 변경 0 — 왜"* 를 적어 사람 판정으로 옮겼다.

⇒ 그런 결재를 옮길 때는 **`반영 커밋` 에 코드 변경이 0인 이유를 한 줄 남긴다.** 비워 둔 채 옮기면
다음 세션이 *"승인만 보고 옮겼다"* 와 구분할 수 없다.

## 되돌리기

`git mv docs/decisions/archive/<파일> docs/decisions/` — 다시 결재함에 뜬다.
