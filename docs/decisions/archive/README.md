# 결재함 보관소 — 반영이 끝났거나 반려된 결재

여기 있는 문서는 **지워진 것이 아니다.** 내용도 파일명도 그대로이고, 위 폴더에서 한 칸 내려왔을 뿐이다.

## 왜 옮기나

어드민 결재함(`/admin/decisions`)은 `import.meta.glob('docs/decisions/*.md', { eager: true })` 로
**결재 원문을 통째로 번들에 박는다.** 그래서 처리 끝난 결재가 쌓이면 그 무게를 *모든 방문자가* 아니라
어드민 청크가 지고, 저장소 번들 총량 예산을 계속 밀어 올린다 —
`scripts/check-bundle-size.mjs` 의 상향 이력이 **아홉 번 연속** 같은 원인을 적고 있고,
그 파일 자신이 *"이 값을 또 올리기 전에 처리 끝난 결재를 archive 로 옮겨라"* 고 요구해 왔다.

glob 이 `*.md`(비재귀)라 **이 폴더는 자동으로 빠진다.** 코드 변경 0.

## 무엇을 옮기고 무엇을 남기나 (2026-09-28 대표 승인)

| | 어디에 | 왜 |
|---|---|---|
| `상태: rejected` | **여기** | 구현할 것이 없다 |
| `상태: approved` + **반영 커밋에 해시** | **여기** | 어드민 화면에서 이미 `반영 끝` 으로 접힌다 |
| `상태: approved` + 반영 커밋 비었거나 "머지 대기" | **위 폴더 유지** | 어드민이 `승인 · 구현 중` 으로 **추적하고 있는 살아 있는 일**이다 |
| `상태: open` | **위 폴더 유지** | 대표 답을 기다리는 것 |

⚠️ **승인만 보고 옮기지 말 것.** 2026-09-28 에 "approved/rejected 20건" 으로 셌다가, 그중 13건이
`반영 커밋` 이 비어 있어 **구현 중인 일**임을 확인하고 7건으로 줄였다. 그 13건을 옮겼으면 대표가
"승인해 줬는데 어디 갔지" 를 겪었을 것이다. 판정은 `parse-decision.ts` 의 `fullyApplied` 가 SSOT 다.

## 되돌리기

`git mv docs/decisions/archive/<파일> docs/decisions/` — 다시 결재함에 뜬다.
