## 질문

## 선택지

1. **공식 코드표를 주신다** — `data.go.kr` → "공정거래위원회 통신판매사업자 등록상세" → **활용가이드**
   첨부 안의 취급품목 코드 표 12줄(스크린샷도 됩니다). 또는 그 페이지 **응답 메시지 명세**의
   `trtmntPrdlstNm` 행 항목설명.
   · 장점: 12코드 전부 정확 · 단점: 대표 시간 필요 · 머니 접촉 **없음**
   ⚠️ 이 환경은 `data.go.kr`(DNS 부재)·`ftc.go.kr`(CONNECT 403)이 막혀 **세션이 직접 못 받습니다**(측정됨).

2. **근거 강한 8코드만 매핑**(`01`·`09`·`11`·`12` 는 `통신판매` 유지) — ⭐ 기본안
   · 장점: **거짓 라벨이 구조적으로 0** · 60.7% 가 라벨을 받는다 · 대표 시간 0
   · 단점: 39.3% 는 그대로 `통신판매` · 머니 접촉 **없음**

3. **12코드 전부 매핑**(`01`=종합몰 · `12`=기타 · `09`=성인 · `11`=상품권 **추정 포함**)
   · 장점: 100% 라벨 · 단점: `09`/`11` 은 **합쳐 8건의 상호로 찍은 추측**이고 ⑤ 때문에 되돌리기 어렵다
   · 머니 접촉 **없음**

4. **안 한다** — 지금처럼 전부 `통신판매` 한 라벨
   · 장점: 변경 0 · 단점: 업종 필터가 통신판매 리드 5.8만 건에 **무의미**하다

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)

**2.** ⑤ 때문에 "틀릴 수 있는 라벨" 의 비용이 비대칭으로 크고, 안 2 는 **그 위험을 0 으로 만들면서**
60.7% 를 가져온다. `01`↔`12`(둘 다 "주제 없음")는 뒤바뀌어도 필터링에 거의 영향이 없지만 **그래도
안 붙이는 쪽**이 낫다 — 종합몰/기타는 필터에서 쓸 값이 아니라서 얻는 것이 거의 없다.
안 1 이 오면 안 2 를 **덮어쓴다**(같은 상수 한 곳이라 충돌 없음).

## 롤백

`PRODUCT_CODE_BUCKETS` 상수 + 호출 한 줄 제거 → `productBucket` 이 다시 텍스트 정규식만 보고
코드는 0건 일치 → `'통신판매'`. **단 이미 승격된 행의 라벨은 안 지워진다**(위 ⑤ — 그래서 안 2 를 권한다).

## 결정 (대표가 한 말 그대로)

> **"업종 92% 문제 최대한 빨리 해결해줘 다른 것도 마찬가지고."** (2026-10-25 16:0x KST)

⇒ **번호를 고를 필요가 없어졌습니다.** 그 지시를 받고 16:00 회차(배포 후 첫 detail 회차)의 응답을
열어 보니 **한글 품목이 같은 레코드에 쌍으로** 들어 있었습니다:

```
trtmntPrdlstNm = '01 02'                        ← 숫자 코드   (coverage 31% = 155/500)
ntslPrdlstCn   = '종합몰 교육/도서/완구/오락'      ← 같은 뜻 한글 (coverage 31% = 155/500, 같은 행)
ntslMthdNm     = '02 03'   ↔  ntslMthdCn = '인터넷 카탈로그'
```

즉 **이 결재의 전제("코드밖에 안 온다")가 사실이 아니었습니다.** 원인은 데이터가 아니라 `g()` 의
별칭 **순서**였고(코드가 한글보다 앞 → 비어 있지 않으니 거기서 멈춤), 한글을 앞으로 옮기는 것으로
끝났습니다. ⇒ 안 1~4 **어느 것도 실행하지 않습니다**(코드표 불필요 · 추측 라벨 0 · 대표 시간 0).

🩸 **왜 이 결재가 애초에 올라왔나(교훈)**: 2026-10-24 에 코드를 보고 *"원본에 코드만 온다"* 고
판단했는데, 그때 본 것은 **status 레코드의 필드 목록**이었습니다(detail 이 굶어 한 번도 안 왔다).
detail 이 도착하자 40개 키 중에 한글 쌍이 있었습니다. ⇒ **"그 값이 없다" 를 말하기 전에 그 값이
오는 경로가 살아 있는지 먼저 확인할 것** — 굶은 경로의 부재를 데이터의 부재로 읽었습니다.

📌 **남은 일(이 결재와 별개)**: 나머지 코드(03~12)의 한글 라벨은 회차가 쌓이며 `description` 에
모입니다. 그 분포를 보고 버킷 표를 넓히면 되고, **표준 목록을 기억으로 적지 않습니다**(추측 라벨은
승격 뒤 코드 롤백으로 안 지워진다 — 위 ⑤).
