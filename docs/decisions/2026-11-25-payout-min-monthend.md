# 매장 주간 정산의 최소 금액을 어떻게 다룰까?

상태: approved
등급: C
역할: finance
올린 날: 2026-11-25
기한: 2026-11-25

## 질문
받을 돈이 최소 금액(1만 원)보다 적은 매장은 언제 정산하나?

## 근거 (실측)
- 주간 정산(`worker/cron/payouts-generate.ts`)은 받을 돈이 1만 원 이상일 때만 지급 대기 건을 만든다(상수 `REFUND_POLICY.COMMISSION_MIN_WITHDRAWAL`). 미만은 다음 주로 쌓인다.
- 상한이 없어 판매가 아주 적은 매장은 몇 달이고 못 받을 수 있었다. 값도 코드 상수라 어드민이 못 바꿨다.

## 선택지
1. 그대로
2. **최소 금액을 어드민 설정으로 + 그달 마지막 목요일엔 금액과 상관없이 정산**

## 기본안
2번.

## 롤백
`platform_settings.payout_min_krw` 로 금액 조정(0 = 최소 없음). 월말 규칙은 revert.
