# 해외판을 연다면 어느 나라부터, 어떤 결제로 갈까요?

상태: open
등급: C
역할: planning
올린 날: 2026-11-02
기한: 2026-11-30

## 질문
해외판 첫 나라와 결제 방식을 아래 선택지 번호로 정해 주시면, 그 범위의 개발(결제 금액 검증·이행, 구글 로그인, 지도)을 시작해도 될까요?

## 근거 (실측)
- 해외판 틀은 있다: 접속 주소로 한국/해외를 가르는 `src/shared/config/region.ts`, 번역 6개 언어(`public/locales`), 환율 표시 `src/utils/currency.ts`.
- 결제: Stripe 코드는 쇼핑 장바구니에만 연결돼 있고, 결제 성공 시 주문 상태만 바꾼다(재고·발급·정산·알림 없음) — `docs/design/global-launch-readiness.md` §4-A.
- 🔴 `src/worker/routes/stripe.routes.ts` `POST /create-intent` 가 손님이 보낸 금액을 그대로 믿는다(서버 재계산 없음) — 같은 문서 §7-5.
- Stripe 는 한국 법인 가입이 안 될 가능성이 높다(공식 목록에서 한국은 '손님 국가'로만 확인) — §7-2. 토스는 '다국어 결제창 + 해외 간편결제' MID 를 따로 계약할 수 있다.
- 구글 로그인은 2026-07-28 키 유출 사고로 일부러 꺼져 있다(#804, `check-no-firebase-auth.mjs`) — §7-4.
- 지도는 카카오맵 전용(파일 17개) — §7-6.
- 이용권·교환권은 한국 매장·한국 통신사 전제라 해외 손님에게 팔 상품이 아직 정해지지 않았다 — §4-D.

## 선택지
1. **토스 해외 간편결제로 시작** — 한국 법인 그대로, 승인 방식이 지금 토스와 같아 개발이 가장 짧다 / 결제수단이 Stripe 보다 적고 요율은 토스 문의 / 머니 접촉 있음.
2. **해외 법인 + Stripe** — 카드·구글페이·애플페이·해외 정산까지 가장 잘 갖춰짐 / 법인 설립·세무 비용과 시간 / 머니 접촉 있음.
3. **지금은 보류** — 무엇을 팔지(§4-D)부터 정하고 그 뒤에 결제 결정 / 개발 0 / 머니 접촉 없음.

함께 정할 것: 첫 나라(예: 일본 / 미국 / 동남아) · 해외에서 팔 상품 · 가격을 원화로 받고 표시만 환산할지(권장) 현지 통화로 받을지.

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
3번. 팔 상품과 나라가 정해지기 전에 결제·지도를 고치면 나라가 바뀔 때 다시 해야 한다. 정해지면 1번이 가장 빠르다.

## 롤백
결정 전에는 바뀌는 코드가 없다. 개발 시작 후에는 해외 도메인을 연결하지 않으면 한국판에 영향이 없다(지역 판정이 접속 주소 기준).

## 결정 (대표가 한 말 그대로)

  ⇒ 해외판도 유어딜과 같은 모델(매장 이용권 · 유어샵)이다. **첫 나라·결제 방식은 아직 미정** — 상태 open 유지.
