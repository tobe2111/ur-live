# 해외결제(토스 해외 간편결제·페이팔) 수수료를 매장이 부담하고, 매장이 해외결제 판매를 켤지 고르게 할까요?

## 질문
해외결제 건에만 **추가 수수료를 매장이 부담**하고, 매장마다 **"외국인 해외결제 판매" 켜기/끄기**를 두는 방향으로 진행할까요? (켜는 경우 추가 수수료 값을 아래 중 고른다)

## 근거 (실측)
- 대표 방향 제시(2026-11-17, 그대로): *"해외를 통해서 판매한다면(해외결제) 수수료가 달라지도록 해야할 것 같은데? 사장님이 부담해야겠지? 그래서 사장님이 해외 결제도 하게 할 것인지 뭐 그런 것도 해야하지 않을까?"*
- 토스페이먼츠 해외 간편결제(PayPal) 요율(대표 공유 화면): 4% + 건당 0.3 USD, 환전·인출 +1.94%(부가세 별도) → 부가세 포함 약 6.5% + 건당 약 460원.
- 국내 카드 PG 약 2.75% 대비 차이 ≈ +3.8%p + 건당 460원. 중개 매장(우리 수수료 5%)은 해외결제 한 건마다 적자.
- 토스 문서: 해외 간편결제는 **USD만**, 취소 시 **거래 수수료 미반환** → 미사용 자동 전액 환불이 그대로 손실.
- 토스페이먼츠 안에서 페이팔을 쓰는 것이라 **페이팔과 별도 계약은 불필요**(MID 추가 계약만). 다만 결제 코드(`FOREIGN_EASY_PAY`·USD 금액·승인)는 새로 붙여야 한다.

## 선택지
1. **매장 부담 추가 수수료 4%p(정률) + 매장 켜기/끄기(기본 꺼짐)** — 단순. 1만 원대 저가 이용권은 건당 460원 때문에 여전히 소폭 적자 → 최소 결제 금액(예: 1.5만 원)과 함께. 머니 접촉: 정산·환불.
2. **매장 부담 추가 수수료 = 실비(정률 3.8%p + 건당 500원)** — 손실 0에 가장 가깝다. 사장님이 계산하기 어렵다. 머니 접촉: 정산·환불.
3. **손님 가격에 반영(달러 환산 시 여유)** — 매장 몫 불변. 카드 수수료 고객 전가 금지(여신법) 해석 리스크 → 법률 확인 필요.

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
1번. 사장님이 이해하기 쉽고(“해외결제는 수수료 +4%”), 켜기/끄기로 원치 않는 매장은 영향 0.
미사용 자동 환불 시 수수료 손실은 별도로 정한다(해외결제 건은 수수료 차감 환불 또는 매장 부담).
