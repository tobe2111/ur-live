# 생활 서비스(이사·입주청소·에어컨 청소)에 숨고식 견적 매칭을 붙인다

상태: approved
등급: C
역할: planning
올린 날: 2026-10-24
기한: 2026-10-24

## 질문
생활 카테고리를 음식점·숙소와 다르게, 손님 요청 → 사장님 알림톡 → 참여권(유료)으로 견적 참여 방식으로 운영할까?

## 근거 (실측)
- 생활 이용권 카테고리 `home_voucher` 는 2026-10-20 라이브(데모 9건, `category=home_voucher`).
- 카카오 로그인 사용자 12명 전원이 카카오 인증 휴대폰 번호를 갖고 있다(`users.phone`, 2026-10-24 D1 실측) → 별도 본인인증 업체 없이 "카카오 인증 번호" 로 본인 확인을 대신할 수 있다.
- 알림톡 발송처 SENS 는 템플릿 심사 전이면 문자로 대체 발송한다(`lib/system-alimtalk.ts`).

## 선택지
1. 견적 매칭 + 이용권 병행(사장님 한 계정) — 이사처럼 가격이 집마다 다른 일은 견적, 에어컨 청소처럼 정해진 일은 이용권. 머니 접촉: 참여권 카드 충전(Toss).
2. 이용권만 — 이사는 가격을 정할 수 없어 못 판다.

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
안 1. 이사처럼 집마다 가격이 다른 일은 이용권으로 팔 수 없다.

## 결정 (대표가 한 말 그대로)
- "바로 유료로 가고, 기사들은 쉽게 모을 수 있어."
- "생활 서비스는 미소, 숨고처럼 그냥 가야할 것 같아. … 생활 서비스 사장님이 유저들의 이사, 청소에 대한 수요가 나오면 알림톡이 와서 그 수요에 참여? 시딩? 할 수 있게끔 … 그러면서 자신들의 이용권도 팔고."
- "그냥 1명부터 열어줘."
- "견적에 참여할 때 금액 적지 않아도 참여(돈을 쓰게끔) 하게끔 하는게 좋지 않을까?"
- "생활 페이지에서 각각의 카테고리 (이사, 입주청소, 에어컨 청소 등등) 는 미리 사전에 사용자의 니즈 리드를 받는게 좋지 않을까? 그 리드에 맞게 알림톡으로 해당하는 사장님한테 알림톡이 가는거지"
- 아래 기본값 묶음에 대해: "좋아 그대로 진행해줘."

### 확정된 값
| 항목 | 값 |
|---|---|
| 지역 오픈 기준 | 사장님 1명부터. 사장님이 없는 지역의 요청은 **보관**했다가 그 지역 사장님이 생기면 보낸다 |
| 견적 금액 | 선택(비우면 "방문 후 견적") |
| 선착순 | 요청당 5명 |
| 참여권 차감 시점 | 견적을 보낼 때 1장 |
| 가입 무료 참여권 | 3장 |
| 묶음 가격 | 5장 5,000원 / 10장 9,000원 / 30장 24,000원 (어드민 조정 대상) |
| 연락처 공개 | 손님이 사장님을 고른 뒤 서로 공개 |
| 자동 반환 | 손님이 요청 취소 · 손님이 48시간 동안 견적을 한 번도 안 열어 봄 → 그 요청의 참여권 반환 |
| 첫 카테고리 | 이사 · 입주청소 · 에어컨 청소 |
| 본인인증 | 카카오 로그인 + 카카오가 인증한 휴대폰 번호 |

### 하지 않는 것
- 실제 손님이 없는 **가짜 요청**을 만들어 사장님이 참여권을 쓰게 하는 기능은 만들지 않는다. 사장님이 돈을 내고 받는 것이 실제 손님이 아니면 기만이 된다(전자상거래법·사기 위험, 플랫폼 신뢰 붕괴). 사장님 영업에는 **실제로 쌓인 요청 수**와 **무료 참여권 3장**을 쓴다.

### 추가 (2026-10-24 대표 "실제 손님 있어. 두 기능 모두 만들어줘")
- **운영팀 대리 접수** — 영업으로 찾은 **실제 손님**의 요청을 운영팀이 `/admin/home-service` 에서 대신 올린다. 손님 동의 기록(`consent_note`)이 없으면 받지 않는다. 손님이 전화로 고른 견적은 운영팀이 대신 누른다(대리 접수 건만 — 앱에서 손님이 올린 요청은 손님만 고른다).
- **유어딜 직영 견적** — 유어딜(또는 협력 업체)이 직접 하는 견적. 손님 화면에 **"유어딜 직영"** 으로 표시한다. 선착순 자리는 똑같이 하나 차지하고, 참여권은 쓰지도 돌려받지도 않는다.

### 충전 켬 (2026-10-25)
대표 "일단 유료 충전 가능하게끔 해주고" → `home_service_charge_enabled=true`(라이브). staging 실결제(S-HOME-5)보다 먼저 켰다 — 첫 실제 충전을 원장·잔액으로 확인한다.

## 롤백
게이트 `home_service_quotes_enabled` 를 끄면 손님 요청 접수·사장님 견적 참여가 멈춘다(충전된 참여권은 보존). 이미 결제된 참여권 환불은 어드민 수동.

## 출시 조건
- 게이트 기본 OFF. **테스트 환경에서 실결제 1회**(참여권 5장 충전 → 견적 1건 → 반환 1건) 후 대표가 켠다.
- 알림톡 템플릿 3종 SENS 등록(`docs/alimtalk-register-list.md`) — 심사 전에는 문자로 나간다.
