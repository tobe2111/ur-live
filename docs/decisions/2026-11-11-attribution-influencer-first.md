# 소개 링크로 들어온 손님이 유어쇼츠·콘텐츠를 보고 사면 누구 성과인가

상태: decided
등급: C
역할: planning
올린 날: 2026-11-11
기한: 2026-11-11

## 질문
인플루언서 소개 링크로 들어온 손님이 24시간 안에 유어쇼츠(또는 상세의 영상·블로그)를 보고 결제하면, 그 결제를 인플루언서 성과로 잡는가?

## 근거 (실측)
- 소개 링크 기본 공유 주소가 **홈**(`affiliate.routes.ts` share_url `urdeal.kr?ref=`)인데, 홈·유어쇼츠·지도로 들어온 `?ref=` 는
  **유입 클릭만** 남고 구매 귀속(`affiliate_ref`)에는 저장되지 않았다(`App.tsx` 2026-08-09 주석 "구매 귀속은 종전과 동일").
- 장바구니 카드 확정(`/cart/confirm-toss`)은 본문 `ref` 만 읽었고, 결제 완료 주소(`?cart=1`)에는 ref 가 없다 → 장바구니 카드 결제는
  늘 무귀속. 라이브 서버 게이트 `voucher_cart_enabled = true` 이지만 화면의 담기 버튼(`VOUCHER_CART_UI_ENABLED`)은 OFF 라 **지금 실제 손실은 없다** — 켜는 순간부터 새던 길.
- 유어쇼츠·콘텐츠를 보고 산 결제는 **아무 표시도 남지 않았다**(갈래를 셀 수 없음).

## 선택지
1. 소개 링크가 이긴다(인플루언서 성과) + 무엇을 봤는지는 따로 기록 — 머니 접촉: 소개비가 설정된 매장에서 귀속 대상이 늘어난다
2. 마지막으로 본 콘텐츠가 이긴다 — 인플루언서가 데려온 손님의 성과가 유어딜로 간다

## 기본안
1안.

## 롤백
`App.tsx` 의 `captureLandingRef` 를 `captureInflowRef` 로 되돌리고, `cart-checkout.routes.ts` 확정의 `pickGbRefSource(...)` 를 `body.ref` 로.
갈래 기록(`order_touch`)은 돈과 무관하니 남겨도 된다.

## 결정 (대표가 한 말 그대로)
"인플루언서 링크를 통해서 들어와선 유어쇼츠를 볼 수도 있잖아. 24시간 내에. 그럼 인플루언서 성과로 안잡히면 안되지. 이런 케이스들을 체계적으로 잡아줘"
