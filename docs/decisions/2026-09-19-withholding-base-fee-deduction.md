# 인플루언서 현금 정산: 원천징수 과세표준에서 정산 수수료를 빼는가?

상태: open
등급: C
역할: finance
올린 날: 2026-09-19
기한: 2026-09-30

## 질문

현금 송금에서 정산 수수료를 뗄 때, **원천징수 과세표준이 "총액 − 수수료" 인가(현재 구현) 아니면
"총액" 인가(대안)?** 코드 문제가 아니라 **세무 사실 확인**입니다.

## 근거 (실측 — 2026-09-19)

**이 질문은 원래 #1269 에 달려 있었는데, 그 PR 이 머지되면서 질문만 갈 곳을 잃었습니다.**
(`docs/decisions/2026-09-15-stalled-pr-triage.md` 를 닫으면서 여기로 이관했습니다.)

**지금 새는 돈은 0 입니다.** 수수료가 안 켜져 있습니다:
```
platform_settings.influencer_payout_cash_fee_pct   ← 키 자체가 없음(미설정)
  → CASH_PAYOUT_FEE_DEFAULT_PCT = 0  (src/shared/influencer-payout-math.ts)
```
수수료가 0 이면 **두 해석의 결과가 산술적으로 같습니다**(검산: 둘 다 967,000원).
⇒ **요율을 0 보다 크게 켜는 순간** 이 질문이 돈 문제가 됩니다. 그 전에 답이 있어야 합니다.

**갈리는 금액** (총액 100만원 · 수수료 10% · 사업소득 3.3% 기준, 검산함):
```
현재 구현   과세표준   900,000 → 원천징수 29,700 → 실지급  870,300원
대안        과세표준 1,000,000 → 원천징수 33,000 → 실지급  867,000원
차이 3,300원  ( = 수수료 × 원천징수율 )
```
차이는 **수수료에 붙는 원천징수분**입니다. 수수료가 커지거나 기타소득(8.8%)이면 더 벌어집니다.

⚠️ **순서 문제가 아닙니다.** *"수수료 먼저냐 원천징수 먼저냐"* 로 생각하면 틀립니다 — 둘 다
곱셈이라 교환법칙이 성립해 순서는 결과를 안 바꿉니다. 갈리는 건 **과세표준에서 수수료를 빼느냐**
하나뿐입니다. (소스 주석에 그 함정과 그것을 잡은 테스트가 적혀 있습니다.)

**영향 범위**: `computeCashPayout()` 하나가 SSOT 이고, 원래 세 곳에 흩어져 있던 계산
(`cron/influencer-payout.ts` · `marketing.routes.ts` · `AdminInfluencerPayoutsPage.tsx`)이
여기로 모였습니다. ⇒ **고칠 자리는 한 곳**입니다. 현재 정산 조건: 월 1회 · 최소 10만원.

## 선택지

1. **현재 구현 유지 — 과세표준 = 총액 − 수수료** (실지급 870,300원)
   근거: 수수료는 유어딜이 제공하는 송금 용역의 대가이므로 인플루언서 소득이 아니라는 해석.
   💰 머니 접촉 있음(수수료를 켠 뒤부터).
2. **대안 — 과세표준 = 총액** (실지급 867,000원)
   근거: 인플루언서가 번 것은 총액이고 수수료는 그 소득에서 나가는 비용이라는 해석.
   💰 머니 접촉 있음. 코드 변경 필요(`computeCashPayout` 1곳 + 주석).
3. **수수료를 영영 안 켠다** — 질문 자체가 사라집니다. 마진을 다른 곳에서 걷는다는 뜻입니다.

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)

**세무 답이 나올 때까지 수수료를 켜지 않는다**(= 사실상 현상 유지). 이유: 원천징수를 잘못
신고하면 되돌리기가 어렵고(지급명세서·연말 정산까지 따라갑니다), 수수료가 0 인 동안은
어느 해석이든 결과가 같아 **서두를 이유가 없습니다.**

⚠️ 세션이 이 질문에 답할 수 없습니다 — 코드로 판정되는 것이 아니라 **세무 사실**입니다.
세무사 한 줄이면 끝납니다: *"플랫폼이 떼는 정산 수수료를 원천징수 과세표준에서 차감할 수 있는가?"*

## 롤백

수수료가 0 인 동안은 어느 쪽을 택해도 실지급이 같으므로 **켜기 전에는 되돌릴 것이 없습니다.**
켠 뒤 해석을 바꾸면 이미 송금·신고된 건을 소급 정정해야 하므로, **켜기 전에 확정하는 것이
곧 롤백 계획**입니다.
