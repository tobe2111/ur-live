# 다크 대비 가드가 콘텐츠 화면을 안 보고 있습니다 — 언제 고칠까요

상태: open
등급: C
역할: dev
올린 날: 2026-09-28
기한: 2026-10-12

## 질문
가드가 빈 껍데기만 재고 초록불을 내는 것을 1·2·3 중 어떻게 할까요?

## 근거 (실측 2026-09-28)
`scripts/check-dark-contrast.mjs` 는 *"53개 경로 실제 렌더 측정, 텍스트 1,998개, 0건"* 으로 초록이다.
그런데 **경로별 측정 개수**를 뽑으면:

| 경로 | 측정된 텍스트 | 실제 화면에 있는 글자 |
|---|---|---|
| 유어샵(모바일) | **8개** | 카드 6장 × 5줄 + 헤더 ≈ 50+ |
| 교환권 | 14개 | 상품 목록 전체 |
| 홈(모바일) | 23개 | 카드 피드 전체 |

상품 API 를 시드하지 않아 목록이 안 그려지는데, 헤더 몇 줄이 바닥값 `EMPTY_FLOOR = 5` 를 넘겨
**"검사됨" 으로 집계**된다. 바닥값이 5인 이유는 그 주석에 있다 —
*"빈 상태 화면(주문 0건 등)도 헤더·안내문 몇 줄은 그린다"*.
즉 **"원래 빈 화면"과 "콘텐츠를 못 불러온 화면"을 구분하지 못한다.**

증거: 유어샵 다크의 취소선 정가를 직접 쟀다 — `rgb(85,83,79)` on `rgb(29,31,41)` = **2.14:1**
(가드 기준 3.0 미만, 보이는 상태, opacity 1). 가드는 이것을 **0건**이라고 보고한다.

⚠️ 곁가지: 같은 글자가 **라이트에서 더 흐리다**(`#D8D2CC` on 흰색 = **1.50:1**).
다만 이건 결함이 아니라 **대표가 8차 시안으로 승인한 가격 블록의 생김새**라 임의로 못 바꾼다.

왜 지금 못 고치나: 고치려면 콘텐츠 경로에 상품 픽스처를 시드해야 하고, 그러면 지금까지 검사 밖이던
영역이 한꺼번에 드러난다. 몇 건일지 모르고 **다른 화면 수정까지 유어샵 PR 로 끌고 오는 것**이 된다.

## 선택지
1. 별건으로 가드부터 고친다 — 픽스처를 시드해 진짜로 검사되게 한 뒤, 나오는 목록을 보고 정리 순서를 정한다. 머니 접촉 없음.
2. 가드를 고치고 취소선 대비도 함께 올린다 — `dark:text-gray-600` → `gray-500`(2.14 → 3.13:1). 홈 포함 6개 화면의 정가 취소선이 조금 진해진다. 머니 접촉 없음.
3. 지금은 둔다 — 기록만 남기고 나중에. 머니 접촉 없음.

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
1. 먼저 **보이게** 만들고, 무엇을 고칠지는 실제 목록을 보고 정하는 순서가 맞다. 취소선 색은 승인된 시안 요소라 그 목록과 함께 보는 편이 낫다.

## 롤백
가드 변경은 픽스처 추가라 되돌리기 쉽고, 색 변경은 클래스 한 곳이다.
