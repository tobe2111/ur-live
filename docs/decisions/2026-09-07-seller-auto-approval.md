# 셀러·사업자정보 승인을 규칙으로 자동화할까 (사업자번호 진위 확인 + 필수 서류)

상태: open
등급: C
역할: ops
올린 날: 2026-09-07
기한: 2026-09-14

## 질문
셀러 승인·사업자정보 승인 큐를 "사업자번호 진위 확인 통과 + 필수값 충족이면 자동 승인, 미달이면 사유와 함께 자동 반려"로 바꿀까?

## 근거 (실측 2026-09-07)
- 어드민에 `PATCH /sellers/:id/approve` · `/sellers/:id/business-info/approve` 등 수동 승인 엔드포인트가 있고 **전부 사람이 누른다**.
- **사업자번호 진위 확인 API 연동은 현재 코드에 없다**(grep 결과 0). 국세청 홈택스 "사업자등록정보 진위확인" API(공공데이터포털)로 가능 — ⚠️ 이 환경에서 `apis.data.go.kr` 은 프록시 차단이라 스펙 검증은 라이브 워커에서만 가능.
- 지금 승인 대기 0(승인 매장 1). 볼륨이 생기기 전에 규칙을 **꺼진 상태로** 넣어 두는 것이 목적.

## 선택지
1. **규칙 자동 승인(게이트 OFF 로 배포)**: 진위 확인 통과(계속사업자) + 사업자번호·대표자명·주소·정산계좌 필수값 + 등록증 이미지 존재 → 자동 승인. 하나라도 미달 → 자동 반려(사유 자동 생성, 재제출 안내). 진위 API 오류 → 사람 큐. 게이트 `seller_auto_approval_enabled`(기본 OFF), 켜는 것은 별도 결재
2. 반자동: 규칙 판정 결과를 "승인 권고/반려 권고" 라벨로만 붙이고 버튼은 사람이
3. 안 한다

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
1. 이유: 승인은 판단이 아니라 검증이다. 검증은 기계가 사람보다 일관되고, 예외(진위 API 오류·의심 서류)만 사람에게 남기면 된다. 공공 API 키 발급은 대표가 한다(공공데이터포털 계정).

## 롤백
게이트 OFF(기본값) → 현행과 byte-동일. 진위 API 키 미설정이면 규칙은 자동으로 "사람 큐"로 폴백.
