# 중개 매장 수수료 5%를 어떻게 가져갈까요?

상태: open
등급: C
역할: finance
올린 날: 2026-11-25
기한: 2026-12-09

## 질문
중개 입점 매장의 유어딜 수수료를 (1) 현행 5% 무기한 (2) 5% 유지하되 기한 있는 출시 요율로 명시 (3) 지금 6% 로 올림, 셋 중 무엇으로 할까요?

## 근거 (실측)
- 라이브 설정(2026-11-25 `platform_settings`): `platform_fee_pct_direct=10` · `platform_fee_pct_brokered=5` · `fee_channel_rates_enabled=true`. 카드 수수료 준비금은 코드 기본 2.75%(`commission-budget.ts` `DEFAULT_PG_RESERVE_PCT`, 토스 정가는 3.4%).
- 건당(15,000원): 직접 1,500 − 413 = 1,088원(7.25%) · 중개 750 − 413 = 338원(2.25%). 정가 3.4% 면 중개 1.6%.
- 에이전시 몫은 **매장 몫에서** 나간다(`agency-share-payout.ts` · `broker-share.ts` "재원은 매장 몫이다"). 유어딜 5% 를 깎지 않는다. 지급 게이트 `agency_share_payout_enabled` 는 OFF(매장이 에이전시에 직접 송금).
- 라이브 규모: 승인 매장 13(직접 8 · 중개 5) · 활성 에이전시 계정 4 · 누적 유어딜 수입 800원. 지금은 요율을 바꿔도 실제 금액 차이가 0 에 가깝다.
- 영업: 대표 전화 영업 0/451 (11-18 이후). 사람 손이 안 드는 확장 경로는 에이전시뿐이다.
- 시나리오(에이전시 1곳 = 매장 30곳 × 월 50건 × 15,000원 = 거래액 2,250만 원): 5% → 순 약 51만 원 · 6% → 73만 원 · 7% → 96만 원.
- 정정: 2026-11-25 새벽 보고의 "에이전시 몫 2% 를 켜면 0.25%" 는 틀렸다(에이전시 몫을 유어딜 수수료에서 뺀다고 잘못 읽음).

## 선택지
1. 현행 유지(5%, 기한 없음). 장점: 바꿀 것 없음 / 단점: 나중에 올리기 어렵다 / 머니 접촉 없음
2. 5% 유지 + 기한 명시(예: 2027-06 까지 가입한 매장은 5%, 그 뒤 신규 중개 매장은 6~7%). 장점: 지금 모집에 영향 없고 인상 길이 열린다 / 단점: 대외 문구(제안서·가이드·`partners-facts.ts`) 수정 필요 / 머니 접촉: 지금은 없음(문구만), 기한 뒤 요율 설정 변경
3. 지금 6%(매장 총부담 10% 기준 유어딜 6 · 에이전시 여유 4). 장점: 순수입 2.25% → 3.25% / 단점: 에이전시가 가져갈 폭이 줄어 모집이 어려워질 수 있다 / 머니 접촉: 요율 설정 변경

요율과 별개로 권하는 것(각각 따로 답해도 된다): (a) 중개 매장 이용권 최저 판매가(예: 1만 원) (b) 토스 계약 실제 요율 확인 (c) 에이전시 정산 대행 켜기(`S-AGENCYSHARE` 실결제 뒤) (d) 에이전시 영업은 숙박·뷰티 우선(12만 원 숙박은 건당 2,700원, 15,000원 식사는 338원).

## 기본안 (답이 없을 때 권하는 것. 자동 실행되지 않는다)
안 2. 거래가 거의 없는 지금은 수익률보다 매장 수가 먼저이고, 기한을 적어 두면 올릴 길이 남는다.

## 롤백
요율 설정을 되돌린다(`platform_fee_pct_brokered`). 이미 찍힌 주문은 주문 시점 요율(`orders.commission_rate`)을 그대로 쓴다.
