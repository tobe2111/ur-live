## 질문
12월 17일 시행 개정 전자금융거래법 아래에서 매장·인플루언서·에이전시 정산을 어떤 구조와 주기로 할 것인가?

## 근거 (실측)
- 현재 돈의 흐름: 구매자 → 토스 결제창 → **유어딜 법인 통장** → 매주 목요일 어드민이 은행 이체 파일로 매장에 송금
  (`src/worker/utils/settlement-schedule.ts`, `src/pages/admin-payouts/BulkPayoutBar.tsx`).
  = "플랫폼 통장 → 셀러 정산" 구조. 12-17 이후 PG업 등록 + 정산자금 100% 예치 대상.
- 2026-10 결제액 46,000원(3건, 매장 2곳) — D1 `orders` 실측. 소액 면제 조항 없음(대표가 받은 법무·세무 답변).
- 지급대행 "가입" 자체는 의무가 아니다. 의무는 "남의 돈을 맡아 정산하면 등록·예치". 지급대행은 그 의무를
  피하는 현실적 방법이다(등록은 자본금 부담, 직매입은 위탁판매로 보아 위험 + 간이·면세 매장 부가세 독박).
- 토스 지급대행 동작(공식 문서 `/reference/additional`): 셀러 등록(KYC, 등록 직후 주 1천만원 한도) →
  지급 요청(최대 100건/회, 잔액 부족 시 실패, 지급 후 회수 어려움) → `payout.changed` 웹훅.

## 선택지
1. PG업 등록 + 100% 예치 — 자본금·전산 부담
2. **토스 지급대행 (중개 유지)** — 송금 요금만, 매장 돈이 우리 통장을 안 거침
3. 매장을 토스 개별 가맹점으로 — 매장 입점 장벽
4. 직매입 전환 — 사후 정산이면 위탁판매로 보아 미등록 PG 위험, 간이·면세 매장 부가세 리스크
5. 현행 유지 — 12-17 이후 위반
