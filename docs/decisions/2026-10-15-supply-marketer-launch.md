## 근거 (실측, 2026-10-15)

**방향** — 대표: *"한동안은 매장을 꾸준히 모으는 형태로 가야지. 인플루언서도 모아야하고 양면성 플랫폼이잖아."*
지금 돈을 막는 것은 게시물 수가 아니라 **팔 물건**이다(`partners-facts.ts` 실측 실제 입점 매장 2곳).
그래서 마케터의 기본 혼합비를 **매장 사장님 3 : 소개 파트너 2 : 손님 0** 으로 두었다(어드민 `social_audience_mix` 로 조정).

**지금 상태** (`GET /api/admin/social/accounts` · `/posts`, 라이브):

|---|---|
| 연결된 SNS 계정 | **0** |
| 초안 | **0** |
| 발행 스위치(`SOCIAL_THREADS/INSTAGRAM/YOUTUBE_ENABLED`) | 전부 꺼짐 |
| 초안 자동 생성(`SOCIAL_AUTO_DRAFT_ENABLED`) | 꺼짐 |

**이번 PR 로 준비된 것** (전부 스위치 OFF 그대로, 켜기 전 라이브 영향 0):
- 매장 사장님·소개 파트너에게 말하는 초안. 수수료 숫자는 **라이브 설정값에서만**(직접 10% · 중개 5%), 그 밖의 퍼센트·규모("N곳")·꺼진 혜택은 검증기가 폐기.
- 게시물마다 추적 링크(`?src=sns-th-12`) → 어드민 "공급 모으기 성과" 표에 랜딩·가입·**매장 등록**·**소개 파트너 신청**이 글 단위로 쌓임.
- 다음 주제는 성과로 고름(안 써 본 주제 먼저, 다 써 봤으면 매장을 더 데려온 주제).
- 초안 생성 주기: 주간 → **매일 09:00**(플랫폼별 미검토 8개 상한).

**Q3 근거 — 랜딩이 꺼진 보상을 약속한다:**
| 페이지 | 문구 | 실제 |
|---|---|---|
| `/influencer` | "유어샵에 담아 링크로 소개하면, 그 링크로 팔릴 때마다 몫이 쌓입니다" | `affiliate_program_enabled` **꺼짐**(`actor-benefit-map.md` §1) |
| `/creators` | "팔릴 때마다 몫을 받으세요. 가입 → 유어샵에 담기 → 링크 공유" | 같음 |

실제로 살아 있는 소개 파트너 보상은 **매장이 제안한 몫**(`seller_influencer_deals`) 하나다.
마케터는 이 두 페이지로 보내지 않고 신청서(`/creators/apply`)로 보내도록 막아 두었다. 하지만 페이지 자체는 여전히 그 말을 한다.

**대표님만 할 수 있는 일** (Q1 이 "예"일 때):
1. 유어딜 공식 **스레드·인스타그램 비즈니스 계정** 개설(인스타는 페이스북 페이지 연결 필요)
2. Meta 개발자 앱에서 Threads API·Instagram Graph API 권한 받기(앱 심사)
3. 유튜브 채널 개설 + 구글 OAuth 앱 검증(검증 전에는 업로드가 비공개로만 된다)
4. 토큰을 어드민 `/admin/social` → 계정 연결에 입력
5. ur-ads 워커 환경변수: `SOCIAL_AUTO_DRAFT_ENABLED=true` (초안만 만든다)

**하지 않는 것** (이번 범위 밖, 이유):
- 네이버 블로그 — 공식 글쓰기 API 가 없다. 브라우저 자동 조작은 약관 위반·계정 정지. 대신 유어딜 자체 `/blog`(네이버에 이미 색인)를 키운다.
- 네이버 카페 생성·맘카페 게시, 여러 계정 운영 — 바이럴 조작(표시광고법)·영구 정지 위험.
- 틱톡 — 앱 심사 전에는 비공개 게시만 가능. 스레드·인스타 성과를 본 뒤.
- 가상의 개인 인물 연기 — 유어딜 **공식 계정**의 사람 같은 말투로만 쓴다.
- 콜드 이메일·문자 발송 — 유어애즈 DB 로 보내는 제휴 제안은 지금처럼 대표가 한다.

## 선택지

**Q2 (발행 방식)**
1. **매번 승인** — 매일 초안이 쌓이고 대표가 `/admin/social` 에서 승인·발행. 가장 안전 / 매일 손이 간다.
2. **2주 승인 후 일부 자동** — 처음 2주는 1번. 사고 없이 지나면 **가격·혜택 숫자가 없는 글**은 예약 발행 자동, 숫자가 있는 글(수수료 등)만 승인 대기. 손이 거의 안 가고 위험한 글만 본다 / 2주 뒤 한 번 더 결재 필요(`SOCIAL_AUTO_PUBLISH_ENABLED` + 자동 승인 규칙 구현).
3. **처음부터 전부 자동** — 손이 전혀 안 간다 / 검증기가 못 잡는 어색한 글·타이밍 사고가 그대로 공개된다. 권하지 않는다.

**Q3 (랜딩 문구)**
- A. **지금 살아 있는 것으로 고친다** — "가게가 몫을 정해 제안하고, 마음에 드는 제안을 골라 소개" 로. 머니 접촉 없음(문구만).
- B. **담기 보상을 다시 켠다** — 문구는 그대로 사실이 된다 / 커미션 재원·예산 아비터 결정이 필요(머니 경로, 별도 결재).

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
Q1 예 · Q2 **2번** · Q3 **A**. 매장이 모이기 전엔 소개 파트너에게 줄 딜이 없으므로, 랜딩이 지금 사실만 말하게 하고 매장 쪽을 먼저 민다.
