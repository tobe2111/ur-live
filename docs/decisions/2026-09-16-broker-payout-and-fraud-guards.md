## 결정 (대표가 한 말 그대로)

> "일단 알겠어. 그렇게 하자." · "응 시작해."

승인된 내용:

### 1. 중개사 정산 — 유어딜이 각자에게 직접 송금
- 중개사가 매장 등록 시 **두 요율**을 정한다: 중개사 몫 % · 인플루언서 예산 **상한** %
- 결제액을 넷으로 쪼개 각자에게: 유어딜 / 중개사 / 인플루언서 / 매장
- 중개사에게 몰아주고 재지급하는 방식은 **안 쓴다**(원천징수 의무가 중개사에게 넘어가고,
  인플루언서가 유어딜이 아니라 중개사에게 의존하게 된다)
- 계좌는 **각자 본인이** 입력한다(원천징수가 수취인 단위). 시점은 **첫 적립 후**

### 2. 매장 영입 2% — 폐지 확정
대표: *"매장 데려온 사람 2%는 이제 아예 없는거야."* 적립은 이미 죽어 있고, 남은 잔재
(설정값·만료 검사·어드민 화면)를 정리한다. 적립 0건이라 잃을 데이터가 없다.

### 3. 사기 방어 — 무료 조합으로

| 구멍 | 처방 | 비용 |
|---|---|---|
| 중개사가 스스로 계약 수락 | **수락은 owner 만**. owner 없는 매장은 계약 미발효 | 0 |
| 훔친 카드 + 차지백 | 중개사·인플루언서 정산도 **사용 확인 게이트** 뒤로 | 0 |
| 매장 도용 | **예금주 = 사업자등록증 상호 또는 대표자명** 일치할 때만 송금 | 0 |
| 신규 매장 대량 사기 | 신규 매장 **한도**(첫 달) | 0 |
| 자기거래·다중계정 | 카카오 **CI** — 지금 신청만(심사 시간) | 0 |

**전화 인증(ARS)은 보류.** 매장 번호가 99% 유선이라 SMS 로 못 하고 ARS 는 유료인데,
예금주 검증이 더 싸고(0원) 더 효과적이다(사기의 *목적*인 돈을 막는다).
매장이 수백 곳 되어 어드민 심사가 버거워질 때 재검토.
