# 이미 지급한 소개비가 나중에 환불된 주문의 것이면, 다음 지급에서 자동으로 뺄까요?

상태: open
등급: C
역할: finance
올린 날: 2026-11-25
기한: 2026-12-09

## 질문
환불된 주문의 소개비가 이미 지급됐을 때 (1) 다음 지급에서 자동으로 뺀다 (2) 어드민 알림만 남기고 사람이 조정한다(지금 상태) (3) 회수하지 않는다 중 무엇으로 할까요?

## 근거 (실측)
- 환불 때 소개비 회수(`voucher-clawback.ts`)는 **아직 지급 안 된 것**만 되돌린다. 지급 완료된 것은 건드리지 않는다. 코드 머리말에는 "다음 정산 음수 처리" 라고 적혀 있었지만 그런 코드는 없었다.
- 2026-11-25 수리: 그 경우 어드민 알림(`지급된 소개비 회수 필요`)이 뜨게 했다. 자동 차감은 넣지 않았다.
- 지금 일어나기 어려운 이유: `payout_requires_voucher_use=true`(라이브) 라 소개비는 **사용된** 이용권만 지급 대상이 되고, 사용된 이용권의 환불 길은 어드민 분쟁 승인뿐이다.
- 라이브(2026-11-25): 지급 완료된 소개비 0건 · 분쟁 0건.

## 선택지
1. 자동 상계: 받을 소개비 잔액을 음수까지 허용하고 다음 지급에서 뺀다. 장점: 손이 안 간다 / 단점: 활동을 멈춘 사람에게선 영영 못 받는다, 지급 계산·화면을 고쳐야 한다 / 머니 접촉: 소개비 지급
2. 알림만(현재). 장점: 단순, 사고 없음 / 단점: 사람이 잊으면 샌다
3. 회수하지 않는다(약관에 "지급 후엔 회수 없음" 으로 명시). 장점: 인플루언서 신뢰 / 단점: 환불된 건의 소개비를 매장이 부담한 채 남는다

## 기본안 (답이 없을 때 권하는 것. 자동 실행되지 않는다)
안 2 유지. 지급 건수가 0 인 지금은 자동화가 얻는 것이 없다. 지급이 월 수십 건을 넘으면 안 1.
