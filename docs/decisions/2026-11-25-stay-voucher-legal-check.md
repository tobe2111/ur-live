# 날짜를 안 정하고 파는 숙박권을 기간이 지나면 환불 없이 이용 처리해도 되는지 법률 확인을 받을까요?

상태: open
등급: C
역할: dev
올린 날: 2026-11-25
기한: 2026-12-09

## 질문
먼저 판매 숙박권(날짜 미지정)의 "유효기간 경과 = 환불 없이 이용 처리" 를 그대로 팔기 전에 법률 확인을 한 번 받을까요? (1 받는다 / 2 그대로 간다 / 3 날짜 미지정 숙박권만 기간 경과 시 일부 환불로 바꾼다)

## 근거 (실측)
- 대표 확정(2026-11-25): *"숙소는 시간 지나면 자동환불이 아니라 사용 완료로 환불이 안되는건데"*. 코드는 이 규칙대로다(`stay-no-show.ts` · `expired-voucher-refund-sql.ts`의 `notStaySql`).
- 날짜 지정 예약의 노쇼를 이용 처리하는 것은 숙박업의 일반 관행이다.
- 날짜 미지정 숙박권은 성격이 다를 수 있다. 공정위 신유형 상품권 표준약관은 유효기간이 지난 상품권도 일정 기간 안에는 구매액의 90% 환불을 요구한다. 먼저 판매 숙박권이 여기에 해당하는지는 세션이 판정할 수 없다(법률 판단).
- 라이브 실측: 숙박 예약 0건, 실제 숙소 0곳(등록 20건은 전부 데모). 지금은 영향 0.

## 선택지
1. 실제 숙소가 먼저 판매로 등록되기 전에 법률 확인 1회. 장점: 분쟁·환불 명령 위험 제거 / 단점: 비용·시간 / 머니 접촉 없음
2. 그대로 간다. 구매 화면·지갑에 "기간이 지나면 환불되지 않아요" 고지는 이미 있다 / 단점: 표준약관 해당 시 소급 환불 위험
3. 날짜 미지정 숙박권만 기간 경과 시 90% 환불로 되돌린다 / 단점: 대표가 정한 규칙과 다름. 머니 경로 접촉

## 기본안 (답이 없을 때 권하는 것. 자동 실행되지 않는다)
안 1. 실제 숙소가 0곳인 지금 확인하는 것이 가장 싸다. 확인 전까지 코드는 대표 규칙(환불 없음) 그대로 둔다.

## 롤백
결정만 하는 건이라 되돌릴 것이 없다. 안 3을 고르면 별도 PR.
