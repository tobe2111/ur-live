# 세션에 모든 권한을 맡길 때, 돈·삭제·발송까지 먼저 묻지 않고 하게 할까?

상태: approved
등급: C
역할: ceo-office
올린 날: 2026-11-25
기한: 2026-11-25

## 질문
지금까지 대표 승인을 먼저 받던 세 가지(실제 돈이 움직이는 스위치·환불·정산 / 데이터 삭제 / 메일·알림 같은 대외 발송)도 세션이 알아서 하고 나중에 보고만 할까요?

## 근거 (실측)
- 대표가 먼저 말했다: *"이건 모든 세션 다 적용인데 너가 모든 권한을 갖도록 승인할게. 계정을 만들든"* (문장이 중간에 끊겼다).
- 그때까지의 규칙: `docs/design/ai-team-operating-model.md` §2 — 머니 경로·게이트 ON·발행·삭제·잠금표 파일·유료 전환은 C(승인 전 실행 금지).
  `CLAUDE.md` 2026-11-17 위임은 "플랫폼 설정 쓰기와 시험 발송" 까지였고 삭제·머니·게이트 ON 은 범위 밖이라고 적혀 있었다.
- 범위가 그 세 가지까지 닿는지에 따라 모든 세션의 행동이 달라지므로 선택지로 물었다.

## 선택지
1. 세 가지만 계속 승인 — 나머지는 전부 세션이 한다. 되돌릴 수 없는 일만 먼저 묻는다
2. 전부 맡김, 시험은 유지 — 세 가지도 세션이 실행·사후 보고. 돈이 걸린 것은 시험 결제를 통과해야 켠다
3. 전부 맡김, 조건 없음 — 세션이 전부 판단해 바로 실행·사후 보고. 시험 없이 켜는 것도 세션 판단. 잘못 나간 돈·지운 데이터는 못 되돌린다

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
안 1. 되돌릴 수 없는 세 가지만 사람이 한 번 본다.
