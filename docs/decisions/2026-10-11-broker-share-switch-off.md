# 라이브에서 켜져 있는 에이전시 몫 지급 스위치를 1단계가 끝날 때까지 끌까요

상태: approved
등급: C
역할: finance
올린 날: 2026-10-11
기한: 2026-10-18

## 질문
`platform_settings.broker_share_enabled` 를 에이전시 1단계(계정·이메일 로그인·매장 귀속·이관)가 끝나고 staging 실결제로 확인할 때까지 **꺼 둘까요?**

## 근거 (실측)
- 2026-10-11 어드민 설정 조회(읽기 전용): `broker_share_enabled=true`.
- `docs/STAGING_CHECKLIST.md` 에 에이전시 몫(S-BROKER) staging 실결제 확인 기록이 없다.
- 지금까지 지급된 에이전시 몫 0건, 중개 매장 4곳.
- 결정 `2026-10-11-agency-model-email-only.md` 로 몫이 붙는 대상이 **개인 계정 → 에이전시 계정**으로 바뀐다. 지금 켜 둔 채 판매가 나면 옛 구조(개인 계정, 3.3% 원천징수 통로)로 적립된다.

## 선택지
1. **끄기** — 1단계 동안 중개 매장 판매에는 에이전시 몫이 붙지 않는다. 새 구조에서 staging 확인 뒤 다시 켠다. 머니 접촉: 있음(적립 중단).
2. 켜 두기 — 판매가 나면 개인 계정 앞으로 적립되고, 이관 때 그 적립분을 에이전시로 옮기는 일이 생긴다.

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
안 1. 지금까지 0건이라 끄는 비용이 거의 없고, 켜 두면 이관 때 옮길 돈이 생긴다.

## 롤백
어드민 플랫폼 설정에서 `broker_share_enabled` 를 다시 `true` 로. (플랫폼 설정 변경은 세션이 하지 않는다 — 대표가 직접.)

## 결정 (대표가 한 말 그대로)

대표(2026-10-13): *"기본안대로 모두 승인 3,4번 은 빼고"* → **안 1(끄기)**.

- 집행: 어드민에 이 스위치를 켜고 끄는 화면이 **없어서**(대표가 직접 끌 자리가 없다) 세션이 어드민 API `PUT /api/admin/tools/settings {"broker_share_enabled":"false"}` 로 껐다. 2026-10-13 KST 다시 읽어 `false` 확인.
- 다시 켤 때: 같은 호출에 `"true"`. 조건은 에이전시 1단계 완료 + staging S-BROKER 통과.
