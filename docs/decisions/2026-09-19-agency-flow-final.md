# 대행사(중개사) 플로우를 무엇으로 확정하는가

상태: approved
등급: C
역할: planning
올린 날: 2026-09-19
기한: 2026-09-19

## 질문

대표가 10단계 플로우(대행사 가입 → 매장 등록 → 매장 가입 유도 → 코드 매칭 → 이용권 생성 → 인플루언서 가입 유도 →
코드 매칭 → 고유 링크 → 홍보 → 성과 확인)를 제시하고 *"이렇게가 가장 이상적일까? 지금껏 구현한 것 확인하고 말해줘"* 라고 물었다.

## 근거 (코드 실측 2026-09-19)

- 에이전시 실체는 2026-09-04 삭제. 중개사 = 셀러 계정 + `seller_operators`.
- 매칭이 네 갈래로 흩어져 있었다: 사장님이 대행사 핸들·이메일 입력 / 사장님이 사업자번호로 claim / 매장이 인플루언서 검색 제안 /
  유어애즈 아웃리치 이메일 토큰.
- 🔴 **매장이 제안한 조건 없는 딜을 인플루언서가 수락하는 엔드포인트가 0** — `sellerApp /deals/:id/respond` 는 인플 제안만,
  `influencerApp` 엔 콘텐츠 링크 제출뿐. 조건 없는 제안은 '대기'에서 영원히 멈췄다.
- 09-16 결재(중개사 몫 직접 송금, 안 1)는 승인됐으나 코드 0.
- 라이브: 승인 매장 1(중개 채널) · 운영 위임 1 · 딜 0 · 주문 0 — 바꾸기 가장 싼 때.

## 선택지

1. 원안 그대로(대행사가 매장 코드 입력, 인플루언서가 매장 코드 입력).
2. **코드 방향을 뒤집는다** — 코드는 대행사가 매장을 등록할 때 생기고 **사장님이** 입력한다(권한을 내주는 쪽이 입력 = 동의).
   인플루언서 코드에는 **기본 %** 를 싣고, 입력 뒤 딜마다 조정한다. 대행사 몫은 09-16 결재대로 직접 송금(게이트 뒤).
3. 코드 없이 지금 구조 유지 — 수락 경로만 메운다.

## 기본안

안 2.

## 결정 (대표가 한 말 그대로)

> "2번에 중개사 몫과 인플루언서들도 각각 협의를 해야하니 커미션 % 를 매번 케이스마다 조정 가능하긴 해야해.
>  아무튼 이걸 최종 플로우로 결정하고 중개사가 끼지 않는 매장 직접 운영도 유사한 형태로 하자.
>  모든 미흡한 부분은 빠짐없이 구현해줘."

⇒ 안 2 확정. 부속: ① 커미션 % 는 코드 기본값 + 딜별 조정(상한 = 매장 `influencer_pct_cap` ∧ 90) ② 직접 운영 매장도
같은 협업 코드·조정·성과 화면 ③ 중개사 몫 직접 송금은 구현하되 **게이트 OFF**(S-BROKER 뒤 대표가 켠다 — 09-16 결재의
"켜는 것은 대표 판단" 그대로).
