## 선택지

**Q1. 유저가 남의 이용권을 "담기"(소개) 하면 무엇을 받나?** (지금: 0 — 어필리에이트 OFF)
1. 계속 0 — 유어샵은 "내 가게 진열대"로만 쓰고 소개 보상은 없다 (심플. 08-22 결정 유지)
2. 소개 커미션을 **매장 부담**(promo, `promo_funding_source=owner`)으로 켠다 — 유어딜 몫 불변, 머니 경로라 staging 실결제 필요
3. 소개 커미션을 **유어딜 부담**으로 켠다 (07-08 원칙과 충돌)

**Q2. 인플루언서 딜 커미션 % 의 상한은?** (문서 "캡 미적용, 입력검증 90" ↔ 설정 `max_influencer_commission_pct=2`)
1. 매장이 제안한 % 그대로, 상한 없음 (매장 부담이므로 유어딜 리스크 0)
2. 상한 N% (값을 적어 주세요) — 설정 `max_influencer_commission_pct` 로 강제

**Q3. 영입 2% — 채널이 "미지정"인 매장(기존 등록분)은?** (지금 라이브 매장 1곳이 brokered 라 아무도 못 받는다)
1. 미지정 = 직접 입점으로 간주해 **지급** (관대 — 영입자를 위해)
2. 미지정 = 중개로 간주해 **미지급** (08-31 결정 그대로 — 유어딜을 위해)
3. 미지정 매장은 등록 시 채널을 **반드시 고르게** 폼을 바꾼다 (정답에 가깝지만 UI 작업)

**Q4. 재원 원칙 — "유어딜 몫은 어떤 커미션에도 쓰지 않는다"(07-08)는 지금도 유효한가?** (08-31 에 "10% 받으니 바뀐 얘기" 라고 하셨으나 확정은 아님)
1. 유효 — 영입 2% 도 포함해 **전부 매장 promo 재원**으로 옮긴다 (flip 작업, 머니 경로)
2. 폐기 — 직접 입점 10% 안에서 영입 2% 등은 유어딜이 낸다. 단 총합이 `수수료 − PG` 를 못 넘게 예산 아비터(`commission_budget_enabled`)를 켠다 (08-31 방향)
3. 절충 — 중개(5%) 매장은 1, 직접(10%) 매장은 2

**Q5. 중개사(운영자)에게 유어딜이 주는 것은 0 — 확정 유지?** (09-04 결정)
1. 유지 — 매장이 5% 차액 안에서 직접 낸다. 유어딜은 관여하지 않는다
2. 재검토 — 중개사가 데려온 매장에도 영입 2% 를 준다 (Q3·Q4 와 함께 다시 계산)

## 기본안 (답이 없을 때 권하는 것 — 자동 실행되지 않는다)
Q1-1 · Q2-1 · Q3-3 · Q4-2 · Q5-1. 이유: 지금 돈이 안 흐르므로 **축을 하나(영입 2%)로 줄이고, 그 하나가 적자를 못 내게 아비터로 막고, 나머지는 매장-당사자 합의에 맡긴다**가 가장 설명하기 쉽다. "설명하기 쉬움"이 이 결정의 기준이어야 한다(대표조차 헷갈린다는 것이 문제 정의다).
