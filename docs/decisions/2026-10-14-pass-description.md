## 무엇이 지금 일어나고 있나 (라이브 실측)

같은 `/pass/:id` 가 **설명을 두 벌** 낸다. `react-helmet` 이 서버 메타를 덮으므로
**JS 를 렌더하는 Googlebot 이 받는 쪽은 화면 버전**이고, 네이버·카톡·AI 봇은 서버 버전을 받는다.

```
서버(이 PR 로 수리됨)   ⭐4.7 서울 서초구 · 달빛한스푼 닭도리탕 31,000원 (정가 35,000원) 11% 할인 매콤한…
화면(GroupBuyDetailPage) 🎉 0% 할인! 달빛한스푼 닭도리탕 공동구매 — 0명 함께 구매 중, 31,000원
```

화면 버전의 문제 셋 (전부 실측):

| | 실측 |
|---|---|
| **줄표 `—`** | #79 가 **서버만** 고쳤다. 화면 쪽은 `src/pages/*.tsx` 라 anti-slop 가드 범위 밖 |
| **`0명 함께 구매 중`** | `group_buy_current` 중앙값 **0 · 샘플 60건 중 59건(98%)이 0명** |
| **`🎉 N% 할인!` 이 안 뜬다** | `displayDiscountPct` 의 뿌리인 선언 컬럼이 **45/45건 0** (서버와 같은 원인) |

즉 구글이 보는 쪽이 세 가지로 더 나쁘고, 그게 가장 큰 검색엔진이다.

## 제안 — 서버와 **같은 함수**로 모은다

`<SEO description>` 을 서버가 쓰는 설명 생성기와 같은 SSOT 로 교체한다
(#71 이 제목에서 한 것과 같은 처방: 두 벌을 없애면 갈릴 수가 없다).

- `GroupBuyDetailPage.tsx` 접촉 = **`description` prop 1곳** (잠긴 항목
  `__SSR_INITIAL_DETAIL__` 즉시 소비·CountdownRing·polling·below-fold lazy 전부 byte-불변)
- 롤백: 그 prop 을 종전 문자열로 환원

## 왜 승인이 필요한가

1. 그 파일은 **로딩 잠금표**에 있다(승인 없이 변경 금지).

   제목과 설명은 SERP 에서 **함께 읽힌다**. 따로 정하면 어긋난다.
