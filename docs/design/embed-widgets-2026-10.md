# 홈페이지 삽입 위젯 (2026-10-31)

대표: *"우리 유어딜 서비스를 다른 홈페이지에 삽입을 하려고 하는데 HTML 코드 만들어줄래? 시안들 보여주고 시작해"*
→ 시안 넷(배너·이용권 위젯·떠 있는 버튼·유어샵) →
*"HTML 임베드를 여러개 만들어줘. 1개만 선택하진 않을거야. 일단 에이전시 홈페이지에 넣을 것. 인플루언서의 홈페이지에 넣을 것(자신의 유어샵 페이지에 있는 이용권들 보이게.) 또 있을까?"*

시안 페이지(대표 비공개 artifact): https://claude.ai/artifact/EKL91P4UAH1sw6RVDA1puf

## 만든 것

| 위젯 | 주소 | 누가 어디에 | 무엇이 보이나 |
|---|---|---|---|
| 유어샵 | `/embed/u/:handle` | 인플루언서·유저 블로그·개인 홈페이지 | 담은 이용권(유어샵 진열 순서) + 내 가게 이용권 |
| 에이전시 | `/embed/agency/:id` | 에이전시 회사 홈페이지 | 맡아 운영하는 매장 이용권(다른 에이전시 담당분 제외) |
| 매장 | `/embed/store/:username` | 사장님 가게 홈페이지 | 그 가게 이용권 |
| 지역 | `/embed/region/:sido/:sigungu?` | 관광·상인회·지역 사이트 | 그 지역 이용권 |
| 이용권 하나 | `/embed/pass/:id` | 블로그 글 속 카드 | 이용권 한 장 + 구매하기 |
| 코드 만들기 | `/embed` | 누구나 | 미리보기 + 복사할 iframe 코드 |

배너(A안)는 개발 없이 시안 페이지의 HTML 을 그대로 쓴다.

## 설계

- **서버가 그리는 HTML, 스크립트 0**: 남의 사이트 iframe 마다 앱 번들을 받지 않게. CSP nonce 를 위젯 문서가 알 수 없어 스크립트는 어차피 막힌다.
- **높이 고정**: 카드는 가로로 넘기는 한 줄(330px), 한 장 카드는 172px. 붙이는 쪽이 높이를 미리 안다.
- **노출 조건은 소비자 피드와 같다**: 승인 매장 · 도매 원본 제외 · 판매 중 · 이용권 카테고리 · 데모 맨 뒤.
- **유어샵 핀은 서버 리다이렉트로** → 소개 값(?aff=)·클릭 기록이 카톡 공유 링크와 똑같이 잡힌다.
- 링크마다 `utm_source=embed&utm_medium=<종류>` — 위젯별 유입을 센다.
- 엣지 캐시 5분(엣지 15분), robots 차단 + noindex.
