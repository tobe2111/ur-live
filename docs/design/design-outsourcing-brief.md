# 🎨 디자인 외주 브리프 — 파일럿 표면 (2026-08-02)

> **용도**: AI 디자이너/외주에게 그대로 전달하는 문서.
> **범위**: P0 파일럿(운영자 몰)에서 **사람이 실제로 보는 화면**만. 기존 소비자 표면은 대상이 아니다.
> **작성 근거**: 각 파일의 실측(줄 수 · 디자인시스템 사용 · 브랜드 컬러 사용).

---

## 0. 한 줄

**기능은 다 만들었고 디자인만 안 입혔다.** 아래 화면들은 전부 원시 Tailwind gray 유틸로만 짜여 있고
**브랜드 컬러 사용이 0**이다(의도적 — 기능 세션에서 디자인을 손대지 않는 것이 원칙이었다).

## 1. 🔴 우선순위 — 파일럿 성패 기준

디자인 우선순위는 **그 판정을 직접 흔드는 순서**로 매겼다.

### Tier 1 — 여기서 막히면 파일럿이 실패한다

| # | 화면 | 경로 | 현재 | 왜 1순위인가 |
|---|---|---|---|---|
| **1** | **운영자 몰 홈** | `/{몰슬러그}` | 192줄 · 브랜드 0 | 소비자가 **처음이자 유일하게** 보는 몰 표면. 운영자가 카톡에 뿌린 링크의 착지점이다. 여기서 안 사면 뒤가 없다 |
| **2** | **3분 공구 등록** | `/seller/products/quick` | 211줄 · 브랜드 0 · 디자인시스템 0 | P0 판정 ①(공구 2회 개설)의 **무대**. 폼이 어려우면 판정이 그대로 실패한다. **모바일 한 손** 전제로 만들었다(사진·가격·마감만) |

## 2. 🔴 반드시 지켜야 하는 제약 — 어기면 CI 가 막는다

이 레포는 디자인 규칙을 **자동 검사**한다. 아래는 취향이 아니라 **빌드 실패 조건**이다.

### 2.1 테마 — 화면마다 규칙이 다르다

| 화면 | 규칙 |
|---|---|
| **셀러·어드민·에이전시 대시보드**(`/seller/*` `/admin/*` `/agency/*`) | 🔴 **라이트 고정.** `dark:` variant **금지** — `check-dashboard-theme.sh` 가 차단 |
| **소비자 화면**(몰 홈 포함) | 🔴 **라이트/다크 양쪽 필수.** 라이트 토큰을 쓰면 `dark:` 짝을 **반드시** 함께 — `check-theme-consistency` 가 차단 |

매핑표(소비자용): `bg-white`↔`dark:bg-[#0A0A0A]` · `text-gray-900`↔`dark:text-white` ·
`border-gray-200`↔`dark:border-[#2A2A2A]` (전체 표는 `CLAUDE.md` 테마 규칙 절).

### 2.2 브랜드 컬러

CSS 변수 기반이라 **하드코딩하지 말 것**:

- `bg-brand` / `hover:bg-brand-dark` — 주 버튼 (#E0526B / #C43D55)
- `text-brand-text` — 로즈 글자·배지 (라이트/다크 보정값이 다름)
- `bg-brand-tint` — 옅은 로즈 배경

### 2.3 모바일 (실사고 기반)

- 🔴 `h-screen`/`min-h-screen`(=100vh) **금지** → **`h-[100dvh]`**. 모바일 100vh 는 주소창을 포함해
  하단이 화면 밖으로 나간다 (또는 `<Screen>` 프리미티브)
- 🔴 스크롤 영역은 **`flex-1 min-h-0 overflow-y-auto`** — `min-h-0` 없으면 형제(하단 버튼)가 밀려 사라진다
- `check-mobile-viewport` 가 신규 라인을 검사한다

### 2.4 그 외 자동 검사

- **PC 소비자**는 **430px 중앙 액자** 안이다(풀와이드 레이아웃 금지 — 대시보드·도매만 풀너비)
- **로딩은 `BrandLoader` 하나로 통일.** 커스텀 스피너 추가 금지
- **입력창에 `text-gray-900` 명시** — 안 하면 다크모드 전역 규칙이 글자를 흰색으로 덮어 안 보인다
- **이미지는 `cfImage()` 경유** — raw `<img src>` 는 원본을 그대로 받아 트래픽이 폭증한다
- **모달/시트 z-index 는 표준값**(`src/constants/z-index.ts`) — 안 그러면 하단 네비에 가려진다
- **파일 600줄 캡** — 넘으면 컴포넌트를 폴더로 분리

## 4. 참고 — 만들 때의 의도 (디자인이 지켜야 할 것)

- **몰 홈**: `powered by 유어딜` 은 **링크가 아니라 문구**다(본진으로 새지 않게). 픽업 배지(냉장·실온)와
  보관 안내는 **목록 하단에 한 번만** 나온다 — 카드마다 반복하면 시끄럽다
- **3분 등록**: 마감일은 **날짜 선택기가 없다.** 프리셋 버튼 3개뿐이다(모바일 한 손). 입력칸은 `h-14`,
  제출 버튼은 하단 고정. **이 단순함이 기능이다** — 폼을 풍부하게 만들면 3분이 깨진다
- **반품 큐**: 승인·거절만 있고 **환불 버튼이 없다.** 상태 전이와 돈을 한 화면에 섞지 않았다
- **빈 상태 vs 실패 상태를 구분**해서 그렸다. "0건"과 "못 불러옴"은 다른 화면이어야 한다
