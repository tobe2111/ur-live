# 🎨 디자인 의뢰서 — **추가분 ①: 화면 A-2 (손님이 보는 상품 상세)**

> 앞서 드린 「유어딜 운영자 몰 파일럿」 의뢰서의 **추가분**입니다. 그 문서를 먼저 읽어 주세요.
> 이 문서는 **화면 하나**를 추가로 부탁드리는 것입니다. 작성 2026-08-02.

---

## 왜 추가로 드리나

처음 의뢰서에서 손님 동선을 이렇게 적었습니다.

```
손님 → 가게 홈(화면 A) → 상품 상세 → 결제
                          └─ "기존 화면, 이번 범위 아님" 이라고 적었습니다
```

**그 판단이 틀렸습니다.** 상품 상세는 화면이 있긴 하지만 **다른 서비스(유어딜 본몰) 손님을 위해**
만들어진 화면이라, 가게 단톡방에서 온 손님에게는 맞지 않는 것들이 섞여 있었습니다.
그 부분은 저희가 코드에서 걷어냈고, **걷어낸 뒤의 화면**을 디자인해 주셨으면 합니다.

**우선순위는 화면 A와 같은 🥇 입니다.** 손님이 실제로 "살까 말까"를 정하는 자리이기 때문입니다.
화면 A가 아무리 좋아도 여기서 멈추면 결제까지 못 갑니다.

## 화면 A-2 — 상품 상세 (모바일 세로)

손님이 가게 홈에서 **상품 카드를 누르면** 오는 화면입니다.

### 위에서 아래로, 지금 화면에 있는 것 (전부)

| # | 영역 | 내용 |
|---|---|---|
| 1 | 상단 | 뒤로가기 · 상품 사진(정사각, 여러 장이면 좌우로 넘김) |
| 2 | 이름·가격 | 상품명 / `7,000원` + ~~10,000원~~ + `30%` |
| 3 | 옵션 | 선택지가 있으면 목록, 없으면 회색 안내줄 하나 |
| 4 | 📦 **픽업 안내** | `받는 날 · 8월 10일` / `받는 곳 · {가게 주소}` / 보관 안내 한 줄 |
| 5 | 수량 | `−` `1` `+` |
| 6 | 부가표시 | `최대 210딜 적립` · `부가세 포함` |
| 7 | 상세정보 | 사진·설명 (길면 `상세정보 펼쳐보기`) |
| 8 | 공유 | 카카오톡 공유 버튼 |
| 9 | 리뷰 | 개수 + 목록 (없으면 빈 상태) |
| 10 | 접이식 3칸 | `상품정보` / `배송·교환·반품` / `유의사항` |
| 11 | **하단 고정 바** | 가격 + `장바구니` + `바로구매` |

### 🔴 4번(픽업 안내)이 이 화면의 핵심입니다

일반 쇼핑몰 상세는 "배송"이 기본값이라 손님이 **아무 설명이 없으면 택배로 믿습니다.**
그런데 이 상품은 **가게에 직접 찾으러 와야** 합니다.

- 4번이 **가격만큼 눈에 띄어야** 합니다. 지금은 옅은 테두리 상자 하나라 흘려보기 쉽습니다.
- `받는 날`은 이 화면에서 **날짜로 읽혀야** 합니다. 손님이 달력에 적을 수 있게요.
- 냉장·냉동이면 그 사실이 **결제 전에** 보여야 합니다(안 찾아가면 환불이 어려운 상품입니다).

> **최근에 저희가 고친 것**: 이 화면 아래쪽에 `🚚 내일 도착 · 5만원 이상 무료` 카드가 있었습니다.
> 픽업 상품에 배송을 약속하고 있었던 셈입니다. **지금은 픽업 상품이면 그 카드가 사라집니다.**
> ⇒ 시안에서도 **배송 관련 표시를 넣지 말아 주세요.**

### 🔴 없어진 것 — 다시 그리지 말아 주세요

아래는 유어딜 본몰 손님용이라 **가게 손님에게는 이제 안 보입니다.** 시안에도 넣지 마세요.

| 없앤 것 | 이유 |
|---|---|
| `🎁 회원가입하고 1판매당 N원 적립받기` 큰 버튼 | 손님을 유어딜 회원으로 데려가는 자리였습니다 |
| `📌 내 링크샵에 담기 + 추천 링크 복사` | 유어딜 창작자용 기능입니다. 반찬가게 단골에겐 의미 없습니다 |
| `친구 초대 공동구매` 섹션 | 유어딜 추천 제도입니다 |
| 하단 유어딜 탭바 / PC 상단 메뉴 / 사이드 배너 | 가게 화면에 다른 서비스 메뉴가 붙어 있었습니다 |

**남긴 것**: 카카오톡 공유 버튼(8번)은 그대로입니다. 단톡방에 상품이 퍼지는 건 사장님에게 이득이고,
유어딜로 데려가는 것이 아니기 때문입니다.

### 🟡 애매한 것 — 판단을 부탁드립니다

- **6번 `최대 210딜 적립`** — 유어딜 포인트 개념입니다. 가게 손님은 모르는 말입니다.
  다만 실제로 적립되긴 합니다. **지우는 게 나을지, 작게 남길지** 시안에서 제안해 주세요.
- **10번 `배송·교환·반품`** — 이름에 배송이 들어갑니다. 픽업 상품엔 어색하지만
  **법적으로 필요한 안내**라 저희가 임의로 못 지웁니다. 제목만 바꾸는 안을 주셔도 좋습니다.
