## 스타일의 한계 (선택 2번의 대가)
- **플랫 일러스트**다. 확정 그림의 털 질감과 입체 조명은 옮기지 않았다(부드러운 그라디언트만). 굿즈에서 3D 느낌이 꼭 필요하면 이 SVG 를 기준으로 사람 작업을 더해야 한다.
- 팔·몸통은 확정본보다 단순하다(팔이 몸통 옆에 붙은 판 모양).
- 수염은 흰색이라 **밝은 바탕에서는 얼굴 밖 부분이 안 보인다.** 흰 굿즈에는 스티커식 흰 테두리(다이컷 여백)를 두르거나 짙은 바탕 위에 올린다. 수염 색은 바꾸지 않는다(정체성).

## 고칠 때
- 이 SVG 를 고치면 `export-vector.mjs` 로 미리보기를 다시 만들고 `udal-qa.py` 로 대조한다. 수치가 확정본에서 ±8% 를 넘으면 되돌린다.
- 새 포즈를 벡터로 그릴 때도 이 파일의 색·눈·코·입·수염 모양을 그대로 가져다 쓴다(부위 이름이 주석으로 달려 있다).
