## ❌ 폐기 (2026-10-11 대표 *"이전에 만든거랑 완전 달라, 느낌이 완전 달라"*)

⇒ **같은 캐릭터를 다른 포즈로 그리려면 원본 그림을 참고 이미지로 넣는 모델이 필요하다**(Figma Weave Nano Banana 등).
