판매 모드 — 방향 3안

1차 시안이 마음에 안 드신다고 하셔서, 무엇이 주인공인가로 갈리는 세 방향을 만들었습니다. 셋 다 같은 구조(마이 → 판매 · 좌석 전환 · 전체 도구로 넘기기)를 쓰고, 화면이 무엇을 먼저 보여주는지만 다릅니다.

1차 시안에서 제가 어긴 것

  • 강조색 자리가 여덟이었다. 우리 규칙은 「강조색 하나, 자리 셋」인데 밴드·버튼·배지·숫자·아이콘 배경·체크·탭·칩까지 전부 파랬다. 파란 게 많으면 아무것도 안 강조된다.
  • 판매 홈에 주인공이 없었다. 같은 무게의 카드 4장을 세로로 쌓아 시선이 어디에도 안 머문다.
  • 주문·이용권·정산이 서로 구별이 안 됐다. 셋 다 흰 카드 + 리스트 행이라 헤더 글자로만 구분된다.
  • 소비자 앱 같지 않았다. 유어딜 문법(티켓·브랜드 점)이 안 살고 그냥 작은 대시보드로 보인다.
안 A

오늘 한 장

주인공 = 숫자

화면을 켜면 오늘 얼마 벌었나 하나가 크게 있고, 나머지는 테두리 없는 조용한 줄이다. 강조색은 밴드 하나에만 쓴다. 사장님이 하루에 여러 번 열어 숫자만 확인하고 나가는 쓰임에 맞다. 대신 할 일이 눈에 덜 띈다.

안 B

주인공 = 파는 물건

안 C

할 일 큐

주인공 = 처리할 것

정산은 화면이 돈을 옮기지 않는다. 출금 신청은 이미 있는 POST /account/withdraw 를 부르고, 실제 송금은 지금처럼 payouts-generate 의 게이트(승인된 매장 · 사용 확인)가 정한다. 화면은 그 앞의 손잡이일 뿐이다. 정산 화면에 매장 이름을 한 번 더 적는 것도 그래서다 — 헤더만 믿고 남의 매장 돈을 보면 안 된다.
