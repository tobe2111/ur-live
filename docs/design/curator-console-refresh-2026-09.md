# 소개 콘솔 재설계 — 시안 A/B (2026-09-29)

> 상태: **대표 선택 대기**. 구현 전이다.
> 시안 이미지: `assets/curator-console-2026-09-29-light.png`(현재/A/B) · `…-dark.png`(A/B 다크)

## 왜

대표: *"소개 콘솔도 페이지 너무 별로다"* → PR #1575 이 **규칙 위반**(이모지 12 · 카드 테두리 ·
강조색 3색)만 제거하고 **구조는 그대로** 뒀다. 대표: *"근데 마음에 들진 않아."*
무엇이 걸리는지 물었더니 **셋 다** 골랐다:

1. **섹션이 너무 많다** (현재 8개 판)
2. **차트·표가 밋밋하다**
3. **목록 문법 자체가 안 맞는다** — 마이의 회색 라벨 + 흰 판이 콘솔에는 수수하다

⇒ ③ 은 내가 09-29 에 넣은 것이다. 마이와 통일하려던 선택인데 콘솔은 **돈 대시보드**라 성격이 다르다.

## 현재 구조 (판 8개, 화면 4장)

`내 가게 목록` · `요약 카드` · `출금 카드(검정 그라디언트)` · `영입한 매장` · `내 상품 CTA` ·
`인기 핀` · `최근 적립` · `일별 차트`

문제: 돈에 관한 것이 **세 곳**(요약·출금·차트)으로 흩어져 있고, 성과도 **세 곳**
(영입 매장·인기 핀·최근 적립)으로 흩어져 있다. 출금은 화면 중간에 묻힌다.

## 두 안 (공통 — 판 8개 → **3개**, 화면 4장 → **1장**)

합치는 규칙은 같다: **돈 한 판 · 성과 한 판 · 진입 한 줄.**

| | A안 — 수익 한 판 | B안 — 통장형 |
|---|---|---|
| 돈 | 흰 판 안에 [이번 달 38px → 면적 그래프 → 받을 돈 + 출금 버튼] | 맨 위 **브랜드 밴드**(티켓 은유, 규칙 ④)에 받을 돈 + 출금 / 아래 본문에 이번 달 + 막대 |
| 추이 | 면적 그래프 + `지난달보다 +38%` | 막대 30개 + `지난달 ₩8,980` + 오늘 값 |
| 성과 | 순위표(상품) + 하단 한 줄로 영입 매장 | 순위표 + **상품/매장 탭** |
| 진입 | 하단 3칸 압축 바(내 유어샵 · 공구 호스팅 · 내 상품 팔기) | 동일 |

**목록 문법 대신 순위표** — `[순번] 이름 / 부제 ......... 금액`. 아이콘 원도 화살표도 없다.
숫자가 오른쪽에 정렬돼 위아래로 읽힌다(규칙 ③ 숫자가 주인공).

### 추천: B안
- 브랜드 밴드가 확정 디자인 시스템의 **티켓 은유**를 그대로 쓴다.
- 콘솔에 오는 이유(*"얼마 받을 수 있나"*)가 첫 줄에 온다.
- A안은 더 차분하지만 출금이 판 아래쪽이라 현재의 문제(출금이 묻힘)를 덜 푼다.

## 지키는 계약 (어느 안이든)

- 표면 규칙 ①~⑥: 카드 테두리 0 · 강조색 하나(`--brand`) · 숫자가 주인공 · 이모지 0 · 색깔 정보상자 0
- 다크에서 `--lift` 없음(면 대비로만 구분)
- **정보는 빼지 않는다** — 최근 적립 내역·영입 매장 상세는 순위표 아래 한 줄(A) / 탭(B)으로 들어간다
- `공구 대행 등록` 버튼은 목록에 없다(2026-09-29 대표 확정) — 행 전체가 그 동작
- 출금 카드의 **검정 그라디언트는 없앤다**(평면 그라디언트는 `check-design-slop` 대상이자 팔레트 밖)
