> 대표 지적: *"버튼들이 AI 스럽다"* → *"버튼의 테두리가 정말 AI스럽다"* → *"아이콘들이 AI가 만든 티가 많이 난다"*
> → *"유어샵의 페이지 디자인 및 UI도 모두 재개편 하는 수준으로 해야해. 세련되어야 하는데 지금 전혀 그렇지 않아."*

대표가 보낸 화면: 상단 네비(홈·교환권·동네딜·유어샵·블로그 + 카테고리 칩). 유어샵 아이콘이 `Sparkles`(반짝임).

## 1. 실측 — 색은 원인이 아니었다

이 앱에는 흔한 AI 지문(보라 그라디언트·무지개색)이 **이미 없다** — 2026-06-19 에 장식색을
전부 잉크 스케일로 중화했기 때문이다. 원인은 다른 데 있었다.

```
<button> 총 2,606   transition 보유 9(0.3%)   눌림반응 194(7%)   그림자 0
boxShadow 커스텀 정의 0개 → 368자리가 전부 Tailwind 기본 '순수 검정'
border border-gray-200  1,350곳 · gray-300 447 · gray-100 184   (border 총 9,024회)
'테두리+그림자+흰바탕' 3중 중첩         65개 파일
lucide-react                            531개 파일 · 대안 아이콘셋 0개
AI 클리셰 아이콘  Sparkles 80 · TrendingUp 90 · Star 48 · Shield 34 · Zap 28 · Rocket 11
버튼 세로여백 6종(py-1/1.5/2/2.5/3/3.5) · 굵기 3종 · 모서리 4종
```

**결론**: ① 버튼이 손가락에 반응하지 않는다 ② 버튼끼리 규칙을 공유하지 않는다
③ 모든 것에 같은 1px 실선이 둘러져 위계가 없다 ④ 아이콘이 lucide 기본값 + 클리셰.

## 2. 테두리의 뿌리 — 토큰이었다

`src/pages/seller-public/theme.ts` 가 **라이트에서** `bg: 'bg-white'`, `card: 'bg-white'`.
바탕과 카드가 같은 색이니 카드를 구분할 방법이 실선뿐이었다.
**다크는 이미 `#0F151D` ↔ `#1A2334` 로 분리돼 있었다 — 라이트만 깨져 있었다.**
(대표가 본 화면이 라이트였다.)

→ `bg` 를 웜 그라운드(`bg-warm` = `#FAF7F5`)로 바꾸면 흰 카드가 저절로 떠오르고
   실선이 할 일이 없어진다. 가드: `src/tests/unit/surface-token-separation.test.ts`

## 5. 구현 (PR #1240)

**방식 = 단일 지점 리매핑, 클래스명 불변** — 2026-07-19 브랜드 컬러 롤아웃이 검증한 방법.
버튼 2,606곳을 개별 수정하면 앞으로 만드는 버튼은 또 빠진다.

| 변경 | 파일 | 영향 |
|---|---|---|
| 전역 `button` transition + `active:scale(.978)` (+`prefers-reduced-motion`) | `src/index.css` | 2,606개 |
| `boxShadow` 순수검정 → 잉크 네이비 `rgb(26 44 66)` | `tailwind.config.js` | 368자리 |
| `focus-visible` `#6b7280` → 브랜드 로즈 | `src/index.css` | 전역 |
| `fontFamily` 에 `'Pretendard Variable'` 추가(누락이었다) | `tailwind.config.js` | `font-sans` 8곳 |
| shadcn 기본값 버튼 갱신 | `src/components/ui/button.tsx` | 15곳 + 향후 |
| **유어샵 `bg` 웜 그라운드** | `seller-public/theme.ts` · `CuratorPage.tsx` | 유어샵 전체 |
| `min-h-screen` → `min-h-[100dvh]` | 유어샵 3곳 | 모바일 하단 잘림 |

그림자를 **네이비**로 한 이유: 웜 브라운은 소비자 웜 바탕(`#FAF7F5`)엔 맞지만
대시보드 쿨 그레이(`#F4F5F7`)·도매몰에서 어긋난다. 네이비는 전 레일에 맞는다.

⚠️ **크로스-레일**: `tailwind.config.js` 는 레포에 하나뿐이고 `index.css` 는 전역이라
도매몰(계열 `<button>` 330개)·공구 서비스·유어애즈에도 닿는다. 머니 경로 무접촉.

## 6. 남은 것

- **아이콘** — 세트 통째 교체(빠름·일관) ↔ 핵심만 유어딜 전용 제작(느림·차별화). 대표 판단.
  유어샵 `Sparkles` 는 "AI 마법"의 관용 기호이고 *내 가게*라는 뜻이 없다.
  대안 스케치: 차양 달린 가게 앞(유어샵) · 접힌 지도(동네딜, 한 지점이 아니라 동네니까) · 선 굵기 2px→1.6px.
- **이모지 플레이스홀더** 정리 — 대표 결정 흔적 없음, 진행 가능.
- **테두리 1,350곳** — 토큰을 더 옅게 낮추고 3중 중첩 65곳은 하나만 남기기.
- **헤더 재배치**(가운데→왼쪽, 원형→각진 아바타, 숫자 3개) — `CuratorHeader` 594줄에
  소유자 인라인 편집·액센트 선택기·SNS 가 얽혀 있어 위험도가 다르다. 별도 라운드.
