# 유어딜 전체 UX/UI 라이브 검사 — 2026-08-17 (대표 지시 "전체 최종 검사")

**방법**: 이 원격환경에서 라이브 `urdeal.kr` 을 실제 Chromium(Playwright, 프록시 TLS1.2 캡)으로
소비자 표면 12페이지 × PC(1600px)/모바일(390px) = **24장 풀페이지 캡처 + 콘솔에러 + 4xx/5xx +
가로 오버플로** 수집 후 검수 에이전트 3조가 전수 열람(의심 부위는 원본 크롭 재확인). **추측 0.**
대상: 홈·교환권·지도·숙소·검색·로그인·블로그·장바구니·FAQ·이용권 상세(25)·교환권 상세(27)·링크샵(/u/jiwon1228).

**한계**: ① 비로그인 표면만(카카오 로그인 자동화 불가 — 마이/결제/내이용권 제외) ② 캡처 환경이
카카오 SDK 등 외부 도메인을 차단 → 지도 타일/일부 외부 이미지 공백은 "환경 의심"으로 분류
③ **고정 하단바가 풀페이지 캡처에서 페이지 중간에 찍히는 것은 캡처 아티팩트** — 단, 최하단
콘텐츠 spacer 여부는 실기기 확인 가치 있음. ④ PR #1161(컴팩트화)은 아직 미배포 — 본 검사는 배포본 기준.

**총평**: 서버 4xx/5xx 0건 · 가로 오버플로 0건 · 진성 콘솔에러 0건 · **레이아웃 P0 깨짐 0건.**
구조는 건강하고, 발견된 것은 **콘텐츠/데이터 품질(가장 심각)** 과 **P1 어긋남·P2 다듬기**다.

## 🟠 P1 — 어긋남/불일치 (코드 수리 가능)

| # | 위치 | 내용 | 수리 방향 |
|---|---|---|---|
| 1 | 교환권 상세 `/vouchers/:id` | 카테고리 배지가 **"이용권" 오표기** — 딜 결제 기프티콘은 명칭 SSOT상 "교환권". 하단 네비의 교환권/이용권 탭과 정면 충돌 | 배지 라벨을 `deal_only` 기준으로 분기 |
| 2 | 검색 `/search?q=김밥` | ① 관련성 붕괴 — 9건 중 8건이 "곱창전골 2인" **동일 상품명 중복**(가격만 다름) ② **자동완성 드롭다운이 결과 위에 열린 채 잔존**해 필터 칩 가림 (PC·모바일) | ② 는 코드(자동 오픈/닫힘), ① 은 데이터(데모 시드 중복)+관련도 로직 규명 |
| 3 | `/vouchers` PC | 타이틀 "커피/음료 교환권 **20**" vs 사이드바 "**775**" — 로드분 카운트가 총계 자리에 표기돼 "20개뿐"으로 읽힘 | 총계 표기 또는 카운트 제거 |
| 4 | `/map` PC·모바일 | 지도 **마커/가격버블 겹침** — 클러스터에서 핀 스택 + 버블 상호 가림(충돌 회피 없음) | 클러스터링 or zIndex/오프셋 |
| 5 | 홈·`/stays` 피드 하단 | 스크롤 하부 카드 이미지 대량 공백(환경 의심 반) — placeholder 에 스피너/블러 없어 빠른 스크롤 시 실사용도 빈 카드 체감 | dominant-color 위 로딩 표시/블러업 |
| 6 | `/stays` 전체 | 데모 시드가 실서비스처럼 전면 노출 — 동일 제목 패턴 40행+, 숙소 무관 이미지(사무실·화장품 매대 등) | 데이터 큐레이션(대표 결정) |
| 7 | 블로그 목록 | 히어로 캡션 "**유어딜 · 유어딜**" 중복 표기 | 템플릿/데이터 확인 |
| 8 | 링크샵 카드 | 밝은 사진 위 흰 제목·가격 — **그라데이션 스크림 없음** → 가독 저하 | 하단 스크림 추가 |

## 🟡 P2 — 다듬기 (그루폰 정합 포함)

- **교환권 PC 카드 헐거움**: 카드 세로 ~400px·첫 화면 8개 — 그루폰 대비 최약 밀도. 할인 소구(정가 취소선/pill) 부재. *(PR #1161 은 홈만 컴팩트화 — `/vouchers` 는 별도 작업 필요)*
- 홈 PC 히어로 우측 ~60% 빈 공간 / 지도 진입 카드 베이스라인 안 맞음
- `/map` 핫딜 스트립 ↔ 리스트 동일 상품 연속 중복 · 썸네일 품질(메뉴판 스캔/로고 사진)
- 지도 검색창 placeholder 글자 중간 절단("…지역 걷") · urdeal 로고가 지도 타일 위 직접 얹힘
- FAQ·블로그 카테고리 칩 우측 하드 잘림(스크롤 힌트 없음 — 동일 클래스)
- 상품명 벤더 원문 노출("퍼페티)츄파춥스300") · 셀러 아바타 빈 원 · gb 상세 탭 행의 용도 불명 ➕ 버튼
- 교환권 상세 PC 하단 ~400px 공백 · 장바구니 빈 상태 여백 과다(추천 한 줄 제안)
- 로그인 PC 바로가기에 숨김 처리된 "쇼핑" 링크 잔존 · 보조 텍스트 저대비(AA 경계)
- 블로그 이모지 썸네일 중복(변별력↓) · 링크샵 "MORE INFO +" 미번역 · 교환권 카테고리 사이드바 🎁 아이콘 반복
- 썸네일 큐레이션 규칙 부재(실사진/로고/간판 혼재 — "음식 사진 우선" 같은 규칙 필요)
