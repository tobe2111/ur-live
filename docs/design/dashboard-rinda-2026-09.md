## 1. 참조 화면 받아쓰기 (Rinda — 수출 영업 SaaS 대시보드)

### 사이드바 (약 280px, **흰 배경**)
| 자리 | 내용 |
|---|---|
| 최상단 | 워드마크 `Rinda`(블루 그라디언트, ~22px 800) + 우측 패널 접기 아이콘 |
| 그 아래 | **워크스페이스 카드** — 테두리 있는 rounded 박스, 작은 회색 `워크스페이스` + 굵은 `유어팀` |
| 본문 | 메뉴 **6개 평면 나열**(해외 시장 탐색 / 바이어 관리 / 캠페인 관리 / 메일 수신함 / 대시보드 / 수출 도구 모음`베타`) — **그룹 라벨 0개** |
| 활성 | 연한 **파랑 면 알약**(rounded-lg) + 잉크 글자 + 파란 아이콘. 세로 막대·그라디언트 없음 |
| 비활성 | 회색 글자 + 회색 아이콘, hover 시 아주 옅은 회색 면 |
| 하단 블록 | ① 파란 점 + `영업정보` ② 구독 카드(테두리 박스, `구독 만료됨` 빨간 pill + 만료일 + chevron) ③ 이름 + 이메일 + 톱니 ④ **꽉 찬 파란 CTA** `플랜 업그레이드` |

### 본문
- 상단바: **흰색**, 사이드바보다 높음(~68px). 우측에 `문의하기`(아웃라인 버튼) + 아이콘 2개
- 배경: 아주 옅은 회색
- 제목: `유어팀 대시보드` ~22px 800 + 회색 부제 한 줄
- **2열 그리드** — 좌(넓음): 인사이트 카드 / 우: 통계 3장 한 줄 + 실시간 활동(큼)
- 카드: 흰색 · 큰 라운드 · **헤어라인 테두리** · 그림자 거의 없음
- 통계 카드: `작은 회색 점 + 라벨` → **큰 숫자 + 단위** → 작은 회색 설명
- 인사이트 카드: 제목 + 부제 → 탭 줄(`전체 3 / 중요 사항 3 / 기회 발견 0 / 개선 제안 0`) → 행마다 [색 사각 아이콘][제목/설명][`바로이동` 연파랑 pill]
- 빈 상태: 가운데 옅은 원 안 아이콘 + `아직 활동 내역이 없어요` + **`캠페인을 발송하면 실시간으로 표시돼요`**

> 🔑 **이 마지막 줄이 이 시안의 핵심이다.** Rinda 는 빈 자리에 `0` 을 띄우지 않고
> **무엇을 하면 채워지는지**를 적는다. 우리 메인이 "보기 안 좋은" 이유의 절반이 여기다.

## 2. 색은 새로 만들지 않는다 — 기존 브랜드 토큰이 이미 Rinda 다

| Rinda | 유어딜 토큰 (`src/index.css`) | 값 |
|---|---|---|
| 사이드바 흰 배경 | `--surface` | `#FFFFFF` |
| 본문 배경 | `--bg` | `#F8F7FC` (Rinda `#F7F8FA` 와 사실상 동일) |
| 활성 메뉴 연파랑 면 | `--brand-tint` | `#EAF1FE` |
| 파란 CTA·아이콘 | `--brand` / `--brand-text` | `#1C69EF` |
| 카드 헤어라인 | `--rule` | `rgb(22 24 28 / 0.08)` |

⇒ **새 hex 0개.** 2026-09-02 코레일톡 시안(🎫)에서 확정된 값 그대로다. 이 표를 벗어난 색을
대시보드에 새로 들이지 말 것.

🔴 **`.seller-light-theme` / `.admin-light-theme` 에 `--brand-tint`·`--brand-text` 를 되박아야 한다.**
그 래퍼는 `--lift`/`--rule`/`--tone-*` 만 라이트로 고정하고 브랜드 틴트는 빠뜨렸다 —
사용자가 다크 모드를 켜 두면 `:root.dark` 의 `--brand-tint: #16243D`(남색)가 새어 들어와
**활성 메뉴 알약이 검게** 뜬다. CSS 주석이 `--lift` 에 대해 경고한 바로 그 사고의 재발이다.

## 3. 카드: 그림자 → 헤어라인

소비자 표면은 `카드 테두리 0 + shadow-lift 한 값`(🎫)이 정본이다. **대시보드는 다르게 간다.**
- 근거: 대시보드는 한 화면에 카드가 10장 넘게 깔린다. 그림자 10개는 화면을 뿌옇게 만들고,
  밀도가 높을수록 "떠 있는 것"이 많아 시선이 안 잡힌다. Rinda 가 헤어라인을 쓰는 이유가 이것이다.
- ⚠️ 소비자 카드에 이 규칙을 옮기지 말 것 — 🎫 절이 정본이고 그쪽은 그림자 한 값이다.
