# 홈 지역 배경 — 사진 → 일러스트 전환 시안 (2026-11-02)

대표: *"파스텔 톤으로 하니까 너무 촌스러워"* → *"세련된 느낌들이 필요해"* → *"일러스트. 부산 일러스트 한번 뽑아볼래?"* → 예시 5장 공유.

## 대표가 준 예시 (스타일만 참고 — 원본은 스톡 저작물이라 레포에 넣지 않는다)
1. 손그림 외곽선 + 맑은 낮(하늘·뭉게구름·노란 해·모래사장, 광안대교 정면)
2. 밤 그라데이션 벡터(남색→보라→분홍 하늘, 초승달·별똥별, 흰 다리 실루엣, 거품 해변)
3. 불꽃축제 밤(금·분홍·파랑 불꽃, 조명 켠 다리·빌딩, 물 반사)
4. 기하 플랫 포스터(슬레이트 보라 주탑, 옅은 청록 하늘, 큰 반투명 원, 빌딩 실루엣)
5. 노을 페인팅(주황·분홍 하늘 빛줄기, 해변 의자의 두 사람 뒷모습, 애니풍 붓질)
