# 링크샵 리디자인 시안 (2026-07-07)

**배경**: 대표 신고 — "상품/이용권이 적어서기도 하지만 UI가 휑하다, 이상적인 느낌이 아니다."
링크샵이 "갖고 싶은 내 쇼핑몰"이 아니라 "빈 링크 목록"처럼 보이는 문제.

**시안(Artifact)**: 방문자가 보는 정지원 님 링크샵 기준, 라이트/다크 토글 포함.
콘텐츠가 적어도 채워진 느낌·명확한 위계·구매 동선을 설계.

**디자인 원칙 (유어딜 기존 시스템 존중)**:
- 크롬은 잉크/뉴트럴 모노톤, 색은 상품 사진(그라데이션 카드)이 담당 — BrowseProductCard 철학 유지.
- 다크 기본 + 라이트 토글. 액센트는 음식 큐레이터 맥락의 웜톤(퍼시몬) 1개만 가격/할인/CTA에 절제 사용.
- 카드 1종(대표 2026-06-25) 원칙 유지.

## 6가지 핵심 변경

| # | 영역 | 변경 | 현재(문제) |
|---|---|---|---|
| 1 | 정체성 | 배너 + **아바타** + **스탯 줄(추천·평점·팔로워)** | 이름/핸들 + 큰 공유버튼 2개 = 상단 텅 빔 |
| 2 | 방문자 동선 | 공유 아이콘화 + **팔로우/구매를 1순위** | "링크복사/카카오공유"가 최상단 점유 |
| 3 | 채워진 느낌 | **대형 '이번 주 픽' 히어로 카드** + 컬렉션 칩(전체·이용권·추천템·지도) | 작은 가로 행 카드 1개 + 넓은 여백 |
| 4 | 카드 통일+신뢰 | 전 섹션 동일 그라데이션 카드 + **안전결제·사업자 인증 배지** | 이용권만 밋밋한 행 카드(→ 이번에 통일 완료) |
| 5 | 빈 상태 | "상품 0" → **"첫 상품 올려 채워보세요" 초대 카드** | "상품 0 + 등록" 한 줄, 존재감 0 |
| 6 | PC 거터 | 큰 QR·중복 CTA → 브랜드 편집 레일 + 얇은 sticky 네비 | 유틸리티(QR 2개·중복 버튼)라 휑함 |

## 구현 우선순위 (승인 후)
1. **1·2·3** (헤더 정체성 + 방문자 동선 + 히어로/칩) — 체감 임팩트 최대, 리스크 낮음
2. **4·5** (신뢰 배지 + 빈 상태 초대 카드)
3. **6** (PC 거터 — ConsumerFrameRails 재설계, 별도)

## ✅ 구현 완료 (라이브)
- **1차** (커밋 `9bfb2c3d` 계열): 아바타(CuratorHeader) + '이번 주 픽' 히어로(FeaturedCard) + 카드 통일(VouchersTab→BrowseProductCard).
- **2차** (커밋 `1d7bd5e9` 계열): 유어딜 안전결제·사업자 인증 신뢰 배지 + "쇼핑몰을 채워보세요" 빈상태 초대 카드.
- 실사진 데모 주입 스크린샷으로 풀 상태 검증 완료 — "빈 링크"→"쇼핑몰" 전환 확인.

## ⏳ 미구현 (선택 — 필요 시 3차)
- 헤더 스탯 줄(추천·평점·팔로워) — 실데이터 배선 필요
- 컬렉션 칩(전체·상품·이용권·지도) — 섹션 스크롤 앵커 필요
- 방문자 CTA에서 공유 강등 + 팔로우 1순위 — 팔로우 API 확인 필요
- PC 거터(ConsumerFrameRails) 재설계 — QR·중복버튼 → 브랜드 레일
