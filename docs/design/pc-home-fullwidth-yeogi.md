## 디자인 토큰 (목업 확정 시 실제 반영)
- **색**: ink `#15161a` · paper `#fff` / warm off-white `#faf9f7` · warm-neutral grey `#71727a`/`#e8e6e1` · **딜 레드 액센트 `#fb2d3f`(할인%·가격 강조 한 곳만)**. 유어딜 기존 B&W 모노 정체성 유지 + 커머스 관습(할인율 레드) 한 스팟.
- **타입**: Pretendard/시스템 한글 스택(CSP 웹폰트 차단 대응 — 데이터URI 한글폰트는 MB급이라 시스템 스택). 위계는 scale/weight/tracking·tabular-nums(가격).
- **레이아웃**: 풀너비 셸 + `max-w 1180` 중앙 콘텐츠. sticky 상단 네비 → full-bleed 히어로(캔버스 오브 배경) + 플로팅 검색카드 → 카테고리 8아이콘 → 프로모 3배너 → 카드 로우(5열) ×3 → 브랜드 그리드(6) → 링크샵 밴드 → 교환권 로우 → 대형 푸터. 라이트/다크 양테마.
