# 생활 견적 요청 흐름: 오늘의집 이사 견적 참고 (2026-10-25 대표 공유)

대표가 오늘의집 이사 견적(`lifecycle.ohou.se`, 페이스북 광고로 진입)을 직접 끝까지 신청하고 화면 12장을 보냈다.
"오늘의집 플로우야". 원본 스크린샷에는 대표 본인의 이름·전화번호·실제 주소가 찍혀 있어서 **공개 레포에 이미지를 넣지 않고
글로만 옮긴다.** 원본이 다시 필요하면 대표에게 요청한다.

## 오늘의집 흐름 (화면 순서)

1. **로그인 없음.** 광고를 누르면 바로 "간단한 정보 입력하고 이사 비교 견적 받아보세요" 화면이 뜬다.
2. 화면은 **요약 카드 하나**(이사예정일 / 이사유형 / 출발지 / 도착지 / 연락처)이고, 칸을 누르면 **바텀시트가 하나씩** 열린다.
   한 시트 = 한 질문. 고르면 시트가 닫히고 다음 시트가 자동으로 열린다.
3. **날짜**: 달력 시트. 오늘 이전은 흐리게, **"손 없는 날"을 점으로 표시**. [선택 완료].
4. **이사유형**: 큰 카드 2개(소형/원룸이사 "1인 가구·간단한 이사에 추천" / 가정이사 "2인 이상 가구·포장 이사에 추천", 그림 포함)
   → 이어서 범위 시트(포장이사 / 반포장 / 일반이사, 각자 한 줄 설명).
5. **출발지**: 주소 검색 시트(단지명·도로명 검색, 예시 3개) → 상세주소 시트(동·호 입력 + "상세 주소는 매칭된 전문가에게만 공개돼요"
   + 평수 칩 8개 + 층 + 엘리베이터).
6. **도착지**: 같은 두 시트.
7. **연락처**: 이름 + 전화번호(010 선택 + 나머지), 하단 "개인정보 이용 및 수집 안내".
8. **가구/가전**: 그림 타일(TV·냉장고·세탁기·건조기·스타일러·에어컨·레인지·안마의자·정수기…) 다중 선택.
   **[건너뛰기] 가능** — "당장 입력이 어렵다면 매칭 후 파트너와 상담하셔도 돼요".
9. 요약 카드 다 채워지면 [견적 신청].
10. **완료 화면 + 교차판매 시트**: "가시는 곳의 이사청소도 함께 신청하시겠어요?" [괜찮아요] / [함께 신청].
11. **알림톡 3통**(카카오 비즈 채널, 수신 즉시): ① [이사 신청 완료] ② [입주청소 신청 완료] ③ [이사 청소 매칭완료] —
    "매칭된 파트너가 연락을 드릴 예정", "모르는 연락처로 문자·전화가 오더라도 꼭 확인", 버튼 [신청내역 확인하기]
    (비회원은 희망일로부터 30일까지 유효한 링크).

## 우리(`/life/request/:category`)와 차이

| 항목 | 오늘의집 | 유어딜 지금 |
|---|---|---|
| 로그인 | **없음** (이름·전화로 접수) | 카카오 로그인 필수(`ProtectedRoute requireUser`) |
| 입력 방식 | 요약 카드 + 질문당 바텀시트 1개, 자동 다음 | 한 화면에 칸 전부(긴 폼) |
| 날짜 | 달력 + 손 없는 날 | 브라우저 기본 date 입력 |
| 주소 | 주소 검색 + 상세주소(매칭 업체에만 공개) | 시·구 텍스트 입력 |
| 선택지 | 그림 있는 큰 카드 + 한 줄 설명 | 알약 칩 |
| 부가 정보 | 가구/가전 타일, 건너뛰기 가능 | 메모 칸 |
| 신청 후 | 교차판매(이사 → 이사청소) | 요청 상세로 이동 |
| 알림 | 신청 완료·매칭 완료 알림톡 즉시 | 템플릿 미승인 — 화면 알림만 |
| 신청 확인 | 알림톡 링크(비회원 30일) | 내 요청(로그인) |
