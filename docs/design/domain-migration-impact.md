# 🌐 도메인 변경 영향 평가 (live.ur-team.com → 신규 도메인) — 2026-07-20

> 대표 질문 "도메인을 바꾸면 변경해야 할 게 많을까?" 에 대한 실측 기반 평가.
> 결론: **코드는 반나절(1세션), 진짜 일은 외부 연동·전파(1~2주 병행). 그리고 구 도메인은 영구 유지(301) 필수.**
> ⚠️ **앱 스토어 제출 전에 확정할 것** — 앱 바이너리에 도메인이 박힘(server.url·딥링크). 제출 후 변경 = 스토어 업데이트 재심사.

## A. 코드 (1세션 — 세션이 일괄 처리)

실측: `live.ur-team.com` 하드코딩 **105개 파일** (2026-07-20 grep). 대부분 기계적 치환.

| 영역 | 내용 |
|---|---|
| 상수 중앙화 | `worker/index.ts BASE_URL` 등 → 치환과 동시에 SSOT 상수/env 로 승격 (재발 방지) |
| 워커/알림 | 알림톡·푸시·이메일 본문 링크 (`lib/notifications.ts`, cron, helpers) |
| QR/공유 | 이용권 QR `https://.../v/{code}` — **신규 발급분만 새 도메인**, 기발급분은 301 로 커버 |
| 앱(캡ac이터) | `capacitor.config.ts` server.url·allowNavigation / AndroidManifest `android:host` / AASA·assetlinks 호스트 |
| SEO/메타 | index.html canonical·OG / sitemap / robots / blog RSS |
| CI/모니터링 | uptime.yml·prod-diag.yml 대상 URL |
| 유지 가능 | `media.ur-team.com`(R2)·`utongstart.com`(도매)은 별개 — 같이 안 바꿔도 됨 |

## B. 인프라 (대표 Cloudflare 대시보드 — 30분)

1. 새 도메인 Cloudflare 존 등록 (+DNS)
2. Pages `ur-live` 에 Custom Domain 추가 (기존 도메인 **삭제하지 않음**)
3. 워커에 구→신 301 리다이렉트 1블록 (세션이 코드로)
4. env/secret 의 도메인 값 (PUBLIC_R2_URL 무관, BASE_URL 계열만)

## C. 외부 연동 (진짜 병목 — 각 콘솔 재등록/재승인)

| 연동 | 작업 | 소요/리스크 |
|---|---|---|
| **카카오 개발자 콘솔** | 플랫폼 웹 도메인·Redirect URI 추가 (구+신 병기) | 즉시. 구 URI 지우지 말 것(전환기) |
| **카카오 알림톡 템플릿** | 버튼 링크 도메인 변경 → **템플릿 재심사(사전승인제)** | 수일. 미리 신청 |
| **토스페이먼츠** | 콘솔 등록 도메인 추가 (successUrl 은 same-origin 이라 코드 자동) | 즉시~1일 |
| **KT Alpha** | 콜백/화이트리스트에 도메인 있으면 변경 요청 | 담당자 확인 필요 |
| **SEO** | 서치콘솔(구글)·서치어드바이저(네이버) 신규 등록 + 주소변경 신고 + 301 | 순위 안정화 수주 |
| **카카오 공유 캐시** | OG 캐시 초기화(개발자도구) — 안 하면 옛 카드 노출 | 즉시 |

## D. 되돌릴 수 없는 것 → 구 도메인 영구 301 필수

이미 세상에 나간 URL 은 회수 불가:
- 발급된 이용권 QR (`/v/{code}`) — 인쇄/캡처본 포함
- 발송된 알림톡·MMS(교환권) 속 링크
- 유저들이 공유한 링크샵/상품 링크, 네이버·구글에 색인된 페이지
→ **ur-team.com 을 만료시키지 말고 301 을 무기한 유지** (연 도메인비 정도의 비용으로 전부 해결).

## E. 순서 권장

1. **새 도메인 확정** (앱 제출 전 — 가장 중요)
2. C 의 알림톡 템플릿 재심사 먼저 신청 (가장 느린 항목)
3. B 인프라 (구+신 병행 서빙)
4. A 코드 1세션 (치환+SSOT+301+검증) — 이 시점부터 신규 발급물은 새 도메인
5. C 나머지 콘솔 + SEO 전파
6. 앱 빌드에 새 도메인 반영 → 스토어 제출

**총평**: 지금(앱 제출 전, 유저 소수)이 도메인 바꾸기 **가장 싼 시점**. 스토어 제출 후·유저 확대 후엔 비용이 계단식으로 커짐.
