# 숙소 "지도로 보기" PC 분할 뷰 — 여기어때 참고 (대표 시안 2026-07-16)

> 대표: "지도로 보기 시, 이런 페이지로 PC가 나왔으면 좋겠어. 여기어때 페이지 참고해줘." + 여기어때 숙소 검색 스크린샷.

## 시안 (여기어때 숙소 검색결과)
- 상단: 필터바 (예약가능 상품만 보기 · 숙소유형 ▾ · 대실예약) + 지역/날짜/인원(강릉 · 7.16–7.17 · 인원2).
- **좌측(≈40%) 스크롤 리스트**: "'강릉' 검색 결과 30개" + 숙소 카드(이미지 좌 + 등급·유형 배지 + 이름 + 위치 + ★평점·후기수 + 쿠폰%·정가 취소선 + **회원가** 강조).
- **우측(≈60%) 지도**(NAVER): 가격 핀 버블(예 212,520원), 판매완료 회색 핀, 클러스터(2), "지도 이동 시 자동 재탐색" 토글, 줌/현위치 컨트롤, 검색바("강릉 주변에서 더 검색").

## 유어딜 각색
| 여기어때 | → 유어딜 |
|---|---|
| 회원가/쿠폰% | 이용권 **할인가**(딜/원) + 할인% (코랄레드) |
| 숙소유형/대실 필터 | 숙소유형 · 날짜 · 인원 (기존 StaysSearchPage 필터 재사용) |
| NAVER 지도 + 가격핀 | Kakao 지도(홈 RestaurantMapPage 인프라 재사용) + 숙소 price_from 핀 |
| 판매완료 핀 | 재고 없음(마감) 핀 회색 |

## 방식 (구현 시)
- **PC(lg+) 전용 분할 뷰** — 좌 리스트(sticky 필터 + 스크롤) + 우 지도(sticky, 100dvh−헤더). 모바일(<lg)은 기존 그리드/지도(RestaurantMapPage 패턴) 유지.
- 지도: 홈 `useKakaoMap`/좌표 인프라 재사용. 숙소 좌표(`product_stay_info`/geocode) 필요 — 좌표 없는 숙소는 리스트만.
- 리스트↔지도 핀 hover 연동(핀 hover 시 카드 하이라이트), "지도 이동 시 자동 재탐색" 토글.
- ⚠️ 지도 SDK + 좌표 연동은 큰 작업 + 이 환경 시각검증 불가 → 목업 승인 후 단계 구현 + staging 확인.
