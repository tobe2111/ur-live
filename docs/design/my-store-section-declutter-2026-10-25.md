## 2차 — 안 D·E (대표 *"더 이상적인 UI 없을까?"*)

A·B·C 는 **지금 있는 부품을 다시 배치**한 것이라 모양 언어 수가 크게 안 줄었다. 2차는 원칙부터 정했다:
**모양 언어를 둘 이하로 · 파란 면은 한 자리 · 상태는 버튼처럼 보이지 않게.**

| | 안 D · 가게 티켓 한 장 (추천) | 안 E · 위 숫자 줄과 같은 문법 |
|---|---|---|
| 생각 | 디자인 시스템 규칙 ④(**티켓 은유 = 색 밴드 + 본문**)를 가게에 그대로 쓴다. 가게 = 카드 한 장 | 새 모양을 **하나도** 안 만든다 — 바로 위 `내 딜 · 이용권 · 쿠폰` 3칸 줄을 그대로 가게에 반복 |
| 머리 | 파란 밴드 안: 가게 이름 + `4곳 ⌄` · 판매 알림 종(흰 배지 8) | 회색 띠로 구역 구분 → 가게 이름(17) + `내 가게 4곳 ⌄` |
| 숫자 | 밴드 안 `오늘 0원`(34) · `주문 0건 · 판매 중 이용권 1개` · 분석 › | 3칸: 오늘 매출 · 오늘 주문 · 판매 중 (0 은 회색) |
| 행동 | 티켓 홈(절취선) 아래 본문에 [QR 사용처리 \| + 이용권 등록] 반반 | 진한 블루 `손님 이용권 사용처리` + 옆에 회색 `+ 등록` |
| 줄 | 판 밖 평면 목록: 주문 · 정산 · 이용권 관리 · 전체 도구 | 판매 알림(8) · 정산 · 전체 도구 (주문은 숫자 칸이 입구) |
| 모양 언어 | 카드 1 + 목록 1 | 숫자 줄 1 + 버튼 줄 1 + 목록 1 (전부 페이지에 이미 있는 것) |
| 대가 | 파란 면이 커서 **0원 날에도** 강조가 크다 · 사용처리와 등록이 같은 무게 | 판 없이 평면이라 *"여기부터 파는 쪽"* 표시가 회색 띠 하나뿐 |

## 3차 — 위쪽(프로필 · 내 딜 · 이용권 · 쿠폰) 시안 (대표 *"위에 내 딜, 이용권, 쿠폰 부분도 개선해볼래? 아직 난 선택 못하겠어 안 E까지도"*)

캔버스 아래 줄. 지금 위쪽의 문제: ① 프로필 줄 오른쪽에 `프로필 편집 ›` + 회색 원 종 — 이름 줄에 셋이 다툰다 ② 숫자 셋이 모두 28px · 각자 `›` 라 **무엇이 돈이고 무엇이 개수인지** 안 갈린다(`111,500` 에 단위 없음) ③ `환급 처리 중` 은 상태인데 테두리 알약 버튼 모양.

## 4차 — 위쪽 안 3 확정(곧 쓸 이용권 제외) + 내 가게 안 F·G·H

## 구현 시 지킬 것 (어느 안이든)
