## 무엇을 바꿨나

색면은 **두 군데**서 그려진다 — 페이지 전체(`PcHomePage`)와 히어로(`HomeHeroDefault` + 좌측
스크림 · 하단 페이드 · 칩 hover 글자색). 두 값이 다르면 **이음매가 그대로 보인다.**
예전엔 양쪽에 hex 를 따로 적어 뒀는데, 그건 한쪽만 고치면 조용히 어긋나는 배치다.

⇒ `src/index.css` `:root` 에 토큰 하나로:

```css
--home-field: #16181C;
--home-field-rgb: 22 24 28;   /* 스크림·페이드가 알파를 얹을 때 */
```

## ⚠️ 색면 ≠ 잉크

이전엔 색면과 제목·가격 잉크가 **둘 다 `#1A2C42`** 라 같은 것처럼 보였다. 이제 다르다 —
**잉크는 딥네이비로 남고 색면만 무채색**이다. 차콜은 무채색이라 네이비 잉크와 충돌하지 않는다
(포레스트·에스프레소를 골랐다면 잉크도 함께 옮겨야 했고, 그건 소비자 화면 전반에 닿는 작업이었다).

동반 변경: 색면 위 그림자가 네이비 혈통(`rgba(10,20,40,…)`)이었던 것을 중립(`rgba(10,11,14,…)`)으로.

## 남은 판단

히어로 배경의 **보라 블룸**(`rgba(120,90,220,.34)`)이 무채색 위에서는 네이비 때보다 도드라진다.
실제 화면은 우측 54%를 딜 사진이 덮어 대부분 가려지지만, "색을 빼서 사진에 양보"라는 채택
이유와는 결이 다르다. 대표 판단 대기 — 줄이거나 로즈 계열로 통일하는 선택지가 있다.
