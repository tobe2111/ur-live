🔑 **이름 칸 폭이 132px 고정이다.** 같은 줄 오른쪽의 버튼 묶음이 먼저 131px 을 가져간다
(`ml-3`(12) + 공유 36 + gap 8 + 관리 알약 ~75). 그 자리는 **방문자에게도 `invisible` 로 예약**돼 있다 —
주인/방문자 폭이 갈리면 서버 첫 화면과 어긋나 마운트 때 아래가 전부 밀리기 때문이다
(`curator-ssr-body.ts` 머리말의 🪑 결정).

24px 한글은 자간 −0.03em 포함 글자당 ~23.3px → **132px 에 5자**. 8자는 186px 이라 두 줄이 된다.
`line-clamp-2` 라 12자 이상은 잘리기까지 한다.

> 🖥️ **PC 는 이미 한 줄이다**(1440px 실측 h1 높이 30 · 폭 186). 2026-10-25 에 lg 에서 버튼 줄을
> 이름 아래로 내린 수정이 그 일을 했다. ⇒ **이 문제는 폰 전용이고, 시안도 폰만 바꾼다.**

### 그래서 처방은 "글자를 줄인다" 가 아니라 "칸을 넓힌다"

버튼 묶음을 `urdeal` 로고와 **같은 줄**로 올리면 이름 칸이 **132 → 278px**:
24px 그대로 **11자**까지 한 줄이다. 글자 크기 축소만으로 8자를 넣으려면 17px 이 필요하고(132/8/0.97≈17),
12자면 11px 까지 내려가야 한다 — **타입 스케일(12·13·15·17·24) 밖이고 읽히지도 않는다.**

🔴 **측정 기반 자동 축소(`ResizeObserver` 로 재서 줄이기)는 쓰지 않는다.** 워커가 그리는 서버 첫 화면
(`curator-ssr-body.ts`)은 브라우저 측정 결과를 모르므로, 서버가 24px 로 그린 뒤 마운트 때 17px 로
바뀌면 **헤더 높이가 튀어 아래가 전부 밀린다**. ⇒ **글자 수 기반 순수 함수 SSOT** 로 하고
워커와 화면이 **같은 함수**를 쓴다(이 레포가 반복해 쓰는 패턴).

## 4. 각 안의 대가 (숨기지 않는다)

- **1안** — 머리 구조는 거의 그대로. 공유 버튼이 로고 줄 오른쪽 끝으로 가서, 방문자에게는
  그 줄에 아이콘 하나만 뜬다(주인은 [공유][관리] 둘).
- **2안** — 이름이 17px 이라 **가게 이름의 존재감이 줄어든다.** 유어샵은 "누구의 가게인가" 가
  정체인 화면이라 이 교환을 대표가 판단해야 한다.
- **3안** — `이용권 N · 누적 구매 M` 줄을 없앤다. 이용권 수는 분류 칩이 이미 말하지만
  **누적 구매는 그 줄에만 있다**. SNS 도 이름표(YouTube/Instagram 글자)에서 **아이콘만**으로 줄어든다.
- **4안** — 2026-09-28 의 D안(2열 큰 카드) 부활이다. 그때 폐기 이유는 *"카드가 아니라 윗부분이 문제"* 였고
  이번엔 윗부분을 먼저 고친 뒤라 조건이 다르다. ⚠️ 그때 적어 둔 대가는 그대로다 —
  **상품이 홀수면 마지막 줄에 칸이 빈다.** 실측상 **핀 1개면 반쪽 카드 하나만 덩그러니** 남아
  지금 라이브(핀 1개)에는 오히려 나쁘다. 핀이 4개 이상으로 늘면 그때 값을 한다.

  `curator-ssr-first-screen-2026-10-09.test.ts` 가 **진짜 컴포넌트를 렌더해** 토큰까지 대조한다.
- 🔒 이 헤더는 **개인 유어샵과 사업자 유어샵이 함께 쓴다**(`SellerPublicPage` 도 `CuratorHeader` 를 렌더 —
  2026-06-25 "헤더 1개" 통일). 한쪽만 보고 고치면 다른 쪽이 갈린다.
- 🔒 소유권은 **prop 으로만**(`check-linkshop-ownership` ③ — 부품이 `seller_token` 을 캐면 안 된다).
- 🔒 버튼 자리 예약(`invisible` 관리 알약)을 없애지 말 것 — 없애면 주인/방문자 폭이 갈려
  서버 첫 화면이 마운트 때 밀린다. 버튼을 다른 줄로 옮길 때도 **그 줄의 폭 예약**은 같이 옮긴다.
- 📏 `scripts/visual-preview.mjs` 에 이번에 추가한 `--ushop-name` / `--ushop-bio` / `--ushop-sns` 로
  경계를 눈으로 다시 확인할 것(`--pins=N` 과 같은 성질의 옵션).
