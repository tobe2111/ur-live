# 유어딜 마스코트 수달 "유달이"(가칭): 3D 캐릭터 제작 의뢰서 (초안)

## 1. 의뢰 개요

유어딜(동네 가게 이용권을 할인가로 사고, 매장에서 QR로 쓰는 서비스)의 마스코트 수달을
**하나의 3D 모델**로 제작합니다. 지금 있는 그림은 AI로 만든 콘셉트 이미지라 장면마다 털색과
비율이 조금씩 다릅니다. 이번 작업의 목적은 **어떤 각도, 어떤 동작에서도 같은 캐릭터**로
보이는 원본을 갖는 것입니다.

쓰임:
- 앱 화면(로딩, 빈 화면, 결제 완료, 사용 완료 등)의 정지 이미지와 짧은 반복 모션
- 매장 스티커·포스터 등 인쇄물
- 실제 식당·숙소 영상에 캐릭터를 합성하는 릴스·쇼츠
- 상표 출원

## 2. 캐릭터 설정 (반드시 지킬 것)

| 항목 | 기준 |
|---|---|
| 종 | 아기 수달(민물 수달). 해달 아님 |
| 비율 | 머리가 전체 키의 약 절반. 머리는 거의 원형(가로:세로 약 1.1:1), 옆으로 넓은 타원 금지. 짧고 통통한 몸, 아주 짧은 팔다리 |
| 질감 | 짧고 보송한 털. 고급 봉제인형 느낌. 점토·플라스틱 질감 아님 |
| 털색 | 밝은 카라멜 갈색 #AA7A5A (진한 초콜릿색 금지) |
| 크림색 | #DDC9B7. 볼·주둥이·턱에서 가슴을 지나 배의 큰 타원까지 |
| 눈 | 아주 큰 동그란 갈색 눈, 하이라이트 2개, 양쪽으로 넓게 |
| 눈썹 | 눈 위에 작고 부드러운 크림색 무늬 2개 |
| 코·입 | 작은 둥근 분홍 코, 작은 미소, 볼 터치 |
| 귀 | 머리 옆 눈 높이에 작고 둥글게, 안쪽이 약간 어둡게 |
| 수염 | 가늘고 흰 수염, 한쪽에 3가닥 |
| 꼬리 | 굵고 끝으로 갈수록 가늘어지는 수달 꼬리 |
| 소품 | 브랜드 블루(#1C69EF) 반다나. 앞에서 매듭, 뒤에서는 삼각형만 보임 |

참고 자료(첨부):
- 턴어라운드 기준 원본: `otter-turnaround-master.png` (정면, 3/4 앞, 측면, 3/4 뒤, 뒤)
- 방향별 투명 PNG: `otter-view-*.png`
- 표정 시트(확정): `otter-expressions-master.png` — 기본, 웃음, 신남, 놀람, 갸웃, 졸림, 미안, 윙크
- 포즈 콘셉트: QR 내밀기, 지갑 안기, 도장 엄지척, 하이파이브, 빈 지갑 들여다보기, 빠진 케이블, 달리기

## 3. 납품물

**A. 3D 모델**
- 리깅된 모델 1종 (몸통, 팔, 다리, 꼬리, 귀, 반다나, 얼굴 표정 블렌드셰이프)
- 형식: `.blend` 원본 + `.fbx` + `.glb`
- 털: 렌더용 고품질 버전과, 실시간용(앱·웹) 가벼운 버전 2종

**B. 표정**
- 블렌드셰이프 8종: 기본, 웃음(눈 감음), 신남, 놀람, 갸웃, 졸림, 미안, 윙크

**C. 포즈 정지 이미지** (투명 배경 PNG, 2048px 이상, 각 1장)
1. QR 화면이 뜬 휴대폰 내밀기 (매장 스티커, 이용권 사용 화면)
2. 이용권 더미 위에서 지갑 안기 (내 이용권)
3. 도장 찍힌 이용권 옆에서 엄지척 (사용 완료)
4. 하이파이브 점프 (사장님 정산 완료 알림)
5. 빈 지갑 들여다보기 (빈 화면)
6. 빠진 케이블 들고 갸웃 (연결 오류)
7. 이용권 들고 달리기 (로딩)
8. 손 흔들며 인사 (첫 가입 환영)

**D. 반복 애니메이션** (투명 배경, 1~2초 루프)
- 달리기(로딩), 갸웃(빈 화면), 흔들흔들(연결 오류), 손 흔들기(환영)
- 형식: 앱용 Lottie 또는 투명 WebM/APNG 중 협의, 그리고 MP4(흰 배경)

**E. 턴어라운드 시트**
- 정면, 3/4 앞, 측면, 3/4 뒤, 뒤 (투명 배경, 같은 크기·같은 바닥선)

## 4. 권리

- 모델, 이미지, 애니메이션 등 **모든 산출물의 저작재산권 전부를 유어딜(유어팀)에 양도**
  (2차적저작물 작성권 포함)
- 상표 출원과 상업적 이용(광고, 굿즈, 인쇄물, 영상) 제한 없음
- 제작자는 포트폴리오 공개 가능 여부를 계약 시 별도 협의
- AI 생성 콘셉트를 참고 자료로 제공하지만, 최종 산출물은 제작자가 직접 모델링한 원본이어야 함

## 5. 진행 단계

1. 러프 모델 정면·측면 시안 → 유어딜 확인
2. 털 질감과 색 확정 렌더 → 확인
3. 리깅과 표정 → 확인
4. 포즈 8종 렌더 → 확인
5. 애니메이션 4종 → 확인 후 납품
