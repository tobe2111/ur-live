## 1. 이 화면이 조화로운 이유 (분해)

색이 예쁜 게 아니라 **규칙이 적어서** 조화롭다. 여섯 개로 다 설명된다.

| # | 규칙 | 시안에서 |
|---|---|---|
| 1 | **표면은 두 톤, 테두리와 그림자는 0** | 바탕 진남색(순검정 아님) / 카드 한 톤 위. 카드 경계는 색 차이로만 |
| 2 | **강조색 하나, 자리 셋** | 블루가 사는 곳: 티켓 상단 밴드 · 주 행동 글자("승차권 확인") · 강조 단어("오는 열차"). 그 외 어디에도 없다 |
| 3 | **숫자가 주인공** | 16:09 / 18:31 이 화면에서 제일 크다. 역 이름은 그 위에 작게. 날짜는 밴드에 |
| 4 | **티켓 은유** | 색 밴드(날짜 + "19일 전") + 본문 = 실물 승차권 한 장. 카드 안에 outline 버튼 하나 |
| 5 | **나머지는 전부 회색** | 안내 3줄은 작은 네모 불릿 + 회색. 크로스셀("오는 열차도 찾아볼까요?")도 같은 카드 표면, 새 장치 없음 |
| 6 | **색이 있는 것은 격리** | 서비스 아이콘 5개만 컬러이고 맨 아래 한 줄에 가둬 둠 |

없는 것도 중요하다: 그라디언트 0 · 이모지 0 · 섹션 라벨(eyebrow) 0 · 체크 원 아이콘 0 · 정보 상자 색깔 0.
"결제가 완료되었어요"는 **제목 한 줄이 전부**이고 초록 체크가 없다.

⇒ 이건 8-30 이후 우리가 정한 규칙과 **같은 문법**이다 (로즈가 사는 자리 셋 · 모양 잠금 · 가운뎃점 사슬 금지). 다만 우리는 규칙을 *지우는 데* 썼고, 이 화면은 규칙으로 *한 장을 지었다*. 차이는 §2.

## 7. 지도 위 UI — B안 (2026-09-02 대표 확정)

대표가 라이브 다크 모드의 지도 홈을 보내며 *"이거 색깔 말이야 눈에 잘 안들어오지 않아?"* · *"이 버튼도 눌렀는지
안눌렀는지 확인도 안돼"* 라고 했다. 시안 셋(A 흰 알약+채색 flat 아이콘 / **B 흰 알약+잉크 선 아이콘, 선택=블루 면** /
C 글자만) 중 B 확정.

원인은 색이 아니라 **자리**였다. 카카오 지도 타일은 테마와 무관하게 밝은데, 칩·검색바·현위치 버튼이 앱 테마를 따라
`dark:bg-[#11141C]` 남색이 되어 파스텔 지도 위에 덩어리로 얹혔고, 선택된 칩은 테두리 한 겹만 달랐다. 현위치 버튼은
[남색+파란 테두리] ↔ [남색+파란 아이콘] 이라 켜짐과 꺼짐이 같은 그림이었다.

| 자리 | 꺼짐 | 켜짐 |
|---|---|---|
| 카테고리 칩 · 필터 | 흰 알약, 잉크 글자·선 아이콘, 들림 그림자 `0 2px 8px 잉크 14%` | 브랜드 블루 면 + 흰 글자 |
| 내 주변 | 흰 알약 + 블루 글자 | 블루 면 |
| 현위치 버튼 | 흰 원 + 잉크 아이콘 | 블루 면 + 흰 아이콘 (측위 중도) |

| 사진 없는 핀·버블 | 중립 회색 `#E4E6EE` (이모지 폴백 삭제) | |

같은 화면의 '오늘의 핫딜' 카드는 할인율을 사진 위 배지에서 가격 줄로 내렸다(2026-08-31 동네딜 카드와 같은 처방),

## 8. PC 홈 다크 모드 — 안A "패널은 흰색" (2026-09-02 대표 확정)

대표가 다크 PC 홈을 보내며 *"색 조합 배치가 가장 이상적인 게 맞을까? 흰색이 없네?"*. 실제 화면에 CSS 만 얹은
세 안(A 다크에서도 패널 흰색 / B 홈 라이트 고정 / C 잉크 크라운) 중 **A 확정**.

라이트 PC 홈은 8월 19일부터 잉크 색면(`--home-field` #16181C) 위 흰 패널(`.ur-home-panel`)이었다. 다크에선
`.dark .ur-home-panel{background:#11141C}` 로 패널이 색면과 거의 같아져 층이 사라졌다. 그 규칙을 지우고, 패널 안의
`dark:` 유틸을 통째로 끄는 **라이트 섬** 장치를 만들었다: `tailwind.config.js`
`darkMode: ['variant', '&:is(.dark *):not(.light-island *)']` + 패널 3곳에 `light-island`. 섬 밖 출력은
`:not(...)` 한 조각만 붙고 동작은 byte-동일. 헤더·내비·히어로는 다크 그대로(대표가 좋아한 어두운 바탕 유지).

같은 장치가 지도 위 오버레이(§7)의 정본이 될 수 있다 — 지금은 `light-fixed` 주석으로 가드를 면제하는 방식이라,
다음에 `MapTopBar` 를 만질 때 `light-island` 로 옮기면 주석 면제가 필요 없어진다.
