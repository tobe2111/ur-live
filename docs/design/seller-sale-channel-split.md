# 판매 방식 분리 — 상시딜 / 공구딜 (셀러 폼 + 메인 피드)

> ⏳ **착수 시점: 지금 아님.** 8월 promo(커미션 예산 아비터 활성) 배치와 **한 세션**에서 구현.
> 콜드스타트 구간엔 공구딜도 메인 노출 유지. 게이트 OFF 기본. (대표 확정 2026-07-06)

## 배경
사업자 유저가 이용권을 **두 채널** 중 하나로 판매:
- **상시딜** = 평소 영업(앱 메인·검색·지도로 상시 노출·유입).
- **공구딜** = 기획전(인플루언서 링크·기간 한정, 더 큰 할인 + 소개비(promo%)로 홍보).

지금은 둘 구분 없이 전부 메인 노출(콜드스타트). 8월 promo 켜질 때 "공구딜은 메인에서 빼고 인플루언서 링크로" flip.

## 확정된 UI 구조 (대표 2026-07-06)
1. **"판매 방식" 라디오 = 셀러 폼 최상단.** 이용권 정보 블록 위가 아니라 **폼의 가장 처음**.
   - 이유: 상시딜/공구딜에 따라 아래 필드 구성이 통째로 갈림(공구딜만 기간·목표인원·promo%).
     매장이 다른 걸 입력하기 전에 채널부터 선택 → 그에 맞는 폼 전개. 중간에 만나면 이미 입력분이 무의미해짐.
2. **라벨은 사장님 언어로**(“메인 노출”·“어트리뷰션” 금지 — 오프라인 영업에 대응):
   - 상시딜 → **"평소 판매 — 앱에서 늘 팔아요 (검색·지도로 손님이 찾아옴)"**
   - 공구딜 → **"기획전 — 인플루언서와 기간 한정으로 팔아요 (더 크게 할인, 소개비로 홍보)"**
   - 프레임: 상시딜 = 정상 영업 / 공구딜 = 이벤트. 온보딩에서 "이걸 왜 나눠?" 질문을 없앰.
3. **메인 피드 flip**: promo 켜질 때 공구딜을 **완전 숨김이 아니라 "오픈 예정" 배지로 유지**.
   - 이미 있는 prelaunch 메커니즘(`product_supply_meta.prelaunch='1'` + FcfsBadge + 상세 CTA) 재사용.
   - 이유: 메인에서 "○○식당 공구 곧 열림"을 본 유저가 인플루언서 링크를 기다림 → 기대감↑.
     완전 숨기면 그 홍보 효과 소멸. (상품 공구의 "오픈 예정 알림받기"와 같은 원리.)

## 타이밍/세션 규칙 (강한 합의)
- ① **지금 당장 안 지음** — 콜드스타트엔 상시 노출 유지.
- ② **지을 땐 promo(#1)와 한 세션·한 배치** — promo% 필드가 공구딜 폼 안에 들어가므로 따로 하면 충돌.
  채널 플래그 + promo% + 검증을 **반드시 한 세션에서**(병렬 세션 충돌 방지 = 서비스 격리 원칙의 실전).
- ③ **전부 게이트 OFF 기본.**

## ⚖️ 미결 정책 결정 (대표) — "같은 이용권을 상시딜+공구딜 동시 가능?"
- **A) 상품 단위 배타** — 이 이용권은 상시딜이거나 공구딜이거나 하나만.
  - 장점: 카니발라이제이션 원천 차단, 매장 멘탈모델 명확("이 상품은 이렇게 판다"), 구현 단순
    (채널 = 상품의 단일 필드 `sale_channel`, 배타는 구조적). **공구가<상시가 검증(#3) 불필요**(같은 상품이 양쪽에 없음).
- **B) 동시 허용** — 같은 매장이 "평소 3만원권 상시딜 + 이번 달 2.4만원 공구딜" 둘 다.
  - 유연하나 **공구가<상시가 검증 필수** + 상품 2행(또는 variant) + 같은 매장 2리스팅 피드 혼동 + 재고 조정 → 복잡.
- **개발 권고: 초기엔 A(배타).** 서초 모델 검증 단계엔 단순한 게 낫고, B는 매장이 재고·기간 관리에
  능숙해진 뒤 열어도 늦지 않음. **A로 확정 시 검증 #3(공구가<상시가)은 빌드 대상에서 제외.**
- 👉 **대표가 A/B 확정 → 이 문서 갱신 후 8월 세션이 그에 맞게 구현.**

## 구현 스케치 (8월 세션용 — 착수 전 재검토)
- 채널 저장: `product_supply_meta.sale_channel = 'always' | 'groupbuy'`(products 컬럼 예산제 — 사이드테이블).
- 공구딜 전용 필드: 기간(fcfs_deadline)·목표인원·promo%(커미션 예산 아비터 `commission_budget_enabled` 연동).
- 피드 게이트: `groupbuy_hidden_from_main` 플래그 OFF(콜드) → ON(flip) 시 공구딜을 prelaunch 배지 노출로 전환.
- A 확정 시: 채널 배타는 폼 라디오로 구조적 보장, 별도 가격 교차검증 없음.
