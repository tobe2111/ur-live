이 계정은 지금 사장님 계정 상태로 로그인이 된거야? 만약 그렇다면 사장님이라고도 표시가 되어있어야 할 것 같은데.

## 실측 (라이브 D1, 읽기만)
- 대표 계정(`users.id=3`) — `sellers.linked_user_id` 로 연결된 매장 **0곳**.
- `seller_operators` 로 **운영자(operator)** 4곳(모두 승인, 넷 다 `linked_user_id` 비어 있음 = 다른 주인 없음,
  `granted_by_user_id = 3` = 대표가 직접 등록하며 운영자가 됨).
- ⇒ 앱은 이 넷을 마이의 '내 가게' 구역으로 보여 준다(판매 도구 전부 사용 가능). 다만 화면 어디에도 "사장님" 이라는 말은 없다.
