## 스크린샷에서 읽은 그루폰 홈 구조 (2026-08 시점)

1. **상단**: 로고 + 대형 라운드 검색바(placeholder 에 인기 검색어) + 우측 유틸(App/Sell/찜/알림/장바구니/계정).
   그 아래 **아이콘+라벨 카테고리 바** 한 줄(Group Deals / Beauty & Spas / Things To Do / Food & Drink / Travel / Goods …, 우측 화살표로 가로 스크롤).
2. **히어로 배너 1장** (풀폭 아님 — 컨테이너 폭, 좌측 카피+프로모코드 버튼, 우측 사진).
3. **테마 섹션 행 반복**: `굵은 제목 + 한 줄 부제("Two tickets, one price — …") + 우측 "View All →"`,
   아래 **카드 4장 + 우측 반쯤 잘린 5번째 카드 + 화살표**(가로 캐러셀 — "더 있음"을 잘린 카드로 암시).
4. **카드 해부** (컴팩트함의 핵심 — 카드 폭 ~350px):
   - 이미지 4:3, 라운드 모서리, 좌상단 배지("Popular Gift"/"5% Cashback"), 우상단 하트(찜)
   - 머천트명(작은 회색) → **굵은 제목 2줄** → 주소 한 줄 + 우측 **거리(10.6 mi)**
   - **★4.7 (84)** 평점+리뷰수
   - 가격 행: 취소선 정가 → **할인가** → 연두 배경 할인율 pill(`-30%`)
   - 프로모 적용가 한 줄 더(보라색 "$31.20 with code TOGETHER")
5. **밀도**: 텍스트 12~14px 위주, 행간 좁음, 섹션 간 여백 크지 않음. 액센트는 그린(가격/할인) 1색.

## 우리(유어딜 PC 홈) 대비 — 이미 같은 것 / 채택 후보

### 이미 정합 (PR #1161 이후)
- 테마 섹션 행 + 더보기(`HomeSections`) · 컨테이너 1440 · 카드 4:3 · 1줄 5개(대표 확정) · 취소선 정가+할인%.

### 채택 후보 (다음 작업 목록 — 각각 독립 적용 가능)
- [ ] **섹션 카드에 평점·리뷰수 노출**: 피드 카드(GroupBuyFeedCard)는 이미 ★평점+구매수를 그리는데
      섹션 카드(HomeSections DealCard)는 없다. `section-rules.ts CARD_COLS` 에 avg_rating/review_count
      서브쿼리(또는 피드 API 와 같은 enrich)를 추가해야 함 — 서버+클라 짝 수정.
- [ ] **할인율 pill 스타일**: 현재 맨 텍스트 `{off}%` → 그루폰처럼 옅은 배경 pill(브랜드 로즈 틴트)로.
- [ ] **섹션 가로 캐러셀**: 4장 그리드 → "4장 + 반쯤 잘린 다음 카드 + 화살표" 가로 스크롤.
      SECTION_DEFAULT_LIMIT 4→8 필요(서버 limit_count 저장값도). 잘린 카드가 "더보기"를 대신 암시.
- [ ] **카드 하트(찜)**: 피드/섹션 카드 우상단 하트 → wishlist API 연결(로그인 게이트 주의 — 비로그인은
      /login?returnUrl). BrowsePage toggleInterest 패턴 재사용.
- [ ] **주소 우측 거리 정렬**: 현재 `📍 주소 · 1.2km` 인라인 → 그루폰처럼 주소(좌)/거리(우) 양끝 정렬.
- [ ] **검색바 대형화**: DesktopTopNav 검색을 그루폰처럼 크고 둥근 단일 포커스로(카테고리 바는 이미 있음).

### 채택하지 않을 것
- 프로모코드 이중 가격 표기(우리 가격 모델에 없음) · 그린 액센트(브랜드 로즈 유지, 색만 이식하면 브랜드 붕괴).
