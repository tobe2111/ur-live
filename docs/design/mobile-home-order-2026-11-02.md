- 시안: **이런 이용권은 어떠세요? → 배너 → 지금 인기 이용권 → 유어쇼츠** → 목록

## 2차 — 대표 *"변경을 해도 맨 위가 이상한데 바로 이런 이용권은 어떠세요? 라고 뜨는게"* → *"시안으로 보여줘"*
- 그림: `assets/mobile-home-top-options-2026-11-02.png` (라이브 캡처 조각을 순서만 바꿔 붙임 · 안 1 의 머리는 '서울' 을 고른 실제 화면)
- 안 1 · 맨 위 지역 사진(추천) — '전국' 에도 대표 사진 → 추천 → 배너 → 인기 → 유어쇼츠. 전국 사진은 아직 없다(임시로 서울).
- 안 2 · 위 얇은 띠 배너 + 추천 아래 큰 배너 — 배너가 두 번(광고가 많아 보일 수 있다).
- 안 3 · 배너는 맨 위 그대로, 유어쇼츠만 인기 아래로 — 가장 안전, '추천 아래 배너' 는 빠진다.

## 3차 — 대표 *"그냥 안 1로 하되, 이런 이용권은 어떠세요? … 를 없애는게 자연스럽지 않을까 … 더보기도 없애고"*
- 그림: `assets/mobile-home-plan1-2026-11-02.png` — 왼쪽 = 지금(라이브 '서울' 실측), 오른쪽 = 시안(같은 라이브 화면에서 DOM 만 옮김)
- 순서: **지역 사진 → (제목·부제·더보기 없는) 첫 이용권 카드들 → 배너 → 지금 인기 이용권 → 유어쇼츠** → 목록
- 첫 섹션은 제목 줄만 걷고 카드는 그대로다 — 지역 사진 머리가 이미 '서울' 을 말하므로 제목이 겹친다.
- ⚠️ '전국' 을 골랐을 때 머리 사진이 아직 없다 → 확정 시 전국 대표 그림 필요(없으면 머리가 비고 카드가 바로 붙는다).

## 구현 메모 (확정 후)
- `MobileHomePage` 의 `<HomeBannerStrip variant="strip" />` 를 첫 섹션 **뒤**로(`HomeSections` 에 슬롯).
- `HomeSections` 의 `{sIdx === 0 && shortsRail}` 을 두 번째 섹션 뒤로.
- ⚠️ 첫 화면(LCP) 영향 — 배너가 첫 화면 이미지였다. 첫 이용권 카드 사진이 LCP 가 된다(워커 프리로드 `home-card-preload` 이미 첫 섹션 카드 대상). 배너 프리로드(`buildHomeHeroPreloadLink`)가 있으면 빼야 낭비가 없다 — 구현 때 확인.
- PC 홈(`PcHomePage`)은 대상 아님(대표가 '모바일 기준' 이라고 했다).

## ✅ 구현 (2026-11-02 대표 *"그냥 안 1로 하되 … 더보기도 없애고"* + *"일단 대한민국은 서울 그림으로"*)
- `HomeSections` 에 `bareFirst`(첫 섹션 제목 줄 없음) · `shortsAfter`(유어쇼츠 자리) — PC 는 안 넘겨 종전 그대로.
- `MobileHomePage` — strip 배너를 midBanner 자리(첫 섹션 뒤)로, `shortsAfter={1}`.
- 서버 첫 화면(`home-first-screen.ts`) — 제목 줄 없이 카드, 배너는 섹션 **뒤**(화면과 같은 순서 — 안 그러면 마운트 때 튄다).
- '전국'(지역·위치 없음) → 서울 그림(`regionHeroFor` 의 `NATIONAL_HERO`). 전국 전용 그림이 오면 그 한 줄만 바꾼다.

- ⚠️ 남은 것: 배너 사진을 응답 헤더로 먼저 받게 하는 처리(`homeLcpImage`)는 그대로다 — 배너가 첫 화면 아래로 내려가 이제 카드 사진과 회선을 나눈다. 라이브 LCP 를 재 보고 필요하면 뺀다.
