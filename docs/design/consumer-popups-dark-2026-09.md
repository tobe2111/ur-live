## 대표 결정 (2026-09-02 — *"option A로 하고, 장바구니 PC버전도 확인이 필요하고, 이용권인데 배송비 표시는 필요없는 것 같아"*)
1. **토스트 = A안(상단 중앙)** 확정. Option B(하단 스낵바) 아트보드는 캔버스에서 제거.
2. **장바구니 PC**: 코드 점검 결과 헤더·전체선택 줄만 448px(`max-w-md`) 이고 본문은 1020px 이라 닫기 버튼·제목이 본문과 다른 축에 섰다 → 같은 폭으로. 셀러 묶음도 요약 카드처럼 모서리 16 + 들림(`lg:`). 시안에 PC 1440 두 장 추가.
3. **이용권은 배송 표시 0**: 09-01 #1294 가 "수령 · 매장에서 사용 (배송 없음)" 으로 바꿔 두었던 줄도 배송 이야기라 **줄 자체를 그리지 않는다**(요약의 배송비 줄은 #1294 에서 이미 제거). 교환권(휴대폰 발송)은 받는 곳이 있으니 "휴대폰 즉시 발송" 으로 남기되 "(무료)" 는 뺐다.
