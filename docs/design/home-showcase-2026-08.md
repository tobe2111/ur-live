## 🚫 대표 확정 제약 두 가지 (이 설계의 뼈대)

1. **"배너를 올리지 않으면 배너는 아예 메인에서 보이지 않도록"**
   → 히어로·중간·와이드 **전부** 데이터가 없으면 `null` 을 반환한다. 회색 플레이스홀더도,
   빈 자리도 없다. 같은 이유로 **상품이 0건인 섹션은 서버가 목록에서 빼고 내려준다** —
   제목만 남은 빈 줄은 "빈손을 광고"하는 것이다.
2. **"이전으로 돌아갈 수도 있게끔"**
   → `HOME_SHOWCASE_ENABLED`(`src/shared/feature-flags.ts`) 하나로 전부 꺼진다.
   OFF 면 `PcHomePage` 는 2026-07-19 확정 구조 그대로다.

## 데이터 모델

### 배너 — `banners` (기존 테이블에 2컬럼 추가)

| 컬럼 | 값 | 왜 |
|---|---|---|
| `banner_type` | `hero` \| `inline` \| `wide` | 배너 행이 **자기 자리를 스스로 안다** → 홈이 조회 한 번으로 배치 결정 |
| `video_url` | URL 또는 NULL | ④의 "영상으로도 되게끔" |

- 기본값은 **`inline`**. 이 컬럼이 생기기 전 등록된 배너는 NULL 인데, 그걸 히어로로 승격시키면
  옛 배너가 갑자기 홈 최상단을 덮는다. 조회도 `COALESCE(banner_type, 'inline')` 으로 읽어
  **옛 배너가 필터에서 조용히 사라지지 않게** 한다.
- 영상 URL 도 이미지와 **같은 URL 검증**(`validateImageUrl` — http/https + 사설 IP 차단)을 태운다.
  어드민 입력이라도 그대로 `<video src>` 가 되기 때문.

### 섹션 — `homepage_sections` (기존 테이블에 4컬럼 추가)

| 컬럼 | 값 |
|---|---|
| `source` | `manual`(기본, 기존 동작) \| `popular` \| `deadline` \| `newest` \| `category` |
| `source_value` | `source='category'` 일 때의 카테고리 |
| `limit_count` | 한 줄 상품 수(기본 4, 최대 12) |
| `more_href` | "더보기" 링크(내부 경로만 — `safeInternalPath`) |

**왜 규칙(질의)을 넣었나**: 시안의 "지금 인기 / 오늘 마감 임박"은 목록이 아니라 **질의**다.
수동 큐레이션으로 만들면 어드민이 매일 손봐야 하고, 안 손보는 순간 홈 최상단이 낡은 채로
방치된다. 규칙은 상품이 들고 나는 대로 저절로 맞는다.
`manual` 은 **그대로 기본값**이라 기존 섹션은 동작이 변하지 않는다.

## 상품 선정 조건은 홈 피드와 **같다**

`section-rules.ts` 의 WHERE 는 `group-buy-public` GET /products 를 그대로 따른다:
`category ∈ VOUCHER_CATEGORIES · is_active=1 · group_buy_status='active' · 도매 원본 제외`
\+ **본진 몰 격리**(`mainScopeFor`) + 데모 후순위(`demoSlugSql`).

다른 조건을 쓰면 "홈엔 있는데 섹션엔 없다"가 생기고 그건 사용자에게 버그로 보인다.
몰 격리는 2026-08-03 지역 집계에서 빠뜨렸다가 `sitemap-mall-scope` 가 잡았다 —
**소비자 집계 쿼리의 기본값으로 생각할 것.**

## ⚠️ 카드 링크는 `getProductFlow` SSOT 로만

교환권(딜 결제, `/vouchers/:id`)과 이용권(카드 결제, `/group-buy/:id`)은 상세 경로가 다르고,
**카테고리 이름으로 찍으면 틀린다**(`meal_voucher` 인데 카드 결제인 경우가 정상).
그래서 규칙/수동 양쪽 SELECT 모두 `deal_only`·`group_buy_status` 를 **화면에 안 쓰더라도 싣는다**.
빼면 교환권이 이용권 상세로 간다. 가드: `check-payment-flow-ssot`.

"등록했는데 홈에 안 뜬다"와 "일부러 안 뜨는 것"이 화면에서 구분되지 않는다.
