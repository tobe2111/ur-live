# 사업자 확인 — 사진 대신 국세청·은행 기록으로 (2026-11-04 대표 확정)

시안: https://claude.ai/artifact/QiE7JRE9CpZHFtsh2kcKcS — 탭 "이후 페이지" ⑥·⑦·⑦-1. 서비스: 유어딜(사장님 판매 준비).

## 대표 확정 (말 그대로의 흐름)
- *"사업자등록증으로 인증하는건 이상적이라고 생각해?"* → 사진만으로는 약하다(위조·남의 등록증, 가게 주인 증명 불가).
- *"사장들의 번거롭다는 문제가 있을텐데"* · *"번거로움과 안정성 둘 다"* → 사진 단계를 대부분 없앤다.
- *"은행 예금주가 회사명일 수도 있지 않나? 다른 사람일 수도 있고?"* → 예금주 = 대표자 / 상호 / '상호(대표자)' / 법인명이면 통과,
  **가족·직원 등 다른 사람 명의 계좌는 받지 않는다.** → *"오케이 그렇게 하자."*

## 규칙
| 사장님 입력 | 자동 확인 |
|---|---|
| 사업자번호 | 국세청 상태조회(영업 중) |
| 개업일(달력 1번) | 국세청 진위확인 — 번호 + **대표자 = 은행 예금주** + 개업일 (법인은 상호 포함) |
| 정산 계좌 | 은행 예금주 조회 → 위 대조 · 사업장 주소 ↔ 등록 가게 주소 |

- 전부 맞으면 사진 없이 "확인 완료" — 어드민은 승인만(2026-06-12 결정대로 승인 버튼은 사람).
- 예금주 불일치 → "정산 계좌는 대표자나 사업자 명의만" 안내 + 다른 계좌. 공동대표·특수 사정만 사진 + 담당자 확인.
