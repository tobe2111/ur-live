# 🕵️ 무단 복제 탐지 — 무료로 가능한 것과 불가능한 것

**결론 먼저**: 복제를 *막는* 무료 수단은 사실상 없다(저장소를 private 으로 돌리는 것 외에).
*탐지*는 무료로 꽤 된다. 아래는 실제로 작동하는 방법만 남긴 것이다.

---

## 1. 고유 문자열 검색 (가장 실효성 높음)

카피된 코드는 **고유한 식별자를 그대로 들고 다닌다.** 새로 심을 필요 없이 이미 충분히 특이한
문자열이 코드베이스에 많다 — 아래를 정기적으로 검색하면 된다.

| 카나리 문자열 | 왜 좋은가 |
|---|---|
| `__SSR_INITIAL_CURATOR__` | 우리가 만든 SSR 슬롯 이름. 일반 명사가 아님 |
| `ur-loader-breathe` / `ur-loader-sweep` | 자체 로더 CSS 클래스 |
| `product_supply_meta` | 사이드테이블 명칭 |
| `check-loader-continuity` | 자체 가드 스크립트명 |
| `DEAL_CATEGORY_ALIAS` · `SHOPPING_TAB_HIDDEN` | 자체 상수명 |
| `유어딜` · `유통스타트` · `딜포인트` | 브랜드·조어 |

**검색처** (전부 무료):

```
# GitHub 전체 코드 검색 — 다른 레포로 복붙된 경우
https://github.com/search?q=%22__SSR_INITIAL_CURATOR__%22&type=code
   ※ 로그인 필요. public 저장소만 검색된다(private 카피는 안 잡힌다).

# 구글/빙/네이버 — 배포된 카피 사이트
"ur-loader-breathe" -site:github.com
"__SSR_INITIAL_CURATOR__"
"딜포인트" "링크샵" -urdeal.kr -ur-team.com
```

> 💡 **새 카나리를 심을 때**: 무해하고 검색 가능한 고유 토큰(예: 주석 한 줄의 UUID)을 넣는다.
> 다만 유지보수 노이즈가 생기므로, 위처럼 **이미 존재하는 자연 카나리**로 충분한 경우가 대부분이다.

## 2. GitHub Fork 목록

저장소 → **Insights → Forks**. public 인 동안 fork 는 자유이지만 **누가 했는지는 보인다.**
LICENSE 는 fork 자체를 막지 못하고(GitHub 약관상 public 저장소의 기본 동작), *사용·배포* 를 금지한다.

## 3. 런타임 신호 — 카피 사이트가 우리 인프라를 부른다

복제자가 코드를 그대로 배포하면 하드코딩된 우리 자산을 그대로 호출하는 경우가 흔하다:
`live.ur-team.com/api/*` · `media.ur-team.com`(R2) · `/cdn-cgi/image/*`.

- Cloudflare 대시보드 → Analytics 에서 **낯선 Referer / 예상 밖 트래픽 급증**을 확인한다.
- 이미지·API 트래픽이 우리 서비스 사용량과 어긋나게 늘면 의심 신호다.

> ⚠️ 코드로 Origin 로깅을 심는 것은 **권장하지 않는다** — 결제·API 핫패스에 부담과 위험을 더한다.
> 대시보드 관측으로 충분하고, 그게 무료다.

## 3.5 ✅ 자동화됨 — `.github/workflows/copy-watch.yml` (2026-07-28)

위 §1·§2 중 기계가 할 수 있는 부분은 **주 1회 자동 실행**된다(월요일 09:20 KST).

| 검사 | 자동 | 비고 |
|---|---|---|
| 새 fork 감지 | ✅ | 기본 `GITHUB_TOKEN` 으로 동작 — 추가 설정 불필요 |
| 카나리 문자열 코드검색 | ⚠️ 조건부 | 저장소 시크릿 **`COPY_WATCH_TOKEN`**(public repo 읽기 PAT)이 있을 때만. 없으면 조용히 생략하고 fork 감시만 수행 |
| Cloudflare 트래픽 이상치 | ❌ | 대시보드 수동 확인(§3) |

**발견될 때만 이슈**를 만든다(라벨 `copy-watch`, 열려 있으면 코멘트로 누적). 조용한 주엔 아무 것도 안 남긴다.

🔔 **토큰이 죽으면 알린다** — 코드검색이 **한 건도 성공 못 하고 인증 오류(401/403)** 면 "토큰 교체 필요" 이슈를 만든다.
안 그러면 코드검색만 조용히 멈추고 fork 감시는 계속 성공해서 **아무도 모른다**(유어애즈 자동정비 무음 정지 #793 과 같은 클래스).
rate limit(429·secondary)은 일시적이라 알리지 않는다 — 오탐이 쌓이면 알림 자체를 무시하게 된다.
비용 월 4분. 수동 실행은 Actions 탭 → `Copy Watch` → Run workflow.

> 코드검색을 켜려면: GitHub → Settings → Developer settings → Personal access tokens 에서
> **public 저장소 읽기만** 가능한 fine-grained PAT 발급 → 레포 Secrets 에 `COPY_WATCH_TOKEN` 으로 등록.
> ⚠️ 권한을 넓게 주지 말 것 — 이 토큰이 새면 그 권한 그대로 유출된다(2026-07-28 CF 토큰 사고와 같은 클래스).

## 4. 정기 점검 (분기 1회, 10분)

1. §1 의 검색 쿼리 3~4개 실행
2. Insights → Forks 훑기
3. Cloudflare Analytics 에서 Referer/트래픽 이상치 확인
4. 발견 시 → 증거 보존(스크린샷·URL·날짜) → LICENSE 근거로 GitHub DMCA 또는 호스팅사 신고

## 한계 (솔직하게)

- **탐지는 사후다.** 이미 복제된 뒤에야 알 수 있다.
- **private 카피는 안 잡힌다.** GitHub 코드 검색은 public 만 본다.
- **프론트엔드는 원래 공개된다.** 저장소를 잠가도 브라우저가 받는 JS/CSS 는 누구나 본다 —
  지킬 가치가 있는 것은 서버(워커) 로직과 데이터이고, 그건 이미 노출되지 않는다.
- **법적 조치는 비용이 든다.** 탐지 자체보다 그 다음이 비싸다. LICENSE 는 그때의 근거일 뿐이다.
- **코드는 해자가 아니다.** 복제자에게 어려운 것은 코드가 아니라 입점 매장, 제조사 계약,
  상권·파트너 데이터, 정산 신뢰다. 방어 노력의 우선순위를 여기에 두는 편이 현실적이다.
