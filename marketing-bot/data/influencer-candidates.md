# 인플루언서 후보 (매주 자동 갱신)

발송·경품·비용은 대표 승인 뒤에만 진행한다. 이 파일에는 후보와 DM 초안만 쌓인다.

## 매주 하는 일
1. 후보 찾기: 유어애즈 인플루언서 DB(읽기 전용) + 스레드·인스타 검색(계정 연결 후)
2. 대상: 식당·뷰티·숙소·동네 생활 카테고리의 소형 계정 (팔로워 1천~3만)
3. 점수(100점)
   - 참여율 40: 최근 게시물 평균 반응 / 팔로워
   - 카테고리 적합 30: 유어딜 이용권 카테고리와 겹치는 정도
   - 지역 적합 20: 실제 판매 중인 매장 지역(현재 서울 마포·서초 등)과 겹치는가
   - 팔로워 규모 10: 소형일수록 가산
4. 상위 10명과 DM 초안을 아래 표에 추가하고, 승인 요청을 올린다.
